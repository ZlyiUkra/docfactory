# Плани вивчення: єдиний макет, живі дані, кластер, крипта

## Узгоджена пропозиція

Три плани вивчення — React, NestJS і Next.js — стають однією родиною з однаковим макетом: спільний розділ
«Порядок трьох планів» (етапи по черзі, скільки днів, що виходить наприкінці), розділ «З чого почати», блоки
всередині довгих фаз. Наскрізний проєкт отримує модуль «список монет» із живими цінами біржі через WebSocket:
спершу SPA слухає біржу напряму, потім ціни йдуть через власний gateway NestJS, потім — у Next.js. Кожен план
закінчує свою частину викотом подів у один кластер k3s на безкоштовній машині Oracle Cloud; план Next.js
завершується фазою про Kubernetes глибше й демо для клієнта. Для тих, хто хоче розібратися в крипті, є
факультатив у трьох блоках: свічки, книга заявок, гаманець, вхід гаманцем, власний токен на локальному ланцюгу.

## Межі та обмеження

- Модель токена не змінюється; API живе під префіксом `/api`, кука refresh — `Path=/api/auth/refresh`.
- Факти про хостинг, біржі й версії — на 02.10.2026, із позначкою, що безкоштовні тарифи змінюються.
- Документації Kubernetes, Docker, бірж і блокчейну в корпусах немає — посилання позначені «поза корпусом».

## Зауваження, що вціліли

- [підтверджено] Шляхи між планами розходились: перевірки стану під префіксом, `/auth/refresh`, квиток і шлях
  socket.io (nitpicker, best-practices).
- [підтверджено] Маршрут NestJS без `sectionName: https` ламав перенаправлення на HTTPS (nitpicker).
- [підтверджено] sslip.io поза Public Suffix List — усі його імена один сайт; для демо — власний домен або
  DuckDNS (security).
- [підтверджено] Один секрет на базу, бекап і API, застосунок суперкористувачем бази (security).
- [підтверджено] CI з повним адміном кластера (security); доступ через тунель SSH із обмеженим ключем.
- [підтверджено] Бекапи без шифрування поруч із репозиторієм (security).
- [підтверджено] Затримка вебсокетів міряна двома годинниками (performance).
- [підтверджено] Машину Oracle заберуть за бездіяльність між планами — інструкція відновлення й запасний k3d
  (pragmatist).
- [підтверджено] Job міграцій у базі Kustomize не перевикочується (nitpicker); таймаути Traefik без власника
  (nitpicker, best-practices); короткі шляхи рвали залежності (best-practices).

## Позначене допитувачем

- [слабке] Прапорці cert-manager «з пам'яті» (pragmatist) — замінено перевіреними з документації.
- [слабке] «PAYG рятує від повернення машини» (pragmatist) — документація винятку не дає, прибрано.
- [слабке] «arm64 у WSL падає без binfmt» (performance) — понижено до поради на випадок помилки.
- [слабке] «symbol із SSE змінює підписку біржі» (security) — понижено; лишилися схема й стеля з'єднань.
- [суперечить security] SOPS проти секретів GitHub (pragmatist) — лишили SOPS, ключ поза репозиторієм.
- [суперечить security] Порт 22 лише з однієї адреси проти раннерів GitHub (nitpicker) — 22 відкритий, вхід
  лише ключем, ключ CI обмежений тунелем до кластера.
