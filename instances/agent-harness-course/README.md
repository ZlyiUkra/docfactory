# agent-harness-course — примірник фабрики docfactory

Захищений MCP-сервер для вивчення відкритого курсу Agent Harness Course
([justxor/agent-harness-course](https://github.com/justxor/agent-harness-course)): як побудувати **харнес**, тобто код
навколо моделі, що робить її агентом, — цикл, інструменти, контекст, пам'ять, субагенти, безпеку, evals (замір якості
агента). Поруч лежить проєкт, який курс розбирає в модулі 8, і сім статей, які курс радить прочитати. Код спільний і
лежить у `../../engine/`, `../../server/` та `../../common/`; ця тека тримає самі дані домену. Загальний устрій
фабрики — у [../../README.md](../../README.md).

План вивчення з практикою за модулями — у [LEARNING.md](LEARNING.md).

## Навіщо

Сервер — довідка під час проходження курсу й написання власного агента: «коли цикл зупиняється», «чому компакція не
може різати на результаті інструмента», «що вимагає чек-лист модуля 6», «як `select_cutoff` вибирає межу», «як те саме
зроблено в LearnHarness». Відповідь будується з уривків курсу, а не з пам'яті моделі, і кожен уривок має адресу файла
чи сторінки.

Промпт сервера вмикає й **режим наставника**: коли людина працює над практикою модуля чи над своїм агентом, він не
видає готового розв'язку без прохання, а називає модуль і функцію та ставить наступне запитання. Коли просять пояснити
механізм, пояснює повністю.

**Лекції й розбір читання.** Для кожного модуля є лекція в теці [lectures/](lectures/), яка пояснює тему з нуля, і розбір у
теці [reading/](reading/), який пояснює кожен текст курсу, статтю й файл коду: розділ за розділом і функція за функцією. Їх
написано для цього плану власними словами. У пошук примірника вони не входять, бо корпус містить лише оригінали.

## Який запит писати

Текст курсу російський, усе інше англійське. Модель векторів (`bge-small`) розуміє лише англійську, а запит без
жодного латинського слова шукається лише по словах (поле `cyrillic_words`). Тому:

- для тексту курсу запит пишемо **російською**, словами курсу: «агентный цикл», «компакция», «песочница», «чек-лист
  модуля»; українські слова знаходять лише те, що пишеться однаково;
- для LearnHarness і статей — **англійською**, їхніми словами: `compaction`, `probe_done`, `lethal trifecta`;
- для коду — **точною назвою**: `select_cutoff`, `repair_dangling_tool_calls`, `compactionCutIndex`.

Те саме написано в описі інструмента `search_docs`, тож модель дотримується цього сама.

## Що не входить

Інші харнеси й фреймворки, які курс лише називає (Codex CLI, Aider, OpenHands, Goose, opencode, LangGraph,
smolagents), специфікація Model Context Protocol, курси Hugging Face і DeepLearning.AI, відео курсу. Із LearnHarness
не взято інтерфейс (`app/`, `components/`), тести (`tests/`, 3,5 МБ) і збирання застосунку. Довідник параметрів API
моделі — в окремому примірнику `anthropic-api`.

Курс не має тегів, тому закріплено коміт `0c90ce7` від 28.10.2026. LearnHarness закріплено на тезі v0.4.1 (на день
збирання збігається з `main`), 12-Factor Agents — на коміті `d20c728`. Статті беруться такими, як їх віддає сайт.

## Корпус лише локально

LearnHarness під AGPL і статті під чужим авторським правом не варто перевидавати у відкритому репозиторії. Тому
**корпус та індекс у git не потрапляють** (`corpus/` і `index/` у `.gitignore`), у git лежать лише налаштування
примірника.

**Де тексти.** Корпус в архіві від самого початку:
`~/archives/docfactory/agent-harness-course-corpus-2026-11-02.tar.gz` (252 тексти, паспорт і сховище сирого `raw/`;
перед видаленням текстів архів розпаковано окремо й звірено з диском) і копія на диску Windows
`C:\Distr\agent-harness-course-corpus-2026-11-02.tar.gz` (звірено за SHA-256). Сервер підіймається з кешу фрагментів
`index/passages.json` (лише на цій машині) і колекції Qdrant. `refresh` відтворює корпус з нуля за три хвилини, але
статті — лише в поточному стані сайтів, тож точна копія — в архіві.

**Як повернути тексти** — перед оновленням корпусу:

```
tar -xzf ~/archives/docfactory/agent-harness-course-corpus-2026-11-02.tar.gz -C instances/agent-harness-course
./df agent-harness-course smoke
```

**Як винести знову** — після оновлення, коли `vectors` і `smoke` пройшли:

```
tar -czf ~/archives/docfactory/agent-harness-course-corpus-РРРР-ММ-ДД.tar.gz -C instances/agent-harness-course corpus raw
find instances/agent-harness-course/corpus -maxdepth 1 -name '*.txt' -delete
rm -rf instances/agent-harness-course/raw
```

Тексти видаляють лише тоді, коли архів звірено з диском. Тоді ж видаляють попередній архів і виправляють назву в цьому
розділі. `check`, `refresh` і `manifest` без текстів працювати не можуть; `smoke` пропускає їхні перевірки з позначкою
«корпус в архіві». **На іншій машині** кешу немає: тексти повертають з архіву, далі `vectors`.

## Як запустити

```
./df agent-harness-course serve
```

Порт `8942`, сервер `agent-harness-course-docs`, адреса `http://127.0.0.1:8942/mcp`, інструменти `search_docs` і
`read_section`. Запис у клієнті MCP:

```
claude mcp add --transport http --scope user agent-harness-course-docs http://127.0.0.1:8942/mcp
```

Приклад питання власному агенту фабрики:

```
./df agent-harness-course ask "Why must compaction never cut on a tool result?"
```
