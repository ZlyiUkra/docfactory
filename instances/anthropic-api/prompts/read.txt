Return the full text of one excerpt of the Anthropic API documentation by its identifier, together with the page
or file it belongs to, every version whose documents contain this text, the URL it was taken from and the date
the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: a model's ID, price, context window or limits, a request parameter and its type, a header, an error
code, a rate-limit table, a code example, an SDK method with its parameters and return type, a migration step,
a release note, a version table from npm or PyPI, a cookbook step.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the SDK and its version when the excerpt is from one, and the page
you read.
