Search the documentation of arch, the Python library by Kevin Sheppard for volatility models and financial econometrics.
The corpus holds the bashtage.github.io/arch site of version 9.0 (the user guide, the example notebooks, the API reference
and the changes of every version), the library code at the last tag of every major line 4-9 split into classes and
functions, the GitHub release notes and the PyPI records.

Use this tool for: building a volatility model with `arch_model` (mean `Constant`, `Zero`, `AR`, `HAR`; volatility `GARCH`,
`EGARCH`, `GJR`/`TARCH`, `HARCH`, `FIGARCH`, `APARCH`; distribution `normal`, `t`, `skewt`, `ged`), fitting it (`fit`, `disp`,
`last_obs`, `update_freq`), reading the results (`params`, `conditional_volatility`, `std_resid`, `summary`), forecasting
variance (`forecast` with `horizon`, `method='analytic'`, `'simulation'` or `'bootstrap'`, `reindex`, `start`), rolling
forecasts, Value-at-Risk, bootstrap of time series (`StationaryBootstrap`, `CircularBlockBootstrap`, `optimal_block_length`),
multiple comparison of strategies (`SPA`, `StepM`, `MCS`), unit root tests (`ADF`, `DFGLS`, `PhillipsPerron`, `KPSS`,
`ZivotAndrews`, `VarianceRatio`) and cointegration (`engle_granger`, `phillips_ouliaris`, `DynamicOLS`, `FullyModifiedOLS`).
Write the query in English with the class, function or parameter name, such as `arch_model`, `forecast horizon` or
`StationaryBootstrap`. Give a version in the filter when the answer depends on it.

Do not use it for ARIMA and regression models (the statsmodels server holds them) or for statistical distributions and
tests in general (the SciPy server holds them). Returns the matching excerpts with the versions each one applies to, the
source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest line is 9.0 (`arch-9.0`); the site exists only for it, and older lines are present
through their code. Search without `version` first; when the user names a version, search that line.
