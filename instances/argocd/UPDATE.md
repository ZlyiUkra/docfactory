# Оновлення корпусу argocd

Сайт і README беруться з закріплених комітів: джерела `argocd-docs`, `argocd-chart`, `image-updater-docs` і `avp-docs`
тримають у полі `tags` коміт останнього тегу кожної мінорної (`vX.Y.Z` Argo CD, Image Updater і argocd-vault-plugin,
`argo-cd-X.Y.Z` чарту в argoproj/argo-helm). Журнал змін і релізи GitHub беруться щоразу заново.

Правило: **нічого не видаляється.** Ані `refresh`, ані `vectors`, ані `manifest` нічого не стирають самі.

**Спершу — повернути тексти.** Корпус примірника в архіві: у `corpus/` лежить лише паспорт, а `check`, `refresh` і
`manifest` працюють із файлами. Перед роботою нижче тексти розпаковують, а після неї — пакують і виносять знову;
обидві дії описані в [README, розділ «Архівний режим»](README.md#архівний-режим-сервер-без-корпусу).

**Нова версія.** Новий патч наявної мінорної — замінити в полі `tags` потрібного джерела коміт і версію її рядка; нова
мінорна — новий рядок нагорі `tags` (від найновішого). Версії чарту пишуться з префіксом `chart-`, Image Updater —
`image-updater-`, argocd-vault-plugin — `avp-`. Коміт тегу дає `git ls-remote --tags https://github.com/argoproj/argo-cd`
(рядок `^{}` — коміт анотованого тегу; так само для argoproj/argo-helm і двох репозиторіїв argoproj-labs).

```
./df argocd check                 # чи змінилося щось нагорі за джерелом
./df argocd refresh               # повне перезавантаження
./df argocd manifest
./df argocd vectors
./df argocd smoke
# Ctrl+C у терміналі з serve, і знову: ./df argocd serve
```

Якщо змінилися підтримувані мінорні (на 26.10.2026 — 3.5, 3.4 і 3.3, найновіша 3.5.6) чи лінія чарту (chart-9), — у
`prompts/search.txt` (абзац «Which version to search first») і `prompts/agent.txt` замінити лінії й числа.

Якщо `smoke` скаржиться на число фрагментів — корпус підріс; нове число записують у `checks.json` полем
`expected_passages`, а в `expected_note` — коли й чому його знято.

## Уточнення відповідей після оновлення

Після кожного оновлення корпусу — цикл із [кроку 7 загального довідника](../../UPDATE.md#крок-7--відновити-уточнення-відповідей):
`./df argocd quality --show`, порівняння обох десяток з попереднім результатом, розбір промахів, правка промпту,
знову замір. Останній результат — у README, розділ «Скільки цього».
