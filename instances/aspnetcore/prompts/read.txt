Return the full text of one excerpt of the ASP.NET documentation by its identifier, together with the page or
file it belongs to, every version whose documents contain this text, the URL it was taken from and the date
the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: a code sample of Program.cs, a controller, a Razor component or a configuration file
(appsettings.json, web.config, launchSettings.json), a step of a tutorial, a type or member of the API
reference with its parameters, return value and exceptions, a breaking change with its recommended action, a
row of an api-diff, a package version and its dependencies, a release note.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the version (or say the page has no version) and the page you read.
