# Missing params property on getStaticPaths route.
# джерело: https://github.com/withastro/docs/blob/931797f45707d05d2cb927141beed3f3e79752a7/src/pages/en/reference/errors/get-static-paths-expected-params.md
# отримано: 2026-09-21
# версія: 1.7

> **GetStaticPathsExpectedParams**: Missing or empty required `params` property on `getStaticPaths` route. (E03013)

## What went wrong?

Every route specified by `getStaticPaths` require a `params` property specifying the path parameters needed to match the route.

For instance, the following code:
```astro
---
export async function getStaticPaths() {
	return [
		{ params: { id: '1' } }
	];
}
---
```
Will create the following route: `site.com/blog/1`.
