# Invalid glob pattern.
# джерело: https://github.com/withastro/docs/blob/931797f45707d05d2cb927141beed3f3e79752a7/src/pages/en/reference/errors/invalid-glob.md
# отримано: 2026-09-21
# версія: 1.7

> **InvalidGlob**: Invalid glob pattern: `GLOB_PATTERN`. Glob patterns must start with './', '../' or '/'. (E04002)

## What went wrong?

Astro encountered an invalid glob pattern. This is often caused by the glob pattern not being a valid file path.
