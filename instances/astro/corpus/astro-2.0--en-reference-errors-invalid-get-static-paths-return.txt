# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/9d4bd688365a562ccf013310d8840f3271c232d9/src/pages/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 2.0

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE` (E03011)

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
