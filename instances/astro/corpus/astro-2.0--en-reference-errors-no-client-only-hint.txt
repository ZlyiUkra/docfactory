# Missing hint on client:only directive.
# джерело: https://github.com/withastro/docs/blob/9d4bd688365a562ccf013310d8840f3271c232d9/src/pages/en/reference/errors/no-client-only-hint.mdx
# отримано: 2026-09-21
# версія: 2.0

> **NoClientOnlyHint**: Unable to render `COMPONENT_NAME`. When using the `client:only` hydration strategy, Astro needs a hint to use the correct renderer. (E03009)

## What went wrong?

`client:only` components are not run on the server, as such Astro does not know (and cannot guess) which renderer to use and require a hint. Like such:

```astro
	<SomeReactComponent client:only="react" />
```
