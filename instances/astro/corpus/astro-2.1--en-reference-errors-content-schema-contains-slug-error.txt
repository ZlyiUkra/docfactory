# Content Schema should not contain slug.
# джерело: https://github.com/withastro/docs/blob/cf19e2935aa5e2974da0f12e53d1d93a3f09cdaf/src/content/docs/en/reference/errors/content-schema-contains-slug-error.mdx
# отримано: 2026-09-21
# версія: 2.1

> A content collection schema should not contain `slug` since it is reserved for slug generation. Remove this from your `COLLECTION_NAME` collection schema. (E09003)

## What went wrong?

A content collection schema should not contain the `slug` field. This is reserved by Astro for generating entry slugs. Remove the `slug` field from your schema, or choose a different name.
