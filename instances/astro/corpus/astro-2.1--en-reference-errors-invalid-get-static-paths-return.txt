# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/cf19e2935aa5e2974da0f12e53d1d93a3f09cdaf/src/content/docs/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 2.1

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE` (E03011)

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
