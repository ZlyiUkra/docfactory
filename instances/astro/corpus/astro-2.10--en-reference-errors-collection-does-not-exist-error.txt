# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/863c3e419f91265fab81cb7fe4b2436b8a0746a2/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 2.10

> A collection queried via `getCollection()` does not exist.

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
