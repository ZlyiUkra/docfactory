# Unsupported image format
# джерело: https://github.com/withastro/docs/blob/1a6c7324251164c3dbfad6b08c1537d55ddd0431/src/content/docs/en/reference/errors/unsupported-image-format.mdx
# отримано: 2026-09-21
# версія: 2.3

> **UnsupportedImageFormat**: Received unsupported format `FORMAT` from `IMAGE_PATH`. Currently only SUPPORTED_FORMATS.JOIN(', ') are supported for optimization. (E03025)

## What went wrong?

The built-in image services do not currently support optimizing all image formats.

For unsupported formats such as SVGs and GIFs, you may be able to use an `img` tag directly:
```astro
---
---

<img src={rocket.src} width={rocket.width} height={rocket.height} alt="A rocketship in space." />
```
