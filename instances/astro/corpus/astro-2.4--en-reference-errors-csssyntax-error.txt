# CSS Syntax Error.
# джерело: https://github.com/withastro/docs/blob/23b619c714bc7875ee48cd016017dd38720d9369/src/content/docs/en/reference/errors/csssyntax-error.mdx
# отримано: 2026-09-21
# версія: 2.4

> **Example error messages:**
CSSSyntaxError: Missed semicolon
CSSSyntaxError: Unclosed string (E05001)

## What went wrong?

Astro encountered an error while parsing your CSS, due to a syntax error. This is often caused by a missing semicolon.
