# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/23b619c714bc7875ee48cd016017dd38720d9369/src/content/docs/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 2.4

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE` (E03011)

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
