# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/ad666cb07cb3a95e34e4567a10b5f19b138feb8f/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 2.6

> A collection queried via `getCollection()` does not exist. (E09004)

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
