# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/ad666cb07cb3a95e34e4567a10b5f19b138feb8f/src/content/docs/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 2.6

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE` (E03011)

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
