# The middleware returned something that is not a Response object.

# отримано: 2026-09-21
# версія: 2.6

> **MiddlewareNotAResponse**: Any data returned from middleware must be a valid `Response` object. (E03032)

## What went wrong?

Thrown in development mode when middleware returns something that is not a `Response` object.

For example:
```ts
export const onRequest = defineMiddleware(() => {
  return "string"
});
```
