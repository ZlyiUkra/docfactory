# Missing value for client:media directive.
# джерело: https://github.com/withastro/docs/blob/ad666cb07cb3a95e34e4567a10b5f19b138feb8f/src/content/docs/en/reference/errors/missing-media-query-directive.mdx
# отримано: 2026-09-21
# версія: 2.6

> **MissingMediaQueryDirective**: Media query not provided for `client:media` directive. A media query similar to `client:media="(max-width: 600px)"` must be provided (E03006)

## What went wrong?

A media query parameter is required when using the `client:media` directive.

```astro
<Counter client:media="(max-width: 640px)" />
```
