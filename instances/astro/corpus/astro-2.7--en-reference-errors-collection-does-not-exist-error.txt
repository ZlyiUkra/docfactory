# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/1d482eea68ff0d1de01733e32e4104de96ad55cb/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 2.7

> A collection queried via `getCollection()` does not exist.

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
