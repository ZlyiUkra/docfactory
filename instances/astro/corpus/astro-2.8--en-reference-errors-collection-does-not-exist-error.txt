# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/c7d147af07b68502d8b42c664452b672cd85be1d/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 2.8

> A collection queried via `getCollection()` does not exist.

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
