# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/22b9c4588ccaabfc8c0e4bf2c17e1880356d0a5e/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 2.9

> A collection queried via `getCollection()` does not exist.

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
