# Collection does not exist
# джерело: https://github.com/withastro/docs/blob/80f55513d7892d70c189bc8196b2e37cdca34bd4/src/content/docs/en/reference/errors/collection-does-not-exist-error.mdx
# отримано: 2026-09-21
# версія: 3.0

> A collection queried via `getCollection()` does not exist.

## What went wrong?

When querying a collection, ensure a collection directory with the requested name exists under `src/content/`.
