# The middleware didn't return a response or call next.
# джерело: https://github.com/withastro/docs/blob/80f55513d7892d70c189bc8196b2e37cdca34bd4/src/content/docs/en/reference/errors/middleware-no-data-or-next-called.mdx
# отримано: 2026-09-21
# версія: 3.0

> **MiddlewareNoDataOrNextCalled**: The middleware needs to either return a `Response` object or call the `next` function.

## What went wrong?

Thrown when the middleware does not return any data or call the `next` function.

For example:
```ts
export const onRequest = defineMiddleware((context, _) => {
	// doesn't return anything or call `next`
	context.locals.someData = false;
});
```
