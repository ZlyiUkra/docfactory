# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/28c3fb4f0a55f40c7f9d8c900172a33df93b3170/src/content/docs/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 3.2

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE`

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
