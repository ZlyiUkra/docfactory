# Cannot use Server-side Rendering without an adapter.
# джерело: https://github.com/withastro/docs/blob/9d31f3510b3e88be4878e452ed45060280b0b302/src/content/docs/en/reference/errors/no-adapter-installed.mdx
# отримано: 2026-09-21
# версія: 4.15

> **NoAdapterInstalled**: Cannot use `output: 'server'` or `output: 'hybrid'` without an adapter. Please install and configure the appropriate server adapter for your final deployment.

## What went wrong?

To use server-side rendering, an adapter needs to be installed so Astro knows how to generate the proper output for your targeted deployment platform.
