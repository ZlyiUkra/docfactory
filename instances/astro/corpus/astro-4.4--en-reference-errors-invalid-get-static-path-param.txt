# Invalid value returned by a getStaticPaths path.
# джерело: https://github.com/withastro/docs/blob/d8a222c5929dc6a5aca3111a4f21894c713e93e1/src/content/docs/en/reference/errors/invalid-get-static-path-param.mdx
# отримано: 2026-09-21
# версія: 4.4

> **InvalidGetStaticPathParam**: Invalid params given to `getStaticPaths` path. Expected an `object`, got `PARAM_TYPE`

## What went wrong?

The `params` property in `getStaticPaths`'s return value (an array of objects) should also be an object.

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
---
```
