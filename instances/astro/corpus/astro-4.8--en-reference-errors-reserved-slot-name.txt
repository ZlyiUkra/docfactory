# Invalid slot name.
# джерело: https://github.com/withastro/docs/blob/326d274941b1a9562d14d748579bc7ad98bb5f89/src/content/docs/en/reference/errors/reserved-slot-name.mdx
# отримано: 2026-09-21
# версія: 4.8

> **ReservedSlotName**: Unable to create a slot named `SLOT_NAME`. `SLOT_NAME` is a reserved slot name. Please update the name of this slot.

## What went wrong?

Certain words cannot be used for slot names due to being already used internally.
