# Invalid value returned by a getStaticPaths path.
# джерело: https://github.com/withastro/docs/blob/738de11b332a8cdde0946774378c3311bd29aa65/src/content/docs/en/reference/errors/invalid-get-static-path-param.mdx
# отримано: 2026-09-21
# версія: 5.1

> **InvalidGetStaticPathParam**: Invalid params given to `getStaticPaths` path. Expected an `object`, got `PARAM_TYPE`

## What went wrong?

The `params` property in `getStaticPaths`'s return value (an array of objects) should also be an object.

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
---
```
