# Invalid glob pattern.
# джерело: https://github.com/withastro/docs/blob/89393ea9cc50debb17cea1fabe75f37d35610d7a/src/content/docs/en/reference/errors/invalid-glob.mdx
# отримано: 2026-09-21
# версія: 5.18

> **InvalidGlob**: Invalid glob pattern: `GLOB_PATTERN`. Glob patterns must start with './', '../' or '/'.

## What went wrong?

Astro encountered an invalid glob pattern. This is often caused by the glob pattern not being a valid file path.
