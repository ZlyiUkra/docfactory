# отримано: 2026-09-21
# версія: 5.4

> `COLLECTION_NAME` → `ENTRY_ID` has an invalid slug. `slug` must be a string.

## What went wrong?

A collection entry has an invalid `slug`. This field is reserved for generating entry slugs, and must be a string when present.
