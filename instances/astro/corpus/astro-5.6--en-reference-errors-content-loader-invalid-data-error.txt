# Content entry is missing an ID
# джерело: https://github.com/withastro/docs/blob/9c0b8113a92a051c1b5516fda3ed4f755d5f34c9/src/content/docs/en/reference/errors/content-loader-invalid-data-error.mdx
# отримано: 2026-09-21
# версія: 5.6

> **Example error message:**
The loader for **blog** returned invalid data.
Object is missing required property "id".

## What went wrong?

The loader for a content collection returned invalid data.
Inline loaders must return an array of objects with unique ID fields or a plain object with IDs as keys and entries as values.
