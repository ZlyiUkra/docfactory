# Invalid value returned by getStaticPaths.
# джерело: https://github.com/withastro/docs/blob/9c0b8113a92a051c1b5516fda3ed4f755d5f34c9/src/content/docs/en/reference/errors/invalid-get-static-paths-return.mdx
# отримано: 2026-09-21
# версія: 5.6

> **InvalidGetStaticPathsReturn**: Invalid type returned by `getStaticPaths`. Expected an `array`, got `RETURN_TYPE`

## What went wrong?

`getStaticPaths`'s return value must be an array of objects.

```ts
export async function getStaticPaths() {
	return [ // <-- Array
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
```
