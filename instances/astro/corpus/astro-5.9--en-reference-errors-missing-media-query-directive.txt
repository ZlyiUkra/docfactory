# Missing value for client:media directive.
# джерело: https://github.com/withastro/docs/blob/b4454f083ffb8ba7c5179ccee1bda22c2df0a368/src/content/docs/en/reference/errors/missing-media-query-directive.mdx
# отримано: 2026-09-21
# версія: 5.9

> **MissingMediaQueryDirective**: Media query not provided for `client:media` directive. A media query similar to `client:media="(max-width: 600px)"` must be provided

## What went wrong?

A media query parameter is required when using the `client:media` directive.

```astro
<Counter client:media="(max-width: 640px)" />
```
