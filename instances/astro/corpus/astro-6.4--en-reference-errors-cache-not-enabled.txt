# Cache is not enabled.
# джерело: https://github.com/withastro/docs/blob/97efa7751328d87e78637b29e054d000032c2d2b/src/content/docs/en/reference/errors/cache-not-enabled.mdx
# отримано: 2026-09-21
# версія: 6.4

> `Astro.cache` is not available because the cache feature is not enabled.

## What went wrong?

Thrown when `Astro.cache` or `context.cache` is used but the cache feature has not been enabled in the Astro config.
