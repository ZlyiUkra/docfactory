# Invalid route parameter returned by getStaticPaths().
# джерело: https://github.com/withastro/docs/blob/97efa7751328d87e78637b29e054d000032c2d2b/src/content/docs/en/reference/errors/get-static-paths-invalid-route-param.mdx
# отримано: 2026-09-21
# версія: 6.4

> **GetStaticPathsInvalidRouteParam**: Invalid `getStaticPaths()` route parameter for `KEY`. Expected a string or undefined, received `VALUE_TYPE` (`VALUE`).

## What went wrong?

Since `params` are encoded into the URL, only certain types are supported as values.

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { id: '1' } } // Works
		{ params: { id: 2 } } // Does not work
		{ params: { id: false } } // Does not work
		{ params: { id: [1, 2] } } // Does not work
	];
}
---
```

In routes using rest parameters, `undefined` can be used to represent a path with no parameters passed in the URL:

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { id: '1' } } // /route/1
		{ params: { id: '2' } } // /route/2
		{ params: { id: undefined } } // /route/
	];
}
---
```
