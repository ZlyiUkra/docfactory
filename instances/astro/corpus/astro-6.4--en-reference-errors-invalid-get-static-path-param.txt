# Invalid value returned by a route from getStaticPaths().
# джерело: https://github.com/withastro/docs/blob/97efa7751328d87e78637b29e054d000032c2d2b/src/content/docs/en/reference/errors/invalid-get-static-path-param.mdx
# отримано: 2026-09-21
# версія: 6.4

> **InvalidGetStaticPathParam**: Invalid `params` value returned by a route from `getStaticPaths()`. Expected an `object`, got `PARAM_TYPE`.

## What went wrong?

The `params` property in `getStaticPaths()`'s return value (an array of objects) should also be an object.

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { slug: "blog" } },
		{ params: { slug: "about" } }
	];
}
---
```
