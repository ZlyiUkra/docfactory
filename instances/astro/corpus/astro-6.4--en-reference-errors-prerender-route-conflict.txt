# Prerendered route generates the same path as another route.
# джерело: https://github.com/withastro/docs/blob/97efa7751328d87e78637b29e054d000032c2d2b/src/content/docs/en/reference/errors/prerender-route-conflict.mdx
# отримано: 2026-09-21
# версія: 6.4

> **PrerenderRouteConflict**: Could not render `PATHNAME` from route `THIS_ROUTE` as it conflicts with higher priority route `WINNING_ROUTE`.

## What went wrong?

Two prerendered routes generate the same path, resulting in a collision.
A static path can only be generated by one route.
