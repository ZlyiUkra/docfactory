# Astro.glob() did not match any files.
# джерело: https://github.com/withastro/docs/blob/61d9e861ef0023126d542a381ac01cb334979356/src/content/docs/en/reference/errors/astro-glob-no-match.mdx
# отримано: 2026-09-21
# версія: 7.2

Deprecated:

This error was removed in Astro v6.0.0 along with the removal of `Astro.glob()`.

> **AstroGlobNoMatch**: `Astro.glob(GLOB_STR)` did not return any matching files.

## What went wrong?

`Astro.glob()` did not return any matching files. There might be a typo in the glob pattern.
