# Invalid glob pattern.
# джерело: https://github.com/withastro/docs/blob/61d9e861ef0023126d542a381ac01cb334979356/src/content/docs/en/reference/errors/invalid-glob.mdx
# отримано: 2026-09-21
# версія: 7.2

Deprecated:

This error was removed in Astro v6.0.0 along with the removal of `Astro.glob()`.

> **InvalidGlob**: Invalid glob pattern: `GLOB_PATTERN`. Glob patterns must start with './', '../' or '/'.

## What went wrong?

Astro encountered an invalid glob pattern. This is often caused by the glob pattern not being a valid file path.
