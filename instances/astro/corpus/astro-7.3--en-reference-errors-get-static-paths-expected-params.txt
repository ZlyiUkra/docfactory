# Missing params property on getStaticPaths() route.
# джерело: https://github.com/withastro/docs/blob/fc25123ddf26abd3115b8bd26c3b7800e5b53a2f/src/content/docs/en/reference/errors/get-static-paths-expected-params.mdx
# отримано: 2026-09-21
# версія: 7.3

> **GetStaticPathsExpectedParams**: Missing or empty required `params` property on `getStaticPaths()` route.

## What went wrong?

Every route specified by `getStaticPaths()` requires a `params` property specifying the path parameters needed to match the route.

For instance, the following code:
```astro
---
export async function getStaticPaths() {
	return [
		{ params: { id: '1' } }
	];
}
---
```
Will create the following route: `site.com/blog/1`.
