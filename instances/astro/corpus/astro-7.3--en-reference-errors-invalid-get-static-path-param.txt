# Invalid value returned by a route from getStaticPaths().
# джерело: https://github.com/withastro/docs/blob/fc25123ddf26abd3115b8bd26c3b7800e5b53a2f/src/content/docs/en/reference/errors/invalid-get-static-path-param.mdx
# отримано: 2026-09-21
# версія: 7.3

> **InvalidGetStaticPathParam**: Invalid `params` value returned by a route from `getStaticPaths()`. Expected an `object`, got `PARAM_TYPE`.

## What went wrong?

The `params` property in `getStaticPaths()`'s return value (an array of objects) should also be an object.

```astro
---
export async function getStaticPaths() {
	return [
		{ params: { id: "blog" } },
		{ params: { id: "about" } }
	];
}
---
```
