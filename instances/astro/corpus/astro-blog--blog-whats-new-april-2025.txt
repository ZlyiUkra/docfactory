## Tips & Tools

The latest community-built utilities and integrations to help you build with Astro. 🛠

- Astro Tanstack - Build a Single Page Application (SPA) with Astro, TanStack Router and Query.
- cfetch - An Astro integration that provides a cacheable fetch function for Astro SSR.
- Astro WordPress - Build WordPress themes using Astro.
- Nova IDE Astro extension - Provides syntax highlighting and basic autocomplete for `.astro` files for Panic's Nova IDE.
- 🌟 Starlight Fullview Mode - A minimalist plugin that collapses Starlight's sidebars and expands the main content to full width.
- Inox Tools: cut short - An Astro integration that lets you stop processing a request instantly and send back a custom response, now with a `disableStreaming` option.
- Typed Rest Routes - An Astro integration that allows for creating type-safe server endpoints.
- 🌟 Starlight scroll to top - Add a scroll to top button to your documentation website.
- Astro og - Astro dev toolbar app that previews your page on social platforms and shows its open graph data.
- Astro Google tag manager - An integration for injecting Google Tag Manager snippets into Astro projects, supporting popular web analytics tools.

... and some built *with* Astro:

- Starlight Changelog - a pretty version of Starlight's own `CHANGELOG.md`, automatically updated with each new release. Bookmark it to keep up with Starlight's changes! Built with Astro’s Starlog theme and the `astro-loader-github-releases` content loader
- Tract Stack - A no-code build your own website funnel that transforms your online presence from a static brochure into a dynamic conversation that adapts to each reader, with a dashboard to understand your user interactions. Built with Astro and Turso.
