## Tips & Tools

The latest community-built utilities and integrations to help you build with Astro. 🛠

- Starwind UI - A set of powerful, accessible components for your Astro projects styled with Tailwind CSS v4.
- Zorn Player - A video player for Astro with several customizable features.
- Accessible Astro - Everything you need to build accessible, performant, and beautiful websites with Astro.
- `astro-obsidian-starlight-notes-template` - A Starlight starter template that uses your Obsidian notes for content.
- `astro-teleport` - A lightweight Astro component for rendering content in a different part of the DOM using a Web Component.
- `astro-typesafe-routes` - An Astro integration for typesafe URL generation and routing.
- `storyblock-loader` - A community-built loader for Astro Content Layer that fetches content from Storyblok's API.
- `astro-qiita-loader` - A Qiita loader for Astro, allowing you to use Qiita posts as content collections.
- Bit - A CLI tool for scaffolding Astro + PocketBase projects.
- `static-only-collections` - Specify content collections that will only be used on static pages to reduce code built server-side and improve page performance.
- Starlight View Transitions Plugin - Add cross-document, browser-native view transitions to your Starlight site with one line in your Astro config.

... and some built *with* Astro:

- StudioCMS - A dedicated CMS for Astro DB, with a fresh beta 8 release.
- Tract Stack - A publishing platform and no-code Astro website builder.
- GitHub Activity - View the recent GitHub activity for any user in a beautiful list.
- Mayo App - A self-hostable, web-based audio streaming app.
