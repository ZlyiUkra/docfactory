### Tips & Tools

The latest community-built utilities and integrations to help you build with Astro:

- `astro-pandabox` - a lightweight Lightbox and gallery component for Astro
- Astro Embed: Baseline Status component - a component that displays browser support for a given web feature according to the Baseline project
- Astsro Embed: Bluesky post - embed a Bluesky post on your Astro site
- `astro-youtube` - a component to embed YouTube videos in your Astro site
- Inox Tools: Astro 5 / Vite 6 support - all your favorite Inox Tools are ready for the latest version of Astro
- `astro-typed-ids` - get typed ids for your Content Layer entries, matching Astro 4 behavior
- Astro Bluesky post loader - load and parse Bluesky posts, and use the data in your Astro site
- `bluesky-comments-tag`- a lightweight, customizable web component to use Bluesky for your website comments
- `starlight-contributor-list` - display a list of all contributors to your GitHub project
- `starlight-sidebar-topics-dropdown` - a Starlight plugin to add a drop down navigation to your sidebar
- `starlight-cooler-credit` - Adds a Houston-themed credit to Starlight or Astro

... and some built *with* Astro:

- Simple Image Compressor - Upload an image, set your target file size, and download the compressed version.
- 1 checkbox per day - the world's simplest to-do app
- Astro Linky - your Astro-powered URL Shortener & QR code generator
- Tract Stack - a no-code website builder and content marketing platform
