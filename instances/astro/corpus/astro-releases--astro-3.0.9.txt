### Patch Changes

-   #8351 `7d95bd9ba` Thanks @lilnasy! - Fixed a case where dynamic imports tried to preload inlined stylesheets.

```vue
    <script>
    // This will not return an optimized asset
    import Component from './Component.vue?component';
    </script>
```
