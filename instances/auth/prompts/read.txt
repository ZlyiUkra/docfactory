Return the full text of one excerpt of the Better Auth and NextAuth.js / Auth.js documentation
(Better Auth 0.0 to 1.7, NextAuth.js 1.1 to 4.24, Auth.js v5 betas and the authjs.dev API
reference) by its identifier, together with the document it belongs to, the URL it was taken
from and the date the text was fetched from that URL -- so a quotation can be checked against the
source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or when
the exact wording matters -- an option with its default, an endpoint with its body, a callback
signature, a database table or a migration step quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not page names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: name the library and its version when
it matters, keep identifiers and titles in English, use Ukrainian words for Ukrainian prose, and
name the document you read.
