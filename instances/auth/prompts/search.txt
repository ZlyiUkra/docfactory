Call this when a question is about adding sign-in, sign-up, sessions or user accounts to a
JavaScript or TypeScript application with Better Auth or with NextAuth.js / Auth.js: configuring
providers, protecting pages and API routes, reading the session on the server and on the client,
the database tables these libraries create, two-factor authentication, organizations and roles,
API keys, tokens and cookies, upgrading between versions, or moving from NextAuth.js to Better
Auth. Example query: "betterAuth emailAndPassword requireEmailVerification".

Do not call this for other authentication products (Clerk, Supabase Auth, Firebase Auth, Lucia,
Passport, Keycloak, Auth0 have no documentation here, apart from the migration guides that
mention them), for OAuth 2.0 and OpenID Connect as protocols, for password hashing or for web
security in general (the OWASP instance covers that), or for the frameworks themselves (Next.js,
NestJS, Express have their own instances): the search will return excerpts that merely mention
them, with confident-looking titles.

`version` narrows the search. Every excerpt carries the library and its version: Better Auth as
"better-auth-1.7", "better-auth-1.6" ... "better-auth-0.0"; NextAuth.js as "next-auth-4.24" ...
"next-auth-1.1"; Auth.js v5 as "next-auth-5.0.0-beta.32" ... "next-auth-5.0.0-beta.4"; the
authjs.dev API reference as "next-auth-5.0.0-beta.32". A filter takes a whole line or a minor
version: "better-auth-1" is every Better Auth 1.x, "better-auth-1.4" is 1.4 only, "next-auth-4"
is every 4.x, "next-auth-5" every beta of v5. Leave `version` empty to search both libraries.
Every excerpt comes back with `versions`: each version whose documents contain this exact text,
newest first -- text that stayed the same across versions is returned once, with all of them
listed, so the oldest version in the list says since when the text has been there.

Which version to answer for. Unless the user names a version: for Better Auth answer for 1.7 and
1.6 -- the two are downloaded almost equally -- and say so when they differ; for NextAuth.js
answer for both v5 (5.0.0-beta, the authjs.dev documentation) and v4 (4.24, next-auth.js.org),
which are downloaded equally, and keep the two apart: their configuration, imports and session
helpers differ. When the user names an older version (a client project pinned to next-auth 3.x or
better-auth 1.2), filter by it and answer for that version only, saying which version the text
belongs to.

Where the documentation lives. Better Auth pages are named by their path under the docs folder

The `search` field of the result says how the excerpts were found: "words" means the words of
