# Оновлення корпусу backtesting

Корпус живе нагорі: репозиторії `kernc/backtesting.py` і `polakowo/vectorbt` та реєстр PyPI. Теги вже вийшлих версій не
змінюються, а нова мінорна лінія потребує правки `sources.json`.

Правило: **нічого не видаляється.** Ані `refresh`, ані `manifest` нічого не видаляють. Лише `vectors` прибирає точки своєї колекції,
чиїх фрагментів у корпусі вже немає.

**Спершу — повернути тексти.** Корпус примірника в архіві, а `check`, `refresh` і `manifest` читають файли. Тому перед роботою нижче
тексти розпаковують, а після неї виносять знову: обидві дії описано в
[README, розділ «Архівний режим»](README.md#архівний-режим-сервер-без-корпусу).

```
./df backtesting refresh <id джерела>   # лише те, що змінилося
./df backtesting manifest
./df backtesting vectors
./df backtesting smoke
# Ctrl+C у терміналі з serve, і знову: ./df backtesting serve
```

## Дозбирати записи PyPI

13.11.2026 записи PyPI не склалися: pypi.org з WSL відповідав лише на половину з'єднань. Коли мережа відновиться, поверніть тексти й
виконайте:

```
./df backtesting refresh btpy-pypi vbt-pypi
./df backtesting manifest
./df backtesting vectors
./df backtesting smoke    # нове число фрагментів записати в checks.json
./df backtesting quality
```

Після цього зробіть новий архів за README і приберіть абзац «Чого ще немає» з README.

## Що міняти, коли вийшла нова лінія

- **Backtesting.py:** дописати новий тег у поле `tags` джерел `btpy-code` і `btpy-docs`, найновіший першим; у `btpy-changelog`
  замінити тег в адресі.
- **vectorbt:** дописати новий тег у `vbt-code` і `vbt-docs`.
- Релізи GitHub і PyPI підтягуються самі.

Якщо `smoke` скаржиться на число фрагментів, корпус підріс: нове число записують в `expected_passages`, а в `expected_note` — коли й
чому його знято.

## Уточнення відповідей після оновлення

Після кожного оновлення корпусу треба виконати `./df backtesting quality --show`, переглянути запити зі знаком «-» і перевірити, чи
справді відповідь змінилася. Ціль розширюють лише тоді, коли знайдена сторінка справді відповідає на запит.
