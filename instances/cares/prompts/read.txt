Return the full text of one excerpt of the c-ares documentation by its identifier, together with the page
or file it belongs to, every release whose documents contain this text, the URL it was taken from and the
date the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: a function's synopsis and return values, a channel option and its default, the release notes that
say which release fixed a vulnerability, the source of a function.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the release and the page or file you read.
