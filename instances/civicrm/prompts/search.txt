Search the documentation of CiviCRM, the open-source system for contacts, memberships, contributions, events and mailings of associations and
non-profit organisations. The corpus holds the guides of docs.civicrm.org (the user guide, the developer guide with the APIs, hooks and extensions, the
system administrator guide, the installation guide), the documentation of about a hundred extensions (GDPR, SEPA, banking, deduper, CiviRules, form
processor and others), the release notes of every version in `release-notes/` of civicrm-core and the Packagist record of `civicrm/civicrm-core`.

Use this tool for: what CiviCRM does for memberships, contributions and events, importing contacts, finding and merging duplicates, consent and GDPR,
installing on WordPress, Drupal, Joomla or Standalone, APIv4, hooks, extensions, and what changed in a version. Write the query in English with the name of
the feature or the page, such as "Find and merge duplicate contacts" or "APIv4".

Do not use it for the code of CiviCRM or for WordPress, Drupal or payment providers as their own projects: other servers hold some of them. The guides carry
no version: they describe the current release, and only the release notes show what changed in an older one. Returns the matching excerpts with the source
address and the fetch date.
