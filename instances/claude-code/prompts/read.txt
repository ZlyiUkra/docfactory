Return the full text of one excerpt of the Claude Code documentation by its identifier, together with the page or
file it belongs to, every version whose documents contain this text, the URL it was taken from and the date the
text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a settings key and its values, a permission rule, a hook event's input and output fields, an exit code, a
CLI flag, an environment variable, a SKILL.md or plugin.json field, a code or configuration example, a changelog
entry, an Agent SDK option, a claude-code-action input, a Claude Tag setting, a version table from npm or PyPI.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool accepts
comes from the `id` field of a `search_docs` result.

The text comes back in English, except the handbook's, which is Russian. Answer the user in their own language and
follow the rules of `search_docs`: names stay in English, name the version when the excerpt has one, say when the
excerpt is from the community handbook, and name the page you read.
