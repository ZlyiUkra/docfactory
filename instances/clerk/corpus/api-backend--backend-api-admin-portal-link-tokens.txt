# Backend API: Admin Portal Link Tokens
# джерело: https://clerk.com/docs/reference/backend-api
# отримано: 2026-09-25

## POST /admin_portal_link_tokens

Create an Admin Portal Link Token

Request body (application/json):

- `organization_id` `string`
- `it_contact_id` `string`
- `scopes` `array of string`
- `seconds_until_expiration` `integer`

Responses:

- `201`: 201 Created
- `400`: 400 Bad Request
- `401`: 401 Unauthorized
- `403`: 403 Forbidden
- `409`: 409 Conflict

## POST /admin_portal_link_tokens/{adminPortalLinkTokenID}/revoke

Revoke an Admin Portal Link Token

Parameters:

- `adminPortalLinkTokenID` (path, required) `string`

Request body (application/json):

- `revocation_reason` `string`

Responses:

- `200`: 200 OK
- `400`: 400 Bad Request
- `401`: 401 Unauthorized
- `403`: 403 Forbidden
- `404`: 404 Not Found
