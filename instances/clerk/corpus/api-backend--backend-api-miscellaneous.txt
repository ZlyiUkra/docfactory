# Backend API: Miscellaneous
# джерело: https://clerk.com/docs/reference/backend-api
# отримано: 2026-09-25

Various endpoints that do not belong in any particular category.

## GET /public/interstitial

Returns the markup for the interstitial page

The Clerk interstitial endpoint serves an html page that loads clerk.js in order to check the user's authentication state.
It is used by Clerk SDKs when the user's authentication state cannot be immediately determined.

Parameters:

- `frontendApi` (query) `string`: Please use `frontend_api` instead
- `frontend_api` (query) `string`: The Frontend API key of your instance
- `publishable_key` (query) `string`: The publishable key of your instance
- `proxy_url` (query) `string`: The proxy URL of your instance
- `domain` (query) `string`: The domain of your instance
- `sign_in_url` (query) `string`: The sign in URL of your instance
- `use_domain_for_script` (query) `boolean`: Whether to use the domain for the script URL

Responses:

- `200`: The interstitial page markup
- `400`: A required query parameter is missing
- `500`: An infinite redirect loop was detected
