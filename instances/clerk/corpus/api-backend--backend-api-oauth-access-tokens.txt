# Backend API: OAuth Access Tokens
# джерело: https://clerk.com/docs/reference/backend-api
# отримано: 2026-09-25

Endpoints for managing OAuth Access Tokens, which are credentials to access protected resources on behalf of a user.

## POST /oauth_applications/access_tokens/verify

Verify an OAuth Access Token

Request body (application/json):

- `access_token` `string`: The access token to verify.
- `secret` `string`: The access token to verify. This is deprecated, use `access_token` instead.

Responses:

- `200`: 200 OK
- `400`: 400 Bad Request
- `404`: 404 Not Found
