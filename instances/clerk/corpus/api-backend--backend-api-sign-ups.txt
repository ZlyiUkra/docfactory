# Backend API: Sign Ups
# джерело: https://clerk.com/docs/reference/backend-api
# отримано: 2026-09-25

Sign-up objects track the progress of a sign-up attempt and store any field collected from user input.

## GET /sign_ups/{id}

Retrieve a sign-up by ID

Retrieve the details of the sign-up with the given ID

Parameters:

- `id` (path, required) `string`: The ID of the sign-up to retrieve

Responses:

- `200`: Success
- `403`: Authorization invalid

## PATCH /sign_ups/{id}

Update a sign-up

Update the sign-up with the given ID

Parameters:

- `id` (path, required) `string`: The ID of the sign-up to update

Request body (application/json):

- `external_id` `string`: The ID of the guest attempting to sign up as used in your external systems or your previous authentication solution. This will be copied to the resulting user when the sign-up is completed.
- `custom_action` `boolean`: If true, the sign-up will be marked as a custom action.

Responses:

- `200`: Success
- `403`: Authorization invalid
