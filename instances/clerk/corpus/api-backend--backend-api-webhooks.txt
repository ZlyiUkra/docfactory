# Backend API: Webhooks
# джерело: https://clerk.com/docs/reference/backend-api
# отримано: 2026-09-25

You can configure webhooks to be notified about various events that happen on your instance.

## POST /webhooks/svix

Create a Svix app

Create a Svix app and associate it with the current instance

Responses:

- `200`: Response that contains a temporary Svix URL to access management dashboard
- `400`: Request was not successful

## DELETE /webhooks/svix

Delete a Svix app

Delete a Svix app and disassociate it from the current instance

Responses:

- `204`: Svix app was successfully deleted
- `400`: Request was not successful

## POST /webhooks/svix_url

Create a Svix Dashboard URL

Generate a new URL for accessing the Svix's management dashboard for that particular instance

Responses:

- `200`: Response that contains a temporary Svix URL to access management dashboard
- `400`: Request was not successful
