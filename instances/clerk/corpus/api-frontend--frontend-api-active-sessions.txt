# Frontend API: Active Sessions
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the sessions of the current user.

## GET /v1/me/sessions/active

Get Active Sessions

Returns all active session for user, including activity information.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns an Active Sessions array.
- `401`: Request was not successful

## POST /v1/me/sessions/{session_id}/revoke

Revoke given session

Revokes given session.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.
- `session_id` (path, required) `string`: The session ID to be revoked.

Responses:

- `200`: Returns a Session object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## GET /v1/me/sessions

Get Sessions

Get all the sessions of the current user.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns Sessions array.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
