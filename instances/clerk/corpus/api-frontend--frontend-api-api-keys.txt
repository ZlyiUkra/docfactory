# Frontend API: API Keys
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Endpoints for managing API Keys

## GET /api_keys

Get API Keys

Parameters:

- `type` (query) `string`
- `subject` (query, required) `string`
- `include_invalid` (query) `string, one of true, false`
- `limit` (query) `number`
- `offset` (query) `number`
- `query` (query) `string`

Responses:

- `200`: 200 OK
- `400`: 400 Bad Request
- `404`: 404 Not Found

## POST /api_keys

Create an API Key

Request body (application/json):

- `type` `string`
- `name` `string`, required
- `description` `string`
- `subject` `string`, required
- `seconds_until_expiration` `number`

Responses:

- `201`: 201 Created
- `400`: 400 Bad Request
- `409`: 409 Conflict

## PATCH /api_keys/{apiKeyID}

Update an API Key

Parameters:

- `apiKeyID` (path, required) `string`

Request body (application/json):

- `description` `string`

Responses:

- `200`: 200 OK
- `400`: 400 Bad Request
- `404`: 404 Not Found

## POST /api_keys/{apiKeyID}/revoke

Revoke an API Key

Parameters:

- `apiKeyID` (path, required) `string`

Request body (application/json):

- `revocation_reason` `string`

Responses:

- `200`: 200 OK
- `400`: 400 Bad Request
- `404`: 404 Not Found
