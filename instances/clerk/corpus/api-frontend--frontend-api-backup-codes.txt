# Frontend API: Backup Codes
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the two factor authentication backup codes of the current user.

## POST /v1/me/backup_codes

Create Backup Codes

Create two factor authentication backup codes for the current user.
A two factor authentication method must be enabled for the environment. Otherwise the endpoint will return an error.

Responses:

- `200`: Returns the response for Session wrapped Backup code object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `500`: Request was not successful
