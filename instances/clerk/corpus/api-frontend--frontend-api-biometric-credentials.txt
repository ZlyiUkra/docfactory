# Frontend API: Biometric Credentials
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with native biometric credentials of the logged in user.

## POST /v1/client/biometric_credentials/validate

Validate Biometric Sign-In Credential

Validates that a local biometric credential can be used by the current native client.

Request body (application/x-www-form-urlencoded):

- `trusted_device_id` `string`, required: The biometric credential ID stored by the native SDK.

Responses:

- `200`: Returns whether the biometric credential is valid for the current client.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## GET /v1/me/biometric_credentials

List Biometric Credentials

Retrieve active biometric credentials associated with the current user.

Responses:

- `200`: Returns the current user's biometric credentials.
- `401`: Request was not successful
- `403`: Request was not successful

## POST /v1/me/biometric_credentials/prepare

Prepare Biometric Credential Enrollment

Issues a one-time challenge for enrolling a native biometric credential.

Request body (application/x-www-form-urlencoded):

- `platform` `string, one of ios, android`, required
- `app_identifier` `string`, required: Bundle identifier or package name for the native application.
- `name` `string`: Optional user-facing credential name.
- `algorithm` `string, one of ES256`, required
- `public_key_jwk` `string`, required: Canonical public JWK for the device-bound P-256 key.

Responses:

- `200`: Returns the enrollment challenge that must be signed by the native private key.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## POST /v1/me/biometric_credentials/attempt

Attempt Biometric Credential Enrollment

Verifies a signed enrollment challenge and creates a biometric credential.

Request body (application/x-www-form-urlencoded):

- `platform` `string, one of ios, android`, required
- `app_identifier` `string`, required: Bundle identifier or package name for the native application.
- `name` `string`: Optional user-facing credential name.
- `algorithm` `string, one of ES256`, required
- `public_key_jwk` `string`, required: Canonical public JWK for the device-bound P-256 key.
- `client_data` `string`, required: Canonical JSON challenge payload returned from prepare.
- `signature` `string`, required: Base64url raw ECDSA P-256 signature over `client_data`.

Responses:

- `200`: Returns the created biometric credential.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## DELETE /v1/me/biometric_credentials/{biometric_credential_id}

Revoke Biometric Credential

Revokes a biometric credential so it can no longer authenticate.

Parameters:

- `biometric_credential_id` (path, required) `string`: The biometric credential ID.

Responses:

- `200`: Returns the revoked biometric credential.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
