# Frontend API: DevBrowser
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to handle dev browsers.

## POST /v1/dev_browser

Create a Dev Browser token

Generate a Dev Browser API token.

This is used to authenticate Development Instances with the `DevBrowser` scheme.
It must be set before making any request to a dev instance, even for endpoints that are public.

Responses:

- `200`: A DevBrowser was created.
- `400`: The hostname is invalid.
