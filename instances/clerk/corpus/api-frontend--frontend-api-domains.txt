# Frontend API: Domains
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the members of an organization. The current user must be an administrator to access them.

## GET /v1/organizations/{organization_id}/domains

Get All Organization Domains

Retrieves a list of all the domains in an organization

The current user must have permissions to manage the domains of the organization.

Parameters:

- `limit` (query) `integer`: Applies a limit to the number of results returned. Can be used for paginating the results together with `offset`.
- `offset` (query) `integer`: Skip the first `offset` results when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`.
- `organization_id` (path, required) `string`: The organization ID.
- `verified` (query) `boolean`: Filter by whether a domain is verified
- `enrollment_mode` (query) `string`: Filter by enrollment mode

Responses:

- `200`: Returns the response for Client wrapped array of OrganizationDomain objects.
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## POST /v1/organizations/{organization_id}/domains

Create Organization Domain

Create a new organization domain.

The current user must have permissions to manage the domains of the organization.

Parameters:

- `organization_id` (path, required) `string`: The organization ID.

Request body (application/x-www-form-urlencoded):

- `name` `string`, required: The name of the new domain
- `enrollment_mode` `string, one of manual_invitation, automatic_invitation, automatic_suggestion, enterprise_sso`: The enrollment mode of the new domain. Defaults to `manual_invitation`.

Responses:

- `200`: Returns the response for Client wrapped OrganizationDomain object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## POST /v1/organizations/{organization_id}/domains/bulk

Bulk Create Organization Domains

Creates up to 10 organization domains by name. Duplicate names in the
request are skipped. The response is a partial-success payload:
successfully created domains are returned in `data`, while per-name
failures are returned in `errors`.

The current user must have permissions to manage the domains of the
organization. Requires the self-serve SSO feature to be enabled on the
instance.

Parameters:

- `organization_id` (path, required) `string`: The organization ID.

Request body (application/x-www-form-urlencoded):

- `names` `array of string`, required: The domain names to create.
- `enrollment_mode` `string, one of manual_invitation, automatic_invitation, automatic_suggestion, enterprise_sso`: The enrollment mode for the new domains. Defaults to `manual_invitation`.

Responses:

- `200`: Returns the per-name partial-success payload for bulk organization domain creation.
- `400`: Request was not successful
- `401`: Request was not successful
- `402`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## POST /v1/organizations/{organization_id}/domains/prepare_ownership_verification/bulk

Bulk Prepare Organization Domain Ownership Verification

Collection-level bulk counterpart of the single
`/domains/{domain_id}/prepare_ownership_verification` endpoint. Accepts a
set of `organization_domain_ids` and issues a fresh TXT challenge for
each. The plaintext TXT record value for each prepared domain is returned
in the response payload and is only stored as a bcrypt digest on the
server. Re-preparing replaces any prior outstanding TXT challenge for the
same domain.

The current user must have permissions to manage the domains of the
organization. Requires the self-serve SSO feature to be enabled on the
instance.

Parameters:

- `organization_id` (path, required) `string`: The organization ID.

Request body (application/x-www-form-urlencoded):

- `organization_domain_ids` `array of string`, required: The organization domain IDs to prepare ownership verification for.

Responses:

- `200`: Returns the per-domain partial-success payload for the bulk organization domain ownership verification endpoints.
- `400`: Request was not successful
- `401`: Request was not successful
- `402`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## POST /v1/organizations/{organization_id}/domains/{domain_id}/attempt_ownership_verification

Attempt Organization Domain Ownership Verification

Resolves the TXT record for the organization domain and, on a successful
match against the outstanding challenge, marks the domain as
ownership-verified and emits an `organization_domain.ownership_verified`
audit event.

The current user must have permissions to manage the domains of the
organization. Requires the self-serve SSO feature to be enabled on the
instance.

Parameters:

- `organization_id` (path, required) `string`: The organization ID.
- `domain_id` (path, required) `string`: The domain ID.

Responses:

- `200`: Returns the response for Client wrapped OrganizationDomain object.
- `400`: Request was not successful
- `401`: Request was not successful
- `402`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
