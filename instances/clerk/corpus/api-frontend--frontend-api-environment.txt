# Frontend API: Environment
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to get and update the current Environment

## GET /v1/environment

Get environment

Get the current environment. The environment contains information about the settings and features enabled for the current instance.

Security: DevBrowser

Responses:

- `200`: Returns the environment.
- `400`: Request was not successful
- `401`: Request was not successful

## PATCH /v1/environment

Update environment

Update environment using request origin

Security: DevBrowser

Parameters:

- `Origin` (header, required) `string`: Origin of the request

Responses:

- `200`: Returns the environment.
- `400`: Request was not successful
- `401`: Request was not successful
