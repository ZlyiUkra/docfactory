# Frontend API: External Accounts
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the external accounts of the current user.

## POST /v1/me/external_accounts

Connect OAuth Accounts

Connect a new External Account from the OAuth providers enabled.

Parameters:

- `Origin` (header) `string`: The origin of the request.

Request body (application/x-www-form-urlencoded):

- `strategy` `string`: The OAuth strategy that the external account provider supports. Optional when `enterprise_connection_id` is provided. Can be one of `oauth_[provider]` or `oauth_token_[provider]`. The `oauth_[provider]` strategy can be used for regular OAuth flows with redirects and a `redirect_url` parameter is also required. The `oauth_token_[provider]` strategy can be used for native flows, along with a `token` or `code` parameter.
- `enterprise_connection_id` `string`: The ID of an enterprise connection to link. When provided, strategy is not required.
- `redirect_url` `string`
- `action_complete_redirect_url` `string`
- `additional_scope` `string`
- `code` `string`: The authorization or grant code that an OAuth provider returns during authentication. Can be used with `oauth_token_[provider]` strategies.
- `token` `string`: The ID token that an OpenID Connect provider returns during authentication. Can be used with `oauth_token_[provider]` strategies.
- `oidc_login_hint` `string`: Used with `oauth_[provider]`. The given value will be forwarded to the OIDC `login_hint` parameter of the generated redirect URL.
- `oidc_prompt` `string`: Used with `oauth_[provider]` or `enterprise_sso`. The given value will be forwarded to the OIDC `prompt` parameter of the generated redirect URL. When using shared credentials this value might be adjusted for security reasons.

Responses:

- `200`: Returns the response for Session wrapped Verification object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful
- `500`: Request was not successful

## PATCH /v1/me/external_accounts/{external_account_id}/reauthorize

Reauthorize External Account

Reauthorize an external account by ID.

Parameters:

- `external_account_id` (path, required) `string`: External account ID

Request body (application/x-www-form-urlencoded):

- `additional_scope` `array of string`
- `redirect_url` `string`, required
- `action_complete_redirect_url` `string`
- `oidc_login_hint` `string`: Used with `oauth_[provider]`. The given value will be forwarded to the OIDC `login_hint` parameter of the generated redirect URL.
- `oidc_prompt` `string`: Used with `oauth_[provider]` or `enterprise_sso`. The given value will be forwarded to the OIDC `prompt` parameter of the generated redirect URL. When using shared credentials this value might be adjusted for security reasons.

Responses:

- `200`: Returns the response for Session wrapped Verification object.
- `400`: Request was not successful
- `401`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## DELETE /v1/me/external_accounts/{external_account_id}

Delete External Account

Delete an external account by ID.

Parameters:

- `external_account_id` (path, required) `string`: External account ID

Responses:

- `200`: Returns a deleted external account.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## DELETE /v1/me/external_accounts/{external_account_id}/tokens

Revoke OAuth tokens

Revoke the OAuth access and refresh token of an external account by ID, if supported by the provider.

Parameters:

- `external_account_id` (path, required) `string`: External account ID

Responses:

- `200`: Returns the response for Session wrapped User object.
- `400`: Request was not successful
- `401`: Request was not successful
- `404`: Request was not successful
