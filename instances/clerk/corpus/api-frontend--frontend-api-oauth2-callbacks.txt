# Frontend API: OAuth2 Callbacks
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to receive callbacks from successful OAuth attempts.

## GET /v1/oauth_callback

OAuth Callback

The endpoint where the OAuth providers redirect to after a successful authentication attempt.

Parameters:

- `scope` (query) `string`: returned scopes from OAuth provider.
- `code` (query) `string`: returned exchange code from OAuth provider.
- `state` (query) `string`: returned state from OAuth provider.
- `error` (query) `string`: returned error state from OAuth provider, if applicable

Responses:

- `200`: [AuthV2] HTML-based redirection in dev instances
- `299`: FAKE SUCCESS
- `301`: Redirect
- `303`: Redirect
- `400`: Request was not successful
- `403`: Request was not successful

## POST /v1/oauth_callback

OAuth Post Callback

Converts a POST to a GET, because if it's a POST coming from an external account. This is necessary because some providers (e.g. Apple) issue a POST instead of a GET request.

Request body (application/x-www-form-urlencoded):

- `code` `string`: returned exchange code from OAuth provider.
- `scope` `string`: returned scopes from OAuth provider.
- `state` `string`: returned state from OAuth provider.
- `error` `string`: returned error state from OAuth provider, if applicable

Responses:

- `303`: Redirect to GET /v1/oauth_callback with same parameters
