# Frontend API: Organization Creation Defaults
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to get suggested defaults when creating a new organization.

## GET /v1/me/organization_creation_defaults

Get organization creation defaults

Get suggested organization name and other defaults for creating a new organization.
Returns suggestions based on the user's email domain or configured naming templates.

Responses:

- `200`: Organization creation defaults
- `401`: Authentication invalid
- `403`: Authorization invalid
