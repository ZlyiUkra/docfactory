# Frontend API: Organization
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with an organization and its properties. The current user must be an administrator to access them.

## POST /v1/organizations

Create Organization

Create an organization and add the current user as admin.

Request body (application/x-www-form-urlencoded):

- `name` `string`: The organization name. May not contain URLs or HTML.
- `slug` `string`: The organization slug

Responses:

- `200`: Returns the response for Client wrapped Organization object.
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## GET /v1/organizations/{organization_id}

Get Organization

Retrieve all properties of an organization that the current user is member of.

Parameters:

- `organization_id` (path, required) `string`: The organization ID.

Responses:

- `200`: Returns the response for Client wrapped Organization object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## PATCH /v1/organizations/{organization_id}

Update Organization

Update the given properties of an organization.

The current user must be an admin in the organization.

Parameters:

- `organization_id` (path, required) `string`: The ID of the organization to update

Request body (application/x-www-form-urlencoded):

- `name` `string`: The organization name. May not contain URLs or HTML.
- `slug` `string`: The organization slug

Responses:

- `200`: Returns the response for Client wrapped Organization object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## DELETE /v1/organizations/{organization_id}
