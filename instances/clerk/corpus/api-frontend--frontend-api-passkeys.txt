# Frontend API: Passkeys
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the passkeys of the logged in user.

## POST /v1/me/passkeys

Create Passkey

Create a new passkey.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.
- `Origin` (header) `string`: The origin of the request.
- `X-Original-Host` (header) `string`: The original host of the request.

Responses:

- `200`: Returns the response for Session wrapped Passkey object.
- `401`: Request was not successful
- `403`: Request was not successful

## GET /v1/me/passkeys/{passkey_id}

Get Passkey

Retrieve all properties associated with a specific passkey.

Parameters:

- `passkey_id` (path, required) `string`: The passkey identification ID.

Responses:

- `200`: Returns the response for Session wrapped Passkey object.
- `401`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## PATCH /v1/me/passkeys/{passkey_id}

Update Passkey

Update properties of a specific passkey.

Parameters:

- `passkey_id` (path, required) `string`: The passkey identification ID.

Request body (application/x-www-form-urlencoded):

- `name` `string`: The name of the passkey.

Responses:

- `200`: Returns the response for Session wrapped Passkey object.
- `401`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## DELETE /v1/me/passkeys/{passkey_id}

Delete Passkey

Delete a passkey by ID.

Parameters:

- `passkey_id` (path, required) `string`: The passkey identification ID.

Responses:

- `200`: Returns a deleted Passkey object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## POST /v1/me/passkeys/{passkey_id}/attempt_verification

Attempt Passkey Verification

Attempts to verify the provided passkey.

Parameters:

- `passkey_id` (path, required) `string`: The passkey identification ID.
- `Origin` (header) `string`: The origin of the request.

Request body (application/x-www-form-urlencoded):

- `strategy` `string, one of passkey`: The strategy used to connect the external account.
- `public_key_credential` `string`: The public key credential of the passkey.

Responses:

- `200`: Returns the response for Session wrapped Passkey object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful
