# Frontend API: Payment Attempts
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with payment attempts for users and organizations.

## GET /v1/me/billing/payment_attempts

List user payment attempts

Returns a list of payment attempts for the current user.

Parameters:

- `limit` (query) `integer`: Applies a limit to the number of results returned. Can be used for paginating the results together with `offset`.
- `offset` (query) `integer`: Skip the first `offset` results when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`.
- `paginated` (query) `boolean`: Whether to paginate the results. If true, the results will be paginated. If false, the results will not be paginated.

Responses:

- `200`: Returns a list of commerce payment attempts.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid

## GET /v1/me/billing/payment_attempts/{paymentAttemptID}

Get user payment attempt

Returns details of a specific payment attempt for the current user.

Parameters:

- `paymentAttemptID` (path, required) `string`: The ID of the payment attempt to retrieve

Responses:

- `200`: Returns a commerce payment attempt.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
