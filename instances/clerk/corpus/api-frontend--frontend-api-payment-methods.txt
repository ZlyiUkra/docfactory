# Frontend API: Payment Methods
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with payment methods belonging to users and organizations.

## GET /v1/me/billing/payment_methods

List user payment methods

Returns a list of all payment methods for the current user.

Parameters:

- `limit` (query) `integer`: Applies a limit to the number of results returned. Can be used for paginating the results together with `offset`.
- `offset` (query) `integer`: Skip the first `offset` results when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`.
- `paginated` (query) `boolean`: Whether to paginate the results. If true, the results will be paginated. If false, the results will not be paginated.

Responses:

- `200`: Returns a list of commerce payment methods.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## POST /v1/me/billing/payment_methods

Create user payment method

Creates a new payment method for the current user.

Request body (application/x-www-form-urlencoded):

- `gateway` `string`, required: Payment gateway to use
- `payment_token` `string`, required: Payment token for the method
- `org_id` `string`: Organization ID (optional)

Responses:

- `200`: Returns a commerce payment method.
- `400`: Request was not successful
- `401`: Authentication invalid
- `422`: Invalid request parameters

## POST /v1/me/billing/payment_methods/initialize

Initialize user payment method

Initializes a payment method setup process for the current user.

Responses:

- `200`: Returns payment method initialization data.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters

## DELETE /v1/me/billing/payment_methods/{paymentMethodID}

Delete user payment method

Deletes a specific payment method for the current user.

Parameters:

- `paymentMethodID` (path, required) `string`: The ID of the payment method to delete

Responses:

- `200`: Returns a commerce payment method.
- `204`: Payment method deleted successfully
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `409`: Request was not successful
- `422`: Invalid request parameters
- `500`: Request was not successful

Responses:
