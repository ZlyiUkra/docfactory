# Frontend API: Phone Numbers
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the phone numbers of the logged in user.

## GET /v1/me/phone_numbers

Get Phone Numbers

Retrieve all phone numbers associated with the current user.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns UserPhoneNumbers array.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## POST /v1/me/phone_numbers

Create Phone Number

Add a phone number to the current user. The phone number then needs to be verified using the sms `prepare_verification` and `attempt_verification` endpoints.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Request body (application/x-www-form-urlencoded):

- `phone_number` `string`, required: The phone number to be added to the user.
- `reserved_for_second_factor` `boolean`: Whether the phone number is reserved for multi-factor authentication.

Responses:

- `200`: Returns the response for Session wrapped Email object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## POST /v1/me/phone_numbers/{phone_number_id}/attempt_verification

Attempt Phone Number Verification

Attempt to verify the given phone number using the code sent during the `prepare_verification` step.

Parameters:

- `phone_number_id` (path, required) `string`: The phone_number_id.
- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Request body (application/x-www-form-urlencoded):

- `code` `string`, required: Strategy used to verify the phone number.

Responses:

- `200`: Returns the response for Session wrapped Email object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful
- `429`: Request was not successful

## POST /v1/me/phone_numbers/{phone_number_id}/prepare_verification

Prepare Phone Number Verification

Sends an SMS to the phone number with the code needed to verify it.

Parameters:

- `phone_number_id` (path, required) `string`: The phone_number_id.
- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Request body (application/x-www-form-urlencoded):

- `strategy` `string, one of phone_code`, required: Strategy used to verify the phone number.
- `proof_token` `string`: Proof token produced by the Clerk Protect SDK.

Responses:

- `200`: Returns the response for Session wrapped Email object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `429`: Request was not successful

## GET /v1/me/phone_numbers/{phone_number_id}

Retrieve Phone Number

Retrieve all properties for the given phone number.

Parameters:

- `phone_number_id` (path, required) `string`: The phone_number_id.
- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns the response for Session wrapped Email object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## PATCH /v1/me/phone_numbers/{phone_number_id}

Update Phone Number

Update the properties of the given phone number.

Parameters:

- `phone_number_id` (path, required) `string`: The phone_number_id.
- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Request body (application/x-www-form-urlencoded):

- `reserved_for_second_factor` `boolean`: Whether the phone number is reserved for multi-factor authentication.
- `default_second_factor` `boolean`: Marks the phone number as the default that will be used in multi-factor authentication.

Responses:

- `200`: Returns the response for Session wrapped Email object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## DELETE /v1/me/phone_numbers/{phone_number_id}

Delete Phone Number

Deletes the phone number with the given ID.

Parameters:

- `phone_number_id` (path, required) `string`: The phone_number_id.
- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns single DeletedPhoneNumber.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
