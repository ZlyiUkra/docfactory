# Frontend API: Plans
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with plans that users and organizations can purchase.

## GET /v1/billing/plans

List billing plans

Returns a list of all publicly visible billing plans.

Parameters:

- `payer_type` (query) `string, one of user, org`: Filter plans by payer type

Responses:

- `200`: Returns a list of commerce plans.
- `400`: Request was not successful
- `403`: Request was not successful
- `422`: Invalid request parameters

## GET /v1/billing/plans/{planIdOrSlug}

Get a billing plan

Returns a billing plan by ID or slug.

Parameters:

- `planIdOrSlug` (path, required) `string`: The ID or slug of the plan

Responses:

- `200`: Returns a commerce plan.
- `400`: Request was not successful
- `404`: Resource not found
- `422`: Invalid request parameters
