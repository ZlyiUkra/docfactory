## GET /v1/redirect

Redirect to a validated URL

Validates and redirects to a safe URL. If no URL is provided, redirects to a default URL.

Parameters:

- `redirect_url` (query) `string`: The URL to redirect to (optional). If empty or not provided, redirects to the default URL.

Responses:

- `307`: Temporary redirect to the validated URL or default URL
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful
