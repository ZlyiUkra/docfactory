# Frontend API: SAML
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used in authentication flows using SAML.

## GET /v1/saml/metadata/{saml_connection_id}.xml

SAML Metadata

The Service Provider's SAML metadata

Security: DevBrowser

Parameters:

- `saml_connection_id` (path, required) `string`: The ID of the SAML Connection

Responses:

- `200`: OK
- `400`: Request was not successful
- `404`: Request was not successful

## POST /v1/saml/acs/{saml_connection_id}

SAML ACS

The SAML Assertion Consumer Service (ACS) endpoint, which processes SAML Responses by the IdP.

Security: DevBrowser

Parameters:

- `saml_connection_id` (path, required) `string`: The ID of the SAML Connection

Responses:

- `302`: OK
- `303`: OK
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
