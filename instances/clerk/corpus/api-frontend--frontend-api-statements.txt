# Frontend API: Statements
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with billing statements for users and organizations.

## GET /v1/me/billing/statements

List user statements

Returns a list of billing statements for the current user.

Parameters:

- `limit` (query) `integer`: Applies a limit to the number of results returned. Can be used for paginating the results together with `offset`.
- `offset` (query) `integer`: Skip the first `offset` results when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`.
- `paginated` (query) `boolean`: Whether to paginate the results. If true, the results will be paginated. If false, the results will not be paginated.

Responses:

- `200`: Returns a list of commerce statements.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid

## GET /v1/me/billing/statements/{statementID}

Get user statement

Returns details of a specific billing statement for the current user.

Parameters:

- `statementID` (path, required) `string`: The ID of the statement to retrieve

Responses:

- `200`: Returns a commerce statement.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## GET /v1/organizations/{organizationID}/billing/statements

List organization statements

Lists all statements for the organization.

Parameters:

- `organizationID` (path, required) `string`: The ID of the organization

Responses:

- `200`: Returns a generic commerce array.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## GET /v1/organizations/{organizationID}/billing/statements/{statementID}

Get organization statement

Gets a specific statement for the organization.

Parameters:

- `organizationID` (path, required) `string`: The ID of the organization
- `statementID` (path, required) `string`: The ID of the statement to retrieve

Responses:

- `200`: Returns a generic commerce object.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
