# Frontend API: Subscription Items
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with subscription items belonging to users and organizations.

## GET /v1/me/billing/subscription_items

List user's subscription items

Returns a list of subscription items for the current user.

Parameters:

- `limit` (query) `integer`: Applies a limit to the number of results returned. Can be used for paginating the results together with `offset`.
- `offset` (query) `integer`: Skip the first `offset` results when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`.
- `paginated` (query) `boolean`: Whether to paginate the results. If true, the results will be paginated. If false, the results will not be paginated.

Responses:

- `200`: Returns a list of commerce subscription items.
- `400`: Request was not successful
- `401`: Authentication invalid

## DELETE /v1/me/billing/subscription_items/{subscriptionItemID}

Cancel user's subscription item

Cancels a subscription item for the current user.

Parameters:

- `subscriptionItemID` (path, required) `string`: The ID of the subscription item to cancel

Responses:

- `200`: Returns a commerce subscription item.
- `204`: Subscription item canceled successfully
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `409`: Request was not successful
- `422`: Invalid request parameters
- `500`: Request was not successful

Responses:
