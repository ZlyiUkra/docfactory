# Frontend API: Subscriptions
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with subscriptions belonging to users and organizations.

## GET /v1/me/billing/subscription

Get user's main billing subscription

Returns the main billing subscription for the current user.

Responses:

- `200`: Returns a commerce subscription.
- `400`: Request was not successful
- `401`: Authentication invalid
- `404`: Resource not found

## GET /v1/organizations/{organizationID}/billing/subscription

Get organization's billing subscription

Returns the billing subscription for the organization.

Parameters:

- `organizationID` (path, required) `string`: The ID of the organization

Responses:

- `200`: Returns a commerce subscription.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
