# Frontend API: Trusted Devices
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Deprecated operations for native trusted-device credentials of the logged in user.

## POST /v1/client/trusted_devices/validate

Validate Trusted Device Sign-In Credential

Validates that a local trusted-device credential can be used by the current native client.

Deprecated.

Request body (application/x-www-form-urlencoded):

- `trusted_device_id` `string`, required: The trusted-device credential ID stored by the native SDK.

Responses:

- `200`: Returns whether the trusted-device credential is valid for the current client.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## GET /v1/me/trusted_devices

List Trusted Devices

Retrieve active trusted-device credentials associated with the current user.

Deprecated.

Responses:

- `200`: Returns the current user's trusted-device credentials.
- `401`: Request was not successful
- `403`: Request was not successful

## POST /v1/me/trusted_devices/prepare

Prepare Trusted Device Enrollment

Issues a one-time challenge for enrolling a native trusted-device credential.

Deprecated.

Request body (application/x-www-form-urlencoded):

- `platform` `string, one of ios, android`, required
- `app_identifier` `string`, required: Bundle identifier or package name for the native application.
- `name` `string`: Optional user-facing device name.
- `algorithm` `string, one of ES256`, required
- `public_key_jwk` `string`, required: Canonical public JWK for the device-bound P-256 key.

Responses:

- `200`: Returns the enrollment challenge that must be signed by the native private key.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## POST /v1/me/trusted_devices/attempt

Attempt Trusted Device Enrollment

Verifies a signed enrollment challenge and creates a trusted-device credential.

Deprecated.

Request body (application/x-www-form-urlencoded):

- `platform` `string, one of ios, android`, required
- `app_identifier` `string`, required: Bundle identifier or package name for the native application.
- `name` `string`: Optional user-facing device name.
- `algorithm` `string, one of ES256`, required
- `public_key_jwk` `string`, required: Canonical public JWK for the device-bound P-256 key.
- `client_data` `string`, required: Canonical JSON challenge payload returned from prepare.
- `signature` `string`, required: Base64url raw ECDSA P-256 signature over `client_data`.

Responses:

- `200`: Returns the created trusted-device credential.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful

## DELETE /v1/me/trusted_devices/{trusted_device_id}

Revoke Trusted Device

Revokes a trusted-device credential so it can no longer authenticate.

Deprecated.

Parameters:

- `trusted_device_id` (path, required) `string`: The trusted-device credential ID.

Responses:

- `200`: Returns the revoked trusted-device credential.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
