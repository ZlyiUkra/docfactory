# Frontend API: Waitlist
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the waitlist.

## POST /v1/waitlist

Join Waitlist

Adds an email address to the waitlist. If the email is already on the waitlist, the request will still succeed,
returning the ID of the existing waitlist entry.

Security: DevBrowser

Request body (application/x-www-form-urlencoded):

- `email_address` `string`, required

Responses:

- `200`: Returns the waitlist object.
- `400`: Request was not successful
- `403`: Request was not successful
- `422`: Request was not successful
