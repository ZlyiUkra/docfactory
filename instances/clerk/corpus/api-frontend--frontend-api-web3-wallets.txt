# Frontend API: Web3 Wallets
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Used to interact with the web3 wallets of the logged in user.

## GET /v1/me/web3_wallets

Get All Web3 Wallets

Retrieve all web3 wallets associated with the current user.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Responses:

- `200`: Returns UserWeb3Wallets array.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## POST /v1/me/web3_wallets

Create Web3 Wallet

Create a new web3 wallet.

Parameters:

- `_clerk_session_id` (query) `string`: The session_id associated with the requesting user.

Request body (application/x-www-form-urlencoded):

- `web3_wallet` `string`, required: The web3 wallet to be added to the user.

Responses:

- `200`: Returns the response for Session wrapped Web3 wallet object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## GET /v1/me/web3_wallets/{web3_wallet_id}

Get Web3 Wallet

Retrieve all properties associated with a specific web3 wallet.

Parameters:

- `web3_wallet_id` (path, required) `string`: The web3 wallet ID.

Responses:

- `200`: Returns the response for Session wrapped Web3 wallet object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## DELETE /v1/me/web3_wallets/{web3_wallet_id}

Delete Web3 Wallet

Delete a web3 wallet by ID.

Parameters:

- `web3_wallet_id` (path, required) `string`: The web3 wallet ID.

Responses:

- `200`: Returns single DeletedPhoneNumber.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful

## POST /v1/me/web3_wallets/{web3_wallet_id}/prepare_verification

Prepare Web3 Wallet Verification

Prepares verification for the provided web3 wallet.

Parameters:

- `web3_wallet_id` (path, required) `string`: The web3 wallet ID.
- `Origin` (header) `string`: The origin of the request.

Request body (application/x-www-form-urlencoded):

- `strategy` `string`, required: The strategy used to verify the web3 wallet.
- `redirect_url` `string`: The redirect URL to redirect the user to after verification.

Responses:

- `200`: Returns the response for Session wrapped Web3 wallet object.
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful

## POST /v1/me/web3_wallets/{web3_wallet_id}/attempt_verification

Attempt Web3 Wallet Verification

Attempts to verify the provided web3 wallet.

Parameters:

- `web3_wallet_id` (path, required) `string`: The web3 wallet ID.
- `Origin` (header) `string`: The origin of the request.

Request body (application/x-www-form-urlencoded):

- `signature` `string`, required: The signature that was generated from your Web3 Wallet to sign the message

Responses:

- `200`: Returns the response for Session wrapped Web3 wallet object.
- `400`: Request was not successful
- `401`: Request was not successful
- `403`: Request was not successful
- `404`: Request was not successful
- `422`: Request was not successful
