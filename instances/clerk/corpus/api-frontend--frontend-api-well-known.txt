# Frontend API: Well Known
# джерело: https://clerk.com/docs/reference/frontend-api
# отримано: 2026-09-25

Well-known endpoints like JWKS, deep linking, and openid-configuration.

## GET /.well-known/assetlinks.json

Get Android Asset Links

Get Android asset links for universal/deep linking

Responses:

- `200`: Get Android asset links for universal/deep linking

## GET /.well-known/jwks.json

JWKS

Retrieve the JSON Web Key Set of the instance

Responses:

- `200`: Get the JSON Web Key Set
- `500`: Request was not successful

## GET /.well-known/apple-app-site-association

Apple App Site Association

Retrieve the Apple App Site Association file of the instance

Responses:

- `200`: Get the Apple App Site Association file
- `500`: Request was not successful

## GET /.well-known/openid-configuration

Basic OpenID Configuration Payload

Get a basic OpenID configuration payload

Responses:

- `200`: Get a basic OpenID configuration payload

## GET /.well-known/oauth-authorization-server

OAuth 2.0 Authorization Server Metadata

Get the OAuth 2.0 Authorization Server Metadata according to RFC 8414

Responses:

- `200`: Get the OAuth 2.0 Authorization Server Metadata

## GET /.well-known/webauthn

WebAuthn Related Origins

Get the WebAuthn Related Origin Requests document. Only available when
the instance uses the auth_host passkey RP ID strategy; returns a not
found error otherwise.

Responses:

- `200`: Get the WebAuthn Related Origin Requests document
- `404`: Request was not successful
