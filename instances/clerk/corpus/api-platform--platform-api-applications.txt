# Platform API: Applications
# джерело: https://clerk.com/docs/reference/platform-api
# отримано: 2026-09-25

An object representing a Clerk application. Each `application` can have multiple `instances`, typically one for development and one for production, each with distinct user pools.

## GET /platform/applications

List applications

List applications.

Security: platform_api_access_token

Parameters:

- `include_secret_keys` (query) `boolean`: Whether to include secret keys in the response.

Responses:

- `200`: Applications retrieved successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid

## POST /platform/applications

Create an application

Create a new application.

Security: platform_api_access_token

Request body (application/json):

- `name` `string`, required: The name of the application.
- `domain` `string`: The domain for the application (optional).
- `proxy_path` `string`: Custom proxy path for provider domains (e.g., "/__clerk"). Must start with a leading slash and be a single path segment. Defaults to "/__clerk" if not provided.
- `environment_types` `array of string`: List of environment types to create instances for. Accepted values are "development" and "production". Defaults to "development" if not provided.
- `template` `string`: Application template to use for configuring the application (e.g., "b2b-saas", "b2c-saas", "waitlist").

Responses:

- `200`: Application created successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `422`: Invalid request parameters

## POST /platform/applications/{applicationID}/rotate_secret_keys

Rotate application secret keys

Rotate the secret keys for an application's instances.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.

Request body (application/json):

- `delay_old_secrets_expiration_hours` `integer`: Number of hours to delay before the old secret keys are deleted. This allows for a graceful transition period where both old and new keys are valid.
- `reason` `string`: The reason for rotating the secret keys. This is stored for audit purposes.

Responses:

- `200`: Secret keys rotated successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## GET /platform/applications/{applicationID}/instances/{envOrInsID}/usage

Get instance usage

Get usage totals for an application instance across meters such as MAU, MAO,
SMS, custom domains, and enterprise connections.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Requires the `application_usage:read` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.
- `start` (query) `string`: Start of the date range for usage data in YYYY-MM-DD format. Both `start` and `end` must be provided together. When omitted, the current billing cycle is used.
- `end` (query) `string`: Inclusive end of the date range for usage data in YYYY-MM-DD format. Both `start` and `end` must be provided together. When omitted, the current billing cycle is used.

Responses:

- `200`: Instance usage retrieved successfully.
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Request was not successful

## POST /platform/applications/{applicationID}/instances

Create instance

Creates a production instance for the given application. Optionally clones
configuration from an existing development instance.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.

Request body (application/json):

- `domain` `string`, required: The production domain for the instance (e.g. "example.com").
- `environment_type` `string, one of production`: Instance environment type. Only production is currently supported.
- `clone_instance_id` `string`: The ID of a development instance to clone configuration from.

Responses:

- `201`: Instance created successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `402`: Payment required
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters

## POST /platform/accountless_applications/claim

Claim an accountless application

Claim an accountless application by assigning it to the authenticated principal's workspace.
The application is identified by a single-use claim token that was generated when the
accountless application was created. Once claimed, the token is invalidated and cannot be reused.

Security: platform_api_access_token

Request body (application/json):

- `token` `string`, required: The single-use claim token for the accountless application.
- `name` `string`, required: The name to assign to the claimed application.

Responses:

- `200`: Application claimed successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters
