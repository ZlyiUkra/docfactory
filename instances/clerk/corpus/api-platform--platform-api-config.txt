# Platform API: Config
# джерело: https://clerk.com/docs/reference/platform-api
# отримано: 2026-09-25

Operations for managing instance configuration. The config API provides a unified interface for reading and updating instance settings, including authentication methods, SSO connections, and other instance-level configuration options.

## GET /platform/applications/{applicationID}/instances/{envOrInsID}/config

Get instance config

Get the configuration for an application instance.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Optionally filter to specific config keys using the `keys` query parameter.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.
- `keys` (query) `array of string`: Config keys to retrieve. If not specified, all keys are returned.

Responses:

- `200`: Instance config retrieved successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## PUT /platform/applications/{applicationID}/instances/{envOrInsID}/config

Replace instance config

Replace the full configuration for an application instance.

Unlike PATCH, PUT requires all config keys to be included in the request body.
If any keys are missing, a 400 error is returned listing the missing keys.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Use the `dry_run` query parameter to preview changes without applying them.
Use the `destructive` query parameter to allow clearing config keys by setting them to null.
Use the `If-Match` header to provide optimistic concurrency control via config version.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.
- `dry_run` (query) `boolean`: If true, preview the changes without applying them.
- `destructive` (query) `boolean`: If true, allow clearing config keys by setting them to null.
- `If-Match` (header) `string`: Config version for optimistic concurrency control.

Request body (application/json):

- (no fields listed)

Responses:

- `200`: Instance config replaced successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `402`: Payment required
- `403`: Authorization invalid
- `404`: Resource not found
- `409`: Conflict
- `422`: Invalid request parameters

## GET /platform/applications/{applicationID}/instances/{envOrInsID}/config/schema

Get instance config schema

Get the JSON Schema for the instance configuration.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Optionally filter to specific config keys using the `keys` query parameter.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.
- `keys` (query) `array of string`: Config keys to retrieve schema for. If not specified, all keys are returned.

Responses:

- `200`: Instance config schema retrieved successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
