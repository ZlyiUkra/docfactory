# Platform API: Domain Intents
# джерело: https://clerk.com/docs/reference/platform-api
# отримано: 2026-09-25

An object representing the intent to create a Clerk domain.
The high-level for domain intent consumption:
1. Create a domain intent, and receive the DNS records for the future domain to function. 2. Create a domain, supplying the intent ID.

## GET /platform/domain_intents

List domain intents

List all domain intents created by the authenticated workspace. Returns
intents sorted by creation date in descending order (most recent first).

Security: platform_api_access_token

Parameters:

- `name` (query) `string`: Filter by exact domain name.
- `status` (query) `array of string, one of pending, completed, expired, canceled`: Filter by domain intent status. Multiple values can be provided by repeating the parameter (e.g., `?status=pending&status=canceled`).
- `limit` (query) `integer`: Number of results to return per page (1-500, default 10).
- `starting_after` (query) `string`: Cursor for pagination. Provide the ID of the last domain intent from the previous page to get the next page of results.
- `ending_before` (query) `string`: Cursor for pagination. Provide the ID of the first domain intent from the previous page to get the previous page of results.

Responses:

- `200`: Domain intents retrieved successfully.
- `401`: Authentication invalid
- `403`: Authorization invalid
- `422`: Invalid request parameters

## POST /platform/domain_intents

Create a domain intent

Create a pending domain intent and receive DNS records for
the domain name.

Security: platform_api_access_token

Request body (application/json):

- `name` `string`, required: Domain name.
- `proxy_path` `string`: Optional proxy path for the domain intent. Treated as a hint to determine optionality of DNS records in the response.

Responses:

- `201`: Domain intent created successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `422`: Invalid request parameters

## GET /platform/domain_intents/{domainIntentID}

Get a domain intent

Retrieve a domain intent by ID.

Security: platform_api_access_token

Parameters:

- `domainIntentID` (path, required) `string`: Domain intent ID.

Responses:

- `200`: Domain intent retrieved successfully.
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## DELETE /platform/domain_intents/{domainIntentID}

Cancel a domain intent

Cancel a pending domain intent.

Security: platform_api_access_token

Parameters:

- `domainIntentID` (path, required) `string`: Domain intent ID.

Responses:

- `200`: Domain intent canceled successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
