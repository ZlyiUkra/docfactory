# Platform API: Native Applications
# джерело: https://clerk.com/docs/reference/platform-api
# отримано: 2026-09-25

Operations for configuring Native API support and registering native applications with an application instance.

## GET /platform/applications/{applicationID}/instances/{envOrInsID}/native_settings

Get native settings

Retrieve Native API settings for an application instance.

The `envOrInsID` parameter can be either an environment type (for example,
`development` or `production`) or an instance ID.

Requires the `applications:read` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type or instance ID.

Responses:

- `200`: Native settings retrieved successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found

## PATCH /platform/applications/{applicationID}/instances/{envOrInsID}/native_settings

Update native settings

Update Native API settings for an application instance.

The `envOrInsID` parameter can be either an environment type (for example,
`development` or `production`) or an instance ID.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type or instance ID.

Request body (application/json):

- `api_enabled` `boolean, one of True`, required: Enable the Native API for the instance. Disabling is not supported by this endpoint.

Responses:

- `200`: Native settings updated successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters

## POST /platform/applications/{applicationID}/instances/{envOrInsID}/native_applications/android

Create an Android native application

Register an Android application with an application instance.

The `envOrInsID` parameter can be either an environment type (for example,
`development` or `production`) or an instance ID.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type or instance ID.
- `Idempotency-Key` (header) `string`: Optional key. If Clerk has cached a completed response for this exact request and key, Clerk replays that response. Reuse the same key only for the same request. Concurrent in-flight requests are not guaranteed to be coalesced, and server-error responses are not cached for this operation.

Request body (application/json):

- `namespace` `string`, required: The Digital Asset Links namespace, typically `android_app`.
- `package_name` `string`, required: The application's Android package name.
- `fingerprints` `array of string`: SHA-256 certificate fingerprints for the Android application's signing certificates. Fingerprints are required to use passkeys.

Responses:

- `200`: Android application registered successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters
