# Platform API: Redirect URLs
# джерело: https://clerk.com/docs/reference/platform-api
# отримано: 2026-09-25

Operations for managing redirect URLs within an application instance.

## GET /platform/applications/{applicationID}/instances/{envOrInsID}/redirect_urls

List redirect URLs

List all redirect URLs for an application instance.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Requires the `applications:read` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.
- `limit` (query) `integer`: Number of results to return per page (1-500, default 10).
- `offset` (query) `integer`: Number of results to skip for pagination.

Responses:

- `200`: Redirect URLs retrieved successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters

## POST /platform/applications/{applicationID}/instances/{envOrInsID}/redirect_urls

Create a redirect URL

Create a redirect URL for an application instance.

The `envOrInsID` parameter can be either an environment type (e.g., "development", "production")
or an instance ID.

Requires the `applications:manage` scope.

Security: platform_api_access_token

Parameters:

- `applicationID` (path, required) `string`: Application ID.
- `envOrInsID` (path, required) `string`: Environment type (e.g., "development", "production") or instance ID.

Request body (application/json):

- `url` `string`, required: The full URL value prefixed with `https://` or a custom scheme e.g. `"https://my-app.com/oauth-callback"` or `"my-app://oauth-callback"`.

Responses:

- `200`: Redirect URL created successfully.
- `400`: Request was not successful
- `401`: Authentication invalid
- `403`: Authorization invalid
- `404`: Resource not found
- `422`: Invalid request parameters
