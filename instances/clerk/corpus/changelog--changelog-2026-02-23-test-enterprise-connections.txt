# Test enterprise connections with shareable links
# джерело: https://clerk.com/changelog/2026-02-23-test-enterprise-connections
# отримано: 2026-09-25

## What's new

- **Shareable test URLs** — From any enterprise connection (SAML or OIDC) in the Dashboard, use **Copy Test URL** to generate a one-time link. Share it with your customer or IT team so they can run a sign-in attempt against your connection.

- **Test logs** — Results of each test URL run (success or failure and details), so you can get more information for troubleshooting.

View video

## Getting started

In the Clerk Dashboard, go to **User authentication** → **SSO connections**, open an enterprise connection, and complete the connection setup. Then use **Copy Test URL** to create and copy a test link. Share it with your customer to run a test sign-in; the attempt will appear under **Test logs**.
