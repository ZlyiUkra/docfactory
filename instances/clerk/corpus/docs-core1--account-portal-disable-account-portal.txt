# Disabling the Account Portal
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/account-portal/disable-account-portal.mdx
# отримано: 2026-09-25
# версія: core-1

If you would like to disable the Account Portal, in the Clerk Dashboard, go to the **Account Portal** page and then open the **Danger** tab. Please ensure that you set up an authentication flow for your users via the instructions below first, as applying this setting will immediately result in a 404 for all Account Portal pages.

  We recommend leaving the Account Portal enabled, even if you do choose to set up your own authentication flow. This helps with testing as well as providing an alternative path for users when needed.

Disable the Account Portal

## Customizing your sign-up/sign-in flow

If you would like to migrate away from the Account Portal and create your own sign-up/sign-in flow, Clerk provides a set of pre-built components that you can use, or you can opt to build your own custom flow.
