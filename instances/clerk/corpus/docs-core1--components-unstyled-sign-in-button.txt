# `<SignInButton>`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/components/unstyled/sign-in-button.mdx
# отримано: 2026-09-25
# версія: core-1

The `<SignInButton>` component is a button that links to the sign-in page or displays the sign-in modal.

## `<SignInButton>` properties

| Name | Type | Description |
| --- | --- | --- |
| `redirectUrl?` | `string` | Full URL or path to navigate after successful sign in or sign up. The same as setting `afterSignInUrl` and `afterSignUpUrl` to the same value. |
| `afterSignInUrl?` | `string` | The full URL or path to navigate to after a successful sign in. |
| `afterSignUpUrl?` | `string` | The full URL or path to navigate to after a successful sign up. |
| `mode?` | `'redirect' \| 'modal'` | Determines what happens when a user clicks on the `<SignInButton>`. Setting this to `'redirect'` will redirect the user to the sign-in route. Setting this to `'modal'` will open a modal on the current route.Defaults to `'redirect'` |
| `children?` | `React.ReactNode` | Children you want to wrap the `<SignInButton>` in. |

## How to use the `<SignInButton>` component

### Basic usage

```jsx
  import { SignInButton } from "@clerk/nextjs";

  export default function Home() {
    return (
      <div>
        <SignInButton />
      </div>
    );
  }
```

```jsx
  import { SignInButton } from "@clerk/clerk-react";

  export default function Example() {
    return (
      <div>
        <SignInButton />
      </div>
    );
  }
```

```jsx
  import { SignInButton } from "@clerk/remix";

  export default function Home() {
    return (
      <div>
        <SignInButton />
      </div>
    );
  }
```

```jsx
  import { SignInButton } from "gatsby-plugin-clerk";

  export default function Home() {
    return (
      <div>
        <SignInButton />
      </div>
    );
  }
```

### Custom usage

In some cases, you will want to use your own button, or button text. You can do that by wrapping your button in the `<SignInButton>` component.

```jsx
  import { SignInButton } from "@clerk/nextjs";

  export default function Home() {
    return (
      <div>
        <SignInButton>
          <button>Sign in with Clerk</button>
        </SignInButton>
      </div>
    );
  }
```

```jsx
  import { SignInButton } from "@clerk/clerk-react";

  export default function Example() {
    return (
      <div>
        <SignInButton>
          <button>Sign in with Clerk</button>
        </SignInButton>
```
