# `getClient()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/client/get-client.mdx
# отримано: 2026-09-25
# версія: core-1

Retrieves a single client by its ID, if the ID is valid. Throws an error otherwise.

```tsx
const clientId = 'my-client-id';

const client = await clerkClient.clients.getClient(clientId);
```

## Required parameters

| Name | Type | Description |
| --- | --- | --- |
| `clientId` | `string` | The ID of the client to retrieve. |
