# `verifyClient()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/client/verify-client.mdx
# отримано: 2026-09-25
# версія: core-1

Retrieves a client for a given session token, if the session is active.

```tsx
const sessionToken = 'my-session-token';

const client = await clerkClient.clients.verifyClient(sessionToken);
```

## Required parameters

| Name | Type | Description |
| --- | --- | --- |
| `sessionToken` | `string` | The session token to verify. |
