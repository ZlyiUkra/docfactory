# `getEmailAddress()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/email-addresses/get-email-address.mdx
# отримано: 2026-09-25
# версія: core-1

Retrieves a single `EmailAddress` by its ID.

```tsx
function getEmailAddress: (emailAddressId: string) => Promise<EmailAddress>;
```

## `getEmailAddress()` parameters

| Name | Type | Description |
| --- | --- | --- |
| `emailAddressId` | `string` | The ID of the email address to retrieve. |

## `getEmailAddress()` example

```tsx
const emailAddressId = 'idn_2V7JJ2R3O7KWHjCmUuEOJESHlPz';

const response = await clerkClient.emailAddresses.getEmailAddress(emailAddressId);

console.log(response);
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/email_addresses/{email_address_id}`. See the BAPI reference for more details.
