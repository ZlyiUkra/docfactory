# `deleteOrganization()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/organization/delete-organization.mdx
# отримано: 2026-09-25
# версія: core-1

Deletes an organization given a valid ID. Throws an error otherwise.

```tsx
const organizationId = 'my-organization-id';

const organization = await clerkClient.organizations.deleteOrganization(organizationId);
```

## Required params

| Name | Type | Description |
| --- | --- | --- |
| `organizationId` | `string` | The ID of the organization to delete. |
