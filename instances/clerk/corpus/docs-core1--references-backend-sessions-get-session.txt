# `getSession()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/sessions/get-session.mdx
# отримано: 2026-09-25
# версія: core-1

Retrieves a single session by its ID, if the ID is valid. Throws an error otherwise.

```tsx
const sessionId = 'my-session-id';

const session = await clerkClient.sessions.getSession(sessionId);
```

## Required parameters

| Name | Type | Description |
| --- | --- | --- |
| `sessionId` | `string` | The ID of the session to retrieve. |
