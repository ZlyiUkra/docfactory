# `deleteUser()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-1/docs/references/backend/user/delete-user.mdx
# отримано: 2026-09-25
# версія: core-1

Deletes a user given a valid ID. Throws an error otherwise.

```tsx
const userId = 'my-user-id';

const user = await clerkClient.users.deleteUser(userId);
```

## Required parameters

| Name | Type | Description |
| --- | --- | --- |
| `userId` | `string` | The ID of the user to delete. |
