# Upgrade to @clerk/clerk-expo v2
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/guides/development/upgrading/upgrade-guides/expo-v2.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: expo

`@clerk/clerk-expo@2` introduces updated platform requirements:

- React Native ≥ `0.73.0`
- Expo SDK ≥ `50.0.0`

## Upgrade steps

### Update Expo to version 50 or later

  Update your Expo package to version `50` or later. To upgrade your Expo package, follow the Expo upgrade guide.

### Update Clerk Expo SDK

  Run the following command to update the Clerk Expo SDK to the latest version:

```npm
  npm install @clerk/clerk-expo@latest
```
