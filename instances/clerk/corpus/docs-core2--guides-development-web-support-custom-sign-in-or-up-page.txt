# Build your own sign-in-or-up page for your Expo web app
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/guides/development/web-support/custom-sign-in-or-up-page.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: expo

This guide shows you how to use the `<SignIn />` prebuilt component in order to build custom page that **allows users to sign in or sign up within a single flow**.

To set up separate sign-in and sign-up pages, follow this guide, and then follow the custom sign-up page guide.

This guide uses Expo Router and the platform-specific extensions to build the sign-in-or-up page specifically for the **web** platform.

## Build a sign-in-or-up page

  The following example demonstrates how to render the `<SignIn />` component to allow users to both sign-in or sign-up from a single flow.

```tsx
  import { SignIn } from '@clerk/clerk-expo/web'

  export default function Page() {
    return <SignIn />
  }
```

## Visit your new page

  To run your project, use the following command:

```npm
  npm run web
```

  Visit your new custom pages locally at localhost:8081/sign-in.
