# `getAllowlistIdentifierList()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/allowlist/get-allowlist-identifier-list.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Retrieves the list of all allowlist identifiers. Returns a `PaginatedResourceResponse` object with a `data` property that contains an array of `AllowlistIdentifier` objects, and a `totalCount` property that indicates the total number of allowlist identifiers in the system.

```ts
function getAllowlistIdentifierList(): Promise<PaginatedResourceResponse<AllowlistIdentifier[]>>
```

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const response = await clerkClient.allowlistIdentifiers.getAllowlistIdentifierList()
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/allowlist-identifiers`. See the BAPI reference{{ target: '_blank' }} for more information.
