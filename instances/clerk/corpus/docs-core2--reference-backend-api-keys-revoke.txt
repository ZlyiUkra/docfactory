# `revoke()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/api-keys/revoke.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

> [!WARNING]
> API keys is currently in beta. The API may change before general availability.

Revokes an API key by its ID. This will immediately invalidate the API key and prevent it from being used to authenticate any future requests. Returns an `APIKey` object.

```ts
function revoke(params: RevokeAPIKeyParams): Promise<APIKeyResource>
```

## `RevokeAPIKeyParams`

  - `apiKeyId`
  - `string`

  The ID of the API key to revoke.

  ---

  - `revocationReason?`
  - `string | null`

  Optional reason for revocation. Useful for your records.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

### Revoke an API key

```tsx
const apiKeyId = 'apikey_123'

const response = await clerkClient.apiKeys.revoke({
  apiKeyId: apiKeyId,
})
```

### Revoke an API key with a reason

```tsx
const apiKeyId = 'apikey_123'

const response = await clerkClient.apiKeys.revoke({
  apiKeyId: apiKeyId,
  revocationReason: 'Key compromised',
})
```

> [!IMPORTANT]
> When you revoke an API key, it is immediately invalidated. Any requests using that API key will be rejected. Make sure to notify users or update your systems before revoking API keys that are in active use.

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/api_keys/{apiKeyID}/revoke`. See the BAPI reference{{ target: '_blank' }} for more information.
