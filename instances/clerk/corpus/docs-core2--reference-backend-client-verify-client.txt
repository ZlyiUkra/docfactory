# `verifyClient()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/client/verify-client.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Verifies the `Client` in the provided token.

```ts
function verifyClient(token: string): Promise<Client>
```

## Parameters

  - `token`
  - `string`

  The session token to verify.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const token = 'my-session-token'

const response = await clerkClient.clients.verifyClient(token)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/clients/verify`. See the BAPI reference{{ target: '_blank' }} for more information.
