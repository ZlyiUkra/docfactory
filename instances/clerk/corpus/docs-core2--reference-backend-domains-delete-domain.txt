# `deleteDomain()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/domains/delete-domain.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Deletes a satellite domain for the instance. It is currently not possible to delete the instance's primary domain. Returns a `DeletedObjectResource`.

```ts
function deleteDomain(id: string): Promise<DeletedObjectResource>
```

## Parameters

  - `id`
  - `string`

  The ID of the domain that will be deleted. Must be a satellite domain.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const id = 'test_123'

const response = await clerkClient.users.deleteDomain(id)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/domains/{domain_id}`. See the BAPI reference{{ target: '_blank' }} for more information.
