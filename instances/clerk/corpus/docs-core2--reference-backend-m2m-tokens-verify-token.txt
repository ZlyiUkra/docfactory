# `verifyToken()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/m2m-tokens/verify-token.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Verifies an M2M token. Must be authenticated via a Machine Secret Key.

```ts
function verifyToken(params: VerifyM2MTokenParams): Promise<M2MToken>
```

## `VerifyM2MTokenParams`

  - `machineSecretKey?`
  - `string`

  Custom machine secret key for authentication. If not provided, the SDK will use the value from the environment variable.

  ---

  - `token`
  - `string`

  The M2M token to verify.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```ts
const response = await clerkClient.m2m.verifyToken({ token })
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/m2m_tokens/verify`. See the BAPI reference{{ target: '_blank' }} for more information.
