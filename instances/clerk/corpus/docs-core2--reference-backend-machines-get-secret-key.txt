# `getSecretKey()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/machines/get-secret-key.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Retrieves a machine secret key by its ID.

```ts
function getSecretKey(machineId: string): Promise<MachineSecretKey>
```

## Parameters

  - `machineId`
  - `string`

  The ID of the machine for which to retrieve the secret key.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```ts
const machineId = 'mch_123'

const response = await clerkClient.machines.getSecretKey(machineId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/machines/{machine_id}/secret_key`. See the BAPI reference{{ target: '_blank' }} for more information.
