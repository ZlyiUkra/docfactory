# `rotateSecretKey()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/machines/rotate-secret-key.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Rotates the machine secret key for a given machine by its ID.

```ts
function rotateSecretKey(params: RotateMachineSecretKeyParams): Promise<MachineSecretKey>
```

## Parameters

  - `machineId`
  - `string`

  The ID of the machine for which to rotate the secret key.

  ---

  - `previousTokenTtl`
  - `number`

  The time in seconds that the previous secret key will remain valid after rotation.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```ts
const machineId = 'mch_123'

const response = await clerkClient.machines.rotateSecretKey({
  machineId,
  previousTokenTtl: 3600,
})
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/machines/{machine_id}/secret_key/rotate`. See the BAPI reference{{ target: '_blank' }} for more information.
