# `createOrganization()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/organization/create-organization.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Creates an `Organization`.

```ts
function createOrganization(params: CreateParams): Promise<Organization>
```

## `CreateParams`

  - `name`
  - `string`

  Name of the Organization.

  ---

  - `createdBy`
  - `string`

  The user ID for the user creating the Organization. The user will become an administrator for the Organization.

  ---

  - `slug?`
  - `string`

  Slug of the Organization.

  ---

  - `publicMetadata?`
  - `OrganizationPublicMetadata`

  Metadata that can be read from both the Frontend API and Backend API{{ target: '_blank' }}, but can be set only from the Backend API.

  ---

  - `privateMetadata?`
  - `OrganizationPrivateMetadata`

  Metadata that is only visible to your Backend API{{ target: '_blank' }}.

  ---

  - `maxAllowedMemberships?`
  - `number`

  The maximum number of memberships allowed in the Organization. Setting this value to `0` removes any limit, allowing an unlimited number of memberships.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const name = 'test-org'

const createdBy = 'user_123'

const response = await clerkClient.organizations.createOrganization({ name, createdBy })
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/organizations`. See the BAPI reference{{ target: '_blank' }} for more information.
