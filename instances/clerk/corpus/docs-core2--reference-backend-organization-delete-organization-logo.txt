# `deleteOrganizationLogo()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/organization/delete-organization-logo.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Deletes an Organization's logo.

```ts
function deleteOrganizationLogo(organizationId: string): Promise<Organization>
```

## Parameters

  - `organizationId`
  - `string`

  The ID of the Organization for which the logo will be deleted.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const organizationId = 'org_123'

const response = await clerkClient.organizations.deleteOrganizationLogo(organizationId)

console.log(response)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/organizations/{organization_id}/logo`. See the BAPI reference{{ target: '_blank' }} for more information.
