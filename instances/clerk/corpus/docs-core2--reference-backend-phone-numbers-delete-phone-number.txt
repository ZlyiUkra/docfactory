# `deletePhoneNumber()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/phone-numbers/delete-phone-number.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Deletes a `PhoneNumber`.

```ts
function deletePhoneNumber(phoneNumberId: string): Promise<PhoneNumber>
```

## Parameters

  - `phoneNumberId`
  - `string`

  The ID of the phone number to delete.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const phoneNumberId = 'idn_123'

const response = await clerkClient.phoneNumbers.deletePhoneNumber(phoneNumberId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/phone_numbers/{phone_number_id}`. See the BAPI reference{{ target: '_blank' }} for more information.
