# `createRedirectUrl()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/redirect-urls/create-redirect-url.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Creates a `RedirectUrl`.

```ts
function createRedirectUrl(params: CreateRedirectUrlParams): Promise<RedirectUrl>
```

## `CreateRedirectUrlParams`

  - `url`
  - `string`

  The full url value prefixed with `https://` or a custom scheme. For example, `https://my-app.com/oauth-callback` or `my-app://oauth-callback`

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const response = await clerkClient.redirectUrls.createRedirectUrl({
  url: 'https://example.com',
})
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/redirect_urls`. See the BAPI reference{{ target: '_blank' }} for more information.
