# `getSession()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/sessions/get-session.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Retrieves a single `Session`.

```ts
function getSession(sessionId: string): Promise<Session>
```

## Parameters

  - `sessionId`
  - `string`

  The ID of the session to retrieve.

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const sessionId = 'sess_123'

const response = await clerkClient.sessions.getSession(sessionId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/sessions/{session_id}`. See the BAPI reference{{ target: '_blank' }} for more information.
