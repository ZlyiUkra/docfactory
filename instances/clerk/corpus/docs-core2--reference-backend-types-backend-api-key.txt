# The Backend `APIKey` object
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/types/backend-api-key.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

The Backend `APIKey` object holds information about an API key.

## Properties

| Property                                         | Type                                       | Description                                                                                                                                                        |
| ------------------------------------------------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  `claims`                     | null \| Record\<string, any\> | Custom claims associated with the API key.                                                                                                                         |
|  `createdAt`               | `number`                                   | The date when the API key was created.                                                                                                                             |
|  `createdBy`               | null \| string                | The user ID for the user creating the API key.                                                                                                                     |
|  `description`           | null \| string                | An optional description for the API key.                                                                                                                           |
|  `expiration`             | null \| number                | The expiration date and time of the API key. `null` if the API key never expires.                                                                                  |
|  `expired`                   | `boolean`                                  | A boolean indicating whether the API key has expired.                                                                                                              |
|  `id`                             | `string`                                   | A unique ID for the API key.                                                                                                                                       |
|  `lastUsedAt`             | null \| number                | The date and time when the API key was last used to authenticate a request.                                                                                        |
|  `name`                         | `string`                                   | The API key's name.                                                                                                                                                |
|  `revocationReason` | null \| string                | The reason for revoking the API key, if it has been revoked.                                                                                                       |
|  `revoked`                   | `boolean`                                  | A boolean indicating whether the API key has been revoked.                                                                                                         |
|  `scopes`                     | string[]                      | An array of scopes that define what the API key can access.                                                                                                        |
|  `secret?`                    | `string`                                   | The API key secret. **This property is only present in the response from `create()` and cannot be retrieved later.** |
|  `subject`                   | `string`                                   | The user or organization ID that the API key is associated with.                                                                                                   |
|  `type`                         | `string`                                   | The type of the API key. Currently always `'api_key'`.                                                                                                             |
|  `updatedAt`               | `number`                                   | The date when the API key was last updated.                                                                                                                        |
