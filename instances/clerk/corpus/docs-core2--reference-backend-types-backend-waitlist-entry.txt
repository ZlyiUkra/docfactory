# The Backend `WaitlistEntry` object
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/types/backend-waitlist-entry.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

The Backend `WaitlistEntry` object holds information about a waitlist entry for a given email address.

## Properties

| Property                                 | Type                                                                                | Description                                         |
| ---------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------- |
|  `createdAt`       | `number`                                                                            | The date when the waitlist entry was first created. |
|  `emailAddress` | `string`                                                                            | The email address to add to the waitlist.           |
|  `id`                     | `string`                                                                            | The unique identifier for this waitlist entry.      |
|  `invitation`     | null \| Invitation | The invitation associated with this waitlist entry. |
|  `isLocked?`        | `boolean`                                                                           | Whether the waitlist entry is locked or not.        |
|  `status`             | "pending" \| "invited" \| "completed" \| "rejected"                    | The status of the waitlist entry.                   |
|  `updatedAt`       | `number`                                                                            | The date when the waitlist entry was last updated.  |
