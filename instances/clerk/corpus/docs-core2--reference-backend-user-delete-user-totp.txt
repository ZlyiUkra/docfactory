# `deleteUserTOTP()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/user/delete-user-totp.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Deletes all of a user's TOTPs.

```ts
function deleteUserTOTP(userId: string): Promise<UserID>
```

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const userId = 'user_123'

const response = await clerkClient.users.deleteUserTOTP(userId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/users/{user_id}/totp`. See the BAPI reference{{ target: '_blank' }} for more information.
