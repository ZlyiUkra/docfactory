# `updateUserProfileImage()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/backend/user/update-user-profile-image.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-backend

Updates a user's profile image. Returns a `User` object.

```ts
function updateUserProfileImage(userId: string, params: { file: Blob | File }): Promise<User>
```

## Example

> [!NOTE]
> Using `clerkClient` varies based on your framework. Refer to the JS Backend SDK overview for usage details, including guidance on how to access the `userId` and other properties.

> [!WARNING]
> Using JS Backend SDK methods can contribute towards rate limiting. To set a user's profile image, it's recommended to use the frontend `user.setProfileImage()` method instead.

```tsx
const userId = 'user_123'
const fileBits = ['profile-pic-content']
const fileName = 'profile-pic.png'
const file = new File(fileBits, fileName, { type: 'image/png' })

const params = {
  file,
}

const response = await clerkClient.users.updateUserProfileImage(userId, params)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/users/{user_id}/profile_image`. See the BAPI reference{{ target: '_blank' }} for more information.
