# `<ClerkDegraded>`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/components/control/clerk-degraded.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: nextjs, react, react-router, chrome-extension, remix, tanstack-react-start

The `<ClerkDegraded>` component indicates that Clerk is partially operational.

## Example

It's not recommended to wrap the entire app in control components; instead, only wrap the components that need access to the `Clerk` object, such as custom flows.

SDK: nextjs

```tsx
    import { ClerkLoaded, ClerkLoading, ClerkDegraded, ClerkFailed } from '@clerk/nextjs'

    export default function Page() {
      return (
        <>
          <ClerkLoading>
            <p>Clerk is loading...</p>
          </ClerkLoading>
          <ClerkLoaded>
            <p>Clerk has loaded (ready or degraded)</p>
            <MyCustomSignInFlow />
            <ClerkDegraded>
              <p>Clerk is experiencing issues. Please try again later.</p>
            </ClerkDegraded>
          </ClerkLoaded>
          <ClerkFailed>
            <p>Something went wrong with Clerk. Please contact support.</p>
          </ClerkFailed>
        </>
      )
    }
```
