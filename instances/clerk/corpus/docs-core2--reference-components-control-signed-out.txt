# `<SignedOut>`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/components/control/signed-out.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: astro, chrome-extension, expo, nextjs, nuxt, react, react-router, remix, tanstack-react-start, vue

The `<SignedOut>` component offers authentication checks as a cross-cutting concern. Any child nodes wrapped by a `<SignedOut>` component will be rendered only if there's no User signed in to your application.

## Example

SDK: nextjs

```tsx
  import { SignedOut } from '@clerk/nextjs'

  export default function Page() {
    return (
      <>
        <SignedOut>
          <div>You are signed out.</div>
        </SignedOut>
        <p>This content is always visible.</p>
      </>
    )
  }
```

## Properties

  - `treatPendingAsSignedOut?`
  - `boolean`

  A boolean that indicates whether to treat pending sessions as signed out. Defaults to `true`.
