# `BackupCodeResource`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/javascript/types/backup-code-resource.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-frontend

An interface that represents a backup code.

  - `id`
  - `string`

  The unique identifier for the set of backup codes.

  ---

  - `codes`
  - `string[]`

  The generated set of backup codes.

  ---

  - `createdAt`
  - `Date`

  The date when the backup codes were created.

  ---

  - `updatedAt`
  - `Date`

  The date when the backup codes were last updated.
