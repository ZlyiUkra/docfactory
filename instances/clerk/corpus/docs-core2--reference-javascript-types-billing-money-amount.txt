The `BillingMoneyAmount` type represents a monetary value with currency information.

## Properties

| Property                                       | Type     | Description                                                                                                                    |
| ---------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
|  `amount`                   | `number` | The raw amount as a number, usually in the smallest unit of the currency (like cents for USD). For example, `1000` for $10.00. |
|  `amountFormatted` | `string` | The amount as a formatted string. For example, `10.00` for $10.00.                                                             |
|  `currency`               | `string` | The ISO currency code for this amount. For example, `USD`.                                                                     |
|  `currencySymbol`   | `string` | The symbol for the currency. For example, `$`.                                                                                 |
