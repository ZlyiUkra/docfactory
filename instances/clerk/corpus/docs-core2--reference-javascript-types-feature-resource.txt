The `FeatureResource` type represents a Feature of a Plan.

## Properties

| Property                               | Type                        | Description                                                                  |
| -------------------------------------- | --------------------------- | ---------------------------------------------------------------------------- |
|  `avatarUrl`     | null \| string | The URL of the Feature's avatar image, or `null` if not set.                 |
|  `description` | null \| string | A short description of what the Feature provides, or `null` if not provided. |
|  `id`                   | `string`                    | The unique identifier for the Feature.                                       |
|  `name`               | `string`                    | The display name of the Feature.                                             |
|  `pathRoot`       | `string`                    | The root path of the resource.                                               |
|  `slug`               | `string`                    | A unique, URL-friendly identifier for the Feature.                           |
