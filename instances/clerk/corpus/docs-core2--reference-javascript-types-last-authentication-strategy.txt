# `LastAuthenticationStrategy`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/javascript/types/last-authentication-strategy.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: js-frontend

The `LastAuthenticationStrategy` enum is used to indicate the last authentication strategy used by a client.

```tsx
type LastAuthenticationStrategy =
  | 'email_address'
  | 'email_code'
  | 'email_link'
  | 'phone_code'
  | 'password'
  | 'username'
  | 'oauth_<provider>'
  | 'web3_metamask_signature'
  | 'web3_base_signature'
  | 'web3_coinbase_wallet_signature'
  | 'web3_okx_wallet_signature'
  | 'web3_solana_signature'
```
