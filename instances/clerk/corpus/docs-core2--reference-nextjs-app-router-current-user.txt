# `currentUser()`
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/nextjs/app-router/current-user.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: nextjs

> [!WARNING]
> For optimal performance and to avoid rate limiting, it's recommended to use the `useUser()` hook on the client-side when possible. Only use `currentUser()` when you specifically need user data in a server context.

The `currentUser()` helper returns the `Backend User` object of the currently active user. It can be used in Server Components, Route Handlers, and Server Actions.

Under the hood, this helper:

- calls `fetch()`, so it is automatically deduped per request.
- uses the `GET /v1/users/{user_id}`{{ target: '_blank' }} endpoint.
- counts towards the Backend API request rate limit.

> [!WARNING]
> The `Backend User` object includes a `privateMetadata` field that should not be exposed to the frontend. Avoid passing the full user object returned by `currentUser()` to the frontend. Instead, pass only the specified fields you need.

```tsx
import { currentUser } from '@clerk/nextjs/server'

export default async function Page() {
  const user = await currentUser()

  if (!user) return <div>Not signed in</div>

  return <div>Hello {user?.firstName}</div>
}
```
