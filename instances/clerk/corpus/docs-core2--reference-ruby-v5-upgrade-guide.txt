# Upgrade to `clerk-sdk-ruby` v5
# джерело: https://github.com/clerk/clerk-docs/blob/core-2/docs/reference/ruby/v5-upgrade-guide.mdx
# отримано: 2026-09-25
# версія: core-2

SDK: ruby

In January 2026, version 5.0 of the Clerk Ruby SDK was released. This guide covers the breaking changes that were introduced.

## Available methods and operations updates

With the introduction of v5, we have deprecated our generated Ruby HTTP Client. All `Clerk::SDK` class methods are generated from the Clerk OpenAPI specification{{ target: '_blank' }} in the gem itself.

This comes with a number of changes to the method names, parameters, and responses. Please refer to the Available Resources and Operations{{ target: '_blank' }} section for more details on the changes required.
