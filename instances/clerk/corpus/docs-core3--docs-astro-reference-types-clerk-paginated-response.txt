# ClerkPaginatedResponse
# джерело: https://clerk.com/docs/astro/reference/types/clerk-paginated-response
# отримано: 2026-09-26
# версія: core-3

An interface that describes the response of a method that returns a paginated list of resources.

## Properties

| Properties   | Type     | Description                                  |
| ------------ | -------- | -------------------------------------------- |
| `data`       | `T[]`    | An array that contains the fetched data.     |
| `totalCount` | `number` | The total count of data that exist remotely. |

## Error handling

Clerk's SDKs always use `Promise<ClerkPaginatedResponse<T>>`. If the promise resolves, you will get back the properties listed above. If the promise is rejected, you will receive a `ClerkAPIResponseError` or network error.
