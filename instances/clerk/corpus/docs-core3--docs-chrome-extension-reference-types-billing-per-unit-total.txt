> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingPerUnitTotal` type represents the per-unit cost breakdown in checkout totals.

## Properties

| Property                           | Type                                                                                                                                        | Description                                            |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
|  `blockSize` | `number`                                                                                                                                    | The number of units represented by one billable block. |
|  `name`           | `string`                                                                                                                                    | The unit name, for example `seats`.                    |
|  `tiers`         | BillingPerUnitTotalTier[] | The tiers breakdown for this unit total.               |
