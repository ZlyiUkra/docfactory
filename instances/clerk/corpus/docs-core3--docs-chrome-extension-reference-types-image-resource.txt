# ImageResource
# джерело: https://clerk.com/docs/chrome-extension/reference/types/image-resource
# отримано: 2026-09-26
# версія: core-3

Represents information about an image.

## Properties

| Property                           | Type                       | Description                         |
| ---------------------------------- | -------------------------- | ----------------------------------- |
|  `id?`              | `string`                   | The unique identifier of the image. |
|  `name`           | `null | string` | The name of the image.              |
|  `publicUrl` | `null | string` | The public URL of the image.        |
