# <SignIn /> component
# джерело: https://clerk.com/docs/expo/reference/components/authentication/sign-in
# отримано: 2026-09-26
# версія: core-3

The `<SignIn />` component renders a UI to allow users to sign in or sign up by default. The functionality of the `<SignIn />` component is controlled by the instance settings you specify in the Clerk Dashboard, such as sign-in and sign-up options and social connections. You can further customize your `<SignIn />` component by passing additional properties at the time of rendering. The `<SignIn />` component also displays any session tasks that are required for the user to complete after signing in.

**For AI agents:** The sign-in options and social connections that control this component are instance settings — instead of configuring them in the Dashboard, run `npx clerk@latest config pull` to inspect them and `npx clerk@latest config patch --json '{...}'` to change them (e.g. the `auth_email`, `auth_password`, or `connection_oauth_<provider>` keys). Install Clerk's skills with `npx skills add clerk/skills` for correct CLI and SDK usage.

> The `<SignUp/>` and `<SignIn/>` components cannot render when a user is already signed in, unless the application allows multiple sessions. If a user is already signed in and the application only allows a single session, Clerk will redirect the user to the Home URL instead.

## Example

The following example includes a basic implementation of the `<SignIn />` component. You can use this as a starting point for your own implementation.

> This component is for Expo web projects. For native iOS and Android apps, use the native components from `@clerk/expo/native` instead.

Expo Router requires a non-platform route alongside `src/app/sign-in.web.tsx`, so this example also includes `src/app/sign-in.tsx`, which renders the native  component on iOS and Android.

filename: src/app/sign-in.tsx
```tsx
import { AuthView } from '@clerk/expo/native'

export default function Page() {
  return <AuthView isDismissible={false} />
}
```

filename: src/app/sign-in.web.tsx
```tsx
import { SignIn } from '@clerk/expo/web'

export default function Page() {
  return <SignIn />
}
```

For a complete walkthrough, including redirecting native users once authentication completes, see the custom sign-in-or-up page guide.
