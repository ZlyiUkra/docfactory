# Billing object
# джерело: https://clerk.com/docs/expo/reference/objects/billing
# отримано: 2026-09-25
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `Billing` object provides methods for managing billing for a user or Organization.

> If an `orgId` parameter is not provided, the methods will automatically use the current user's ID.

## Methods

### `getCreditBalance()`

Gets the credit balance for the current payer.

Returns a BillingCreditBalanceResource object.

```typescript
function getCreditBalance(params: GetCreditBalanceParams): Promise<BillingCreditBalanceResource>
```

#### `GetCreditBalanceParams`

| Property                    | Type     | Description                                               |
| --------------------------- | -------- | --------------------------------------------------------- |
|  `orgId?` | `string` | The ID of the Organization to get the credit balance for. |

### `getPaymentAttempt()`

Gets details of a specific payment attempt for the current user or supplied Organization.

Returns a BillingPaymentResource object.

```typescript
function getPaymentAttempt(params: GetPaymentAttemptParams): Promise<BillingPaymentResource>
```

#### `GetPaymentAttemptParams`

| Property                                | Type     | Description                                                                                                                                                         |
| --------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                    | `string` | The unique identifier for the payment attempt to get.                                                                                                               |
|  `initialPage?` | `number` | A number that specifies which page to fetch. For example, if `initialPage` is set to `10`, it will skip the first 9 pages and fetch the 10th page. Defaults to `1`. |
|  `orgId?`             | `string` | The Organization ID to perform the request on.                                                                                                                      |
|  `pageSize?`       | `number` | A number that specifies the maximum number of results to return per page. Defaults to `10`.                                                                         |

#### Example

The `Billing` object is available on the Clerk object. Use the useClerk() hook to access the `clerk.billing` object, and then call the `getPaymentAttempt()` method.

filename: src/app/(clerk)/index.tsx
```tsx
import { useClerk } from '@clerk/expo'
import { Button, Text, View } from 'react-native'
import { useState } from 'react'

export default function Page() {
  // Use the useClerk hook to access the clerk object
  const clerk = useClerk()
  const [paymentAttempt, setPaymentAttempt] = useState<Awaited<
    ReturnType<typeof clerk.billing.getPaymentAttempt>
  > | null>(null)

  const handleGetPaymentAttempt = async () => {
    // Call the getPaymentAttempt() method
    const paymentAttempt = await clerk.billing.getPaymentAttempt({
      id: 'payment_attempt_123',
    })

    setPaymentAttempt(paymentAttempt)
  }

  return (
    <View>
      <Button title="Get payment attempt" onPress={handleGetPaymentAttempt} />
      {paymentAttempt ? <Text>{JSON.stringify(paymentAttempt, null, 2)}</Text> : null}
    </View>
  )
}
```

### `getPlans()`

Gets a list of all publically visible Billing Plans.

Returns a ClerkPaginatedResponse of BillingPlanResource objects.

```typescript
function getPlans(params?: GetPlansParams): Promise<ClerkPaginatedResponse<BillingPlanResource>>
```

#### `GetPlansParams`

| Property                                | Type                                 | Description                                                                                                                                                                                                                          |
| --------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `for?`                                  | `"user" | "organization"` | The type of payer for the Plans.                                                                                                                                                                                                     |
|  `initialPage?` | `number`                             | A number that specifies which page to fetch. For example, if `initialPage` is set to `10`, it will skip the first 9 pages and fetch the 10th page. Defaults to `1`.                                                                  |
| `minSeats?`                             | `number`                             | The minimum number of seats that the returned plans needs to support.                                                                                                                                                                |
| `orgId?`                                | `string`                             | The organization ID to fetch plans for (needs to match the current Active Organization ID). Providing this parameter will populate the `availablePrices` field with the prices that are available to the authenticated organization. |
|  `pageSize?`       | `number`                             | A number that specifies the maximum number of results to return per page. Defaults to `10`.                                                                                                                                          |

#### Example

The `Billing` object is available on the Clerk object. Use the useClerk() hook to access the `clerk.billing` object, and then call the `getPlans()` method.

filename: src/app/(clerk)/index.tsx
```tsx

    <View>
      <Button title="Get plans" onPress={handleGetPlans} />

    </View>
  )
}
```

### `startCheckout()`

Creates a new Billing checkout for the current user or supplied Organization.

Returns a BillingCheckoutResource object.

```typescript
function startCheckout(params: CreateCheckoutParams): Promise<BillingCheckoutResource>
```

#### `CreateCheckoutParams`

| Property                    | Type                            | Description                                                                                             |
| --------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------- |
|  `orgId?` | `string`                        | The Organization ID to perform the request on.                                                          |
| `planId`                    | `string`                        | The unique identifier for the Plan.                                                                     |
| `planPeriod`                | `"month" | "annual"` | The billing period for the Plan.                                                                        |
| `priceId?`                  | `string`                        | The specific price ID to check out for, used when the desired price ID is not the current default price |
| `seatsQuantity?`            | `number`                        | The number of total seats to check out for                                                              |

#### Example

The `Billing` object is available on the Clerk object. Use the useClerk() hook to access the `clerk.billing` object, and then call the `startCheckout()` method.

> Clerk Billing checkout is supported in Expo web apps only. Native iOS and Android apps can use the Billing object's data APIs to access Plans, Subscriptions, statements, and payment attempts, and use `has()` to check Plan or Feature access. Clerk doesn't provide a native checkout surface or integrate with Apple In-App Purchase or Google Play Billing. See the Billing FAQ for more information.

filename: src/components/Checkout.web.tsx
```tsx
import { useClerk } from '@clerk/expo'
import { useState } from 'react'

export default function Checkout() {
  // Use the useClerk hook to access the clerk object
  const clerk = useClerk()
  const [checkout, setCheckout] = useState<Awaited<
    ReturnType<typeof clerk.billing.startCheckout>
  > | null>(null)

  const handleStartCheckout = async () => {
    // Call the startCheckout() method
    const checkout = await clerk.billing.startCheckout({
      planId: 'plan_123',
      planPeriod: 'month',
    })

    setCheckout(checkout)
  }

  return (
    <div>
      <button onClick={handleStartCheckout}>Start checkout</button>
      {checkout ? <pre>{JSON.stringify(checkout, null, 2)}</pre> : null}
    </div>
  )
}
```

### `updateCheckout()`

Applies or removes a promo code on an existing Billing checkout for the current user or supplied Organization.

Returns a BillingCheckoutResource object.

```typescript
function updateCheckout(params: UpdateCheckoutParams): Promise<BillingCheckoutResource>
```

#### `UpdateCheckoutParams`

| Property                           | Type     | Description                                                                    |
| ---------------------------------- | -------- | ------------------------------------------------------------------------------ |
|  `id`               | `string` | The unique identifier for the checkout session.                                |
|  `orgId?`        | `string` | The Organization ID to perform the request on.                                 |
|  `promoCode` | `string` | The promo code to apply. Use an empty string to remove the applied promo code. |

> Clerk Billing checkout is supported in Expo web apps only. Native iOS and Android apps can use the Billing object's data APIs to access Plans, Subscriptions, statements, and payment attempts, and use `has()` to check Plan or Feature access. Clerk doesn't provide a native checkout surface or integrate with Apple In-App Purchase or Google Play Billing. See the Billing FAQ for more information.
