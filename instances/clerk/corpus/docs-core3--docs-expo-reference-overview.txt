# Clerk Expo SDK
# джерело: https://clerk.com/docs/expo/reference/overview
# отримано: 2026-09-25
# версія: core-3

The Clerk Expo SDK gives you access to prebuilt components, React hooks, and helpers to make user authentication easier. Refer to the quickstart guide to get started.

## Hosted authentication

useHostedAuth() opens Clerk's Account Portal in a browser authentication session and activates the session created there. Choose hosted authentication for the fastest setup and support for every authentication method enabled in the Clerk Dashboard.

See the hosted authentication guide for setup instructions and tradeoffs.

## Components

### Native components

> **Beta:** This feature is currently in beta. Functionality may change before general availability. If you run into any issues, please reach out to our support team.

Prebuilt native components rendered with **SwiftUI** on iOS and **Jetpack Compose** on Android. These components require a development build.

-  - Renders a full authentication interface, supporting multiple sign-up and sign-in methods, multi-factor authentication (MFA), and password recovery flows.
-  - Displays the signed-in user's profile image.
-  - Renders a complete user profile interface with personal information, security settings, account switching, and sign-out options.

See the native components overview for more details.

### Control components

These components work across all approaches:

-  - Conditionally render content based on auth state
-  - Render children after Clerk loads
-  - Render children while Clerk loads

### Web components

All Clerk components are available from `@clerk/expo/web` for Expo web projects. See the component docs for more information.

## Hooks

### Native sign-in hooks

Hooks for native OAuth authentication without browser redirects. These hooks require a development build.

- useSignInWithApple() - Native Sign in with Apple (iOS only)
- useSignInWithGoogle() - Native Sign in with Google (iOS and Android)
- useSSO() - Browser-based SSO and OAuth flows

### Expo-specific hooks

Hooks designed specifically for Expo environments. They provide native authentication-flow state, local credential storage, biometric sign-in, browser-based OAuth flows, and user profile navigation capabilities.

- useAuthViewState() - Track completion of a native root authentication flow
- useBiometricCredentials() - Clerk-backed biometric credential enrollment and sign-in
- useHostedAuth() - Hosted sign-in and sign-up through Account Portal
- useLocalCredentials() - Store password credentials locally for biometric retrieval
- useOAuth() - Browser-based OAuth flows
- useUserProfileCustomPageNavigation() - Navigation from custom pages in the native user profile

### React hooks

Because the Expo SDK is built on top of the Clerk React SDK, you can use the hooks that the React SDK provides. These hooks include access to the Clerk object, User object, Organization object, and a set of useful helper methods for signing in and signing up.

- useUser()
- useClerk()
- useAuth()
- useOAuthConsent()
- useSignIn()
- useSignUp()
- useWaitlist()
- useSession()
- useSessionList()
- useOrganization()
- useOrganizationList()
- useOrganizationCreationDefaults()
- useReverification()
- useCheckout()
- usePaymentElement()
- usePaymentMethods()
- usePlans()
- useSubscription()
- usePaymentAttempts()
- useStatements()
- useAPIKeys()

## Custom flows

Clerk provides prebuilt components for **native** applications and **web** applications. Use the components that correspond to your platform:

- For native apps, see the native components.
- For web apps, see the web components.

If the prebuilt components don't meet your needs, you can build custom flows using the Clerk API.
