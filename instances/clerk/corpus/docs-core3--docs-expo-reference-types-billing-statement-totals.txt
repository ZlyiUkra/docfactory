# BillingStatementTotals
# джерело: https://clerk.com/docs/expo/reference/types/billing-statement-totals
# отримано: 2026-09-25
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingStatementTotals` type represents the total costs, taxes, and other pricing details for a statement.

## Properties

| Property                             | Type                                                                                      | Description                                                                                                               |
| ------------------------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
|  `grandTotal` | BillingMoneyAmount | The total amount for the checkout, including taxes and after credits/discounts are applied. This is the final amount due. |
|  `subtotal`     | BillingMoneyAmount | The price of the items or Plan before taxes, credits, or discounts are applied.                                           |
|  `taxTotal`     | BillingMoneyAmount | The amount of tax included in the checkout.                                                                               |
