# Quickstarts
# джерело: https://clerk.com/docs/getting-started/quickstart/overview
# отримано: 2026-09-26
# версія: core-3

Have your agent use Clerk's CLI and Skills to get started, or explore the SDK-specific quickstarts below.

- Agent prompt: `Add Clerk auth to my app: clerk.com/SKILL.md`
- CLI: `npx clerk@latest init`
- Agent Skills: `npx skills add clerk/skills`

## Full Stack

- Next.js: Easily add secure, beautiful, and fast authentication to your Next.js application with Clerk.
- Astro: Easily add secure and SSR-friendly authentication to your Astro application with Clerk.
- Nuxt: Easily add secure, beautiful, and fast authentication to Nuxt with Clerk.
- React Router: The Clerk React Router SDK provides prebuilt components, hooks, and stores to make it easy to integrate authentication and user management in your React Router app.
- TanStack React Start: Easily add secure and SSR-friendly authentication to your TanStack React Start application with Clerk.

## Frontend

- React: Easily add secure, beautiful, and fast authentication to your React application with Clerk.
- Chrome Extension (Plasmo): Use the Chrome Extension SDK with Plasmo to authenticate users in your Chrome extension.
- Chrome Extension (JavaScript): Use the Chrome Extension SDK with plain TypeScript to authenticate users in your Chrome extension.
- Expo: Use Clerk with Expo to authenticate users in your React Native application.
- Android: Use the Clerk Android SDK to authenticate users in your native Android applications.
- iOS: Use the Clerk iOS SDK to authenticate users in your native Apple applications.
- JavaScript: Easily add secure, beautiful, and fast authentication to your JavaScript application with Clerk.
- Vue: Easily add secure, beautiful, and fast authentication to your Vue application with Clerk.

## Backend

- Express: Easily add secure, beautiful, and fast authentication to your Express application with Clerk.
- Fastify: Easily add secure, beautiful, and fast authentication to your Fastify application with Clerk.
