### FreeTrialAlreadyActive

`FreeTrialAlreadyActive` is returned when a payer tries to check out for the
same plan/period they are already free-trialing. Seat additions on the
active trial are allowed; this error covers the stale "Start free trial"
re-checkout path that would otherwise convert the trial into a $0 paid item.

filename: Status Code: 409
```json
{
  "shortMessage": "Free trial already active",
  "longMessage": "You already have an active free trial for this plan.",
  "code": "free_trial_already_active"
}
```

### FreeTrialAlreadyClaimed

`FreeTrialAlreadyClaimed` is returned by a confirm that lost a race: another
account on the same email claimed the trial after this checkout was created.
The create path never returns it; an ineligible payer just gets a paid checkout.

filename: Status Code: 409
```json
{
  "shortMessage": "Free trial already claimed",
  "longMessage": "A free trial has already been used with this email address.",
  "code": "free_trial_already_claimed"
}
```
