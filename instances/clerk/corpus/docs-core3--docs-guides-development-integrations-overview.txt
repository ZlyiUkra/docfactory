# Integrations
# джерело: https://clerk.com/docs/guides/development/integrations/overview
# отримано: 2026-09-26
# версія: core-3

Use these guides to connect Clerk with databases, platforms, frameworks and analytics tools.

## Databases

- Convex: Clerk offers a first-class integration with Convex, the serverless state management platform.
- Firebase: Clerk integrates directly with Firebase, a popular Platform-as-a-Service (PaaS) provider, so developers can easily add our beautiful Sign Up, Sign In, and User Profile UIs to their Firebase application.
- Grafbase: Build applications with serverless GraphQL backends provided by Grafbase and user authentication provided by Clerk.
- Hasura: Easily connect to your Hasura GraphQL endpoint using Clerk as your authentication provider.
- Instant: Clerk has a default integration with Instant. You get all the auth features of Clerk, and a relational database you can use directly from the browser.
- Neon: Build applications using Neon's serverless Postgres database with Clerk as your authentication provider.
- Nhost: The open source alternative to Firebase with GraphQL seamlessly integrates with Clerk to provide authenticated queries.
- Prisma Postgres: Build applications using Prisma Postgres with Clerk as your authentication provider.
- Supabase: Clerk embraces the open source alternative to Firebase and offers a first-class integration with Supabase.

## Platforms

- Shopify: Use Clerk as your preferred Auth solution for your Shopify store.
- Vercel Marketplace: Configure and integrate Clerk into your Vercel projects through the Vercel Marketplace.

## Frameworks

- Encore: Integrate Clerk into your Encore backend using Encore's built-in auth handler pattern.

## Analytics

- Google Analytics: Send user authentication events to your Google Analytics property to enable metrics tracking on user sign up and sign in events.
