# Clerk JavaScript SDK
# джерело: https://clerk.com/docs/js-frontend/reference/overview
# отримано: 2026-09-26
# версія: core-3

The Clerk JavaScript SDK, or ClerkJS, is our foundational JavaScript library for building user management and authentication. It enables you to register, sign in, verify, and manage users for your application using highly customizable flows. It powers the other JavaScript SDKs, such as the React and Next.js SDKs. Refer to the JavaScript quickstart to get started.
