# BillingInitializedPaymentMethodResource
# джерело: https://clerk.com/docs/js-frontend/reference/types/billing-initialized-payment-method-resource
# отримано: 2026-09-25
# версія: core-3

The `BillingInitializedPaymentMethodResource` type represents a payment method that has been initialized for checkout session.

## Properties

| Property                                                 | Type                  | Description                                                                                                                                                                |
| -------------------------------------------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `externalClientSecret` | `string`              | A client secret from an external payment provider (such as Stripe) used to complete the payment on the client-side.                                                        |
|  `externalGatewayId`       | `string`              | The unique identifier for the external payment gateway used for this checkout session.                                                                                     |
|  `id?`                                    | `string`              | The unique identifier of the resource.                                                                                                                                     |
|  `paymentMethodOrder`     | `string[]` | The order the payment methods will be displayed in when  renders. |
