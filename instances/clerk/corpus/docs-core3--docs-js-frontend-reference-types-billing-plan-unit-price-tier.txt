The `BillingPlanUnitPriceTier` type represents a single pricing tier for a unit type on a plan.

## Properties

| Property                                     | Type                                                                                             | Description                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
|  `endsAfterBlock` | `null | number`                                                                       | The final block this tier applies to. `null` means unlimited. |
|  `feePerBlock`       | BillingMoneyAmount | The fee charged for each block in this tier.                  |
|  `id`                         | `string`                                                                                         | The unique identifier of the unit price tier.                 |
|  `startsAtBlock`   | `number`                                                                                         | The first block number this tier applies to.                  |
