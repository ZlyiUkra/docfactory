# отримано: 2026-09-25
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingPlanUnitPrice` type represents unit pricing for a specific unit type (e.g., seats) on a plan.

## Properties

| Property                           | Type                                                                                                                                     | Description                                        |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
|  `blockSize` | `number`                                                                                                                                 | Number of units represented by one billable block. |
|  `name`           | `string`                                                                                                                                 | The unit name, for example `seats`.                |
|  `tiers`         | BillingPlanUnitPriceTier[] | Tiers that define how each block range is priced.  |
