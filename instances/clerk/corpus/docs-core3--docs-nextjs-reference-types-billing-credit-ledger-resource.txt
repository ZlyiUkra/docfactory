# BillingCreditLedgerResource
# джерело: https://clerk.com/docs/nextjs/reference/types/billing-credit-ledger-resource
# отримано: 2026-09-26
# версія: core-3

The `BillingCreditLedgerResource` type represents a credit ledger entry for the current payer or given Organization.

## Properties

| Property                             | Type                                                                                        | Description                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------- | -------------------------------------------------- |
|  `amount`         | BillingMoneyAmount | The amount of the credit ledger entry.             |
|  `createdAt`   | `Date`                                                                                      | The date when the credit ledger entry was created. |
|  `id`                 | `string`                                                                                    | The ID of the credit ledger entry.                 |
|  `sourceId`     | `string`                                                                                    | The ID of the source of the credit ledger entry.   |
|  `sourceType` | `string`                                                                                    | The type of the source of the credit ledger entry. |
