# BillingDiscountRedemption
# джерело: https://clerk.com/docs/nextjs/reference/types/billing-discount-redemption
# отримано: 2026-09-25
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

A discount redemption applied to a subscription item.

## Properties

| Property                                             | Type                                                                                        | Description                                                                                                                                                                         |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `amount?`                        | BillingMoneyAmount | The monetary value of the discount applied to the subscription item.                                                                                                                |
|  `amountOff?`                  | BillingMoneyAmount | The configured fixed amount off when `effect` is `'fixed_amount'`. This is the discount's configured value, which can differ from the `amount` actually applied to the transaction. |
|  `cyclesApplied`           | `number`                                                                                    | The number of billing cycles to which the discount has already been applied.                                                                                                        |
|  `cyclesRemaining`       | `null | number`                                                                  | The number of billing cycles for which the discount remains active. `null` means the discount does not expire after a fixed number of cycles.                                       |
|  `discountId`                 | `string`                                                                                    | The unique identifier of the redeemed discount.                                                                                                                                     |
|  `effect?`                        | `"percentage" | "fixed_amount"`                                                  | Whether the discount subtracts a percentage or a fixed amount.                                                                                                                      |
|  `id`                                 | `string`                                                                                    | The unique identifier of the discount redemption.                                                                                                                                   |
|  `name`                             | `string`                                                                                    | The display name of the discount.                                                                                                                                                   |
|  `percentOff?`                | `number`                                                                                    | The percentage deducted when `effect` is `'percentage'`.                                                                                                                            |
|  `promoCode?`                  | `string`                                                                                    | The promotion code used to redeem the discount.                                                                                                                                     |
|  `redeemedAt`                 | `Date`                                                                                      | The date and time when the discount was redeemed.                                                                                                                                   |
|  `redeemedBy`                 | `null | string`                                                                  | The identifier of the user who redeemed the discount. `null` if no user was recorded.                                                                                               |
|  `source`                         | `"promotion" | "manual" | "promo_code"`                                          | How the discount was applied to the subscription item.                                                                                                                              |
|  `status?`                        | `"active" | "exhausted" | "removed"`                                             | The current status of the discount redemption.                                                                                                                                      |
|  `subscriptionItemId` | `string`                                                                                    | The unique identifier of the subscription item receiving the discount.                                                                                                              |
