# Options prop
# джерело: https://clerk.com/docs/react/guides/customizing-clerk/appearance-prop/options
# отримано: 2026-09-26
# версія: core-3

The `options` property can be used to change the layout and behavior of Clerk's prebuilt components, as well as set important links to your support, terms, and privacy pages.

## Usage

Pass the `appearance` prop to the  component. The `appearance` prop accepts the `options` property, which can be used to apply different changes to the widget.

```tsx
<ClerkProvider
  appearance={{
    options: {
      socialButtonsPlacement: 'bottom',
      socialButtonsVariant: 'iconButton',
      termsPageUrl: 'https://clerk.com/terms',
    },
  }}
>
  {/* ... */}
</ClerkProvider>
```
