# OrganizationCreationDefaults
# джерело: https://clerk.com/docs/react/reference/types/organization-creation-defaults
# отримано: 2026-09-26
# версія: core-3

An interface representing an Organization creation defaults.

| Name                                                                      | Type                                                     | Description |
| ------------------------------------------------------------------------- | -------------------------------------------------------- | ----------- |
| code - The advisory type. Currently only 'organization\_already\_exists'. | severity - The severity level. Currently only 'warning'. |             |
| name - The suggested Organization name.                                   | slug - The suggested Organization slug.                  |             |
