> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingSubscriptionItemNextPayment` type represents the upcoming payment details for a subscription item.

## Properties

| Property                                    | Type                                                                                                                           | Description                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- |
|  `amount`                | BillingMoneyAmount                              | The amount of the next payment.                             |
|  `date`                    | `Date`                                                                                                                         | The date when the next payment is due.                      |
|  `perUnitTotals?` | BillingPerUnitTotal[] | Per-unit cost breakdown for the next payment (e.g., seats). |
|  `totals?`               | BillingTotals                                         | Full cost breakdown for the next payment.                   |
