# OrganizationCustomRoleKey
# джерело: https://clerk.com/docs/react-router/reference/types/organization-custom-role-key
# отримано: 2026-09-25
# версія: core-3

`OrganizationCustomRoleKey` is a type that represents the user's Role in an Organization. It will be string unless the developer has provided their own types through `ClerkAuthorization`.

Clerk provides the default Roles `org:admin` and `org:member`. However, you can create Custom Roles as well.
