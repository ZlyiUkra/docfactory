# getAllowlistIdentifierList()
# джерело: https://clerk.com/docs/reference/backend/allowlist/get-allowlist-identifier-list
# отримано: 2026-09-25
# версія: core-3

Gets the list of allowlist identifiers for the instance. By default, the list is returned in descending order by creation date (newest first).

Returns a `PaginatedResourceResponse` object with a `data` property containing an array of `AllowlistIdentifier` objects and a `totalCount` property containing the total number of allowlist identifiers for the instance.

```typescript
function getAllowlistIdentifierList(params: ClerkPaginationRequest): Promise<PaginatedResourceResponse<AllowlistIdentifier[]>>
```

## `ClerkPaginationRequest`

| Property                      | Type     | Description                                                                                                                                                                            |
| ----------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `limit?`   | `number` | Maximum number of items returned per request. Must be an integer greater than zero and less than `501`. Can be used for paginating the results together with offset. Defaults to `10`. |
|  `offset?` | `number` | Skip the first `offset` items when paginating. Needs to be an integer greater or equal to zero. To be used in conjunction with `limit`. Defaults to `0`.                               |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const response = await clerkClient.allowlistIdentifiers.getAllowlistIdentifierList()
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/allowlist-identifiers`. See the BAPI reference for more information.
