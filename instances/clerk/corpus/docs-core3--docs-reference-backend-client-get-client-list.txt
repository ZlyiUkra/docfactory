# getClientList() (Deprecated)
# джерело: https://clerk.com/docs/reference/backend/client/get-client-list
# отримано: 2026-09-26
# версія: core-3

> **Deprecated:** This method is deprecated and will be removed in a future version. There is no direct replacement for listing all clients. To retrieve a specific client, use `getClient()` instead.

```tsx
const clients = await clerkClient.clients.getClientList()
```
