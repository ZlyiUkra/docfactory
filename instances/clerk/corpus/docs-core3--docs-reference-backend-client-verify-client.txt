# verifyClient()
# джерело: https://clerk.com/docs/reference/backend/client/verify-client
# отримано: 2026-09-26
# версія: core-3

Verifies the client in the given token.

Returns the verified `Client`.

```typescript
function verifyClient(token: string): Promise<Client>
```

## Parameters

| Parameter | Type     | Description          |
| --------- | -------- | -------------------- |
| `token`   | `string` | The token to verify. |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const token = 'my-session-token'

const response = await clerkClient.clients.verifyClient(token)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/clients/verify`. See the BAPI reference for more information.
