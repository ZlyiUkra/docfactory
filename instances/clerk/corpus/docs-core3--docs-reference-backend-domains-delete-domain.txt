# deleteDomain() (Deprecated)
# джерело: https://clerk.com/docs/reference/backend/domains/delete-domain
# отримано: 2026-09-25
# версія: core-3

> **Deprecated:** This method is deprecated. Use the `delete()` method instead.

Deletes a domain for the instance. You can't delete the active domain. Returns a `DeletedObject`.

```ts
function deleteDomain(domainId: string): Promise<DeletedObject>
```

## Parameters

| Name     | Type   | Description                     |
| -------- | ------ | ------------------------------- |
| domainId | string | The ID of the domain to delete. |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const response = await clerkClient.domains.deleteDomain('domain_123')
```
