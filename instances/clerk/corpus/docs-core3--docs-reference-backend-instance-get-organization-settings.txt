# getOrganizationSettings()
# джерело: https://clerk.com/docs/reference/backend/instance/get-organization-settings
# отримано: 2026-09-26
# версія: core-3

Gets the Organization-related settings for the current instance.

Returns the `OrganizationSettings` object.

```typescript
function getOrganizationSettings(): Promise<OrganizationSettings>
```

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```ts
const response = await clerkClient.instances.getOrganizationSettings()
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/instance/organization_settings`. See the BAPI reference for more information.
