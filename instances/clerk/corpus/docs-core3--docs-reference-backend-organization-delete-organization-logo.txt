# deleteOrganizationLogo()
# джерело: https://clerk.com/docs/reference/backend/organization/delete-organization-logo
# отримано: 2026-09-25
# версія: core-3

Deletes the logo of the given Organization.

Returns the deleted `Organization`.

```typescript
function deleteOrganizationLogo(organizationId: string): Promise<Organization>
```

## Parameters

| Parameter        | Type     | Description                                        |
| ---------------- | -------- | -------------------------------------------------- |
| `organizationId` | `string` | The ID of the Organization to delete the logo for. |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const organizationId = 'org_123'

const response = await clerkClient.organizations.deleteOrganizationLogo(organizationId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/organizations/{organization_id}/logo`. See the BAPI reference for more information.
