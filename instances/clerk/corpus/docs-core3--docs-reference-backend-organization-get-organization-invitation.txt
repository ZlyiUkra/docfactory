# getOrganizationInvitation()
# джерело: https://clerk.com/docs/reference/backend/organization/get-organization-invitation
# отримано: 2026-09-25
# версія: core-3

Gets an `OrganizationInvitation`.

```typescript
function getOrganizationInvitation(params: GetOrganizationInvitationParams): Promise<OrganizationInvitation>
```

## `GetOrganizationInvitationParams`

| Property                                     | Type     | Description                                           |
| -------------------------------------------- | -------- | ----------------------------------------------------- |
|  `invitationId`     | `string` | The ID of the Organization invitation to get.         |
|  `organizationId` | `string` | The ID of the Organization to get the invitation for. |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const organizationId = 'org_123'

const invitationId = 'orginv_123'

const response = await clerkClient.organizations.getOrganizationInvitation({
  organizationId,
  invitationId,
})
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/organizations/{organization_id}/invitations/{invitation_id}`. See the BAPI reference for more information.
