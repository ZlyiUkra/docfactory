# updateOrganization()
# джерело: https://clerk.com/docs/reference/backend/organization/update-organization
# отримано: 2026-09-25
# версія: core-3

Updates an Organization.

Returns the updated Organization.

```typescript
function updateOrganization(organizationId: string, params: { adminDeleteEnabled?: boolean; maxAllowedMemberships?: number; name?: string; privateMetadata?: OrganizationPrivateMetadata; publicMetadata?: OrganizationPublicMetadata; slug?: string }): Promise<Organization>
```

## Parameters

| Parameter                       | Type                                                                                                                                                                                                                                                                                                                                                                                              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `organizationId`                | `string`                                                                                                                                                                                                                                                                                                                                                                                          | The ID of the Organization to update.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `params`                        | { adminDeleteEnabled?: boolean; maxAllowedMemberships?: number; name?: string; privateMetadata?: OrganizationPrivateMetadata; publicMetadata?: OrganizationPublicMetadata; slug?: string; } | The parameters to update the Organization with.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `params.adminDeleteEnabled?`    | `boolean`                                                                                                                                                                                                                                                                                                                                                                                         | Whether the Organization allows admins to delete users.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `params.maxAllowedMemberships?` | `number`                                                                                                                                                                                                                                                                                                                                                                                          | The maximum number of memberships allowed in the Organization. `0` means unlimited.                                                                                                                                                                                                                                                                                                                                                                                         |
| `params.name?`                  | `string`                                                                                                                                                                                                                                                                                                                                                                                          | The name to update the Organization with.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `params.privateMetadata?`       | OrganizationPrivateMetadata                                                                                                                                                                                                                                                                                     | **Deprecated.** Updating metadata via `updateOrganization()` is deprecated. Use `updateOrganizationMetadata()` for partial updates (deep merge) or `replaceOrganizationMetadata()` for full replacement. |
| `params.publicMetadata?`        | OrganizationPublicMetadata                                                                                                                                                                                                                                                                                       | **Deprecated.** Updating metadata via `updateOrganization()` is deprecated. Use `updateOrganizationMetadata()` for partial updates (deep merge) or `replaceOrganizationMetadata()` for full replacement. |
| `params.slug?`                  | `string`                                                                                                                                                                                                                                                                                                                                                                                          | The slug to update the Organization with.                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const organizationId = 'org_123'
const name = 'Test Updated'

const response = await clerkClient.organizations.updateOrganization(organizationId, { name })
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `PATCH/organizations/{organization_id}`. See the BAPI reference for more information.
