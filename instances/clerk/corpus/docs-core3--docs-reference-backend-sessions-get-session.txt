# getSession()
# джерело: https://clerk.com/docs/reference/backend/sessions/get-session
# отримано: 2026-09-25
# версія: core-3

Gets the given `Session`.

```typescript
function getSession(sessionId: string): Promise<Session>
```

## Parameters

| Parameter   | Type     | Description                   |
| ----------- | -------- | ----------------------------- |
| `sessionId` | `string` | The ID of the session to get. |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const sessionId = 'sess_123'

const response = await clerkClient.sessions.getSession(sessionId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/sessions/{session_id}`. See the BAPI reference for more information.
