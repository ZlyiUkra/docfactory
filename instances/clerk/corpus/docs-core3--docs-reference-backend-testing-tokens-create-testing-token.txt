# createTestingToken()
# джерело: https://clerk.com/docs/reference/backend/testing-tokens/create-testing-token
# отримано: 2026-09-25
# версія: core-3

Creates a Testing Token for the instance.

Returns the created `TestingToken` object.

```typescript
function createTestingToken(): Promise<TestingToken>
```

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const response = await clerk.testingTokens.createTestingToken()
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/testing_tokens`. See the BAPI reference for more information.
