# The Backend AgentTask object
# джерело: https://clerk.com/docs/reference/backend/types/backend-agent-task
# отримано: 2026-09-26
# версія: core-3

The Backend `AgentTask` object represents an Agent Task resource. Agent Tasks are used for testing purposes and allow creating sessions for users without requiring full authentication flows.

## Properties

| Property                               | Type     | Description                                                                                                                                                                                                                                                        |
| -------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  `agentId`         | `string` | The identifier for the agent, unique per `agent_name` within an instance.                                                                                                                                                                                          |
|  `agentTaskId` | `string` | The unique identifier for this Agent Task.                                                                                                                                                                                                                         |
|  ~~`taskId`~~       | `string` | **Deprecated.** Use `agentTaskId` instead.                                                                                                                                                                                                                         |
|  `url`                 | `string` | The Frontend API URL that, when visited, creates a session for the user. Only returned by `create()`; omitted from `revoke()`. |
