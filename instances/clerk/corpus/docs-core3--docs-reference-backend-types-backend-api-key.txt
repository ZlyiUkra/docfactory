# The Backend APIKey object
# джерело: https://clerk.com/docs/reference/backend/types/backend-api-key
# отримано: 2026-09-25
# версія: core-3

The Backend `APIKey` object holds information about an API key.

## Properties

| Property                                         | Type                                    | Description                                                                                         |
| ------------------------------------------------ | --------------------------------------- | --------------------------------------------------------------------------------------------------- |
|  `claims`                     | null | Record<string, any> | Custom claims associated with the API key.                                                          |
|  `createdAt`               | `number`                                | The Unix timestamp (in milliseconds) when the API key was created.                                  |
|  `createdBy`               | `null | string`              | The user ID for the user creating the API key.                                                      |
|  `description`           | `null | string`              | A description for the API key.                                                                      |
|  `expiration`             | `null | number`              | The Unix timestamp (in milliseconds) when the API key expires. `null` if the API key never expires. |
|  `expired`                   | `boolean`                               | Whether the API key has expired.                                                                    |
|  `id`                             | `string`                                | The unique identifier for the API key.                                                              |
|  `lastUsedAt`             | `null | number`              | The Unix timestamp (in milliseconds) when the API key was last used to authenticate a request.      |
|  `name`                         | `string`                                | The API key's name.                                                                                 |
|  `revocationReason` | `null | string`              | The reason for revoking the API key, if it has been revoked.                                        |
|  `revoked`                   | `boolean`                               | Whether the API key has been revoked.                                                               |
|  `scopes`                     | `string[]`                   | An array of scopes that define what the API key can access.                                         |
|  `secret?`                    | `string`                                | The API key secret.                                                                                 |
|  `subject`                   | `string`                                | The user or organization ID that the API key is associated with.                                    |
|  `type`                         | `string`                                | The type of the API key. Currently always `'api_key'`.                                              |
|  `updatedAt`               | `number`                                | The Unix timestamp (in milliseconds) when the API key was last updated.                             |
