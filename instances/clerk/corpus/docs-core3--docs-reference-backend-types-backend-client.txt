# The Backend Client object
# джерело: https://clerk.com/docs/reference/backend/types/backend-client
# отримано: 2026-09-26
# версія: core-3

The Backend `Client` object is similar to the Client object as it holds information about the authenticated sessions in the current device. However, the Backend `Client` object is different from the `Client` object in that it is used in the Backend API and is not directly accessible from the Frontend API.

## Properties

| Property                                                             | Type                                                                                                                                | Description                                                                                                                      |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
|  `createdAt`                                   | `number`                                                                                                                            | The Unix timestamp when the `Client` was first created.                                                                          |
|  `id`                                                 | `string`                                                                                                                            | The unique identifier for the `Client`.                                                                                          |
|  `lastActiveSessionId`               | `null | string`                                                                                                          | The ID of the last active `Session`.                        |
|  `lastAuthenticationStrategy` | null | LastAuthenticationStrategy | The last authentication strategy used by the `Client`.                                                                           |
|  `sessionIds`                                 | `string[]`                                                                                                               | An array of Session IDs associated with the `Client`.       |
|  `sessions`                                     | Session[]                              | An array of `Session` objects associated with the `Client`. |
|  `signInId`                                     | `null | string`                                                                                                          | The ID of the associated SignIn.                                          |
|  `signUpId`                                     | `null | string`                                                                                                          | The ID of the associated SignUp.                                          |
|  `updatedAt`                                   | `number`                                                                                                                            | The Unix timestamp when the `Client` was last updated.                                                                           |
