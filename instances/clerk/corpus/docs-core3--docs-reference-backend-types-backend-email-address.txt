# The Backend EmailAddress object
# джерело: https://clerk.com/docs/reference/backend/types/backend-email-address
# отримано: 2026-09-25
# версія: core-3

The Backend `EmailAddress` object is a model around an email address.

Email addresses must be **verified** to ensure that they are assigned to their rightful owners. The `EmailAddress` object holds all necessary state around the verification process.

For implementation examples for adding and verifying email addresses, see the email link custom flow and email code custom flow guides.

## Properties

| Property                                 | Type                                                                                                                          | Description                                                                                                     |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
|  `emailAddress` | `string`                                                                                                                      | The value of the email address.                                                                                 |
|  `id`                     | `string`                                                                                                                      | The unique identifier for the email address.                                                                    |
|  `linkedTo`         | IdentificationLink[] | An array of objects containing information about any identifications that might be linked to the email address. |
|  `verification` | null | Verification         | An object holding information on the verification of the email address.                                         |
