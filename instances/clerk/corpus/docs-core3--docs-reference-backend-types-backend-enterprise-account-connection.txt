# The Backend EnterpriseAccountConnection object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-account-connection
# отримано: 2026-09-25
# версія: core-3

The Backend `EnterpriseAccountConnection` object represents an enterprise SSO connection associated with an enterprise account.

## Properties

| Property                                                                         | Type                       | Description                                                                                   |
| -------------------------------------------------------------------------------- | -------------------------- | --------------------------------------------------------------------------------------------- |
|  `active`                                                     | `boolean`                  | Whether the connection is currently active.                                                   |
|  `allowIdpInitiated`                               | `boolean`                  | Whether IdP-initiated SSO is allowed.                                                         |
|  `allowSubdomains`                                   | `boolean`                  | Whether subdomains are allowed for this connection.                                           |
|  `createdAt`                                               | `number`                   | The Unix timestamp when this connection was created.                                          |
|  `disableAdditionalIdentifications` | `boolean`                  | Whether additional identifications are disabled for users authenticating via this connection. |
|  `domain`                                                     | `string`                   | The domain associated with this connection.                                                   |
|  `id`                                                             | `string`                   | The unique identifier for this enterprise connection.                                         |
|  `logoPublicUrl`                                       | `null | string` | The public URL of the connection's logo, if available.                                        |
|  `name`                                                         | `string`                   | The name of the enterprise connection.                                                        |
|  `protocol`                                                 | `string`                   | The SSO protocol used (e.g., `saml` or `oauth`).                                              |
|  `provider`                                                 | `string`                   | The SSO provider (e.g., `saml_custom`, `saml_okta`).                                          |
|  `syncUserAttributes`                             | `boolean`                  | Whether user attributes are synced from the IdP.                                              |
|  `updatedAt`                                               | `number`                   | The Unix timestamp when this connection was last updated.                                     |
