# The Backend EnterpriseAccount object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-account
# отримано: 2026-09-26
# версія: core-3

The Backend `EnterpriseAccount` object represents an identification obtained via enterprise SSO (SAML or OIDC).

## Properties

| Property                                                     | Type                                                                                                                                                  | Description                                                                                               |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
|  `active`                                 | `boolean`                                                                                                                                             | Whether this enterprise account is currently active.                                                      |
|  `emailAddress`                     | `string`                                                                                                                                              | The email address associated with this enterprise account.                                                |
|  `enterpriseConnection`     | null | EnterpriseAccountConnection | The enterprise connection through which this account was authenticated.                                   |
|  `enterpriseConnectionId` | `null | string`                                                                                                                            | The ID of the enterprise connection associated with this account.                                         |
|  `firstName`                           | `null | string`                                                                                                                            | The user's first name as provided by the IdP.                                                             |
|  `id`                                         | `string`                                                                                                                                              | The unique identifier for this enterprise account.                                                        |
|  `lastAuthenticatedAt`       | `null | number`                                                                                                                            | The date when the user last authenticated via this enterprise account.                                    |
|  `lastName`                             | `null | string`                                                                                                                            | The user's last name as provided by the IdP.                                                              |
|  `protocol`                             | `string`                                                                                                                                              | The SSO protocol used (e.g., `saml` or `oauth`).                                                          |
|  `provider`                             | `string`                                                                                                                                              | The SSO provider (e.g., `saml_custom`, `saml_okta`).                                                      |
|  `providerUserId`                 | `null | string`                                                                                                                            | The unique ID of the user in the provider.                                                                |
|  `publicMetadata`                 | `Record`<`string`, `unknown`>                                                                                                                        | Metadata that can be read from the Frontend API and Backend API and can be set only from the Backend API. |
|  `verification`                     | null | Verification                                 | An object holding information on the verification of this enterprise account.                             |
