# The Backend EnterpriseConnectionCustomAttribute object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-connection-custom-attribute
# отримано: 2026-09-25
# версія: core-3

A custom attribute mapping included on a Backend API EnterpriseConnection response.

## Properties

| Property                               | Type      | Description                                                   |
| -------------------------------------- | --------- | ------------------------------------------------------------- |
|  `key`                 | `string`  | The key the custom attribute is stored under.                 |
|  `multiValued` | `boolean` | Whether the custom attribute holds multiple values.           |
|  `name`               | `string`  | The display name of the custom attribute.                     |
|  `scimPath`       | `string`  | The SCIM attribute path the value is read from.               |
|  `ssoPath`         | `string`  | The SSO (SAML or OIDC) attribute path the value is read from. |
