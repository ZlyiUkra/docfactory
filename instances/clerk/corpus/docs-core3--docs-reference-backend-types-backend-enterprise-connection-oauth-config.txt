# The Backend EnterpriseConnectionOauthConfig object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-connection-oauth-config
# отримано: 2026-09-26
# версія: core-3

OAuth configuration included on a Backend API EnterpriseConnection response.

## Properties

| Property                                   | Type                            | Description                                                                |
| ------------------------------------------ | ------------------------------- | -------------------------------------------------------------------------- |
|  `authUrl`             | `undefined | string` | The OAuth authorization URL.                                               |
|  `clientId`           | `undefined | string` | The OAuth client ID.                                                       |
|  `createdAt`         | `number`                        | The date when the configuration was first created.                         |
|  `discoveryUrl`   | `undefined | string` | The OpenID Connect discovery URL.                                          |
|  `id`                       | `string`                        | The unique identifier for the OAuth configuration.                         |
|  `logoPublicUrl` | `undefined | string` | The public URL of the OAuth provider logo, if available.                   |
|  `name`                   | `string`                        | The name to use as a label for the configuration.                          |
|  `providerKey`     | `string`                        | The OAuth provider key of the configuration. For example, `'custom_oidc'`. |
|  `requiresPkce`   | `boolean`                       | Whether the OAuth configuration requires PKCE.                             |
|  `tokenUrl`           | `undefined | string` | The OAuth token URL.                                                       |
|  `updatedAt`         | `number`                        | The date when the configuration was last updated.                          |
|  `userInfoUrl`     | `undefined | string` | The OAuth user info URL.                                                   |
