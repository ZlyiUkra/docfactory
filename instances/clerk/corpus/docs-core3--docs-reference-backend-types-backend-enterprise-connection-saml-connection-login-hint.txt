# The Backend EnterpriseConnectionSamlConnectionLoginHint object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-connection-saml-connection-login-hint
# отримано: 2026-09-26
# версія: core-3

The `login_hint` configuration included on a Backend API EnterpriseConnectionSamlConnection response.

## Properties

| Property                      | Type                                                      | Description                                                                                                                                                                                                                                       |
| ----------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `mode`      | `"email_address" | "custom_attribute" | "off"` | How the SAML connection emits the `login_hint` sent to the IdP: `'email_address'` sends the typed identifier, `'custom_attribute'` sends the value stored at the user `publicMetadata` key named by `source`, and `'off'` omits the `login_hint`. |
|  `source?` | `string`                                                  | The user `publicMetadata` key the `login_hint` value is read from. Only set when `mode` is `'custom_attribute'`.                                                                                                                                  |
