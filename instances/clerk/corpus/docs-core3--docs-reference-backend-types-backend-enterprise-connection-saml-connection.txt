# The Backend EnterpriseConnectionSamlConnection object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-connection-saml-connection
# отримано: 2026-09-26
# версія: core-3

The Backend `EnterpriseConnectionSamlConnection` object holds information about a SAML enterprise connection for an instance or organization.

## Properties

| Property                                                       | Type                                                                                                                                                        | Description                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `acsUrl`                                   | `undefined | string`                                                                                                                             | The Assertion Consumer Service (ACS) URL of the connection.                                                                                                                                                                                                                                                                                               |
|  `active`                                   | `boolean`                                                                                                                                                   | Whether the SAML connection is active.                                                                                                                                                                                                                                                                                                                    |
|  `allowIdpInitiated`             | `boolean`                                                                                                                                                   | Whether IdP-initiated SSO is allowed.                                                                                                                                                                                                                                                                                                                     |
|  `allowSubdomains`                 | `boolean`                                                                                                                                                   | Whether users with an email address subdomain are allowed to use this connection.                                                                                                                                                                                                                                                                         |
|  `forceAuthn`                           | `boolean`                                                                                                                                                   | Whether the SAML connection requires force authentication.                                                                                                                                                                                                                                                                                                |
|  `id`                                           | `string`                                                                                                                                                    | The unique identifier for the SAML connection.                                                                                                                                                                                                                                                                                                            |
|  `idpCertificate`                   | `undefined | string`                                                                                                                             | The X.509 certificate as provided by the Identity Provider (IdP).                                                                                                                                                                                                                                                                                         |
|  `idpCertificateExpiresAt` | `undefined | number`                                                                                                                             | The Unix timestamp when the Identity Provider (IdP) certificate expires.                                                                                                                                                                                                                                                                                  |
|  `idpCertificateIssuedAt`   | `undefined | number`                                                                                                                             | The Unix timestamp when the Identity Provider (IdP) certificate was issued.                                                                                                                                                                                                                                                                               |
|  `idpEntityId`                         | `undefined | string`                                                                                                                             | The Entity ID as provided by the Identity Provider (IdP).                                                                                                                                                                                                                                                                                                 |
|  ~~`idpMetadata`~~                     | `undefined | string`                                                                                                                             | The XML content of the Identity Provider (IdP) metadata file. **Deprecated.** The Backend API does not return this field, so it is always `undefined`.                                                                                                                                                                                                    |
|  `idpMetadataUrl`                   | `undefined | string`                                                                                                                             | The URL which serves the Identity Provider (IdP) metadata.                                                                                                                                                                                                                                                                                                |
|  `idpSsoUrl`                             | `undefined | string`                                                                                                                             | The Single-Sign On URL as provided by the Identity Provider (IdP).                                                                                                                                                                                                                                                                                        |
|  `loginHint`                             | `EnterpriseConnectionSamlConnectionLoginHint` | The `login_hint` configuration of the SAML connection.                                                                                                                                                                                                                                                                                                    |
|  `name`                                       | `string`                                                                                                                                                    | The name to use as a label for the connection.                                                                                                                                                                                                                                                                                                            |
|  `spEntityId`                           | `undefined | string`                                                                                                                             | The Entity ID as provided by the Service Provider (Clerk).                                                                                                                                                                                                                                                                                                |
|  `spMetadataUrl`                     | `undefined | string`                                                                                                                             | The metadata URL as provided by the Service Provider (Clerk).                                                                                                                                                                                                                                                                                             |
|  ~~`syncUserAttributes`~~       | `undefined | boolean`                                                                                                                            | Whether the connection syncs user attributes between the IdP and Clerk. **Deprecated.** The Backend API does not return this field on the nested SAML connection, so it is always `undefined`. Use the top-level `syncUserAttributes` on EnterpriseConnection instead. |
