# The Backend EnterpriseConnection object
# джерело: https://clerk.com/docs/reference/backend/types/backend-enterprise-connection
# отримано: 2026-09-25
# версія: core-3

The Backend `EnterpriseConnection` object holds information about an enterprise connection (SAML or OAuth) for an instance or organization.

## Properties

| Property                                                                         | Type                                                                                                                                                                          | Description                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  `active`                                                     | `boolean`                                                                                                                                                                     | Whether the connection is active or not.                                                                                                                                                                                                         |
|  `allowOrganizationAccountLinking`   | `boolean`                                                                                                                                                                     | Whether existing users who are members of the organization can link their account to their enterprise identity.                                                                                                                                  |
|  ~~`allowSubdomains`~~                               | `undefined | boolean`                                                                                                                                              | Whether users with an email address subdomain are allowed to use this connection or not. **Deprecated.** The Backend API does not return this field at the top level, so it is always `undefined`. Use `samlConnection.allowSubdomains` instead. |
|  `authenticatable`                                   | `boolean`                                                                                                                                                                     | Whether the connection can be used for sign-in and sign-up.                                                                                                                                                                                      |
|  `createdAt`                                               | `number`                                                                                                                                                                      | The date when the connection was first created.                                                                                                                                                                                                  |
|  `customAttributes`                                 | undefined | EnterpriseConnectionCustomAttribute[] | The custom attribute mappings of the connection. Only returned when the custom attributes feature is enabled for the instance.                                                                                                                   |
|  `disableAdditionalIdentifications` | `boolean`                                                                                                                                                                     | Whether additional identifications are disabled for this connection.                                                                                                                                                                             |
|  `disableJitProvisioning`                     | `boolean`                                                                                                                                                                     | Whether Just-in-Time (JIT) provisioning of users is disabled for the connection.                                                                                                                                                                 |
|  `domains`                                                   | `string[]`                                                                                                                                                         | The domain of the enterprise. Sign-in flows using an email with this domain may use the connection.                                                                                                                                              |
|  `id`                                                             | `string`                                                                                                                                                                      | The unique identifier for the connection.                                                                                                                                                                                                        |
|  `logoPublicUrl`                                       | `undefined | string`                                                                                                                                               | The public URL of the provider logo, if available.                                                                                                                                                                                               |
|  `name`                                                         | `string`                                                                                                                                                                      | The name to use as a label for the connection.                                                                                                                                                                                                   |
|  `oauthConfig`                                           | null | EnterpriseConnectionOauthConfig                | OAuth (OIDC) configuration when the enterprise connection uses OAuth.                                                                                                                                                                            |
|  `organizationId`                                     | `null | string`                                                                                                                                                    | The Organization ID if the connection is scoped to an organization.                                                                                                                                                                              |
|  `provider`                                                 | `string`                                                                                                                                                                      | The identity provider (IdP) of the connection. For example, `'saml_custom'` or `'oidc_custom'`.                                                                                                                                                  |
|  `samlConnection`                                     | null | EnterpriseConnectionSamlConnection          | SAML connection details when the enterprise connection uses SAML.                                                                                                                                                                                |
|  `syncUserAttributes`                             | `boolean`                                                                                                                                                                     | Whether the connection syncs user attributes between the IdP and Clerk or not.                                                                                                                                                                   |
|  `updatedAt`                                               | `number`                                                                                                                                                                      | The date when the connection was last updated.                                                                                                                                                                                                   |
