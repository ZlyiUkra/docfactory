# The Backend InstanceRestrictions object
# джерело: https://clerk.com/docs/reference/backend/types/backend-instance-restrictions
# отримано: 2026-09-25
# версія: core-3

The `InstanceRestrictions` object represents the restrictions settings for the current instance.

## Properties

| Property                                                               | Type      | Description                                                                                                                                                                                               |
| ---------------------------------------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `allowlist`                                     | `boolean` | Whether the instance has **Allowlist** enabled.                                                                                   |
|  `blockDisposableEmailDomains` | `boolean` | Whether the instance has **Block sign-ups that use disposable email addresses** enabled. |
|  `blockEmailSubaddresses`           | `boolean` | Whether the instance has **Block email subaddresses** enabled.                                                     |
|  `blocklist`                                     | `boolean` | Whether the instance has **Blocklist** enabled.                                                                                   |
|  `ignoreDotsForGmailAddresses` | `boolean` | Whether the instance is set to ignore dots for Gmail addresses.                                                    |
