# The Backend M2MToken object
# джерело: https://clerk.com/docs/reference/backend/types/backend-m2m-token
# отримано: 2026-09-25
# версія: core-3

The Backend `M2MToken` object holds information about a machine-to-machine token.

## Properties

| Property                                         | Type                                    | Description                                                               |
| ------------------------------------------------ | --------------------------------------- | ------------------------------------------------------------------------- |
|  `claims`                     | null | Record<string, any> | The claims of the M2M token.                                              |
|  `createdAt`               | `number`                                | The Unix timestamp (in milliseconds) when the M2M token was created.      |
|  `expiration`             | `null | number`              | The Unix timestamp (in milliseconds) when the M2M token expires.          |
|  `expired`                   | `boolean`                               | Whether the M2M token has expired.                                        |
|  `id`                             | `string`                                | The ID of the M2M token.                                                  |
|  `revocationReason` | `null | string`              | The reason for revoking the M2M token.                                    |
|  `revoked`                   | `boolean`                               | Whether the M2M token has been revoked.                                   |
|  `scopes`                     | `string[]`                   | The scopes of the M2M token.                                              |
|  `subject`                   | `string`                                | The subject of the M2M token.                                             |
|  `token?`                      | `string`                                | The token string.                                                         |
|  `updatedAt`               | `number`                                | The Unix timestamp (in milliseconds) when the M2M token was last updated. |
