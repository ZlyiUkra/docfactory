# The Backend MachineScope object
# джерело: https://clerk.com/docs/reference/backend/types/backend-machine-scope
# отримано: 2026-09-26
# версія: core-3

The Backend `MachineScope` object holds information about a machine scope.

## Properties

| Property                                   | Type      | Description                                                  |
| ------------------------------------------ | --------- | ------------------------------------------------------------ |
|  `createdAt?`        | `number`  | The Unix timestamp when the machine scope was created.       |
|  `deleted?`            | `boolean` | Whether the machine scope has been deleted.                  |
|  `fromMachineId` | `string`  | The ID of the machine that has access to the target machine. |
|  `toMachineId`     | `string`  | The ID of the machine that is being accessed.                |
