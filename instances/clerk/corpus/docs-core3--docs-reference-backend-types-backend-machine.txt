# The Backend Machine object
# джерело: https://clerk.com/docs/reference/backend/types/backend-machine
# отримано: 2026-09-26
# версія: core-3

The Backend Machine object holds information about a machine.

## Properties

| Property                                       | Type                                                                                                   | Description                                                                   |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
|  `createdAt`             | `number`                                                                                               | The Unix timestamp when the machine was created.                              |
|  `defaultTokenTtl` | `number`                                                                                               | The default time-to-live (TTL) in seconds for tokens created by this machine. |
|  `id`                           | `string`                                                                                               | The unique identifier for the machine.                                        |
|  `instanceId`           | `string`                                                                                               | The ID of the instance the machine belongs to.                                |
|  `name`                       | `string`                                                                                               | The name of the machine.                                                      |
|  `scopedMachines`   | Machine[] | The machines that the current machine has access to.                          |
|  `secretKey?`            | `string`                                                                                               | The secret key for the machine.                                               |
|  `updatedAt`             | `number`                                                                                               | The Unix timestamp when the machine was last updated.                         |
