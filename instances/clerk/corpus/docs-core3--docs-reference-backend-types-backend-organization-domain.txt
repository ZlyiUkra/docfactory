# The Backend OrganizationDomain object
# джерело: https://clerk.com/docs/reference/backend/types/backend-organization-domain
# отримано: 2026-09-26
# версія: core-3

The `OrganizationDomain` object is the model around an Organization's Verified Domain.

## Properties

| Property                                                       | Type                                                                                                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  `affiliationEmailAddress` | `null | string`                                                                                  | The email address used to verify the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|  `createdAt`                             | `number`                                                                                                    | The Unix timestamp when the domain was created.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|  `enrollmentMode`                   | `"manual_invitation" | "automatic_invitation" | "automatic_suggestion"`                          | The enrollment mode that determines how matching users are added to the Organization.  `manual_invitation`: No automatic enrollment. Users with a matching email domain are not given any invitation or suggestion; an admin must invite them manually. `automatic_invitation`: Users with a matching email domain automatically receive a pending invitation (assigned the Organization's default role) which they can accept to join. `automatic_suggestion`: Users with a matching email domain automatically receive a suggestion to join, which they can request.  |
|  `id`                                           | `string`                                                                                                    | The unique identifier of the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|  `name`                                       | `string`                                                                                                    | The name of the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|  `organizationId`                   | `string`                                                                                                    | The ID of the Organization that the domain belongs to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|  `totalPendingInvitations` | `number`                                                                                                    | The total number of pending invitations for the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|  `totalPendingSuggestions` | `number`                                                                                                    | The total number of pending suggestions for the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|  `updatedAt`                             | `number`                                                                                                    | The Unix timestamp when the domain was last updated.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|  `verification`                       | `null | { attempts: null | number; expireAt: null | number; status: string; strategy: string; }` | The verification details of the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| `verification.status`                                          | `string`                                                                                                    | The current status of the verification.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `verification.strategy`                                        | `string`                                                                                                    | The strategy used to verify the domain.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
