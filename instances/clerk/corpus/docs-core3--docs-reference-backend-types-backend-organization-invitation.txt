# The Backend OrganizationInvitation object
# джерело: https://clerk.com/docs/reference/backend/types/backend-organization-invitation
# отримано: 2026-09-25
# версія: core-3

The Backend `OrganizationInvitation` object is similar to the OrganizationInvitation object as it's the model around an Organization invitation. However, the Backend `OrganizationInvitation` object is different in that it's used in the Backend API and is not directly accessible from the Frontend API.

## Properties

| Property                                                      | Type                                                                                                                              | Description                                                                                                                                                  |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  `createdAt`                            | `number`                                                                                                                          | The Unix timestamp when the invitation was first created.                                                                                                    |
|  `emailAddress`                      | `string`                                                                                                                          | The email address of the user who is invited to the `Organization`.                |
|  `expiresAt`                            | `number`                                                                                                                          | The Unix timestamp when the invitation expires.                                                                                                              |
|  `id`                                          | `string`                                                                                                                          | The unique identifier for the `OrganizationInvitation`.                                                                                                      |
|  `organizationId`                  | `string`                                                                                                                          | The ID of the `Organization` that the user is invited to.                          |
|  `privateMetadata`                | OrganizationInvitationPrivateMetadata | Metadata that can be read and set only from the Backend API.                                                 |
|  `publicMetadata`                  | OrganizationInvitationPublicMetadata   | Metadata that can be read from the Frontend API and Backend API and can be set only from the Backend API.    |
|  `publicOrganizationData?` | `null | { has_image: boolean; id: string; image_url?: string; name: string; object: ObjectType; slug: string; }`       | Public data about the Organization that the user is invited to.                                                                                              |
| `publicOrganizationData?.has_image`                           | `boolean`                                                                                                                         | Whether the Organization has a profile image.                                                                                                                |
| `publicOrganizationData?.id`                                  | `string`                                                                                                                          | The unique identifier for the resource.                                                                                                                      |
| `publicOrganizationData?.image_url?`                          | `string`                                                                                                                          | Holds the default Organization profile image. Compatible with Clerk's Image Optimization. |
| `publicOrganizationData?.name`                                | `string`                                                                                                                          | The name of the Organization.                                                                                                                                |
| `publicOrganizationData?.object`                              | `ObjectType`                                                                                                                      | The type of the resource.                                                                                                                                    |
| `publicOrganizationData?.slug`                                | `string`                                                                                                                          | The slug of the Organization.                                                                                                                                |
|  `role`                                      | `string`                                                                                                                          | The Role of the invited user.                                         |
|  `roleName`                              | `string`                                                                                                                          | The name of the Role of the invited user.                             |
|  `status?`                                 | `"expired" | "revoked" | "pending" | "accepted"`                                                                       | The status of the invitation.                                                                                                                                |
|  `updatedAt`                            | `number`                                                                                                                          | The Unix timestamp when the invitation was last updated.                                                                                                     |
|  `url`                                        | `null | string`                                                                                                        | The URL that the user can use to accept the invitation.                                                                                                      |
