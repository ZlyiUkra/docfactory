# The Backend SignInToken object
# джерело: https://clerk.com/docs/reference/backend/types/backend-sign-in-token
# отримано: 2026-09-25
# версія: core-3

The Backend `SignInToken` object holds information about a sign-in token.

## Properties

| Property                           | Type     | Description                                         |
| ---------------------------------- | -------- | --------------------------------------------------- |
|  `createdAt` | `number` | The Unix timestamp when the token was created.      |
|  `id`               | `string` | The unique identifier for the token.                |
|  `status`       | `string` | The status of the token.                            |
|  `token`         | `string` | The token itself.                                   |
|  `updatedAt` | `number` | The Unix timestamp when the token was last updated. |
|  `url`             | `string` | The URL the token is for.                           |
|  `userId`       | `string` | The ID of the user the token is for.                |
