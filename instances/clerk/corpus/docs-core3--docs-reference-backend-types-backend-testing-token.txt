# The Backend TestingToken object
# джерело: https://clerk.com/docs/reference/backend/types/backend-testing-token
# отримано: 2026-09-26
# версія: core-3

The Backend `TestingToken` object holds information about a Testing Token.

## Properties

| Property                           | Type     | Description                                |
| ---------------------------------- | -------- | ------------------------------------------ |
|  `expiresAt` | `number` | The Unix timestamp when the token expires. |
|  `token`         | `string` | The token string.                          |
