# The Backend WaitlistEntry object
# джерело: https://clerk.com/docs/reference/backend/types/backend-waitlist-entry
# отримано: 2026-09-26
# версія: core-3

The Backend `WaitlistEntry` object holds information about a waitlist entry.

## Properties

| Property                                 | Type                                                                                                              | Description                                                  |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
|  `createdAt`       | `number`                                                                                                          | The Unix timestamp when the waitlist entry was created.      |
|  `emailAddress` | `string`                                                                                                          | The email address to add to the waitlist.                    |
|  `id`                     | `string`                                                                                                          | The unique identifier for the waitlist entry.                |
|  `invitation`     | null | Invitation | The invitation associated with the waitlist entry.           |
|  `isLocked?`        | `boolean`                                                                                                         | Whether the waitlist entry is locked.                        |
|  `status`             | `"pending" | "invited" | "completed" | "rejected"`                                                     | The status of the waitlist entry.                            |
|  `updatedAt`       | `number`                                                                                                          | The Unix timestamp when the waitlist entry was last updated. |
