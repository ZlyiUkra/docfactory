# Backend BillingPlan object
# джерело: https://clerk.com/docs/reference/backend/types/billing-plan
# отримано: 2026-09-26
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingPlan` object is similar to the BillingPlanResource object as it holds information about a Plan, as well as methods for managing it. However, the `BillingPlan` object is different in that it is used in the Backend API and is not directly accessible from the Frontend API.

## Properties

| Property                                         | Type                                                                                                                | Description                                                                                                                                      |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
|  `annualFee`               | null | BillingMoneyAmount | The annual fee of the Plan.                                                                                                                      |
|  `annualMonthlyFee` | null | BillingMoneyAmount | The annual fee of the Plan on a monthly basis.                                                                                                   |
|  `avatarUrl`               | `null | string`                                                                                          | The URL of the Plan's avatar image.                                                                                                              |
|  `description`           | `null | string`                                                                                          | The description of the Plan.                                                                                                                     |
|  `features`                 | Feature[]                                                                        | The Features the Plan offers.                                                       |
|  `fee`                           | null | BillingMoneyAmount | The monthly fee of the Plan.                                                                                                                     |
|  `forPayerType`         | `"user" | "org"`                                                                                         | The type of payer for the Plan.                                                                                                                  |
|  `freeTrialDays`       | `null | number`                                                                                          | The number of free trial days for this plan.                                                                                                     |
|  `freeTrialEnabled` | `boolean`                                                                                                           | Whether free trial is enabled for this plan.                                                                                                     |
|  `hasBaseFee`             | `boolean`                                                                                                           | Whether the Plan has a base fee.                                                                                                                 |
|  `id`                             | `string`                                                                                                            | The unique identifier for the Plan.                                                                                                              |
|  `isDefault`               | `boolean`                                                                                                           | Whether the Plan is the default Plan.                                                                                                            |
|  `isRecurring`           | `boolean`                                                                                                           | Whether the Plan is recurring.                                                                                                                   |
|  `name`                         | `string`                                                                                                            | The name of the Plan.                                                                                                                            |
|  `publiclyVisible`   | `boolean`                                                                                                           | Whether the Plan is displayed in the  component. |
|  `slug`                         | `string`                                                                                                            | The URL-friendly identifier of the Plan.                                                                                                         |
