# Backend Domain object
# джерело: https://clerk.com/docs/reference/backend/types/domain
# отримано: 2026-09-25
# версія: core-3

The `Domain` object represents a domain that is managed by the instance.

## Properties

| Property                                            | Type                       | Description                                                                                        |
| --------------------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------- |
|  `accountsPortalUrl?` | `null | string` | The Account Portal URL for the domain. |
|  `cnameTargets`            | `CnameTarget[]` | The CNAME targets for the domain.                                                                  |
|  `developmentOrigin`  | `string`                   | The development origin for the domain.                                                             |
|  `frontendApiUrl`        | `string`                   | The Frontend API URL for the domain.                                                               |
|  `id`                                | `string`                   | The unique identifier of the domain.                                                               |
|  `isSatellite`              | `boolean`                  | Whether the domain is a satellite domain.                                                          |
|  `name`                            | `string`                   | The name of the domain.                                                                            |
|  `proxyUrl?`                   | `null | string` | The proxy URL for the domain. |
