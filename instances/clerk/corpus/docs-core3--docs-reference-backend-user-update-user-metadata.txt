# updateUserMetadata()
# джерело: https://clerk.com/docs/reference/backend/user/update-user-metadata
# отримано: 2026-09-26
# версія: core-3

Updates the metadata for the given user, by merging existing values with the provided parameters.

A "deep" merge will be performed - "deep" means that any nested JSON objects will be merged as well. You can remove metadata keys at any level by setting their value to `null`.

> If you want to fully replace the existing metadata instead of merging, use `replaceUserMetadata()`.

Returns the updated `User`.

```typescript
function updateUserMetadata(userId: string, params: { privateMetadata?: UserPrivateMetadata; publicMetadata?: UserPublicMetadata; unsafeMetadata?: UserUnsafeMetadata }): Promise<User>
```

## Parameters

| Parameter                 | Type                                                                                                                                                                                                                                                                                                                                                                                           | Description                                                                                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `userId`                  | `string`                                                                                                                                                                                                                                                                                                                                                                                       | The ID of the user to update.                                                                                                                             |
| `params`                  | { privateMetadata?: UserPrivateMetadata; publicMetadata?: UserPublicMetadata; unsafeMetadata?: UserUnsafeMetadata; } | The metadata to update.                                                                                                                                   |
| `params.privateMetadata?` | UserPrivateMetadata                                                                                                                                                                                                                                                                                                  | Metadata that can be read and set only from the Backend API.                                              |
| `params.publicMetadata?`  | UserPublicMetadata                                                                                                                                                                                                                                                                                                    | Metadata that can be read from the Frontend API and Backend API and can be set only from the Backend API. |
| `params.unsafeMetadata?`  | UserUnsafeMetadata                                                                                                                                                                                                                                                                                                    | Metadata that can be read and set from the Frontend API. It's considered unsafe because it can be modified from the Frontend API.                         |

## Usage

> Using `clerkClient` varies based on the SDK you're using. Refer to the overview for usage details, including guidance on how to access the `userId` and other properties.

```tsx
const userId = 'user_123'

const response = await clerkClient.users.updateUserMetadata(userId, {
  publicMetadata: {
    example: 'metadata',
  },
})
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `PATCH/users/{user_id}/metadata`. See the BAPI reference for more information.

Here's an example of making a request directly to the endpoint using cURL.

Replace `YOUR_SECRET_KEY` with your Clerk Secret Key. You can find your Secret Key on the **API keys** page in the Clerk Dashboard.

filename: curl.sh
```bash
curl -XPATCH -H 'Authorization: Bearer {{secret}}' -H "Content-type: application/json" -d '{
  "public_metadata": {
    "birthday": "1990-01-01"
  }
}' 'https://api.clerk.com/v1/users/{user_id}/metadata'
```
