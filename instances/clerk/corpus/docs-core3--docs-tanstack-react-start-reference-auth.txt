# auth()
# джерело: https://clerk.com/docs/tanstack-react-start/reference/auth
# отримано: 2026-09-25
# версія: core-3

The `auth()` helper returns the `Auth` object of the currently active user.

## Parameters

| Name                                                                            | Type                                                                                                                        | Description |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------- |
| acceptsToken?: The type of authentication token(s) to accept. Valid values are: | treatPendingAsSignedOut?: A boolean that indicates whether to treat pending session status as signed out. Defaults to true. |             |

## Returns

`auth()` returns the `Auth` object.
