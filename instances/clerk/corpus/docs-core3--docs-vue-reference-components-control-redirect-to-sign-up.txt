# <RedirectToSignUp /> component
# джерело: https://clerk.com/docs/vue/reference/components/control/redirect-to-sign-up
# отримано: 2026-09-25
# версія: core-3

The `<RedirectToSignUp />` component will navigate to the sign up URL which has been configured in your application instance. The behavior will be just like a server-side (3xx) redirect, and will override the current location in the history stack.

## Example

filename: App.vue
```vue
<script setup lang="ts">
import { Show, RedirectToSignUp, UserButton } from '@clerk/vue'
</script>

<template>
  <Show when="signed-in">
    <UserButton />
  </Show>
  <Show when="signed-out">
    <RedirectToSignUp />
  </Show>
</template>
```
