# BillingPlanPrice
# джерело: https://clerk.com/docs/vue/reference/types/billing-plan-price
# отримано: 2026-09-26
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingPlanPrice` type represents a specific possible price for a given Clerk Billing Plan.

## Properties

| Property                                         | Type                                                                                                                    | Description                                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
|  `annualMonthlyFee` | null | BillingMoneyAmount | The effective monthly price when billed annually or `null` if the price is not annual. |
|  `fee`                           | null | BillingMoneyAmount | The monthly price or `null` if the price is not monthly.                               |
|  `id`                             | `string`                                                                                                                | The unique identifier of the price                                                     |
|  `isDefault`               | `boolean`                                                                                                               | Whether this price is the default price for the plan it's associated with.             |
|  `unitPrices?`            | BillingPlanUnitPrice[] | The individual unit prices applicable to this price.                                   |
