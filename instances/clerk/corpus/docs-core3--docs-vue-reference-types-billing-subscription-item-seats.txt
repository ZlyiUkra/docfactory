> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingSubscriptionItemSeats` type represents seat entitlements attached to a subscription item.

## Properties

| Property                         | Type                                                                                                                           | Description                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
|  `quantity` | `null | number`                                                                                                     | The seat limit active while the parent subscription item was active. `null` means unlimited. |
|  `tiers?`      | BillingPerUnitTotalTier[] | The tier-level breakdown of seats for this subscription item.                                |
