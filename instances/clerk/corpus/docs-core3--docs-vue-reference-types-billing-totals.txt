# BillingTotals
# джерело: https://clerk.com/docs/vue/reference/types/billing-totals
# отримано: 2026-09-25
# версія: core-3

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the pinning documentation.

The `BillingTotals` type represents a granular breakdown of the total amount that will be charged, either during
checkout or at renewal.

## Properties

| Property                                                      | Type                                                                                                                    | Description                                                |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
|  `baseFee`                                | null | BillingMoneyAmount | Base fee component before per-unit charges and adjustments |
|  `credit?`                                 | null | BillingMoneyAmount | Credit amount                                              |
|  `credits`                                | null | BillingCredits          | Unified credits breakdown                                  |
|  `discounts`                            | null | BillingDiscounts      | Information about the discounts applied to the payment     |
|  `grandTotal`                          | BillingMoneyAmount                                | Grand total amount                                         |
|  `pastDue?`                               | null | BillingMoneyAmount | Past due amount                                            |
|  `perUnitTotals?`                   | BillingPerUnitTotal[]   | Per-unit total breakdown (e.g., seats)                     |
|  `subtotal`                              | BillingMoneyAmount                                | Subtotal before adjustments                                |
|  `taxTotal`                              | BillingMoneyAmount                                | Total tax amount                                           |
|  `totalDueAfterFreeTrial?` | null | BillingMoneyAmount | Total amount due after free trial ends                     |
|  `totalDueNow?`                       | BillingMoneyAmount                                | Total amount due now                                       |
|  `totalDuePerPeriod?`           | BillingMoneyAmount                                | The expected total payment for each future billing period  |
|  `totalsDuePerPeriod?`         | BillingPeriodTotals                              | Per-period renewal totals, broken down granularly          |
