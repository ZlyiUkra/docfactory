Search the documentation of CuPy, the array library that runs NumPy- and SciPy-style code on NVIDIA CUDA and AMD ROCm GPUs. The corpus
holds docs.cupy.dev at the last release of every major from 1 to 14: the user guide (basics of `cupy.ndarray`, moving data between host
and device, memory pools, streams and events, user-defined kernels with `ElementwiseKernel`, `ReductionKernel`, `RawKernel` and
`cupyx.jit`, interoperability with NumPy, PyTorch and DLPack, performance best practices, differences from NumPy), the API reference of
every function in `cupy`, `cupyx`, `cupyx.scipy` and `cupy.cuda`, installation per CUDA version, and the upgrade guide between
versions; the GitHub release notes and the PyPI record.

Use this tool for: whether a NumPy function exists in CuPy and how it differs; how to move an array to the GPU and back, and what that
costs; why a GPU computation is slow and how to avoid synchronisation and copies; how the memory pool works and how to free memory;
how to write a custom kernel; which package to install for a given CUDA version; what changed between CuPy versions. Write the query
in English with the name of the function or class, such as `cupy.asnumpy` or `ElementwiseKernel`, or with plain words for what is
wanted. Give a version in the filter when the answer depends on it.

Do not use this tool for NumPy itself, CUDA C programming, PyTorch or RAPIDS. Returns the matching excerpts with the version each one
applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. CuPy 14 is the current major. Search without `version` first; when the user names the CuPy version
they use, search that version, written as `cupy-14`, `cupy-13` and so on.
