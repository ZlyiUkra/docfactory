Search the documentation of three Python libraries used to read Excel files, clean tables and find duplicate records: pandas,
openpyxl and RapidFuzz. The corpus holds, for pandas: the user guide, getting started and the what's new notes of the last patch of
every minor line 0.4-3.1, the API reference generated from the code for the lines 1.5-3.1, and the PyPI records of every stable
version. For openpyxl: the documentation of the lines 2.4-3.1 with the module reference, and the PyPI records of every stable version
with their README. For RapidFuzz: the current site, the documentation of the lines 0.12-3.14 and the PyPI records of every stable
version.

Use this tool for: reading and writing Excel with `pandas.read_excel`, `openpyxl.load_workbook` and worksheets, merging tables with
`DataFrame.merge` and `concat`, cleaning columns, `drop_duplicates` and `duplicated`, fuzzy matching with `rapidfuzz.process`,
`rapidfuzz.fuzz` and distance functions, and what changed between versions. Write the query in English, with the name of the
function or the page, such as `DataFrame.merge` or `fuzz.token_sort_ratio`. Give a version in the filter when the answer depends on it.

Do not use it for other Python libraries, for the Python language itself (a separate server holds it), or for Excel as a Microsoft
product. Older lines have gaps: the API reference of pandas older than 1.5 and the site of openpyxl older than 2.4 are no longer
published, so for those lines only the texts listed above exist. Returns the matching excerpts with the versions each one applies to,
the source address and the fetch date.
