# Примірник deep-learning-theory

Цей примірник шукає в матеріалах оксфордського курсу C6.5 Theories of Deep Learning і в книжках та статтях, на яких курс
стоїть. Глибоке навчання — це спосіб отримати програму не написанням правил, а підбором чисел на прикладах. Ці числа називаються
вагами нейронної мережі, і їх бувають мільйони. Мережа бачить тисячі підписаних фотографій і поступово сама налаштовує ваги
так, щоб відрізняти кота від собаки.
Курс питає, чому це взагалі працює: чому глибока мережа краща за мілку, чому навчання не застрягає, чому крихітна зміна
картинки може обдурити мережу і як цьому запобігти.

Курс читає Jared Tanner у Математичному інституті Оксфордського університету: 16 лекцій щоосені, магістерський рівень. Сайт
курсу на Moodle відкритий для гостя, тож примірник бере все, що гість бачить, за всі сім років, від 2020-21 до 2026-27.
Слайди самі по собі стислі: формула і кілька слів. Тому поруч лежать чотири книжки, які пояснюють ті самі теми повільніше, і
статті, на які посилаються слайди.

Навчальний план за цим примірником лежить у [LEARNING.md](LEARNING.md). Код практики пишеться на PyTorch, його документацію і
книжки тримає примірник [`pytorch`](../pytorch/README.md).

**Статті:** 97 статей arXiv, на які посилаються слайди всіх років, від Mallat, Group Invariant Scattering (2011) до статей
2024 року про спектр шарів уваги. Перелік із назвами записано в `sources.json`, джерело `papers`.

Усього 1675 документів, з них пошук будує 13 455 фрагментів. Фрагмент — це невеликий шматок тексту, який знаходить пошук.
Документ курсу — один PDF, а кожен слайд у ньому — окремий розділ із назвою кадру. Документ книжки — глава чи розділ за
закладками PDF. Документ статті — уся стаття, поділена на розділи за нумерованими заголовками.

Замір `quality` на 11.11.2026 дав такі числа. Запити назвами галузі («adversarial examples fast gradient sign method»)
знаходять потрібне 10 із 10, а модель зазвичай питає саме так. Запити своїми словами («крихітна непомітна зміна картинки
змушує класифікатор помилитися») знаходять потрібне 5 із 10.

**Чого немає.**

- Аркушів завдань 2021-22 і пізніших років немає: Moodle віддає їх лише після входу через Oxford SSO. Розв'язків немає за
  жоден рік, бо курс не видає їх студентам.
- Слайдів лекції 14 року 2024-25 немає: файл важить понад 50 МБ, а це стеля відповіді, яку фабрика завантажує.
- Відеозаписів лекцій і списку літератури немає: обидва за входом.
- Книжки Goodfellow, Bengio, Courville, Deep Learning, яку радить курс, немає. Сайт deeplearningbook.org віддає її як HTML,
  зверстаний з PDF, і для такого HTML потрібен окремий читач.

## Обмеження текстів

Формули в слайдах і книжках витягуються як плаский текст. Індекс іде слідом за символом через пробіл: `W ( i ) h ( i ) + b
( i )` означає W⁽ⁱ⁾h⁽ⁱ⁾ + b⁽ⁱ⁾. Великі дужки й знаки суми іноді лишаються окремими рядками. Пояснення словами від цього не
страждає, тому шукати краще словами навколо формули, а не самою формулою.

Приклади міні-проєктів курс викладає сканами без текстового шару, тому їхній текст розпізнано програмою OCR. Такий документ
починається з позначки про розпізнавання. Числа й формули в ньому треба звіряти з PDF.

## Як читаються файли

- `moodle-course` написано для цього примірника. Він бере сторінку курсу одного року й іде за кожним посиланням на матеріал.
  Ресурс береться за постійною адресою `view.php?id=`, бо адреса самого PDF містить номер ревізії, який змінюється з кожним
  оновленням файла. Слайди LaTeX Beamer він ріже по сторінках: слайд — розділ із назвою кадру, колонтитул із номером випадає, а
  сторінки покрокового показу того самого кадру зливаються в одну. Текст збирається зі шматків сторінки, бо LaTeX не ставить
  пробілу на межі шрифту чи кольору, і звичайне видобування склеювало слова («beingfully connectedand»). PDF без текстового
  шару розпізнає OCR. Розв'язки й шаблони LaTeX він пропускає, а поле `assign: false` вимикає вкладення завдань.
- `pdf-outline` ділить книжку на документи за закладками до глибини 2: глава й розділ.
- `pdf-list` бере кожну статтю arXiv як один документ і ділить її на розділи за нумерованими заголовками.

Сім років курсу зведено в родину `c65` у `config.json`. Тому слайд, що повторюється з року в рік без змін, займає у видачі одне
місце і показує найновіший рік.

## Корпус лише локально

Корпус — це тексти слайдів, глав і статей, а індекс — кеш фрагментів, з якого підіймається сервер. Слайди курсу не мають
ліцензії, а книжки належать видавцям, тому **корпус, індекс і сховище сирого в git не потрапляють** (`corpus/`, `index/`,
`raw/` і `out/` у `.gitignore`). У git лежать лише налаштування примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/deep-learning-theory-corpus-2026-11-11.tar.gz` разом із паспортом,
сховищем сирого і розпізнаними сторінками в `out/ocr/`. Копія лежить на Windows:
`C:\Distr\deep-learning-theory-corpus-2026-11-11.tar.gz`. Архів звірено з диском файл за файлом, а копію — за SHA-256.
Сервер підіймається з кешу `index/passages.json` і колекції Qdrant, тому тексти йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/deep-learning-theory-corpus-2026-11-11.tar.gz -C instances/deep-learning-theory
./df deep-learning-theory smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df deep-learning-theory vectors`: кеш збереться
заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df deep-learning-theory serve
```

Сервер слухає порт `8969`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user deep-learning-theory-docs http://127.0.0.1:8969/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. У сесії Claude Code команда `/mcp` має показати сервер
`deep-learning-theory-docs` з інструментами `search_docs` і `read_section`. Якщо порт зайнятий, `serve` скаже про це і не
підніметься: тоді сервер цього примірника вже працює в іншому терміналі. Якщо `/mcp` показує помилку з'єднання, сервер не
запущено.

Перевірка: `./df deep-learning-theory smoke` і `./df deep-learning-theory quality`.
