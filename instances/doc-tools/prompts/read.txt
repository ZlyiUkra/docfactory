Return the full text of one excerpt of the file tools documentation by its identifier, together with the page
or file it belongs to, every version whose documents contain this text, the URL it was taken from and the date
the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a command-line option and what it does, a man page section, a policy.xml rule, a delegate, a magic
rule, a C or Python function with its parameters, a ChangeLog or NEWS entry, a tag table row, a version table
from npm or PyPI.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the tool, the version and the page you read.
