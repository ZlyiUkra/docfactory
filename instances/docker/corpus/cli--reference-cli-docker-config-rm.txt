# docker config rm
# джерело: https://docs.docker.com/reference/cli/docker/config/rm
# отримано: 2026-10-02

**Description:** Remove one or more configs

**Usage:** `docker config rm CONFIG [CONFIG...]`

**Aliases:** `docker config remove`

**Orchestrator:** Swarm

## Description

Removes the specified configs from the Swarm.

For detailed information about using configs, refer to store configuration data using Docker Configs.

> [!NOTE]
> This is a cluster management command, and must be executed on a Swarm
> manager node. To learn about managers and workers, refer to the
> Swarm mode section in the
> documentation.

## Examples

This example removes a config:

```console
$ docker config rm my_config
sapth4csdo5b6wz2p5uimh5xg
```

> [!WARNING]
> This command doesn't ask for confirmation before removing a config.
{ .warning }
