# Docker Buildx release: v0.3.0
# джерело: https://github.com/docker/buildx/releases/tag/v0.3.0
# отримано: 2026-10-02
# версія: 0.3.0

Tag v0.3.0, published 2019-08-02.

### Notable Changes

* Custom buildkitd daemon flags https://github.com/docker/buildx/pull/102
* Environment variables are used in compose files https://github.com/docker/buildx/pull/117
* Fix bug where `--build-arg foo` would not read `foo` from environment  https://github.com/docker/buildx/pull/116
* Bake now honors `--no-cache` and `--pull` https://github.com/docker/buildx/pull/118
* Custom buildkit config file https://github.com/docker/buildx/pull/121
* Entitlements support with `build --allow` https://github.com/docker/buildx/pull/104
* Driver-specific options on `create` https://github.com/docker/buildx/pull/122
