# Docker Buildx release: v0.4.0
# джерело: https://github.com/docker/buildx/releases/tag/v0.4.0
# отримано: 2026-10-02
# версія: 0.4.0

Tag v0.4.0, published 2020-04-30.

### Notable Changes

* New driver: kubernetes https://medium.com/nttlabs/buildx-kubernetes-ad0fe59b0c64 https://github.com/docker/buildx/pull/167
* Upgrade bake to HCL2 with support for variables and functions https://github.com/docker/buildx/pull/192
* New global `--builder` flag to override builder instance for a single command https://github.com/docker/buildx/pull/246
* New `prune` and `du` commands for managing local builder cache https://github.com/docker/buildx/pull/249
* Bake now supports `--load` and `--push` https://github.com/docker/buildx/pull/164
* Bake now supports wildcard overrides for multiple targets, eg. `--set *.platform=linux/arm64` https://github.com/docker/buildx/pull/164
* New `pull` and `no-cache` options can be set for HCL targets https://github.com/docker/buildx/pull/165/
* Container driver allows setting environment variables via driver-opt https://github.com/docker/buildx/pull/170

Please try out the release binaries and report any issues at
https://github.com/docker/buildx/issues.
