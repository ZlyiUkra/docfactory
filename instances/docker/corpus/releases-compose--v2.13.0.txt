Tag v2.13.0, published 2022-11-23.

## What's Changed

### ✨ Enhancements

* Add `--no-consistency` flag to convert command by @glours in https://github.com/docker/compose/pull/9976
* Add `--build` to `compose run` by @laurazard in https://github.com/docker/compose/pull/10007
* Display creation warnings from the engine by @glours in https://github.com/docker/compose/pull/9998

### 🐛 Fixes

* Map deploy.restart_policy.condition to engine values by @glours in https://github.com/docker/compose/pull/9944
* Add support of deploy.reservation.memory by @glours in https://github.com/docker/compose/pull/9947
* Use COMPOSE_PROFILES value only if no command line arg profiles used by @glours in https://github.com/docker/compose/pull/9906
* Check if a missing image won't be build via a service declared in depends_on section by @glours in https://github.com/docker/compose/pull/9984
* Ignore error parsing container number label, just warn by @ndeloof in https://github.com/docker/compose/pull/10005
* Use platform defined by DOCKER_DEFAULT_PLATFORM when pulling and no service platform defined by @glours in https://github.com/docker/compose/pull/9999

### 🔧 Internal

* Remove uses of deprecated gotest.tools v2 by @thaJeztah in https://github.com/docker/compose/pull/9935
* Ci: update dependencies to latest by @milas in https://github.com/docker/compose/pull/9982
* Exclude issues with the `kind/feature` label from stale bot process by @glours in https://github.com/docker/compose/pull/9992

### Bumps

* build(deps): bump github.com/stretchr/testify from 1.8.0 to 1.8.1 by @dependabot in https://github.com/docker/compose/pull/9945
* build(deps): bump github.com/containerd/containerd from 1.6.8 to 1.6.9 by @dependabot in https://github.com/docker/compose/pull/9949
* build(deps): bump github.com/containerd/containerd from 1.6.9 to 1.6.10 by @dependabot in https://github.com/docker/compose/pull/9995
* go.mod: update docker-credential-helpers v0.7.0 by @thaJeztah in https://github.com/docker/compose/pull/9936
