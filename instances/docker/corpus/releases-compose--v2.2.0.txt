# Docker Compose release: v2.2.0
# джерело: https://github.com/docker/compose/releases/tag/v2.2.0
# отримано: 2026-10-02
# версія: 2.2.0

Tag v2.2.0, published 2021-11-24, pre-release.

## What's Changed

* Better detect container will restart by @ndeloof in https://github.com/docker/compose/pull/8898
* Type mismatch checking tmpfs conflicting options by @ndeloof in https://github.com/docker/compose/pull/8904
* Remove unused flag by @ulyssessouza in https://github.com/docker/compose/pull/8923
* Use Dockerfile directly when path is absolute otherwise join it with Context path by @glours in https://github.com/docker/compose/pull/8929
* Interrupt printer when `compose log` is cancelled by @ndeloof in https://github.com/docker/compose/pull/8926
* Restore `compose build` to support context set as a git URL by @ndeloof in https://github.com/docker/compose/pull/8933
* Upgrade containerd version - security fix by @glours in https://github.com/docker/compose/pull/8936
* Don't SetRawTerminal when run is ran with -T by @ndeloof in https://github.com/docker/compose/pull/8938
* Fix typo in --wait option mechanism by @PierreAntoineGuillaume in https://github.com/docker/compose/pull/8888
* Detect volume we didn't created and ask user to explicitely mark them as external by @ndeloof in https://github.com/docker/compose/pull/8941
* Bump compose-go to v1.0.8 by @mat007 in https://github.com/docker/compose/pull/8956
* Don't normalize compose model in compatibility mode by @ndeloof in https://github.com/docker/compose/pull/8943
* Don't try to start services with 0 replicas by @akerouanton in https://github.com/docker/compose/pull/8834
* Introduce docker compose config --images by @ndeloof in https://github.com/docker/compose/pull/8955
* Introduce run —quiet-pull to align with up by @ndeloof in https://github.com/docker/compose/pull/8947
