## ✨ Features

* align with OCI artifact best practices by @ndeloof in https://github.com/docker/compose/pull/11121
* introduce --resolve-image-digests for publish to seal service images by @ndeloof in https://github.com/docker/compose/pull/11136
* improve watch configuration logging by @glours in https://github.com/docker/compose/pull/11161
* reject compose file using `secrets|configs.driver or template_driver` by @ndeloof in https://github.com/docker/compose/pull/11185

## 🐛 Fixes

* fail start if depependency is missing by @ndeloof in https://github.com/docker/compose/pull/11110

* Fix --hash regression by @mattwalo32 in https://github.com/docker/compose/pull/11146
* Fix for "Application failed to start after update" when an external network is on a watched service by @kimdcottrell in https://github.com/docker/compose/pull/11092
* fix --pull documentation by @ndeloof in https://github.com/docker/compose/pull/11164
* fix docker/compose#11170 add newline in cmd/compose/build.go fmt.Fprint by @szampardi in https://github.com/docker/compose/pull/11171
* render quiet after filtering applied by @ndeloof in https://github.com/docker/compose/pull/11177
