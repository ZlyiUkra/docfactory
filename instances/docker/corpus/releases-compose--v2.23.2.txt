Tag v2.23.2, published 2023-11-22.

## ✨ Features

* `push` also consider `build.tags` by @ndeloof in https://github.com/docker/compose/pull/11201
* Build services with the latest version of the source code when starting `watch` command by @glours in https://github.com/docker/compose/pull/11213

## 🐛 Fixes

* Fix `--remove-orphans` not to consider disabled services as orphaned by @ndeloof in https://github.com/docker/compose/pull/11204
* Identify services to build and don't display 'building' if none by @glours in https://github.com/docker/compose/pull/11209

## 🔧 Internal

* Make it `context aware` and add test skipping options through environment variables by @ulyssessouza in https://github.com/docker/compose/pull/11192
* Introduce `RuntimeVersion` for code to check container runtime support by @ndeloof in https://github.com/docker/compose/pull/11206
* Avoid use of []types.ServiceConfig by @ndeloof in https://github.com/docker/compose/pull/11211
* Assume /src/pkg/compose/testdata absolute workingdir to make tests reproducible by @ndeloof in https://github.com/docker/compose/pull/11212
