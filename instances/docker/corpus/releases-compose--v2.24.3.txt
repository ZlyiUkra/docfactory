## What's Changed

This release fixes build issue with Docker Desktop for Windows introduced in Compose `v2.24.0`

### 🔧 Internal

* introduce stopAndRemoveContainer to share logic scaling down by @ndeloof in https://github.com/docker/compose/pull/11393

### ⚙️ Dependencies

* use a custom version of fsutils that fixes a bug on Windows causing all Compose builds to fail by @glours in https://github.com/docker/compose/pull/11400
