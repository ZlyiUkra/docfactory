## What's Changed

### 🐛 Fixes

* Fix load .env from project directory when project file is set by COMPOSE_FILE by @ndeloof in https://github.com/docker/compose/pull/11405
* Pass All option to backend api.Service when length statuses is not equal to zero by @1arp in https://github.com/docker/compose/pull/11475
* Fix deadlock collecting large logs by @ndeloof in https://github.com/docker/compose/pull/11496

### 🔧 Internal

* [CI] docker engine version matrix by @ndeloof in https://github.com/docker/compose/pull/11459
* Include all networks in ContainerCreate call if API >= 1.44 by @laurazard in https://github.com/docker/compose/pull/11429
* Chore(load): ensure context passed to load by @milas in https://github.com/docker/compose/pull/11466
* Feat(tracing): add project hash attribute by @milas in https://github.com/docker/compose/pull/11465
* Add OTEL build,depends and capabilities to attributes by @jhrotko in https://github.com/docker/compose/pull/11485
* Use listener for file metadata by @jhrotko in https://github.com/docker/compose/pull/11492
* Docs: unify no trailing dots in docstrings and help by @PiotrDabrowskey in https://github.com/docker/compose/pull/11301
* Chore(watch): remove old `docker cp` implementation by @milas in https://github.com/docker/compose/pull/11497
* Docs: update cli reference link by @dvdksn in https://github.com/docker/compose/pull/11487
* Use listeners to collect include metrics by @ndeloof in https://github.com/docker/compose/pull/11503
