# Docker Compose release: v2.3.0

Tag v2.3.0, published 2022-03-04.

## What's Changed

* Don't wait forever for unhealthy dependencies by @benesch in https://github.com/docker/compose/pull/9092
* Add progress output while waiting for dependencies by @benesch in https://github.com/docker/compose/pull/9088
* Discard env_file section on convert/config by @ulyssessouza in https://github.com/docker/compose/pull/9101
* Return only numbers in short version by @guillaumerose in https://github.com/docker/compose/pull/9096
* Don't SetRawTerminal() when exec is run with -T by @x-yuri in https://github.com/docker/compose/pull/9113
* only remove volumes set by compose file by @ndeloof in https://github.com/docker/compose/pull/9074
* Set NetworkMode correctly according to network priorities by @laurazard in https://github.com/docker/compose/pull/9130
* go.mod: github.com/buger/goterm v1.0.4 by @thaJeztah in https://github.com/docker/compose/pull/9142
* Fix typo in `reference/compose_up.md` by @danBamikiya in https://github.com/docker/compose/pull/9164
* Fix pause/unpause by only applying to running containers by @ulyssessouza in https://github.com/docker/compose/pull/9137
* use CustomLabels for composeV2 metadata and not impact service hash by @ndeloof in https://github.com/docker/compose/pull/8960
* use golangci-lint-action by @ndeloof in https://github.com/docker/compose/pull/9183
* Adds support to list the config files on `docker compose ls` by @KoditkarVedant in https://github.com/docker/compose/pull/9175
* declare `--volume` as an alias for `--volumes` by @ndeloof in https://github.com/docker/compose/pull/9182
* bump buildx to 0.7.1 by @ndeloof in https://github.com/docker/compose/pull/9189
* Wait and scale 0 by @glours in https://github.com/docker/compose/pull/9192
* Bump github.com/containerd/containerd from 1.5.8 to 1.6.0 by @dependabot in https://github.com/docker/compose/pull/9178
* COMPOSE_REMOVE_ORPHANS can be set to always apply --remove-orphans by @ndeloof in https://github.com/docker/compose/pull/9200
* Using start, stop, restart from outside the working directory using --project-name (#9147) by @arhemd in https://github.com/docker/compose/pull/9148
* exclude com.docker.compose.image label from service hash by @ndeloof in https://github.com/docker/compose/pull/9214
* Bump compose-go 1.0.9 by @ulyssessouza in https://github.com/docker/compose/pull/9146
* Bump compose-go 1.1.0 by @ulyssessouza in https://github.com/docker/compose/pull/9219
* Bump docker/distribution -> v2.8.0 by @ulyssessouza in https://github.com/docker/compose/pull/9221
* report external volume name not found by @ndeloof in https://github.com/docker/compose/pull/9217
* Bump github.com/containerd/containerd from 1.6.0 to 1.6.1 by @dependabot in https://github.com/docker/compose/pull/9225
* CONTRIBUTING.md file. Update slack sign-up link by @teror4uks in https://github.com/docker/compose/pull/9228
* Add function to convert strings to bool by @ulyssessouza in https://github.com/docker/compose/pull/9230
* Add -i and -t to run and exec by @ulyssessouza in https://github.com/docker/compose/pull/9229
