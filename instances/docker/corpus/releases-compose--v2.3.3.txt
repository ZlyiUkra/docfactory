## What's Changed

* use plain text progress when ansi=never is set by @ndeloof in https://github.com/docker/compose/pull/9247
* build full compose model from resources, then filter by services by @ndeloof in https://github.com/docker/compose/pull/9250
* add run with dependencies e2e test by @glours in https://github.com/docker/compose/pull/9252
* add support for device_cgroup_rules by @ndeloof in https://github.com/docker/compose/pull/9251
* composeService to use dockerCli's In/Out/Err streams by @ndeloof in https://github.com/docker/compose/pull/9198
* fix generated YAML missing an "examples" section, and update cli-docs-tool to v0.4.0 by @thaJeztah in https://github.com/docker/compose/pull/9253
