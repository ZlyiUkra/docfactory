* Bump Buildx to v0.8.0 by @ndeloof in https://github.com/docker/compose/pull/9254
* kill only need project name by @ndeloof in https://github.com/docker/compose/pull/9280
* don't remove external volumes/networks by @ndeloof in https://github.com/docker/compose/pull/9281
* use docker/cli RunExec and RunStart to handle all the interactive/tty/* terminal logic by @ndeloof in https://github.com/docker/compose/pull/9258
* Validate doc on pr by @glours in https://github.com/docker/compose/pull/9293
