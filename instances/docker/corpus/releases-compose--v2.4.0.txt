## What's Changed

* pass interactive flag to ExecOptions for the RunExec command by @glours in https://github.com/docker/compose/pull/9318
* go.mod: pin k8s version to fix build on go1.16, and update buildx to v0.8.1 by @thaJeztah in https://github.com/docker/compose/pull/9317
* support cache_from|to|no|pull by @ndeloof in https://github.com/docker/compose/pull/9222
* fix race condition on start-stop e2e tests running in parrallel by @glours in https://github.com/docker/compose/pull/9331
* Add support of ssh authentications defined in compose file or via cli… by @glours in https://github.com/docker/compose/pull/9325
* fix typo in ssh option description by @mschoettle in https://github.com/docker/compose/pull/9334
* Takes COMPOSE_PROJECT_NAME into consideration on commands by @ulyssessouza in https://github.com/docker/compose/pull/9332
* Remove dead warning code by @ulyssessouza in https://github.com/docker/compose/pull/9335
* Fix down command without any resource to delete by @ulyssessouza in https://github.com/docker/compose/pull/9336
* vendor: github.com/containerd/containerd v1.6.2 by @thaJeztah in https://github.com/docker/compose/pull/9309
