## What's Changed

* Fix search/replace typo in --no-TTY documentation by @ericfreese in https://github.com/docker/compose/pull/9329
* Fix panic with down command when -p flag specified by @glours in https://github.com/docker/compose/pull/9354
* use project we just created to start services by @ndeloof in https://github.com/docker/compose/pull/9365
* include services declared by `links` as implicit dependencies by @ndeloof in https://github.com/docker/compose/pull/9368
* `pull` to respect pull_policy by @ndeloof in https://github.com/docker/compose/pull/9376
* don't ignore error by @ndeloof in https://github.com/docker/compose/pull/9384
* project name MUST be lowercase by @ndeloof in https://github.com/docker/compose/pull/9385
* add support for build secrets by @ndeloof in https://github.com/docker/compose/pull/9386
* create also a checksums.txt file, add --binary by @MaxPeal in https://github.com/docker/compose/pull/9389
* add support for ppc64le for docker compose by @snehakpersistent in https://github.com/docker/compose/pull/9392
* inspect image ID after pull to se com.docker.compose.image by @ndeloof in https://github.com/docker/compose/pull/9366
* Fix cannot setup IPAM gateway by @qnap-ericfan in https://github.com/docker/compose/pull/9363
