# Docker Compose release: v2.6.1
# джерело: https://github.com/docker/compose/releases/tag/v2.6.1
# отримано: 2026-10-02
# версія: 2.6.1

Tag v2.6.1, published 2022-06-23.

## What's New

### Enhancements ✨

* Support for setting secret from env variable by @ndeloof in https://github.com/docker/compose/pull/9553

### Fixes 🐛

* Do not start unrelated dependencies on `run`  by @laurazard in https://github.com/docker/compose/pull/9558
* Fix service not found errors when using `--no-deps` by @nicksieger in https://github.com/docker/compose/pull/9504
* Respect `COMPOSE_REMOVE_ORPHANS` env var on `down` by @nicksieger in https://github.com/docker/compose/pull/9564
* Fix project level bind mounts volumes by @ulyssessouza in https://github.com/docker/compose/pull/9514
* Respect `deploy.limits.cpus` and `deploy.limits.pids` by @glours in https://github.com/docker/compose/pull/9552

### Internal 🔧

* Upgrade: Go v1.18.3 by @thaJeztah in https://github.com/docker/compose/pull/9525
* Upgrade: compose-go v1.2.8 by @milas in https://github.com/docker/compose/pull/9588
* Upgrade: buildx v0.8.2 by @dependabot in https://github.com/docker/compose/pull/9544
* Upgrade: containerd v1.6.6 by @dependabot in https://github.com/docker/compose/pull/9546
