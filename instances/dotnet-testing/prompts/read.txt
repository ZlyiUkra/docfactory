Return the full text of one excerpt of the documentation of the .NET testing libraries (xUnit.net, NUnit,
bUnit, FluentAssertions, Shouldly, Moq, NSubstitute, AngleSharp, Respawn) by its identifier, together with the
page or file it belongs to, every version whose documents contain this text, the URL it was taken from and the
date the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: a code sample of a test, an attribute with its parameters, a constraint or assertion with its
failure message, an analyzer rule with its fix, a configuration option with its default, a type or member of
the API reference with its parameters, return value and exceptions, a method of the source code or a test, a
package version and its dependencies, a release note with a breaking change.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the version (or say the page has no version) and the page you read.
