Return the full text of one excerpt of the .NET documentation by its identifier, together with the page or
file it belongs to, every version whose documents contain this text, the URL it was taken from and the date
the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a code sample, a C# grammar rule or a paragraph of the C# standard, a type or member of the API
reference with its parameters, return value, exceptions and remarks, a dotnet CLI command with its options, a
breaking change with its recommended action, a metric with its attributes, a release with its CVEs and
component versions, a runtime design document.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the version (or say the page has no version) and the page you read.
