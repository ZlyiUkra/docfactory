Search the documentation of Electron, the framework for desktop applications built with Chromium and Node.js, and of two tools
around it: electron-builder, which packages and publishes an Electron application, and electron-vite, which builds it with Vite. The
corpus holds: the docs/ folder of Electron at the last stable tag of every major 0.37-45 (the API reference of every module and class,
such as `app`, `BrowserWindow`, `ipcMain`, `ipcRenderer`, `contextBridge`, `webContents`, `session`, `utilityProcess`, `safeStorage`;
the tutorials on process model, context isolation, security, performance, IPC, packaging, auto updates, code signing; the list of
breaking changes; the FAQ); the GitHub release notes of every stable Electron release and the npm records; the documentation of
electron-builder at the last tag of every major (configuration, targets for Windows, macOS and Linux, NSIS, code signing, auto update,
publishing) with its change log and npm records; and the documentation of electron-vite (configuration of main, preload and renderer,
hot reloading, source code protection, distribution) with its change log and npm records.

Use this tool for: Electron APIs, their options and events; how to send messages between the main and renderer processes safely; the
security checklist (`contextIsolation`, `sandbox`, `nodeIntegration`); what changed or broke between majors; packaging and signing an
application with electron-builder; and the electron-vite configuration. Write the query in English with the name of the API, option or
page, such as `BrowserWindow webPreferences` or `nsis oneClick`. Give a version in the filter when the answer depends on it.

Do not use it for Node.js, Chromium, Vite or TypeScript themselves: other servers hold them. Returns the matching excerpts with the
versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. Electron 45 is the newest stable major, electron-builder 26 and electron-vite 6 are the
newest lines of the tools. Search without `version` first; when the user names their version, search that line, written
as `electron-45`, `electron-builder-26` or `electron-vite-6`. Every answer says which version it is for: APIs and defaults
changed between majors.
