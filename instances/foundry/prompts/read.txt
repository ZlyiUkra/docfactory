Return the full text of one excerpt of the Foundry documentation (the Foundry Book on the release
day of every stable release, the markdown of the foundry-rs/foundry repository, the release
notes, forge-std's README, Solidity source and release notes, the npm version table) by its
identifier, together with the document it belongs to, every version whose documents contain this
text, the URL it was taken from and the date the text was fetched from that URL -- so a quotation
can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut (`truncated: true`), or
when the exact wording matters -- a cheatcode signature, a flag, a foundry.toml key and its
default, a breaking change or a code example quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not command names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their
own language, and follow the same rules as for `search_docs`: keep identifiers and titles in
English, use Ukrainian words for Ukrainian prose, and name the version and the document you read.
