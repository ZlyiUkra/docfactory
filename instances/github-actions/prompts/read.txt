Return the full text of one excerpt of the GitHub Actions documentation (the Actions, Pages and
Packages sections of GitHub Docs, the Dependabot and billing pages, the README of each major
version and the release notes of the official actions and of the runner) by its identifier,
together with the document it belongs to, the URL it was taken from and the date the text was
fetched from that URL -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a workflow key, an event filter, an expression, an input of an
action or a permission quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not workflow keys and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: name the major version of an action
when it matters, keep identifiers and titles in English, use Ukrainian words for Ukrainian prose,
and name the document you read.
