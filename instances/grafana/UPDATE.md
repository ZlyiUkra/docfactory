# Оновлення корпусу grafana

Документація береться з закріплених тегів: джерело `gf-docs-N` тримає в полі `tags` останній тег кожної мінорної
мажору N, README пакетів — тег v13.2.4. Релізи й реєстр npm беруться щоразу заново.

Правило: **нічого не видаляється.** Ані `refresh`, ані `vectors`, ані `manifest` нічого не стирають самі.

**Спершу — повернути тексти.** Корпус примірника в архіві: у `corpus/` лежить лише паспорт, а `check`, `refresh` і
`manifest` працюють із файлами. Перед роботою нижче тексти розпаковують, а після неї — пакують і виносять знову;
обидві дії описані в [README, розділ «Архівний режим»](README.md#архівний-режим-сервер-без-корпусу).

**Нова версія Grafana.** Новий патч наявної мінорної — замінити в полі `tags` джерела `gf-docs-13` тег і версію цієї
мінорної; нова мінорна — дописати пару «тег: версія» першою (найновіший тег іде першим: з нього читач бере адресу
файла). Перелік тегів дає `git ls-remote --tags https://github.com/grafana/grafana`; беруться лише `vX.Y.Z` без
суфіксів. Для README пакетів — замінити тег у полі `tags` джерела `gf-readme`. Коли вийде 14.0 — нове джерело
`gf-docs-14` за зразком `gf-docs-13` (з полем `site`), а в `gf-docs-13` поле `site` прибрати: адреса `latest` тоді
вестиме вже на 14.x.

```
./df grafana check                 # чи змінилося щось нагорі за джерелом
./df grafana refresh gf-docs-13 gf-readme gf-releases   # лише змінене; повне — близько двох з половиною годин
./df grafana manifest
./df grafana vectors
./df grafana smoke
# Ctrl+C у терміналі з serve, і знову: ./df grafana serve
```

Коли виходить нова мінорна — у `prompts/search.txt` (абзац «Which version to search first»), `prompts/agent.txt` і
`prompts/loaded.txt` замінити найновішу версію й межі ліній.

Якщо `smoke` скаржиться на число фрагментів — корпус підріс; нове число записують у `checks.json` полем
`expected_passages`, а в `expected_note` — коли й чому його знято.

## Уточнення відповідей після оновлення

Після кожного оновлення корпусу — цикл із [кроку 7 загального довідника](../../UPDATE.md#крок-7--відновити-уточнення-відповідей):
`./df grafana quality --show`, порівняння обох десяток з попереднім результатом, розбір промахів, правка промпту,
знову замір. Останній результат — у README, розділ «Скільки цього».
