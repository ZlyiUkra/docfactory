# gymnasium — примірник фабрики docfactory

Цей примірник зібрав документацію Gymnasium і віддає її через сервер MCP, щоб модель відповідала з текстів бібліотеки, а не з
пам'яті.

Gymnasium — бібліотека для Python, яка описує, як програма, що вчиться (агент), спілкується зі світом, у якому вона діє
(середовищем). Раніше бібліотека називалася OpenAI Gym, тепер її веде Farama Foundation. Середовище — це клас із двома головними
методами. Метод `reset` починає новий епізод і повертає перше спостереження. Метод `step` приймає дію агента й повертає п'ять
значень: нове спостереження, винагороду, ознаку `terminated` (епізод закінчився за правилами задачі), ознаку `truncated` (епізод
обірвано ззовні, наприклад за лімітом кроків) і словник з додатковими даними. Які спостереження й дії можливі, описують простори:
`Box` для чисел у межах, `Discrete` для вибору одного з кількох варіантів тощо. Обгортки (wrappers) змінюють поведінку середовища,
не чіпаючи його коду: обмежують довжину епізоду, нормують спостереження, записують відео.

Майже всі бібліотеки навчання з підкріпленням, серед них Stable-Baselines3, приймають середовище саме в цьому вигляді. Тому власне
торгове середовище пишуть як клас `gymnasium.Env`.

## Скільки цього

Усього 1 084 документи і 5 161 фрагмент. Фрагмент — це шматок документа, який пошук повертає як окремий результат. Розділ з однаковим
текстом у кількох версіях займає у видачі одне місце й показує перелік цих версій.

| Що | Версії | Документів |
|---|---|---|
| сайт gymnasium.farama.org: вступ, довідник API (`Env`, простори, обгортки, векторні середовища, реєстр), сторінка кожного вбудованого середовища, підручники, нотатки випусків | 1.4.0, 1.3.0, 1.2.3, 1.1.1, 1.0.0, 0.29.0, 0.28.1, 0.27.1, 0.26.3 | 909 |
| сайт ale.farama.org (Arcade Learning Environment): сторінка кожної гри Atari, інтерфейс Gymnasium і Python, векторне середовище `AtariVectorEnv`, багатоагентні ігри, нотатки випусків | 0.12.1 | 141 |
| нотатки релізів GitHub `Farama-Foundation/Gymnasium` | усі стабільні теги | 19 |
| записи PyPI пакета `gymnasium` з README | усі стабільні версії | 15 |

Мітка версії — мінорна лінія: `1.4`, `0.29`. Сторінки сайту Atari мають мітку `ale-0.12`.

**Де є прогалини.**

- Сайт публікує по одній теці на мінорну лінію, і не завжди це останній патч: для лінії 0.29 є лише тека `v0.29.0`, теки
  `v0.29.1` немає.
- Середовища Atari описано двічі. У версіях Gymnasium 0.26–0.29 їхні сторінки лежали на сайті Gymnasium. Починаючи з 1.0 вони
  живуть на окремому сайті ale.farama.org, і його взято одним знімком версії 0.12.1. Старіших версій цього сайту в корпусі немає.
- Ігри Atari важливі для навчання: на них перевіряють майже всі алгоритми, від DQN до Rainbow. Сторінку гри шукають за
  ідентифікатором середовища, наприклад `ALE/Breakout-v5`.
- Головна сторінка кожної версії в корпус не входить: на ній лише обкладинка сайту без тексту.
- Старий OpenAI Gym (до 0.26) не взято. Сторінка «Gym Release Notes» на сайті Gymnasium переказує його історію.

Замір `quality` на 12.11.2026 дав такі числа. Запити назвами з документації знаходять потрібне 10 із 10, а модель зазвичай питає
саме так. Запити своїми словами знаходять потрібне 9 із 10. Сторінку середовища краще шукати за його ідентифікатором
(`CartPole-v1`): заголовки сторінок пишуть назву двома словами («Cart Pole»).

## Що в цій теці

- `corpus/` — паспорт `index.json`; текстів тут немає: корпус в архіві (розділ «Архівний режим» нижче).
- `index/` — кеш фрагментів, з якого сервер підіймається: у git — стиснений `passages.json.gz`, а розпакований `passages.json` лежить
  поруч і в git не потрапляє.
- `sources.json` — звідки корпус будується, і водночас білий список для оновлювача.
- `config.json` — порт, колекція Qdrant, модель векторів, пауза між зверненнями.
- `prompts/` — описи інструментів для моделі, системний промпт власного агента, текст відмови.
- `checks.json` — чим `smoke` і `quality` перевіряють саме цей корпус.
- `.mcp.json` — запис HTTP-сервера для Claude Code.

Кроки нижче запускаються з кореня фабрики (`docfactory/`) через `./df gymnasium <крок>`.

## Звідки документація

| Що | Джерело | Читач |
|----|---------|-------|
| сайт Gymnasium | `gymnasium.farama.org/v*/` | `html-pages` |
| сайт Arcade Learning Environment | `ale.farama.org/v0.12.1/` | `html-pages` |
| нотатки релізів | релізи GitHub `Farama-Foundation/Gymnasium` | `ghreleases-pattern` |
| записи PyPI | `pypi.org/pypi/gymnasium/json` | `pypi-versions` |

**Чому `html-pages`, а не читач Sphinx.** Сайт зібрано Sphinx, але адреси сторінок закінчуються текою (`/api/env/`), а не файлом
`.html`, і читач `sphinx-html` таких посилань не бачить. Бічне меню головної сторінки версії перелічує всі її сторінки, тому
`html-pages` бере перелік звідти. Поле `heading` каже читачеві брати назву сторінки із заголовка всередині статті: у версії 0.26
першим на сторінці стоїть заголовок сайту «Gymnasium Documentation».

## Як підняти сервер

Сервер працює у спільному середовищі фабрики, власного `.venv` примірник не має. В окремому терміналі виконайте:

```
./df gymnasium serve
```

Порт — `8972`. Якщо порт зайнято, `serve` скаже про це й зупиниться: швидше за все, цей сервер уже запущено в іншому терміналі.

Під'єднати сервер до Claude Code можна двома способами. Перший — файл `.mcp.json` цієї теки. Другий — команда:

```
claude mcp add --transport http --scope user gymnasium-docs http://127.0.0.1:8972/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама: WSL віддає порт на `127.0.0.1` Windows.

У сесії Claude Code команда `/mcp` має показати сервер `gymnasium-docs` з інструментами `search_docs` і `read_section`. Якщо сервер
позначено як недоступний, перевірте, чи працює `serve`, і чи запущено контейнер Qdrant.

## Родина «Навчання з підкріпленням»: піднімати разом

Цей примірник — частина родини «Навчання з підкріпленням»: теорія і три бібліотеки, якими її застосовують. Питання про те, чому
агент не вчиться, починається в документації алгоритму Stable-Baselines3, а закінчується в теорії або в описі середовища
Gymnasium. Тому примірники родини піднімають у Claude Code разом, а `.mcp.json` цієї теки перелічує всі чотири сервери:
підключивши будь-який із них, Claude Code бачить решту.

| Примірник | Сервер | Порт | Що |
|-----------|--------|-----:|----|
| `reinforcement-learning` | `reinforcement-learning-docs` | 8971 | теорія: книжки, курси й статті про навчання з підкріпленням і бандитів, торгове середовище, навчання на записаній історії |
| `gymnasium` | `gymnasium-docs` | 8972 | Gymnasium 0.26–1.4: інтерфейс середовища, простори, обгортки, векторні середовища |
| `stable-baselines3` | `stable-baselines3-docs` | 8973 | Stable-Baselines3 0.11–2.9, sb3-contrib і RL Zoo: готові алгоритми, колбеки, векторні середовища |
| `d3rlpy` | `d3rlpy-docs` | 8974 | d3rlpy 0.2–2.8: навчання на записаній історії без живого середовища (CQL, IQL, Decision Transformer) |

Усі чотири одним терміналом:

```
cd ~/Projects/docfactory && tools/up.sh reinforcement-learning gymnasium stable-baselines3 d3rlpy
```

`prompts/loaded.txt` каже моделі, що цей набір — частина родини, і які сервери її доповнюють. Повний перелік родин — у
кореневому README.md, розділ «Родини примірників».

## Архівний режим: сервер без корпусу

Корпус примірника в архіві від самого початку: у `corpus/` лежить лише паспорт. Серверу вистачає кешу фрагментів
(`index/passages.json`) і колекції Qdrant; відповіді ті самі до символу, бо адреса й дата лежать у кеші кожного фрагмента.

**Де тексти.** В архіві `~/archives/docfactory/gymnasium-corpus-2026-11-12-atari.tar.gz` (1 084 тексти, паспорт і сховище сирого `raw/`;
перед видаленням текстів розпакований окремо й звірений із диском) і в копії на диску Windows
`C:\Distr\gymnasium-corpus-2026-11-12-atari.tar.gz` (звірено за SHA-256). В історії git текстів немає.

**Як винести знову** — після оновлення, коли `vectors` і `smoke` пройшли:

```
ls -l instances/gymnasium/index/passages.json  # кеш має бути на місці й свіжий
tar --sort=name -czf ~/archives/docfactory/gymnasium-corpus-РРРР-ММ-ДД.tar.gz -C instances/gymnasium corpus raw
find instances/gymnasium/corpus -maxdepth 1 -name '*.txt' -delete
rm -rf instances/gymnasium/raw
gzip -9 -c instances/gymnasium/index/passages.json > instances/gymnasium/index/passages.json.gz
```

і закомітити паспорт `corpus/index.json` та `index/passages.json.gz`. Видаляти тексти й `raw/` можна лише після того, як новий архів
звірено з диском. Тоді ж видаляють попередній архів, а ім'я нового записують сюди.

**Як повернути тексти** — перед будь-яким оновленням корпусу; разом із ними повертається й `raw/`:

```
tar -xzf ~/archives/docfactory/gymnasium-corpus-2026-11-12-atari.tar.gz -C instances/gymnasium
./df gymnasium smoke
```

**Що перестає працювати.** `check`, `refresh` і `manifest` читають файли, і без текстів вони не працюють; перевірки `smoke`, яким
потрібні тексти, пропускаються («корпус в архіві»).
