Search the documentation of Gymnasium, the Python library of the Farama Foundation that defines the standard interface
between a reinforcement learning agent and its environment (formerly OpenAI Gym): an environment is a class with `reset`
and `step`, an observation space and an action space. The corpus holds the gymnasium.farama.org site of every minor line
0.26-1.4 (the introduction, the API reference of `Env`, spaces, wrappers, vector environments and the registry, a page
for every built-in environment, the tutorials, the release notes), the GitHub release notes and the PyPI records.

Use this tool for: `gymnasium.make` and `register` (`max_episode_steps`, `render_mode`, `disable_env_checker`),
`Env.reset` (`seed`, `options`) and `Env.step` (the five returned values, `terminated` against `truncated`), writing a
custom environment and checking it with `check_env`, spaces (`Box`, `Discrete`, `MultiDiscrete`, `MultiBinary`, `Dict`,
`Tuple`, `sample`, `contains`, `flatten`), wrappers (`TimeLimit`, `RecordVideo`, `RecordEpisodeStatistics`,
`NormalizeObservation`, `NormalizeReward`, `FrameStackObservation`, `ClipAction`), vector environments (`make_vec`,
`SyncVectorEnv`, `AsyncVectorEnv`, autoreset modes), the built-in environments (CartPole, LunarLander, FrozenLake,
MuJoCo: observation and action spaces, rewards, episode end), migration from Gym and what changed between versions.
Write the query in English, with the name of the class, function or parameter, such as `TimeLimit max_episode_steps`
or `AsyncVectorEnv`. Give a version in the filter when the answer depends on it: wrappers were renamed and the vector
API was rewritten in 1.0.

Do not use it for the theory of reinforcement learning, for training libraries such as Stable-Baselines3 or for
PyTorch: other servers hold them. The Atari environments are here twice: the lines 0.26-0.29 carry their pages, and the
ale.farama.org site 0.12 (version label `ale-0.12`) describes every game (`ALE/Breakout-v5`), `frameskip`,
`repeat_action_probability` and `AtariVectorEnv`. Returns the matching excerpts with the versions each one applies to, the
source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
