# htdp — примірник фабрики docfactory

Захищений MCP-сервер для читання книжки «How to Design Programs, Second Edition» — Matthias Felleisen, Robert Bruce
Findler, Matthew Flatt, Shriram Krishnamurthi; MIT Press, 2018 — за онлайн-виданням авторів на htdp.org, разом із
довідником мов і бібліотек, якими книжка пише (docs.racket-lang.org). Код спільний і лежить у `../../engine/`,
`../../server/` та `../../common/`; ця тека тримає самі дані домену. Загальний устрій фабрики — у
[../../README.md](../../README.md).

## Навіщо

Книжка вчить систематично проєктувати програми: «рецепт проєктування» (design recipe) — визначення даних, підпис
функції, призначення, приклади, шаблон за формою даних, тіло, тести. Пише вона навчальними мовами Racket (BSL, ISL,
ASL) у середовищі DrRacket, а графіку й анімацію робить бібліотеками `2htdp/image` і `2htdp/universe`. Сервер — довідка
під час читання: «що вимагає крок шаблону для itemization», «що питає вправа 143», «чим ISL відрізняється від BSL»,
«що робить `place-image`». Вправи робляться в DrRacket, як у книжці, а поруч — переклад рецепта на TypeScript.

Онлайн-видання на htdp.org новіше за друковане: автори досі його виправляють, на 26.10.2026 найновіше датоване
28.05.2026. Файл EPUB, який був у користувача, — неофіційна конвертація чернетки 2017 року, тож узято htdp.org.

## Корпус лише локально

Текст книжки захищений авторським правом: на htdp.org його можна читати вільно, але не перевидавати. Тому **корпус і
індекс у git не потрапляють** (`corpus/` і `index/` у `.gitignore`), у git лежать лише налаштування примірника. З тієї ж
причини промпт велить переказувати своїми словами, цитувати коротко й давати адресу сторінки з номером розділу.
Довідник docs.racket-lang.org вільний (Racket — MIT і Apache 2.0), але лежить у тому самому корпусі.

**Де тексти.** Корпус в архіві від самого початку: `~/archives/docfactory/htdp-corpus-2026-10-26.tar.gz` (29 текстів,
паспорт і сховище сирого `raw/`; перед видаленням текстів архів розпаковано окремо й звірено з диском) і копія на
Windows `C:\Distr\htdp-corpus-2026-10-26.tar.gz` (звірено за SHA-256). Сервер підіймається з кешу фрагментів
`index/passages.json` (лише на цій машині) і колекції Qdrant. `refresh` відтворює корпус з нуля за хвилину, але лише
в поточному стані htdp.org, тож точна копія — в архіві.

**Як повернути тексти** — перед оновленням корпусу:

```
tar -xzf ~/archives/docfactory/htdp-corpus-2026-10-26.tar.gz -C instances/htdp
./df htdp smoke
```

**Як винести знову** — після оновлення, коли `vectors` і `smoke` пройшли:

```
tar -czf ~/archives/docfactory/htdp-corpus-РРРР-ММ-ДД.tar.gz -C instances/htdp corpus raw
find instances/htdp/corpus -maxdepth 1 -name '*.txt' -delete
rm -rf instances/htdp/raw
```

Тексти видаляють лише тоді, коли архів звірено з диском. Тоді ж видаляють попередній архів, а ім'я нового пишуть у
«Де тексти». `check`, `refresh` і `manifest` без текстів працювати не можуть; `smoke` пропускає їхні перевірки з
позначкою «корпус в архіві». **На іншій машині** кешу немає: тексти повертають з архіву, далі `./df htdp vectors`.

Разом 29 документів, 3196 фрагментів (`expected_passages` у `checks.json`). Замір `quality`: по словах 9 із 10, за
змістом 8, разом 8, «як модель» 10 із 10, без перемикачів. Промахи першої десятки своїми словами: «функція над списком

картинку в точці порожнього тла» (`place-image`, `empty-scene`). Окремо перевірено пошук усіх 528 вправ запитом
«Exercise N exN»: перша у видачі — 516, у першій трійці — усі 528.

Чого немає:

- Сторінки-змісту книжки (`index.html`) і першого видання (htdp.org/2003-09-26).
- Відрендерених картинок і формул: у Scribble це зображення без тексту, тож формула відстані в вправі 1 у тексті
  випадає.
- Старих навчальних бібліотек першого видання (`htdp/draw`, `htdp/world` тощо), крім `htdp/dir`, яку бере частина IV.
- Racket загалом, Typed Racket, посібника DrRacket.

## Що в цій теці

- `corpus/` — паспорт `index.json` (тексти — в архіві, див. вище); у git не потрапляє.
- `index/` — кеш фрагментів, з якого підіймається сервер; у git не потрапляє.
- `sources.json` — звідки будується корпус. Він же білий список для оновлювача.
- `config.json` — порт, колекція Qdrant, модель векторів, пауза між зверненнями і профіль домену.
- `prompts/` — описи інструментів для моделі, системний промпт власного агента, текст відмови.
- `checks.json` — чим `smoke` і `quality` перевіряють саме цей корпус.
- `.mcp.json` — запис HTTP-сервера для Claude Code.

Кроки нижче запускаються з кореня фабрики (`docfactory/`) через `./df htdp <крок>`.

## Звідки документація

| Що | Джерело | Читач |
|----|---------|-------|
| книжка | 14 сторінок htdp.org/2026-5-28/Book/ (part_preface … part_epilogue), переліком у `sources.json` | `scribble` |
| мови | 6 сторінок docs.racket-lang.org/htdp-langs/ | `scribble` |
| бібліотеки | 9 сторінок docs.racket-lang.org/teachpack/ | `scribble` |

Новий читач `scribble` (engine/readers/scribble.py): і книжку, і довідник генерує Scribble, а він пише код таблицею
(рядок коду — рядок таблиці, токени — окремі `span`, відступи — нерозривні пробіли), граматику мов — таблицею без
класу, а нотатки на полях — посеред речення. Читач робить з коду й граматики блоки коду racket з відступами, ставить
підзаголовок з іменем перед кожною рамкою визначення довідника (`circle`, `big-bang`), позначає нотатки на полях
«(Margin note: …)» і знімає навігацію, кнопки-якорі та таблиці змісту.

Кожна вправа книжки стає окремим розділом «Exercise N (exN)». Мітка `exN` потрібна пошуку по словах: голий номер
нічого не розрізняє, бо «12» — це й розділи 12.1–12.8, і числа в коді. Тому промпт велить шукати вправу запитом
«Exercise N exN». Розділ вправи триває до наступного заголовка, тож текст книжки одразу після вправи може лягти в
той самий уривок.

Ім'я документа не містить дати випуску (`htdp-part-one`, а не `2026-5-28-book-part-one`), тож новий випуск htdp.org
лягає поверх тих самих документів.

## Установка venv

Власний venv цьому примірнику не потрібен: `./df htdp …` бере спільне середовище з кореня репозиторію (`.venvs/cpu`
або `.venvs/gpu`). Як збудувати його один раз — у кореневому README, розділ «Спільне середовище».

## Збирання корпусу

```
./df htdp sources --why   # перелік джерел і білий список
./df htdp refresh         # завантажити все задеклароване (близько хвилини)
./df htdp manifest        # оновити паспорт
./df htdp setup           # Qdrant чи пошук лише по словах
./df htdp vectors         # залити корпус у docs-htdp
./df htdp smoke           # перевірки
```

Порядок оновлення — у [UPDATE.md](UPDATE.md). Після будь-якого оновлення корпусу `serve` треба перезапустити.

## Сервер під Claude Code

**1. Підняти сервер** в окремому терміналі WSL і лишити його працювати:

```
cd ~/Projects/docfactory
./df htdp serve          # порт 8912
```

Сервер готовий, коли надрукував кількість фрагментів і адресу `http://127.0.0.1:8912/mcp`.

**2. Додати сервер у Claude Code** — у тому середовищі, де відкрито вікно:

```
claude mcp add --transport http --scope user htdp-book http://127.0.0.1:8912/mcp
```

У WSL і у Windows Claude Code тримає окремі налаштування. Вікно VS Code на боці Windows читає
`C:\Users\<ім'я>\.claude.json`, тож команду треба виконати в PowerShell або додати сервер кнопкою «Add server» у вікні
`/mcp` (тип HTTP, рівень User). Сам сервер з Windows доступний за тією ж адресою: WSL2 прокидає порт.

**3. Перевірити.** `/mcp` має показати `htdp-book` і два інструменти: `search_docs` і `read_section`.

Зупинка — Ctrl+C у терміналі сервера. Решта (scope запису, «address already in use») — так само, як у [README
примірника react-router](../react-router/README.md#спосіб-б--сервер-під-claude-code-http).
