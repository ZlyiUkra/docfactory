Return the full text of one excerpt of the JSON Schema and Ajv documentation by its identifier, together with
the page, specification section or file it belongs to, every draft or version whose documents contain this
text, the URL it was taken from and the date the text was fetched -- so a quotation can be checked against the
source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: a numbered section of the specification with its MUST and SHOULD, a meta-schema, a group of the Test
Suite with every instance and its verdict, an Understanding JSON Schema page, an Ajv option and its default,
an API method, a strict mode rule, a keyword of ajv-keywords, an error message of ajv-errors, a release note,
a line of Ajv source code or its test, a version table from npm.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the draft or the package and version, and the page or section you
read.
