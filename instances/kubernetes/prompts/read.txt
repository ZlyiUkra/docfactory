Return the full text of one excerpt of the Kubernetes documentation or of the documentation of
a tool around the cluster (k3s, k3d, Gateway API, Traefik, cert-manager, Helm, Kustomize, the
kubectl book, SOPS, age, metrics-server, Let's Encrypt; changelogs, release dates and release
notes included) by its identifier, together with the document it belongs to, every version
whose documents contain this text, the URL it was taken from and the date the text was fetched
from that URL -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a field of an API object, a kubectl flag, a manifest, an
upgrade step, a feature state, a breaking change or a rate limit quoted half-way is how a wrong
answer starts.

Do not guess identifiers: they are not URLs, not object names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: keep identifiers, field names and
titles in English, use Ukrainian words for Ukrainian prose, and name the tool, the version and
the document you read.
