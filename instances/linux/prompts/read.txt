Return the full text of one excerpt of the Linux documentation (Ubuntu man pages, the Linux
man-pages project, the kernel admin-guide, systemd, the GNU manuals of bash, coreutils, grep,
sed, findutils and tar, vim help, the Debian Handbook, the Ubuntu Server and Rocky Linux guides,
the LFCS exam page) by its identifier, together with the document it belongs to, every version
whose documents contain this text, the URL it was taken from and the date the text was fetched
from that URL -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- an option of a command, a directive of a configuration file,
a unit setting, a permission bit or a step of a procedure quoted half-way is how a wrong answer
starts.

Do not guess identifiers: they are not URLs, not command names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: keep commands, options, paths and
titles in English, use Ukrainian words for Ukrainian prose, and name the project, the version
and the document you read.
