Return the full text of one excerpt of the llhttp documentation by its identifier, together with the file it
belongs to, every release whose documents contain this text, the URL it was taken from and the date the text
was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a function's signature, the list of error codes, a test case with its expected events, a release
note that says which release fixed a vulnerability.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the release and the file you read.
