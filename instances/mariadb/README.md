# Примірник mariadb

Цей примірник шукає в документації MariaDB. MariaDB — це сервер реляційної бази даних: він зберігає дані в таблицях і виконує
запити мовою SQL. Колись MariaDB відгалузилася від MySQL, але тепер це окремий продукт, і багато що в ньому працює інакше. Тому
документація MySQL лежить в окремому примірнику [`mysql`](../mysql/README.md).

## Що всередині

| Що | Версії | Звідки |
|---|---|---|
| Сервер: SQL, типи даних, сховища, реплікація, адміністрування | одне поточне видання | репозиторій `mariadb-docs` |
| Примітки до випусків | кожної версії | репозиторій `mariadb-docs` |
| Конектори для Java, Node.js, C, C++, ODBC, Python і R2DBC | одне поточне видання | репозиторій `mariadb-docs` |
| Galera Cluster, MaxScale, ColumnStore, інструменти, початок роботи | одне поточне видання | репозиторій `mariadb-docs` |
| Випуски сервера | останні стабільні | GitHub `MariaDB/server` |
| Пакет npm `mariadb` | усі стабільні, README кожної | реєстр npm і GitHub |
| Образ `mariadb` | теги й сторінка образу | Docker Hub, `docker-library/docs` |

Усього 9283 документи, із них пошук будує 56 847 фрагментів. Фрагмент — це невеликий шматок тексту, який знаходить пошук.

## Важливі межі

- Сайт MariaDB існує одним поточним виданням. Окремої копії для кожної версії немає, тому відмінності між версіями видно лише
  з приміток у тексті, блоків **Variant** і приміток до випусків. Блок **Variant** — це вкладка сайту на кшталт `< 12.0`.
- До примірника не входять GridGain, MariaDB Cloud, Exa і внутрішні `agent-skills`, бо вони не стосуються самої бази.
- Два порожні README приміток MaxScale (21.06 і 22.08) читач не записав, бо тексту в них немає.
- Запити своїми словами знаходять потрібну сторінку лише в 1 із 10 випадків. Запити точними назвами дають 10 із 10, тому питайте
  назвою інструкції, функції чи змінної, наприклад `ALTER TABLE` або `wsrep_sync_wait`.

## Архівний режим

Сервер працює без текстів: він підіймається з кешу `index/passages.json.gz` у git і колекції Qdrant. Тексти потрібні лише для
оновлення чи перебудови.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/mariadb-corpus-2026-11-04.tar.gz` разом зі сховищем сирого `raw/`.
Копія лежить на Windows: `C:\Distr\mariadb-corpus-2026-11-04.tar.gz`. Архів звірено з диском файл за файлом, а копію — за SHA-256.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/mariadb-corpus-2026-11-04.tar.gz -C instances/mariadb
./df mariadb smoke
```

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df mariadb serve
```

Сервер слухає порт `8953`. Перевірка: `./df mariadb smoke` і `./df mariadb quality`.
