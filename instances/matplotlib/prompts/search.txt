Search the documentation of Matplotlib, the Python library for static, animated and interactive charts. The corpus
holds the whole matplotlib.org site of every minor line 1.2-3.11, each at its last patch: the User Guide (quick start,
Figure and Axes, arranging Axes, layout engines, colors and colormaps, text and annotations, dates, animations,
backends, saving figures), the API reference with a page for every `pyplot` function and every `Axes` method, the
gallery of examples, the plot types, What's New and the API changes between versions; the PyPI records of every stable
version; and the GitHub release notes of every stable tag.

Use this tool for: creating figures and grids of Axes (`plt.subplots`, `subplot_mosaic`, `GridSpec`), line, bar,
scatter and histogram plots (`plot`, `bar`, `scatter`, `hist`), shaded bands (`fill_between`), reference lines
(`axhline`, `axvline`), a second y-axis (`twinx`), annotations (`annotate`, `text`), legends, date axes
(`matplotlib.dates`, `ConciseDateFormatter`, `AutoDateLocator`, `autofmt_xdate`), layout (`constrained_layout`,
`tight_layout`), saving to files (`savefig` with `dpi`, `bbox_inches`, `format`), backends for scripts and servers
without a display (`Agg`, `matplotlib.use`), animations (`FuncAnimation`), styles and `rcParams`, and what changed
between versions. Write the query in English, with the name of the function, method, parameter or User Guide topic,
such as `savefig bbox_inches` or `ConciseDateFormatter`. Give a version in the filter when the answer depends on it:
functions and parameters were added, renamed and removed between lines.

Do not use it for seaborn, mplfinance (candlestick charts), plotly, the plotting methods of pandas or NumPy: other
servers hold them. Lines older than 1.2 are not here, because the site publishes no older version. Returns the matching
excerpts with the versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. Matplotlib 3.11.2 is the newest release. Search without `version` first; when the user
names their Matplotlib version, search that line, written as `matplotlib-3.11`, `matplotlib-3.5` or `matplotlib-2.2`.
Every answer about a parameter says which line it is for.
