Return the full text of one excerpt of MDN Web Docs (JavaScript, Web APIs, CSS, HTML, HTTP,
accessibility, the Learn course, the glossary and the other sections) by its identifier,
together with the document it belongs to, the URL it was taken from and the date the text
was fetched from that URL -- so a quotation can be checked against the source even a year
later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a method signature, the formal syntax of a CSS property,
the values of an HTTP header, an ARIA requirement or a Baseline date quoted half-way is how
a wrong answer starts.

Do not guess identifiers: they are not URLs, not interface names and cannot be assembled by
hand. Every identifier this tool accepts comes from the `id` field of a `search_docs`
result.

The text comes back in English, as the documentation is written. Answer the user in their
own language, and follow the same rules as for `search_docs`: keep identifiers and titles in
English, use Ukrainian words for Ukrainian prose, and name the document you read.
