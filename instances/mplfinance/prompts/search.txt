Search the documentation of mplfinance, the matplotlib library that draws financial charts in Python: candlestick, OHLC
bar, line, renko and point-and-figure charts with volume, moving averages and extra panels. mplfinance has no
documentation site, so the corpus holds what serves as its documentation: the README and the markdown pages, the example
notebooks (adding plots with `make_addplot`, panels, styles and market colors, candle widths, saving figures, external
axes, filling between lines, lines `hlines`, `vlines`, `alines`, `tlines`, scaling, resampling, indicators such as MACD,
Ichimoku, Supertrend, Parabolic SAR, Donchian channels) at the last tag of the lines 0.12.4, 0.12.8, 0.12.9 and 0.12.10;
the library code split into classes and functions, where every keyword argument of `mpf.plot`, `mpf.make_addplot`,
`mpf.make_marketcolors` and `mpf.make_mpf_style` is declared with its default, validator and description; the release
notes, the GitHub release notes, the pages of the GitHub wiki and the PyPI records of every version.

Use this tool for: how to draw candles with volume and moving averages, how to add an indicator in its own panel, how to
mark trades with markers, how to change colors and styles, how to get the figure and axes back (`returnfig=True`) or
draw into your own axes, how to save a chart to a file, how to show a time axis without gaps, and what changed between
versions. Write the query in English with the function or keyword argument name, such as `make_addplot`, `panel_ratios`,
`returnfig` or `mav`. Every version of mplfinance is an alpha or beta release; the newest is 0.12.10b0.

Do not use it for matplotlib itself (the matplotlib server holds it), for pandas or for indicator formulas (the
technical indicators server holds TA-Lib, pandas-ta-classic and ta). Returns the matching excerpts with the versions each
one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest line is 0.12 and the newest tag is 0.12.10b0. Search without `version` first;
when the user names a version, search that version.
