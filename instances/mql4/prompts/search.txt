Search the documentation of MQL4, the programming language of MetaTrader 4, and of the MetaTrader 4 client terminal. The corpus
holds the two help files that MetaQuotes ships with the terminal and the book MQL4 Tutorial. The MQL4 Reference describes the
language (types, operators, functions, the preprocessor and `#property strict`), the program types and their event handlers
(`OnInit`, `OnTick`, `OnCalculate`, `OnTimer`, `OnChartEvent`, and the old `init`, `start`, `deinit`), the predefined variables
(`Bid`, `Ask`, `Digits`, `Point`), every function group (trade functions such as `OrderSend`, `OrderSelect`, `OrderModify` and
`OrderClose`, `MarketInfo`, the technical indicators such as `iMA` and `iRSI` with their `shift` parameter, timeseries access
such as `iClose` and `CopyRates`, account information, charts and objects, files, global variables of the terminal) and the
standard constants, enumerations and error codes. The MetaTrader 4 Help describes the terminal: trading and order types, charts,
the built-in technical indicators with their calculation formulas, Expert Advisors and custom indicators in the terminal, the
Strategy Tester with its modelling methods and optimization, signals, virtual hosting and the settings. The book MQL4 Tutorial
by S. Kovalyov (book.mql4.com) teaches the language from the beginning with full program listings: variables, operators, special
functions, trade operations step by step, a simple Expert Advisor, custom indicators, and the requirements and limitations of
making trades. The book was written for the old MQL4, so its programs use `start()`, not `OnTick()`.

Use this tool for: the signature of an MQL4 function and the meaning of each parameter; what a function returns and how errors
are reported with `GetLastError`; how an order is opened, modified and closed in MQL4; which event handler runs when; how an
indicator value is read; how the MetaTrader 4 terminal, its Strategy Tester and its built-in indicators work; how a whole
trading program is built, explained step by step. Write the query in English with the name of the function, constant or terminal
window, such as `OrderSend` or `MarketInfo`, or with plain words for what is wanted.

Do not use this tool for MQL5 or MetaTrader 5 (only the pages of this reference that compare MQL4 with MQL5 are here), Pine
Script, Python libraries or the REST APIs of brokers. Returns the matching excerpts with the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
