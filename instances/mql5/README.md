# Примірник mql5

Цей примірник шукає в документації MQL5. MQL5 — це мова програмування торгового терміналу MetaTrader 5, схожа на C++. Нею пишуть
торгових роботів (Expert Advisors), які самі відкривають і закривають угоди, індикатори, які малюють на графіку власні лінії, скрипти й
служби. Програма на MQL5 не має головного циклу: термінал викликає її функції-обробники, коли щось стається. Наприклад, `OnTick`
викликається на кожну нову ціну, а `OnTimer` — за таймером. Угоду програма відкриває торговим запитом `OrderSend` або класом `CTrade`
стандартної бібліотеки, а значення індикатора читає функцією `CopyBuffer`.

## Що всередині

| Що | Тем (документів) | Звідки |
|---|---|---|
| Довідник MQL5 (MQL5 Reference): мова, обробники подій, усі групи функцій, ONNX, OpenCL, інтеграція з Python, стандартна бібліотека | 4128 | PDF з mql5.com |
| Книжка MQL5 Programming for Traders: мова й програмні інтерфейси крок за кроком, з повними текстами програм | 581 | PDF з mql5.com |
| Книжка Neural Networks for Algorithmic Trading with MQL5: нейромережі на MQL5 і OpenCL, від перцептрона до уваги, навчання й перевірка | 112 | PDF з mql5.com, видання 15.06.2026 |
| Довідка терміналу MetaTrader 5 (MetaTrader 5 Help): торгівля й види наказів, графіки, вбудовані технічні індикатори з формулами розрахунку, тестер стратегій і оптимізація, налаштування | 377 | файл `mt5terminal.chm`, який термінал кладе сам, додано 13.11.2026 |

Документ — одна тема закладок PDF чи змісту довідки. Усього 5198 документів, з них пошук будує 20 933 фрагменти. Фрагмент — це
невеликий шматок тексту, який знаходить пошук. Версій тут немає: кожен файл — одне поточне видання.

Довідник і книжки зроблено програмою Help+Manual. Для них написано читач `helpmanual-pdf`. Він бере шрифт кожного символу, тож код стає
окремим блоком з відступами, назва параметра — окремим рядком, а підзаголовки «Parameters», «Return Value», «Example» — розділами.
Першим рядком кожного документа стоїть шлях розділів, наприклад «Section: Part 4. Common APIs › 4.4 Mathematical functions».

Довідка терміналу — файл CHM (Compiled HTML Help): архів сторінок HTML разом зі змістом `.hhc`. Його розпаковано 7-Zip-ом у
`raw/local/mt5terminal/`, а читає його новий читач `chm-local`. Він іде змістом довідки, кожна тема стає документом, а першим рядком
теж стоїть шлях розділів («Section: Price Charts, Technical and Fundamental Analysis › Technical Indicators › Oscillators»).
Підзаголовки й приклади коду Help+Manual у HTML — це абзаци з класами `p_H2`, `p_CodeExample`; читач перетворює їх на заголовки й
блоки коду. Сторінки вбудованих індикаторів мають розділ «Calculation» з формулою: за ним звіряють, чи рахує MetaTrader індикатор так
само, як бібліотеки Python у примірнику `ta-indicators`.

## Чого тут немає

- MQL4 і MetaTrader 4: вони мають окремий примірник `mql4`. Тут є лише сторінка довідника про перехід з MQL4.
- Статей, форуму й бази коду mql5.com.

Сторінку 427 книжки MQL5 Programming for Traders бібліотека pypdf, якою читаються PDF, не розкодовує: на ній є шрифт із корейським
кодуванням `KSCms-UHC-H`. Таку сторінку читач бере через PDFium (бібліотека pypdfium2, вона вже є в спільному середовищі) і пише її номер
у журнал. Відступи коду на ній відновлено з координат знаків, тож вони можуть відрізнятися від книжки на пробіл.

## Чому файли завантажує людина

Умови користування mql5.com забороняють збирати сайт програмами й копіювати його вміст. Тому наш завантажувач на mql5.com не ходить.
Довідник і обидві книжки людина завантажує браузером як PDF зі сторінок `https://www.mql5.com/en/docs`, `https://www.mql5.com/en/book` і
`https://www.mql5.com/en/neurobook`. Ці ж адреси стоять у шапці кожного документа.

Файли лежать у `raw/local/` під іменами `mql5-reference.pdf`, `mql5-programming-for-traders.pdf` і
`neural-networks-for-algorithmic-trading.pdf`. Оригінали лишаються в теці «Завантаження» Windows.

Довідку терміналу ніхто не завантажує окремо: термінал MetaTrader 5 сам кладе її у `%APPDATA%\MetaQuotes\Terminal\Help\mt5terminal.chm`.
Копія файла лежить у `raw/local/mt5terminal.chm`, а розпакована тека — у `raw/local/mt5terminal/` (команда `7z x mt5terminal.chm
-oraw/local/mt5terminal`; 7-Zip узято з Windows, у WSL його немає). У шапці кожної теми стоїть адреса онлайн-довідки
`https://www.metatrader5.com/en/terminal/help`.

## Корпус лише локально

Корпус — це тексти тем, а індекс — кеш фрагментів, з якого підіймається сервер. Умови mql5.com не дозволяють поширювати вміст. Тому
**корпус, індекс і файли PDF у git не потрапляють** (`corpus/`, `index/` і `raw/` у `.gitignore`). У git лежать лише налаштування
примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/mql5-corpus-2026-11-13.tar.gz` разом із паспортом, файлами PDF і довідкою
терміналу в `raw/local/`. Копія лежить на Windows: `C:\Distr\mql5-corpus-2026-11-13.tar.gz`. Архів звірено з диском файл за файлом, а
копію — за SHA-256. Сервер підіймається з кешу `index/passages.json` і колекції Qdrant, тому тексти йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/mql5-corpus-2026-11-13.tar.gz -C instances/mql5
./df mql5 smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df mql5 vectors`: кеш збереться заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df mql5 serve
```

Сервер слухає порт `8958`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user mql5-docs http://127.0.0.1:8958/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. Перевірка: `./df mql5 smoke` і `./df mql5 quality`.
