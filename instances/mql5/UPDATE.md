# Оновлення корпусу mql5

Нове видання довідника MQL5 чи книжок не приходить само. Умови mql5.com забороняють збирати сайт програмами, тому людина завантажує
файли PDF браузером.

Правило: **нічого не видаляється.** Лише `vectors` прибирає точки своєї колекції, чиїх фрагментів уже немає в корпусі.

1. Поверніть тексти за [README, розділ «Корпус лише локально»](README.md#корпус-лише-локально).
2. Завантажте браузером новий PDF і покладіть його в `instances/mql5/raw/local/` на місце старого, з тим самим іменем.
3. Оновіть примірник. Довідник розбирається близько 15 хвилин, книжка MQL5 Programming for Traders — близько години:

```
./df mql5 refresh mql5-reference      # або mql5-book, neurobook
./df mql5 manifest
./df mql5 vectors
./df mql5 smoke
./df mql5 quality
```

4. Запишіть нове число фрагментів у `checks.json`, зробіть новий архів і звірте його з диском. Лише тоді видаляйте тексти з теки
   та попередній архів.

Джерела позначено `frozen`, тому `refresh` без імен їх не чіпає. Якщо тему перейменовано, `refresh` пише її новим файлом поруч зі
старим, і старий файл сам не зникає: такі файли прибирають вручну перед `manifest`.
