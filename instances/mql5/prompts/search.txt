Search the documentation of MQL5, the programming language of MetaTrader 5. The corpus holds three texts that MetaQuotes publishes
on mql5.com. The MQL5 Reference describes the language (types, operators, functions, classes, templates, preprocessor), the event
handlers (`OnInit`, `OnTick`, `OnCalculate`, `OnTrade`, `OnTradeTransaction`, `OnTimer`), every function group (trade
functions such as `OrderSend` and `PositionSelect`, the technical indicators such as `iMA` and `iRSI`, timeseries access such as
`CopyRates` and `CopyBuffer`, account, market and symbol information, charts and objects, files, networking, matrices and vectors,
ONNX models, OpenCL, DirectX, Python integration) and the Standard Library (`CTrade`, `CPositionInfo`, indicator and panel classes).
The book MQL5 Programming for Traders teaches the language and the APIs step by step with full program listings. The book Neural
Networks for Algorithmic Trading with MQL5 builds neural network models in MQL5 and OpenCL: layers, attention, training, testing.

Use this tool for: the signature of a function and the meaning of each parameter; what a function returns and how errors are reported;
how trade requests are filled and what each return code means; how an indicator handle and its buffers are read; how events reach a
program; how to call ONNX models and OpenCL from MQL5; how a neural network is built in MQL5. Write the query in English with the name
of the function, class or constant, such as `OrderSend` or `CopyBuffer`, or with plain words for what is wanted.

Do not use this tool for MQL4 itself (only the page on moving from MQL4 is here), Pine Script, Python libraries or the REST APIs of
brokers. Returns the matching excerpts with the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
