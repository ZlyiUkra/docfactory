# Hybrid Application
# джерело: https://github.com/nestjs/docs.nestjs.com/blob/dacbef74628f43d20544b75c1fb3b3e7fa33a18d/src/app/homepage/pages/faq/hybrid-application/hybrid-application.component.html
# отримано: 2026-09-21
# версія: 4

The hybrid application's an application with the connected microservice/s. It's possible to combine the `INestApplication` with the endless number of the `INestMicroservice` instances.

```typescript
const app = await NestFactory.create(ApplicationModule);
const microservice = app.connectMicroservice({
    transport: Transport.TCP,
});

await app.startAllMicroservicesAsync();
await app.listen(3001);
```
