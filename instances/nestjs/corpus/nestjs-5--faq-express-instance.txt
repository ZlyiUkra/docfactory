# Express instance
# джерело: https://github.com/nestjs/docs.nestjs.com/blob/8729a48188b1097a4f7d7bb8dc8a3d525297ce7e/src/app/homepage/pages/faq/express-instance/express-instance.component.html
# отримано: 2026-09-21
# версія: 5

In order to have a full control of the `express` lifecycle, you can pass a self-created instance as a second argument of the `NestFactory.create()` method.

```typescript
const server = express();
const app = await NestFactory.create(ApplicationModule, server);
```
