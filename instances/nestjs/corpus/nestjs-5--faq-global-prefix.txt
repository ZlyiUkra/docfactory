# Global Prefix
# джерело: https://github.com/nestjs/docs.nestjs.com/blob/8729a48188b1097a4f7d7bb8dc8a3d525297ce7e/src/app/homepage/pages/faq/global-prefix/global-prefix.component.html
# отримано: 2026-09-21
# версія: 5

In order to set a prefix for each route registered in the application at once, you can use the `setGlobalPrefix()` method of the `INestApplication` instance.

```typescript
const app = await NestFactory.create(ApplicationModule);
app.setGlobalPrefix('v1');
```
