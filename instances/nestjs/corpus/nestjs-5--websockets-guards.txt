There's no difference between web sockets guards and the regular guards. The only thing you should be aware of is that instead of throwing `HttpException`, you should use the `WsException`.

Hint The `WsException` class is exposed from `@nestjs/websockets` package.

Here is an example that makes use of a method-scoped guard (class-scoped works either):

```typescript
@UseGuards(AuthGuard)
@SubscribeMessage('events')
onEvent(client, data: any): WsResponse<any> {
  const event = 'events';
  return { event, data };
}
```
