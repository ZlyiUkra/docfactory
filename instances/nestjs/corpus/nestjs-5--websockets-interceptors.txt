There's no difference between regular interceptors and the web sockets interceptors. Here is an example that makes use of a manually instantiated method-scoped filter (class-scoped works either):

```typescript
@UseInterceptors(new TransformInterceptor())
@SubscribeMessage('events')
onEvent(client, data: any): WsResponse<any> {
  const event = 'events';
  return { event, data };
}
```
