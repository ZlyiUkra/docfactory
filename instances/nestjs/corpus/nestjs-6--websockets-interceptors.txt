# Interceptors
# джерело: https://github.com/nestjs/docs.nestjs.com/blob/0350411971ec2f5083837227ba786b40df24bf84/content/websockets/interceptors.md
# отримано: 2026-09-21
# версія: 6

There is no difference between regular interceptors and the web sockets interceptors. Here is an example that makes use of a manually instantiated method-scoped interceptor (class-scoped works too):

```typescript
@@filename()
@UseInterceptors(new TransformInterceptor())
@SubscribeMessage('events')
handleEvent(client: Client, data: unknown): WsResponse<unknown> {
  const event = 'events';
  return { event, data };
}
@@switch
@UseInterceptors(new TransformInterceptor())
@SubscribeMessage('events')
handleEvent(client, data) {
  const event = 'events';
  return { event, data };
}
```
