# Global prefix
# джерело: https://github.com/nestjs/docs.nestjs.com/blob/9782b894805423cc95b02d7e2f8367671e38dd48/content/faq/global-prefix.md
# отримано: 2026-09-21
# версія: 7

To set a prefix for **every route** registered in an HTTP application, use the `setGlobalPrefix()` method of the `INestApplication` instance.

```typescript
const app = await NestFactory.create(AppModule);
app.setGlobalPrefix('v1');
```
