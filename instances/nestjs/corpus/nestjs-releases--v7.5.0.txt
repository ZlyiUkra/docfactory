# NestJS release: v7.5.0
# джерело: https://github.com/nestjs/nest/releases/tag/v7.5.0
# отримано: 2026-09-21
# версія: 7.5.0

Tag v7.5.0, published 2020-11-02.

### Features

- **common**: support conditional cache TTL value (support async factories) https://github.com/nestjs/nest/pull/5366
- **core**: add Server-Sent Events (SSE) support https://github.com/nestjs/nest/pull/4842
- **core**: add `abortOnError` option. When enabled, Nest will rethrow the exception instead of killing the process https://github.com/nestjs/nest/pull/5327
- **microservices**: pass `GrpcCall` reference to call handlers https://github.com/nestjs/nest/pull/5143

### Improvements

- **microservices**: update Kafka configuration interfaces, add missing options https://github.com/nestjs/nest/pull/5443 https://github.com/nestjs/nest/pull/5634 https://github.com/nestjs/nest/pull/5638
- **microservices**: add `persistent` option https://github.com/nestjs/nest/pull/5597 and support `urls` object https://github.com/nestjs/nest/pull/5609 (RabbitMQ)

### Bug fixes

- **common**: `expectedType` should take precedence over `metatype` in the `ValidationPipe` https://github.com/nestjs/nest/pull/5605
- **core**: use `.toString()` as functions representation when serialising dynamic modules metadata https://github.com/nestjs/nest/pull/5189
- **core**: fix invalid middleware execution order when request-scoped dependencies are being used by a host middleware https://github.com/nestjs/nest/pull/5623
- **microservices**: await consumer and producer disconnect operations https://github.com/nestjs/nest/pull/5422
- **microservices**: check `replyTo` channel presence (NATS) https://github.com/nestjs/nest/pull/5530
- **platform-fastify**: add missing chaining API to the `inject()` method https://github.com/nestjs/nest/pull/5628
