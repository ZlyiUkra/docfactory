# Source Maps
# джерело: https://github.com/vercel/next.js/blob/v10.0.9-canary.4/docs/advanced-features/source-maps.md
# отримано: 2026-10-01
# версія: 10.0.9-canary, 10.0.8, 10.0.8-canary, 10.0.7, 10.0.7-canary, 10.0.6, 10.0.6-canary, 10.0.5, 10.0.5-canary, 10.0.4, 10.0.4-canary

Enables browser source map generation during the production build.

Source Maps are enabled by default during development. During production builds they are disabled as generation source maps can significantly increase build times and memory usage while being generated.

Next.js provides a configuration flag you can use to enable browser source map generation during the production build:

```js
// next.config.js
module.exports = {
  productionBrowserSourceMaps: true,
}
```

When the `productionBrowserSourceMaps` option is enabled the source maps will be output in the same directory as the JavaScript files, Next.js will automatically serve these files when requested.

## Caveats

- Can increase `next build` time
- Increases memory usage during `next build`
