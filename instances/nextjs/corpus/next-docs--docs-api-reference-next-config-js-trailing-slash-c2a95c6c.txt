# Trailing Slash
# джерело: https://github.com/vercel/next.js/blob/v9.5.2-canary.0/docs/api-reference/next.config.js/trailing-slash.md
# отримано: 2026-10-01
# версія: 9.5.2-canary, 9.5.1, 9.5.1-canary, 9.5.0, 9.4.5-canary

Configure Next.js pages to resolve with or without a trailing slash.

By default Next.js will redirect urls with trailing slashes to their counterpart without a trailing slash. For example `/about/` will redirect to `/about`. You can configure this behavior to act the opposite way, where urls without trailing slashes are redirected to their counterparts with trailing slashes.

Open `next.config.js` and add the `trailingSlash` config:

```js
module.exports = {
  trailingSlash: true,
}
```

With this option set, urls like `/about` will redirect to `/about/`.
