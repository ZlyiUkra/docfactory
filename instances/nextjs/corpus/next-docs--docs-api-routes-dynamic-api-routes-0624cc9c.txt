# Dynamic API Routes
# джерело: https://github.com/vercel/next.js/blob/v9.1.7-canary.15/docs/api-routes/dynamic-api-routes.md
# отримано: 2026-10-01
# версія: 9.1.7-canary

API pages support dynamic routes, and follow the same file naming rules used for `pages`.

For example, the API route `pages/api/post/[pid].js` has the following code:

```js
export default (req, res) => {
  const {
    query: { pid },
  } = req

  res.end(`Post: ${pid}`)
}
```

Now, a request to `/api/post/abc` will respond with the text: `Post: abc`.
