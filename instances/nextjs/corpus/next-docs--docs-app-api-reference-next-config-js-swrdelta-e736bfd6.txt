# App Router: swrDelta
# джерело: https://github.com/vercel/next.js/blob/v15.0.0-rc.0/docs/02-app/02-api-reference/05-next-config-js/swrDelta.mdx
# отримано: 2026-10-01
# версія: 15.0.0-rc.0, 15.0.0-canary, 14.3.0-canary

Set a custom stale-while-revalidate period for ISR enabled pages.

You can specify a custom stale-while-revalidate period for CDNs to consume in the `Cache-Control` header for ISR enabled pages.

Open `next.config.js` and add the `swrDelta` config:

`next.config.js`

```js
module.exports = {
  // one year in seconds
  swrDelta: 31536000,
}
```

Now instead of an empty `stale-while-revalidate` period being provided in the `Cache-Control` header, the custom period will be included.
