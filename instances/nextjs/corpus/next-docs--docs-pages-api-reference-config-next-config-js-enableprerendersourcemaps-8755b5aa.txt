# Pages Router: enablePrerenderSourceMaps
# джерело: https://github.com/vercel/next.js/blob/v16.4.0-canary.55/docs/02-pages/04-api-reference/04-config/01-next-config-js/enablePrerenderSourceMaps.mdx
# отримано: 2026-10-01
# версія: 16.4.0-canary

Enable source maps for errors during prerendering in next build.

The `enablePrerenderSourceMaps` option lets Node.js use existing source maps during the prerender phase of `next build`. When source maps are available, error stack traces point to the original source code. It defaults to `true`.

This option does not generate source maps. Webpack does not generate server source maps by default. To generate them when investigating prerender errors, use `next build --debug-prerender`.

To disable it, set `enablePrerenderSourceMaps` to `false`:

`next.config.ts`

```ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  enablePrerenderSourceMaps: false,
}

export default nextConfig
```

`next.config.js`

```js
/** @type {import('next').NextConfig} */
const nextConfig = {
  enablePrerenderSourceMaps: false,
}

module.exports = nextConfig
```

## Reference

| Option                      | Type      | Default |
| --------------------------- | --------- | ------- |
| `enablePrerenderSourceMaps` | `boolean` | `true`  |

Disabling source maps during prerendering can reduce build memory usage, but makes prerendering errors harder to debug.

## Version History

| Version   | Changes                                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
