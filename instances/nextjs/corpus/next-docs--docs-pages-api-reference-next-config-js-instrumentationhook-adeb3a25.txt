Use the instrumentationHook option to set up instrumentation in your Next.js App.

The experimental `instrumentationHook` option allows you to set up instrumentation via the `instrumentation` file in your Next.js App.

`next.config.js`

```js
module.exports = {
  experimental: {
    instrumentationHook: true,
  },
}
```

| Version   | Changes                                                     |
