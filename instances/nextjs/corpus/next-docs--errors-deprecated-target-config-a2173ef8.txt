# Deprecated target config
# джерело: https://github.com/vercel/next.js/blob/v12.0.2-canary.8/errors/deprecated-target-config.md
# отримано: 2026-10-01
# версія: 12.0.2-canary, 12.0.1, 12.0.1-canary, 12.0.0, 11.1.3-canary

#### Why This Error Occurred

The `target` property in `next.config.js` has been deprecated. Please migrate to leverage the default target instead.

#### Possible Ways to Fix It

For serverless cases, leverage the new output file traces or deploy your application somewhere where they are leveraged automatically like Vercel.
