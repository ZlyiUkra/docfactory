# `Head` or `NextScript` attribute `crossOrigin` is deprecated
# джерело: https://github.com/vercel/next.js/blob/v8.1.1-canary.40/errors/doc-crossorigin-deprecated.md
# отримано: 2026-10-01
# версія: 8.1.1-canary, 8.1.0, 8.0.5-canary, 8.0.4, 8.0.4-canary, 8.0.3, 8.0.3-canary, 8.0.2, 8.0.2-canary, 8.0.1, 8.0.1-canary, 8.0.0, 8.0.0-canary, 7.0.2-canary

#### Why This Error Occurred

This option has been moved to `next.config.js`.

#### Possible Ways to Fix It

Add the config option:

```js
// next.config.js
module.exports = {
  crossOrigin: 'anonymous'
}
```
