# Redirect During getStaticProps Prerendering
# джерело: https://github.com/vercel/next.js/blob/v12.1.6-canary.5/errors/gsp-redirect-during-prerender.md
# отримано: 2026-10-01
# версія: 12.1.6-canary, 12.1.5, 12.1.5-canary, 12.1.4, 12.1.4-canary, 12.1.3, 12.1.3-canary, 12.1.2, 12.1.2-canary, 12.1.1, 12.1.1-canary, 12.1.0, 12.0.11-canary, 12.0.10, 12.0.10-canary

#### Why This Error Occurred

The `redirect` value was returned from `getStaticProps` during prerendering which is invalid.

#### Possible Ways to Fix It

Remove any paths that result in a redirect from being prerendered in `getStaticPaths` and enable `fallback: true` to handle redirecting for these pages.
