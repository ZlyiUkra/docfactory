# Install `sharp` to Use Built-In Image Optimization
# джерело: https://github.com/vercel/next.js/blob/v10.0.1-canary.1/errors/install-sharp.md
# отримано: 2026-10-01
# версія: 10.0.1-canary, 10.0.0, 9.5.6-canary

#### Why This Error Occurred

Using Next.js' built-in Image Optimization requires that you install `sharp`.

Since `sharp` is optional, it may have been skipped if you installed `next` with the `--no-optional` flag or it may have been skipped if your platform does not support `sharp`.

#### Possible Ways to Fix It

Option 1: Install the `sharp` package in your project.

```bash
npm i sharp
# or
yarn add sharp
```

Option 2: Configure an external loader in `next.config.js` such as imgix.

```js
module.exports = {
  images: {
    path: 'https://example.com/myaccount/',
    loader: 'imgix',
  },
}
```
