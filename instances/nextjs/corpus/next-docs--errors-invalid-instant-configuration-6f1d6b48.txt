# Invalid Instant Configuration
# джерело: https://github.com/vercel/next.js/blob/v16.3.0-preview.2/errors/invalid-instant-configuration.mdx
# отримано: 2026-10-01
# версія: 16.3.0-preview.2, 16.3.0-preview.1, 16.3.0-preview.0, 16.3.0-canary

## Why This Message Occurred

You provided an invalid configuration for `export const unstable_instant` in a Layout or Page file.

### Example of Correct Usage

#### Indicating instant UI

`app/[slug]/page.tsx`

```tsx
export const unstable_instant = true
```

#### Customizing the validation level

`app/[slug]/page.tsx`

```tsx
export const unstable_instant = {
  level: 'warning',
}
```

#### Indicating that there is no instant UI

This does not disable prefetching.

`app/[slug]/page.tsx`

```tsx
export const unstable_instant = false
```
