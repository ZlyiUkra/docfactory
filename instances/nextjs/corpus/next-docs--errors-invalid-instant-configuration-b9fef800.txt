# Invalid Instant Configuration
# джерело: https://github.com/vercel/next.js/blob/v16.2.0-canary.28/errors/invalid-instant-configuration.mdx
# отримано: 2026-10-01
# версія: 16.2.0-canary

## Why This Message Occurred

You provided an invalid configuration for `export const unstable_instant` in a Layout or Page file.

### Example of Correct Usage

#### Static Prefetching

`app/.../layout.tsx`

```tsx
export const unstable_instant = {
  prefetch: 'static',
}
```

#### Runtime Prefetching

`app/[slug]/page.tsx`

```tsx
export const unstable_instant = {
  prefetch: 'runtime',
  samples: [
    {
      cookies: [{ name: 'experiment', value: 'A' }],
      params: { slug: 'example' },
    },
  ],
}
```
