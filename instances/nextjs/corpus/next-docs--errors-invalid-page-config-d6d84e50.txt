# Invalid Page Config
# джерело: https://github.com/vercel/next.js/blob/v9.0.5/errors/invalid-page-config.md
# отримано: 2026-10-01
# версія: 9.0.5, 9.0.5-canary, 9.0.4, 9.0.4-canary, 9.0.3, 9.0.3-canary, 9.0.2, 9.0.2-canary

#### Why This Error Occurred

In one of your pages you did `export const config` with an invalid value.

#### Possible Ways to Fix It

The page's config must be an object initialized directly when being exported.

This is not allowed

```js
export const config = 'hello world'
```

This is allowed

```js
export const config = { amp: true }
```
