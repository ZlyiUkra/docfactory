# `<title>` should not be used in \_document.js's `<Head>`
# джерело: https://github.com/vercel/next.js/blob/v9.4.5-canary.28/errors/no-document-title.md
# отримано: 2026-10-01
# версія: 9.4.5-canary, 9.4.4, 9.4.4-canary, 9.4.3, 9.4.3-canary

#### Why This Error Occurred

Adding `<title>` in `pages/_document.js` will lead to unexpected results with `next/head` since `_document.js` is only rendered on the initial pre-render.

#### Possible Ways to Fix It

Set `<title>` in `pages/_app.js` instead:

```js
// pages/_app.js
import App from 'next/app'
import Head from 'next/head'
import React from 'react'

export default class MyApp extends App {
  static async getInitialProps({ Component, ctx }) {
    let pageProps = {}

    if (Component.getInitialProps) {
      pageProps = await Component.getInitialProps(ctx)
    }

    return { pageProps }
  }

  render() {
    const { Component, pageProps } = this.props

    return (
      <>
        <Head>
          <title>My new cool app</title>
        </Head>
        <Component {...pageProps} />
      </>
    )
  }
}
```
