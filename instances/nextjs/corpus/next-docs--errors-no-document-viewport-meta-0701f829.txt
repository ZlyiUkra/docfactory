# Viewport `meta` tags should not be used in `_document.js`'s `<Head>`
# джерело: https://github.com/vercel/next.js/blob/v10.0.5/errors/no-document-viewport-meta.md
# отримано: 2026-10-01
# версія: 10.0.5, 10.0.5-canary, 10.0.4, 10.0.4-canary, 10.0.3, 10.0.3-canary, 10.0.2, 10.0.2-canary, 10.0.1, 10.0.1-canary, 10.0.0, 9.5.6-canary, 9.5.5, 9.5.5-canary, 9.5.4, 9.5.4-canary

#### Why This Error Occurred

Adding `<meta name="viewport" ...>` in `pages/_document.js` will lead to unexpected results since it cannot be deduped.
The viewport tag should be handled by `next/head` in `pages/_app.js`.

#### Possible Ways to Fix It

Set your viewport `meta` tag in `pages/_app.js` instead:

```tsx
// pages/_app.js
import Head from 'next/head'

function MyApp({ Component, pageProps }) {
  return (
    <>
      <Head>
        <meta name="viewport" content="viewport-fit=cover" />
      </Head>
      <Component {...pageProps} />
    </>
  )
}

export default MyApp
```
