# No HTML link for pages
# джерело: https://github.com/vercel/next.js/blob/v11.1.1-canary.11/errors/no-html-link-for-pages.md
# отримано: 2026-10-01
# версія: 11.1.1-canary, 11.1.0, 11.0.2-canary, 11.0.1, 11.0.1-canary, 11.0.0, 10.2.4-canary, 10.2.3, 10.2.3-canary, 10.2.2, 10.2.2-canary, 10.2.1, 10.2.1-canary

### Why This Error Occurred

An HTML anchor element, `<a>`, was used to navigate to a page route without using the `Link` component.

The `Link` component is required in order to enable client-side route transitions between pages and provide a single-page app experience.

### Possible Ways to Fix It

Make sure to import the `Link` component and wrap anchor elements that route to different page routes.

**Before:**

```jsx
function Home() {
  return (
    <div>
      <a href="/about">About Us</a>
    </div>
  )
}
```

**After:**

```jsx
import Link from 'next/link'

function Home() {
  return (
    <div>
      <Link href="/about">
        <a>About Us</a>
      </Link>
    </div>
  )
}

export default Home
```
