# Using Node.js module in Edge runtime
# джерело: https://github.com/vercel/next.js/blob/v12.3.7/errors/node-module-in-edge-runtime.md
# отримано: 2026-10-01
# версія: 12.3.7, 12.3.6, 12.3.5, 12.3.4, 12.3.3, 12.3.2, 12.3.2-canary, 12.3.1, 12.3.1-canary, 12.3.0, 12.2.6, 12.2.6-canary, 12.2.5, 12.2.5-canary, 12.2.4, 12.2.4-canary, 12.2.3, 12.2.3-canary, 12.2.2, 12.2.2-canary, 12.2.1, 12.2.1-canary

#### Why This Error Occurred

The code in your Middleware or your Edge API routes is using a feature from Node.js runtime.

However, the Edge Runtime does not support Node.js APIs and globals.

#### Possible Ways to Fix It

When it runs in dev mode, your application will show in the console, and in your browser, which file is importing and using an unsupported module.
This module must be avoided: either by not importing it, or by replacing it with a polyfill.

Please note your code can import Node.js modules **as long as they are not used**.
The following example builds and works at runtime:

```ts
import { NextResponse } from 'next/server'
import { spawn } from 'child_process'

export default async function middleware() {
  if (process.version) {
    spawn('ls', ['-lh'])
  }
  return NextResponse.next()
}
```

Dynamic imports in unreachable code path is also supported.
