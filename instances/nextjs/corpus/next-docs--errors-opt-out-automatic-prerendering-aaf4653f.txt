# Opt-out of Automatic Prerendering
# джерело: https://github.com/vercel/next.js/blob/v9.0.5/errors/opt-out-automatic-prerendering.md
# отримано: 2026-10-01
# версія: 9.0.5, 9.0.5-canary, 9.0.4, 9.0.4-canary, 9.0.3, 9.0.3-canary, 9.0.2, 9.0.2-canary, 9.0.1, 9.0.1-canary, 9.0.0, 8.1.1-canary

#### Why This Warning Occurred

You are using `getInitialProps` in your Custom `<App>`.

This causes **all pages** to be executed on the server -- disabling Automatic Prerendering.

#### Possible Ways to Fix It

Be sure you meant to use `getInitialProps` in `pages/_app`!
There are some valid use cases for this, but it is often better to handle `getInitialProps` on a _per-page_ basis.

If you copied the Custom `<App>` example, you may be able to remove your `getInitialProps`.

The following `getInitialProps` does nothing and may be removed:

```js
class MyApp extends App {
  // Remove me, I do nothing!
  static async getInitialProps({ Component, ctx }) {
    let pageProps = {}

    if (Component.getInitialProps) {
      pageProps = await Component.getInitialProps(ctx)
    }

    return { pageProps }
  }

  render() {
    // ...
  }
}
```
