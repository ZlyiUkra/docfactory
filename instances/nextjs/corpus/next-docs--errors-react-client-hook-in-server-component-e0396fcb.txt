# React client hook in Server Component
# джерело: https://github.com/vercel/next.js/blob/v15.0.8/errors/react-client-hook-in-server-component.mdx
# отримано: 2026-10-01
# версія: 15.0.8, 15.0.7, 15.0.6, 15.0.5, 15.0.4, 15.0.4-canary, 15.0.3, 15.0.3-canary

## Why This Error Occurred

You are using a React client hook in a Server Component.

## Possible Ways to Fix It

Mark the component using the hook as a Client Component by adding `'use client'` at the top of the file.

### Before

`app/example.js`

```jsx
import { useEffect } from 'react'

export default function Example() {
  useEffect(() => {
    console.log('in useEffect')
  })
  return <p>Hello world</p>
}
```

### After

`app/example.js`

```jsx
'use client'

import { useEffect } from 'react'

export default function Example() {
  useEffect(() => {
    console.log('in useEffect')
  })
  return <p>Hello world</p>
}
```
