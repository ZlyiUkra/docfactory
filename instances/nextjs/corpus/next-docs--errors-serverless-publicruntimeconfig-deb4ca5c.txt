# Using `publicRuntimeConfig` with `target` set to `serverless`
# джерело: https://github.com/vercel/next.js/blob/v9.1.2-canary.1/errors/serverless-publicRuntimeConfig.md
# отримано: 2026-10-01
# версія: 9.1.2-canary, 9.1.1, 9.1.1-canary, 9.1.0, 9.0.9-canary, 9.0.8, 9.0.8-canary, 9.0.7, 9.0.7-canary, 9.0.6, 9.0.6-canary, 9.0.5, 9.0.5-canary, 9.0.4, 9.0.4-canary, 9.0.3, 9.0.3-canary, 9.0.2, 9.0.2-canary, 9.0.1, 9.0.1-canary, 9.0.0, 8.1.1-canary

#### Why This Error Occurred

In the `serverless` target environment `next.config.js` is not loaded, so we don't support `publicRuntimeConfig`.

#### Possible Ways to Fix It

Use config option `env` to set **build time** variables like such:

```js
// next.config.js
module.exports = {
  env: {
    special: 'value',
  },
}
```

```js
// pages/index.js
console.log(process.env.special) // value
```
