# Using `publicRuntimeConfig` with `target` set to `serverless`
# джерело: https://github.com/vercel/next.js/blob/v8.1.1-canary.40/errors/serverless-publicRuntimeConfig.md
# отримано: 2026-10-01
# версія: 8.1.1-canary, 8.1.0, 8.0.5-canary, 8.0.4, 8.0.4-canary, 8.0.3, 8.0.3-canary, 8.0.2, 8.0.2-canary, 8.0.1, 8.0.1-canary, 8.0.0, 8.0.0-canary

#### Why This Error Occurred

In the `serverless` target environment `next.config.js` is not loaded, so we don't support `publicRuntimeConfig`.

#### Possible Ways to Fix It

Use config option `env` to set **build time** variables like such:

```js
// next.config.js
module.exports = {
  env: {
    special: "value"
  }
}
```

```js
// pages/index.js
console.log(process.env.special) // value
```
