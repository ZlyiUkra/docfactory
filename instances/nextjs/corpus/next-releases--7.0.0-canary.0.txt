Tag 7.0.0-canary.0, published 2018-08-16, pre-release.

## Major

- Implement webpack autoDLLPlugin in development, speeding up rebuilds a bit: #4951
- Upgrade Babel to 7.0.0-rc.1 (#4937)
  - Make sure all your `@babel/` dependencies are using version `7.0.0-rc.1`
  - See https://github.com/babel/babel/releases for breaking changes
- Upgrade styled-jsx to v3 (#4936)
  - See https://github.com/zeit/styled-jsx/releases/tag/v3.0.0 for changes
  - The main breaking change being that global external styles now require `css.global` https://github.com/zeit/styled-jsx#external-css-and-styles-outside-of-the-component
