### Major Changes

- Webpack 4, react-error-overlay, react-loadable: #4639
- Implement hard-source-webpack-plugin: #5181
- Implement webpack autoDLLPlugin in development: #4951
- Throw error if getInitialProps is defined as as instance method: #4922
- Remove __next-error div: #5107
- Upgrade to Babel 7 stable: #5042
  - Note that this is semi-breaking as we already used Babel 7 beta. If you don't have a `.babelrc` there is no breaking change. If you do have a `.babelrc` you'll have to upgrade the specific preset/plugin to the latest version.
  - Make sure all your `@babel/` dependencies are using version `7.0.0`
  - See https://github.com/babel/babel/releases for breaking changes
- Upgrade styled-jsx to v3 (#4936)
  - See https://github.com/zeit/styled-jsx/releases/tag/v3.0.0 for changes
  - The main breaking change being that global external styles now require `css.global` https://github.com/zeit/styled-jsx#external-css-and-styles-outside-of-the-component
- Rename commons directory to runtime: #4853
- Compile pages to .next/static directory: #4828
- Use nonce attribute for all scripts and preloads if provided: #4539
- Support `events` emitter for router: #4726
