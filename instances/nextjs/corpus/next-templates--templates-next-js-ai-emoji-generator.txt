## Tech Stack

- Replicate - AI provider
- Bun - Package Manager
- PlanetScale - MySQL database
- Prisma - ORM
- Next.js - App Router, Server Actions
- Vercel Blob - Storage Bucket
- Vercel KV - Redis Database
- Vercel - Hosting

## Deploy Your Own

You can deploy this template to Vercel with the button below:

Deploy with Vercel

Note that you'll need to:

- Set up Replicate
- Set up PlanetScale
- Set up Vercel Blob
- Set up Vercel KV
