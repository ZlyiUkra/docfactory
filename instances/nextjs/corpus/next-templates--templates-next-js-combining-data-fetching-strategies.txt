### Clone and Deploy

Execute `create-next-app` with npm or Yarn to bootstrap the example:

```bash
npx create-next-app --example https://github.com/vercel/examples/tree/main/solutions/combining-data-fetching-strategies combining-data-fetching-strategies
# or
yarn create next-app --example https://github.com/vercel/examples/tree/main/solutions/combining-data-fetching-strategies combining-data-fetching-strategies
```

Next, run Next.js in development mode:

```bash
npm install
npm run dev

# or

yarn
yarn dev
```

Deploy it to the cloud with Vercel (Documentation).
