A minimal template for building full-stack React applications using Next.js, Vercel, and Convex.

## Welcome to your Convex + Vercel app

This is a Convex project demonstrating how to use Convex with Vercel.

After the initial setup (<2 minutes) you'll have a working full-stack app using:

- Convex as your backend (database, server logic)
- React as your frontend (web page interactivity)
- Next.js for optimized web hosting and page routing
- Tailwind for building great looking accessible UI
- Vercel for hosting and deployment by integrating Convex through the Vercel Marketplace.
