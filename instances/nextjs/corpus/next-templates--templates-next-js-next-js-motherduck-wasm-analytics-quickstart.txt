## Next.js MotherDuck Wasm analytics quickstart

This is a Next.js app using the MotherDuck storage backend with the Wasm-SDK client, with an interactive data analytics example. A live demo can be found here.

A minimal starter template can be found here.

Deploy with Vercel

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open http://localhost:3000 with your browser to see the result.
