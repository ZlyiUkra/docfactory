A full-stack React template with Next.js, Vercel, using native AWS integration.

## AWS Aurora DQSL Movies Demo

This demo uses AWS DSQL Postgres with Next.js to fetch movies from the database. It is able to securely connect to DSQL without using hardcoded access tokens through Vercel's OIDC Federation.

## Requirements

- Installed Aurora DSQL. You can do that via Vercel Marketplace

## Local Setup

1. Pull vercel environment variables locally

```bash
vercel env pull
```

2. Install dependencies:

```bash
pnpm install
```

3. Run migrations to create tables:

```bash
pnpm run db:migrate
```

4. Seed the database with movie data:

```bash
pnpm run db:seed
```

5. Start the development server:

```bash
pnpm run dev
```
