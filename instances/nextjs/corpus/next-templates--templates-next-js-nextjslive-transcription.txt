## Local Development

```bash
git clone https://github.com/deepgram-devs/nextjs-live-transcription.git
cd nextjs-live-transcription
npm install
cp sample.env.local .env.local  # Add your DEEPGRAM_API_KEY
npm run dev
```

Open http://localhost:3000 in your browser.
