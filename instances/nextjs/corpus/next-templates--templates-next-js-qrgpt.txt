## Tech Stack

- Next.js App Router
- Replicate for the AI model
- Vercel Blob for image storage
- Vercel KV for redis storage and rate limiting
- Shadcn UI for the component library

## Deploy Your Own

You can deploy this template to Vercel with the button below:

Deploy with Vercel

Note that you'll need to:

- Set up Replicate
- Set up Vercel KV
- Set up Vercel Blob
