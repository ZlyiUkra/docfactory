## Instructions

1. Define environment variables in `.env` file.

```sh
cp .env.example .env
```

2. Install dependencies:

```sh
npm install
# or
pnpm install
```

3. Run Next.js locally:

```sh
npm run dev
```

4. Run React Email locally:

```sh
npm run email
```

5. Submit form
