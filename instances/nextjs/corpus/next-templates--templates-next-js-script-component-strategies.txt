## How to Use

You can choose from one of the following two methods to use this repository:

### Clone and Deploy

Execute `create-next-app` with npm or Yarn to bootstrap the example:

```bash
npx create-next-app --example https://github.com/vercel/examples/tree/main/solutions/script-component-strategies script-component-strategies
# or
yarn create next-app --example https://github.com/vercel/examples/tree/main/solutions/script-component-strategies script-component-strategies
```

Next, run Next.js in development mode:

```bash
npm install
npm run dev

# or

yarn
yarn dev
```

Deploy it to the cloud with Vercel (Documentation).
