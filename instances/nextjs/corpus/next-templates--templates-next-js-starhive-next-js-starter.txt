# отримано: 2026-10-01

Repository: https://github.com/starhive-labs/starhive-nextjs-starter
Demo: https://starhive-nextjs-starter.vercel.app/

Creates a Next.js project connected to Starhive as a backend. Easy onboarding flow with domain code generation.

This is a starter project using Next.js and Starhive.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open http://localhost:3000 with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses `next/font` to automatically optimize and load Inter, a custom Google Font.
