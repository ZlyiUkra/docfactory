Return the full text of one excerpt of the Node.js and npm documentation (the Node.js API
reference of the even majors 12 to 26, the nodejs.org/learn guides, the npm CLI documentation of
npm 6 to 12 and the docs.npmjs.com guides) by its identifier, together with the document it
belongs to, the URL it was taken from and the date the text was fetched from that URL -- so a
quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a function signature, an option, the "Added in" and "History"
lines of an API, a package.json field or an npm command flag quoted half-way is how a wrong
answer starts.

Do not guess identifiers: they are not URLs, not module names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: name the Node.js or npm version when it
matters, keep identifiers and titles in English, use Ukrainian words for Ukrainian prose, and
name the document you read.
