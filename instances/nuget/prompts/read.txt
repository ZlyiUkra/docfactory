Return the full text of one excerpt of the documentation of NuGet (the package manager of .NET) by its
identifier, together with the page or file it belongs to, every version whose documents contain this text, the URL
it was taken from and the date the text was fetched -- so a quotation can be checked against the source even a
year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a command with its options, a nuget.config or project file fragment, an MSBuild property with its
default, an error or warning with its fix, an HTTP request and response of the V3 protocol, a type or member of the
API reference with its parameters, return value and exceptions, a method of the source code or a test, a package
version and its dependencies, a release note with a breaking change, a section of a design specification.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the version (or say the page has no version) and the page you read.
