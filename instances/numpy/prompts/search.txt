Search the documentation of NumPy, the Python library for n-dimensional arrays and numerical computing. The corpus holds the
documentation site of every minor line 1.13-2.5 as published on numpy.org: the user guide (array creation, indexing, broadcasting,
copies and views, dtypes, structured arrays, I/O), the API reference generated from the code (one page per function, method and
class, such as `numpy.argsort`, `numpy.ndarray.astype`, `numpy.searchsorted`, `numpy.lib.stride_tricks.sliding_window_view`,
`numpy.random.Generator`), the C API, F2PY, the release notes of every version with deprecations and expired deprecations, the NumPy
2.0 migration guide and the developer guide; plus the PyPI records of every stable version.

Use this tool for: the signature, parameters and return value of a NumPy function, dtype and type promotion rules, broadcasting and
indexing rules, memory layout, views and copies, `float32` versus `float64` precision, vectorizing a loop, random number generation,
saving and loading arrays, and what changed or was removed between versions (for example `np.float` removed in 1.24, the NumPy 2.0
namespace cleanup). Write the query in English, with the name of the function or the page, such as `numpy.searchsorted` or
`broadcasting`. Give a version in the filter when the answer depends on it.

Do not use it for CuPy, pandas, SciPy, XGBoost, LightGBM or the Python language: other servers hold them. The site publishes no line
older than 1.13. Returns the matching excerpts with the versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. NumPy 2.5 is the newest line. Search without `version` first; when the user names their
NumPy version, search that line, written as `numpy-2.5` or `numpy-1.26`. Every answer about a function says which line it
is for: functions, aliases and defaults were added, renamed and removed between lines.
