Return the full text of one excerpt of the NVIDIA Container Toolkit documentation by its identifier, together
with the page or file it belongs to, every release whose documents contain this text, the URL it was taken from
and the date the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: an installation or configuration command (nvidia-ctk runtime configure, nvidia-ctk cdi generate, the
apt or dnf repository setup), a flag of nvidia-ctk, nvidia-cdi-hook or the installer with its usage and default
(the Flags list of a cli.Command is long Go code), a config.toml option, an environment variable and its
accepted values, a step of the troubleshooting page, a field of the CDI specification, a release note or
changelog entry, the dependencies and versions of an APT package, a type or function of the nvcdi Go API.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the release (or say the document has no version) and the page you
read.
