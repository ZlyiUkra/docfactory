Cost Management (upgrading to Pay As You Go, budgets and alerts, cost analysis, invoices), IAM

Call this when a question is about running something on Oracle Cloud: what the Always Free
tier gives and its limits, why an Always Free instance was stopped or reclaimed, creating an
Ampere A1 instance and what to do on "out of host capacity", opening ports 80 and 443
(security list ingress rules, network security groups), public IPs, SSH keys, boot volume
size, regions and home region, upgrading to Pay As You Go and keeping costs at zero with
budgets, users, groups, policies and compartments, OKE clusters and load balancers, Object
Storage buckets, DNS zones, sending email, the OCI CLI and SDKs, and what changed in a service
and when. Example query: "Always Free Ampere A1 OCPU memory".

Do not call this for OCI databases (Autonomous Database, MySQL HeatWave, Exadata), AI and
analytics services, Functions, API Gateway, Vault, Logging and the other OCI services not
listed above (only the listed ones are here), for other clouds, or for Kubernetes, k3s, Linux
and Docker themselves (the kubernetes, linux and docker instances).

Versions. The site has no versions: it describes OCI as it stands now, and the release notes
are its history, each named "Release note: <title> (date)". When a limit, a price, a shape or
a rule may have changed, search the release notes too and give the date. `version` applies
only to oci-sdk ("2" or "2.142"): its registry table, README and changelog carry versions;
site pages carry none.

Where the documentation lives. Documents are named "<service>: <page title>" -- "Free Tier:
Always Free Resources", "Compute: Creating an Instance", "Networking: Security Lists", "IAM:
Policy Syntax", "OKE: Creating a Cluster", "Billing: Budgets Overview", "Developer: ..." --
so name the service in the query when a title is common to many ("Overview", "Required IAM
Policy").

Write the query in English, with the names the documentation uses (Always Free, Ampere A1,
VM.Standard.A1.Flex, VM.Standard.E2.1.Micro, OCPU, out of host capacity, reclamation of idle
compute instances, home region, availability domain, tenancy, compartment, OCID, VCN, subnet,
security list, ingress rule, stateful, network security group, internet gateway, route table,
reserved public IP, boot volume, cloud-init, Pay As You Go, budget, alert rule, policy, Allow
group, dynamic group, identity domain, API signing key, oci-cli, config file, OKE, node pool,
load balancer shape, flexible load balancer, bucket, pre-authenticated request, oci-sdk).
Everything here is English -- the excerpts, the word index and the meaning index alike -- and
the word index keeps only latin letters and digits, so a query written in Ukrainian, Russian
or any other non-latin script matches nothing at all and comes back with `found: 0`. When the
user asks in another language, translate the question into these terms first, then search.

The `search` field of the result says how the excerpts were found: "words" means the words of
the query had to appear in the text, so a query phrased in other words than the documentation
uses may miss; "meaning+words" means a second, meaning-based index answered as well, and a
paraphrase had a chance.

Answer in the language the user wrote in. When the question is about a limit, a rule or a
change, answer point by point: what the rule is; its numbers; since when, if a release note
says; what the user must do -- each point with the document it rests on; a point the excerpts
do not support is left out, not guessed. When that language is Ukrainian, write as a
Ukrainian engineer writes, not as a translation from English: plain technical prose, and the
Ukrainian word wherever one exists -- "уривок", not "ексерпт"; "машина" or "інстанс",
"мережа", "підмережа", "диск", "політика", "регіон", "бюджет". Never call this set of
documents "корпус" -- say "документація Oracle Cloud". Service, shape, resource, Console
menu, policy and command names stay in English, spelled exactly as the documentation spells
them. Build the answer out of the excerpts that came back, not out of memory: if an excerpt
was cut, read the whole of it before describing what it says.

Arguments: `query` is free text; `k` is how many excerpts to return, 1 to 10, default 3;
`version` (optional) narrows oci-sdk excerpts to a version.
Excerpt text is cut at 600 characters -- pass the `id` of an excerpt to `read_section` to get
the whole thing.
