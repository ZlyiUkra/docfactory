# Примірник pine-script

Цей примірник шукає в довіднику мови Pine Script. Pine Script — це мова програмування сайту TradingView. Нею пишуть індикатори, які
малюють на графіку ціни власні лінії й позначки, і стратегії, які на історії графіка купують і продають за правилами скрипту й
показують, скільки б ця торгівля заробила. Мова має сотні вбудованих функцій і змінних: ковзні середні (`ta.sma`), перетин двох
ліній (`ta.crossover`), дані іншого інструмента чи таймфрейму (`request.security`), торгові накази стратегії (`strategy.entry`,
`strategy.exit`) і малювання (`line.new`, `table.new`). Довідник описує кожну з них окремим записом.

## Що всередині

| Що | Версії мови | Записів у довіднику |
|---|---|---|
| Довідник мови (Language Reference Manual) | v6 | 945 |
| Довідник мови | v5 | 866 |
| Довідник мови | v4 | 569 |

Запис — це одна вбудована функція, змінна, константа, тип, ключове слово, оператор чи анотація `//@`. У записі є опис, синтаксис з
усіма варіантами виклику, кожен аргумент з його типом, що повертається, примітки про поведінку, приклад коду й перелік споріднених
записів «See also».

Однаковий запис кількох версій лежить одним документом із переліком версій. Тому з 2380 записів трьох версій вийшло 2238 документів, а
пошук будує з них 6408 фрагментів. Фрагмент — це невеликий шматок тексту, який знаходить пошук. Мітка версії має вигляд `pine-v6`,
`pine-v5` або `pine-v4`.

## Чого тут немає

- Посібника користувача (User Manual). Саме він пояснює, як скрипт виконується бар за баром, чому індикатор перемальовує минуле, як
  емулятор брокера виконує накази стратегії, які обмеження має скрипт і як переходити з v5 на v6. Довідник описує кожну вбудовану
  функцію окремо, а не роботу скрипту загалом.
- Довідника версій 3 і старших.
- Документації MQL5 і REST API TradingView.

## Чому файли зберігає людина

Сайт TradingView збирає довідник у браузері з файлів JavaScript, тож у HTML, який віддає сервер, жодного запису немає. До того ж умови
користування TradingView забороняють збирати вміст сайту програмами й копіювати його. Тому наш завантажувач на цей сайт не ходить. Людина
відкриває сторінку довідника кожної версії в браузері, чекає, поки сторінка домалюється, і зберігає її командою «Зберегти як → Веб-сторінка
повністю». Читач `pine-reference-local` читає ці збережені файли без звернень до мережі. Посилання в кожному записі веде на справжню
адресу запису на сайті, наприклад `https://www.tradingview.com/pine-script-reference/v6/#fun_ta.sma`.

Збережені файли лежать у `raw/local/` під іменами `pine-reference-v6.html`, `pine-reference-v5.html` і `pine-reference-v4.html`.
Оригінали лишаються в теці «Завантаження» Windows.

## Корпус лише локально

Корпус — це тексти записів, а індекс — кеш фрагментів, з якого підіймається сервер. Умови TradingView не дозволяють поширювати вміст
сайту. Тому **корпус, індекс і збережені сторінки в git не потрапляють** (`corpus/`, `index/` і `raw/` у `.gitignore`). У git лежать
лише налаштування примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/pine-script-corpus-2026-11-08.tar.gz` разом із паспортом і збереженими
сторінками в `raw/local/`. Копія лежить на Windows: `C:\Distr\pine-script-corpus-2026-11-08.tar.gz`. Архів звірено з диском файл за
файлом, а копію — за SHA-256. Сервер підіймається з кешу `index/passages.json` і колекції Qdrant, тому тексти йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/pine-script-corpus-2026-11-08.tar.gz -C instances/pine-script
./df pine-script smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df pine-script vectors`: кеш збереться заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df pine-script serve
```

Сервер слухає порт `8957`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user pine-script-docs http://127.0.0.1:8957/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. Перевірка: `./df pine-script smoke` і `./df pine-script quality`.
Замір «як модель» на 08.11.2026 дає 10 із 10, а запити своїми словами — 9 із 10.
