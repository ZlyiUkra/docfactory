# Оновлення корпусу pine-script

Нова версія довідника Pine Script не приходить сама. Умови TradingView забороняють збирати вміст сайту програмами, тому людина зберігає
сторінки браузером.

Правило: **нічого не видаляється.** Лише `vectors` прибирає точки своєї колекції, чиїх фрагментів уже немає в корпусі.

1. Поверніть тексти за [README, розділ «Корпус лише локально»](README.md#корпус-лише-локально).
2. Відкрийте в браузері довідник потрібної версії, наприклад `https://www.tradingview.com/pine-script-reference/v6/`, дочекайтеся, поки
   сторінка домалюється, і збережіть її командою «Зберегти як → Веб-сторінка повністю». Покладіть HTML у
   `instances/pine-script/raw/local/` під іменем `pine-reference-v<номер>.html`. Нову версію мови допишіть у поле `files` джерела
   `pine-reference` у `sources.json`, найновішу першою.
3. Оновіть примірник:

```
./df pine-script refresh pine-reference
./df pine-script manifest
./df pine-script vectors
./df pine-script smoke
./df pine-script quality
```

4. Запишіть нове число фрагментів у `checks.json`, зробіть новий архів і звірте його з диском. Лише тоді видаляйте тексти з теки
   та попередній архів.

Джерело позначено `frozen`, тому `refresh` без імені його не чіпає. Якщо сайт змінив розмітку довідника, читач скаже, що в
файлі немає жодного запису, і тоді треба оновити вирази в `engine/readers/pinereference.py`.

Коли запис змінився, `refresh` пише його новим файлом поруч зі старим, бо ім'я файла містить хеш тексту. Старі файли сам
`refresh` не видаляє: їх прибирають вручну перед `manifest`, звіривши з тим, що дає читач.
