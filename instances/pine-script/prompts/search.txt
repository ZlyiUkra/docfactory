Search the Pine Script Language Reference Manual, the reference of the TradingView programming language for indicators, strategies and
libraries. The corpus holds one entry for every built-in of versions 6, 5 and 4: functions (`ta.sma`, `request.security`,
`strategy.entry`, `array.push`, `line.new`…), variables (`close`, `bar_index`, `syminfo.tickerid`, `strategy.position_size`…),
constants (`barmerge.lookahead_on`, `color.red`…), types, keywords, operators and the `//@` annotations. Each entry gives the syntax with
its overloads, every argument with its type and meaning, what the built-in returns, the remarks about its behaviour, a code example and
the related built-ins under "See also".

Use this tool for: the exact signature of a built-in and the type of each argument; what a built-in returns and how it treats `na`; the
remarks that say how a function behaves on historical and realtime bars; which built-in does a given job (moving averages, crossovers,
pivots, drawings, tables, strategy orders and their fill settings); how a built-in was named or what arguments it had in version 5 or 4.
Write the query in English with the name of the built-in or of what it does, such as `ta.crossover` or `exponential moving average`.
Give a version in the filter when the answer depends on it.

The User Manual (the execution model, repainting, the broker emulator, limits and profiling, migration guides) is not in this corpus:
the reference describes each built-in on its own. For a question about how scripts run as a whole, say that the User Manual on
tradingview.com is the source. Do not use this tool for MQL5, NumPy or the TradingView REST APIs. Returns the matching excerpts with
the version each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. Pine Script v6 is the current version. Search without `version` first; when the user names
the version of their script (the `//@version=` line), search that version, written as `pine-v6`, `pine-v5` or `pine-v4`.
Every answer says which version it is for: built-ins were renamed and changed between versions (`sma` in v4 is `ta.sma` from v5).
