Search the documentation of plotly.py, the Python library that draws interactive charts in the browser and in notebooks.
The corpus holds: the guide pages of plotly.com/python at the last patch of every minor line 4.4-7.1 (candlestick and OHLC
charts, time series with range sliders and range selectors, removing weekend gaps with `rangebreaks`, line, bar and scatter
charts, subplots with `make_subplots` and secondary y axes, Plotly Express, figure updates with `update_layout`,
`update_traces` and `add_trace`, shapes, lines and annotations, hover templates, templates and themes, colors, saving to
HTML with `write_html` and to images with `write_image` and Kaleido, renderers, animations and FigureWidget); the API
reference of plotly.com/python-api-reference for 7.1, with a page for every Plotly Express function and every graph_objects
class and its properties (`go.Candlestick`, `go.Ohlc`, `go.Scatter`, `go.Figure`, `layout.XAxis`); the change log of every
stable version, the GitHub release notes, the migration guides and the PyPI records.

Use this tool for: how to draw a candlestick chart of quotes with volume below it, how to add moving averages and trade
markers, how to hide the range slider or the gaps of weekends and nights, how to save a chart to an HTML file or a PNG, how
to change hover text, colors and themes, and what changed between versions. Write the query in English with the function,
class or property name, such as `go.Candlestick`, `make_subplots`, `rangebreaks` or `write_image`. Give a version in the
filter when the answer depends on it.

Do not use it for Dash apps, for plotly.js in JavaScript, for matplotlib or mplfinance (they have their own servers) or for
indicator formulas (the technical indicators server holds them). Returns the matching excerpts with the versions each one
applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest line is 7.1 (`plotly-7.1`); the API reference exists only for it. Search without
`version` first; when the user names a version, search that line. Version 6.0 removed old APIs and 7.0 changed defaults, so
say which version an answer is for.
