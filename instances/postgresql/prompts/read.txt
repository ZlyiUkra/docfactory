Return the full text of one excerpt of the PostgreSQL documentation (every major version from
9.0 to 19: tutorial, SQL language, administration, client interfaces, server programming, the
reference of SQL commands and applications, internals, appendixes and release notes) by its
identifier, together with the document it belongs to, the URL it was taken from and the date
the text was fetched from that URL -- so a quotation can be checked against the source even a
year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a command synopsis, the default of a configuration parameter,
a lock level or an isolation guarantee quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not command names and cannot be assembled by
hand. Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: name the version, keep SQL,
identifiers and titles in English, use Ukrainian words for Ukrainian prose, and name the
document you read.
