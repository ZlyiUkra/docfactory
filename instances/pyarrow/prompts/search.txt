Search the documentation of PyArrow, the Python library of Apache Arrow: columnar tables in memory and the file formats
around them. The corpus holds the Python section of arrow.apache.org of every major line 1.0-26.0, each at its last
minor: the User Guide (arrays, tables and record batches, data types, compute functions, Parquet, Feather, CSV, JSON and
ORC files, datasets split over many files, file systems, interoperability with pandas and NumPy, memory and IPC
streams, timestamps) and the API reference with a page for every class and function; the PyPI records of every stable
version; and the GitHub release notes of Apache Arrow.

Use this tool for: reading and writing Parquet (`pyarrow.parquet.write_table` with `compression` and `row_group_size`,
`read_table` with `columns` and `filters`, `ParquetFile`, `write_to_dataset`), datasets partitioned by date or symbol
(`pyarrow.dataset.dataset`, `partitioning`, `write_dataset`), conversion with pandas (`Table.from_pandas`,
`to_pandas`, zero copy, types that change on the way), compute functions (`pyarrow.compute`: `sum`, `mean`, `filter`,
`group_by`), timestamps and time zones, Feather and the Arrow IPC stream format, CSV reading, data types and schemas,
and what changed between versions. Write the query in English, with the name of the function, class, parameter or
guide topic, such as `write_table compression` or `pyarrow.dataset partitioning`. Give a version in the filter when the
answer depends on it.

Do not use it for pandas, NumPy, Polars, DuckDB or the Arrow libraries for other languages: they are not here. Lines
older than 1.0 are not here, because the site publishes no older version. Returns the matching excerpts with the
versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. PyArrow 26.0.1 is the newest release. Search without `version` first; when the user
names their PyArrow version, search that line, written as `pyarrow-26.0`, `pyarrow-18.1` or `pyarrow-10.0`. Every
answer about a parameter says which line it is for.
