# Примірник pytorch

Цей примірник шукає в документації PyTorch, у підручниках і книжках про нього. PyTorch — це бібліотека Python, у якій
пишуть нейронні мережі. Вона зберігає числа в тензорах (таблицях будь-якої кількості вимірів), сама рахує похідні для
навчання (механізм autograd) і має готові шари, функції втрат і оптимізатори. torchvision — бібліотека поруч із PyTorch:
набори картинок (MNIST, CIFAR-10, ImageNet), перетворення картинок і готові навчені моделі.

Примірник зібрано під практику плану [теорії глибокого навчання](../deep-learning-theory/LEARNING.md): там кожна лекція
закінчується експериментом на PyTorch. Теорії тут немає, її тримає примірник
[`deep-learning-theory`](../deep-learning-theory/README.md).

Чотири книжки — платні, з файлів користувача (корпус лише на цій машині, див. нижче). Документ книжки — розділ за закладками
PDF. Рання версія книжки Stevens містить лише ті глави, що вже вийшли. Код у книжці Julian написано під PyTorch 1.0, і частина
його API з того часу змінилась.

Усього 7801 документ, з них пошук будує 39 627 фрагментів. Фрагмент — це невеликий шматок тексту, який знаходить пошук.

Замір `quality` на 11.11.2026 дав такі числа. Запити назвами класів і функцій (`torch.nn.CrossEntropyLoss`,
`torch.compile`) знаходять потрібне 10 із 10, а модель зазвичай питає саме так. Запити своїми словами («зберегти навчені
ваги у файл і потім відновити») знаходять потрібне 4 із 10: документація PyTorch пише назвами, а не описом.

**Чого немає.** TensorFlow, Keras і JAX. Окремих сторінок функцій для версій до 2.15. На сайті зламано кілька старих сторінок:
`masked.html` у 1.12 і `__config__.html` у 1.7.1, 1.10, 1.11 і 1.12 відповідають помилкою 503, а дві сторінки підручників (`speech command
classification`, `reinforcement PPO`) — 404. Їх пропущено. Російський переклад книжки Pointer, Programming PyTorch for Deep
Learning, не взято: її теми покривають інші книжки, а модель векторів розуміє лише англійську.

## Як читаються сторінки

- `sphinx-html` обходить сайт кожної версії від стартової сторінки. У `torch-api` і `vision` стоїть `qualify_titles: true`.
  PyTorch називає сторінку класу коротким ім'ям («CrossEntropyLoss»), а сторінку функції — повним («torch.compile»), тому без
  цього поля запит `torch.nn.CrossEntropyLoss` не підіймав сторінку класу нагору. З полем сторінка класу дістає назву з
  власної сигнатури: «torch.nn.CrossEntropyLoss». У `torch-docs`, `torch-docs-old` і `tutorials` стоїть `skip_untitled: true`:
  стартова сторінка 1.10 і сторінки-переадресації підручників не мають заголовка, і без поля обхід зупинявся.
- `sitemap-html` бере Learn PyTorch за картою сайту; поле `drop` вирізає якорі заголовків «¶».
- `pdf-outline` ділить книжки за закладками: глибина 2, а для Godoy — 3, бо його глави лежать усередині чотирьох частин.
- `ghreleases-pattern` бере лише стабільні теги, `pypi-versions` — усі стабільні версії.

Три джерела документації PyTorch зведено в родину `pytorch-docs` у `config.json`, тому той самий розділ кількох версій займає у
видачі одне місце й показує найновішу.

## Корпус лише локально

Корпус — це тексти сторінок і глав, а індекс — кеш фрагментів, з якого підіймається сервер. Чотири книжки платні, тому
**корпус, індекс, сховище сирого і файли книжок у git не потрапляють** (`corpus/`, `index/`, `raw/` і `out/` у `.gitignore`).
У git лежать лише налаштування примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/pytorch-corpus-2026-11-11.tar.gz` разом із паспортом, сховищем
сирого і файлами книжок у `raw/local/`. Копія лежить на Windows: `C:\Distr\pytorch-corpus-2026-11-11.tar.gz`. Архів звірено з
диском файл за файлом, а копію — за SHA-256. Сервер підіймається з кешу `index/passages.json` і колекції Qdrant, тому тексти
йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/pytorch-corpus-2026-11-11.tar.gz -C instances/pytorch
./df pytorch smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df pytorch vectors`: кеш збереться заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df pytorch serve
```

Сервер слухає порт `8970`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user pytorch-docs http://127.0.0.1:8970/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. У сесії Claude Code команда `/mcp` має показати сервер
`pytorch-docs` з інструментами `search_docs` і `read_section`. Якщо порт зайнятий, `serve` скаже про це і не підніметься: тоді
сервер цього примірника вже працює в іншому терміналі. Якщо `/mcp` показує помилку з'єднання, сервер не запущено.

Перевірка: `./df pytorch smoke` і `./df pytorch quality`.
