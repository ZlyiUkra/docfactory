Search the documentation of PyTorch, the Python library for tensors and neural networks, together with torchvision and the
best tutorials and books about it. The corpus holds:
- the PyTorch 2.15 documentation in full: every page of docs.pytorch.org/docs/2.15, the API reference of every class and function
  (`torch.nn.Linear`, `torch.optim.Adam`, `torch.autograd.grad`, `torch.nn.utils.prune`, `torch.compile`), the notes and the
  user guide;
- the documentation of every older minor line, 0.1 to 2.14, without the per-function API pages (before 1.6 the module pages hold
  the whole API, later lines keep only the narrative pages);
- the official tutorials of docs.pytorch.org/tutorials: the beginner course, recipes, intermediate and advanced tutorials;
- the torchvision 0.29 documentation: datasets (MNIST, CIFAR-10, ImageNet), transforms, pretrained models (ResNet, VGG, ViT);
- the GitHub release notes and the PyPI records of torch and torchvision;
- Bourke, Learn PyTorch for Deep Learning: Zero to Mastery, a free online book from tensors to transfer learning;
- the UvA Deep Learning Tutorials (University of Amsterdam), PyTorch notebooks on activation functions, optimisation and
  initialisation, ResNet, transformers, autoencoders, adversarial attacks, debugging;
- four books: Godoy, Deep Learning with PyTorch Step-by-Step; Raschka, Liu, Mirjalili, Machine Learning with PyTorch and
  Scikit-Learn; Stevens, Antiga, Huang, Viehmann, Deep Learning with PyTorch, 2nd ed. (early access, the first chapters); Julian,
  Deep Learning with PyTorch Quick Start Guide (written for PyTorch 1.0).

Use this tool for: what a PyTorch function or module does, its arguments and defaults; how to write the training loop, a
`Dataset` and `DataLoader`, a custom `nn.Module`; how autograd computes gradients and when `.grad` accumulates; initialisation
with `torch.nn.init`; optimisers and learning-rate schedulers; saving and loading models; running on a GPU; `torch.compile`;
torchvision datasets, transforms and pretrained models; what changed between PyTorch versions; how a tutorial or a book builds a
model step by step. Write the query in English with the exact name (`torch.nn.CrossEntropyLoss`, `DataLoader`,
`torch.autograd.functional.hessian`) or plain words for what is wanted.

Do not use this tool for the theory of why deep networks work, for the mathematics behind a method or for the Oxford course
C6.5: the `deep-learning-theory-docs` server holds those. For NumPy use `numpy-docs`, for the Python language `python-docs`, for
scikit-learn `scikit-learn-docs`. TensorFlow, Keras and JAX are not here. Returns the matching excerpts with the version each one
applies to, the source address and the fetch date.

Which version to search first. PyTorch 2.15 is the current version, and only 2.15 has the page of every function. Search without
`version` first; when the user names the version they use, search that line, written as `2.15`, `2.9`, `1.13`; torchvision lines
are written as `torchvision-0.29`. The books, Learn PyTorch and the UvA tutorials carry no version, and code in a book may use an
older API: check a function against the 2.15 reference before relying on it.

Rights: the four books are paid and stay on this machine: retell them in your own words and quote briefly. The PyTorch
documentation and tutorials are under the BSD licence, Learn PyTorch code under MIT, the UvA tutorials under MIT for code.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
