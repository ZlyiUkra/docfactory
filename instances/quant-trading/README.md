# quant-trading — примірник фабрики docfactory

Цей примірник шукає в книжках і статтях про системну торгівлю. Системна торгівля — це торгівля за правилами, які записано заздалегідь
і які можна перевірити на історії: де входити, де поставити стоп-лос (ціну, на якій збиткова угода закривається), де тейк-профіт
(ціну, на якій закривається прибуткова), скільки грошей ризикувати в одній угоді. Книжки пояснюють, як такі правила будувати, як
рахувати, чи дають вони перевагу, і як не обдурити себе тестом на історії.

Примірник зібрано під проєкт торгового робота для валютних пар, де ризик угоди відноситься до цілі як 1:2,5–1:3. Тому головні теми
тут — ризик в одиницях R (R — це сума, яку угода втратить, якщо спрацює стоп-лос), очікуваний прибуток на угоду в цих одиницях,
розмір позиції, перевірка на наступних відрізках історії (walk-forward) і перепідгонка стратегії під історію.

Усього 908 документів, з них пошук будує 4642 фрагменти. Фрагмент — це невеликий шматок тексту, який знаходить пошук. Документ
книжки — глава чи розділ за закладками PDF або змістом EPUB, документ статті без закладок — шматок у чотири сторінки з назвою
«pp. N–M». Книжки López de Prado (Advances in Financial Machine Learning) і Jansen лежать у примірнику `tree-models`, а книжки про

Замір `quality` на 13.11.2026 дав такі числа. Запити назвами з книжок знаходять потрібне 10 із 10, а модель зазвичай питає саме так.
Запити своїми словами знаходять потрібне 6 із 10.

## Обмеження текстів

Формули в PDF витягуються як текст і часто розсипаються, а підписи до рисунків стоять посеред абзаців. Текст Sperandeo розпізнано
сканером ще до нас, і в ньому трапляються помилки розпізнавання («8017c» замість «80%»), тому цитату з нього треба звіряти зі
сторінкою скану; кожен його документ починається з такої позначки.

## Як читаються файли

- `pdf-outline` ділить PDF на документи за закладками до заданої глибини. Закладки глав Aronson називаються «ch1»…«ch9», а Carver —
  «Chapter One»…«Chapter Eleven». З такими назвами не видно, про що глава, тому читач отримав необов'язкове поле `titles`:
  воно підставляє справжню назву глави (її взято з першого рядка глави).
- `epub-toc` — новий читач для EPUB Tharp. Книжка не має тегів заголовків: назва глави й підзаголовки зверстані звичайними блоками
  `<div>` з різними класами, і `epub-local` не знаходить у ній жодної глави. Тому `epub-toc` бере назви глав і межі розділів зі змісту
  книжки `toc.ncx`.
- Sperandeo: файл користувача названо `.pdf`, але насправді це скан DjVu з текстовим шаром. Текстовий шар разом із рамками рядків
  витягнуто один раз командою `djvutxt --detail=line` (пакет djvulibre) у теку `out/ocr/sperandeo`, по файлу JSON на сторінку, у
  тому самому вигляді, що й розпізнані сторінки в примірнику `algorithms`. Далі їх читає `ocr-pages`, а межі глав задано полем
  `page_titles` за змістом книжки.

## Корпус лише локально

Корпус — це тексти глав і статей, а індекс — кеш фрагментів, з якого підіймається сервер. Платні книжки не можна поширювати, тому
**корпус, індекс і файли книжок у git не потрапляють** (`corpus/`, `index/`, `raw/` і `out/` у `.gitignore`). У git лежать лише
налаштування примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/quant-trading-corpus-2026-11-13.tar.gz` разом із паспортом, сховищем
сирого, файлами книжок у `raw/local/` і сторінками Sperandeo в `out/ocr/`. Копія лежить на Windows:
`C:\Distr\quant-trading-corpus-2026-11-13.tar.gz`. Архів звірено з диском файл за файлом, а копію — за SHA-256. Сервер підіймається з
кешу `index/passages.json` і колекції Qdrant, тому тексти йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/quant-trading-corpus-2026-11-13.tar.gz -C instances/quant-trading
./df quant-trading smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df quant-trading vectors`: кеш збереться заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df quant-trading serve
```

Сервер слухає порт `8978`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user quant-trading-docs http://127.0.0.1:8978/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. Перевірка: `./df quant-trading smoke` і
`./df quant-trading quality`.
