# React Hook Form changelog: 6.14.0
# джерело: https://github.com/react-hook-form/react-hook-form/blob/master/CHANGELOG.md
# отримано: 2026-09-26
# версія: 6.14.0

Released 2020-12-31.

### Changed

- `setValue` without shouldUnregister:false will no longer deep clone its value instead with shallow clone

### Added

- new formState `isValidating`, this will set to `true` during validation.

```ts
const {
  formState: { isValidating },
} = useForm();
```
