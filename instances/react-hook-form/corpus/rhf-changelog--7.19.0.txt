# React Hook Form changelog: 7.19.0
# джерело: https://github.com/react-hook-form/react-hook-form/blob/master/CHANGELOG.md
# отримано: 2026-09-26
# версія: 7.19.0

Released 2021-11-05.

### Added

- new `resetField` API

```tsx
const { resetField } = useForm();

resetField('test');

resetField('test', {
  keepError: true,
  keepDirty: true,
  keepTouched: true,
  defaultValue: 'test1',
});
```

### Changed

- `useController` will return shallow clone value for the following data type on each rerender
  - object: `{... value}`
  - array: `[...value]`
