# React Hook Form changelog: 7.20.0
# джерело: https://github.com/react-hook-form/react-hook-form/blob/master/CHANGELOG.md
# отримано: 2026-09-26
# версія: 7.20.0

Released 2021-11-19.

### Added

- new `exact` prop for `useWatch`
- new `exact` prop for `useFormState`

```tsx
useWatch({
  name: 'test.test',
  exact: true,
});

useFormState({
  name: 'test.test',
  exact: true,
});
```

### Changed

- `useWatch` subscription will occurred at `useEffect` instead before `render`
