# React Hook Form release: Version 3.8.12
# джерело: https://github.com/react-hook-form/react-hook-form/releases/tag/3.8.12
# отримано: 2026-09-26
# версія: 3.8.12

Tag 3.8.12, published 2019-07-24.

Fixes #136

**Changes:**
- `ErrorMessages` now can have an object using either `strings` or `Error` objects for values. (This is what fixes #136)
- Removed `Omit`, it is included in v3.5 of Typescript (https://devblogs.microsoft.com/typescript/announcing-typescript-3-5/#the-omit-helper-type)
- Anything that was manually setting up the index for an object, now is using `Record<key, value>` (https://www.typescriptlang.org/docs/handbook/release-notes/typescript-2-1.html#partial-readonly-record-and-pick)
- exporting `Mode` as a type
- Re-used some already built out types (`VoidFunction` and `NumberOrString`
- Aliased `Data[Name]` to `Value` in the `FormProps` interface.
- Used `object` instead of `{}`
