❤️ Type improvement #358 #360
🤘 New Feature on `reValidateMode` #362

Default re-validate error is still `onChange`, however now you can config how re-validate gets triggered:

```
useForm({
  mode: 'onBlur',
  reValidateMode: 'onBLur',
})
```
