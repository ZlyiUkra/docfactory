✨ New Feature: setErrors support multiple errors at once

```
const { setError } = useForm();

setError([
  {
    type: 'test',
    name: 'input',
    message: 'wow',
  },
  {
    type: 'test1',
    name: 'input1',
    message: 'wow1',
  },
])
```
