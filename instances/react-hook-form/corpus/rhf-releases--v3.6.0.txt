# React Hook Form release: Version 3.6.0

# отримано: 2026-09-26
# версія: 3.6.0

Tag v3.6.0, published 2019-05-18.

- support `defaultValues` as optional argument for `useForm`

```
const { register, handleSubmit } = useForm({
    defaultValues: {
      firstName: "bill",
      lastName: "luo",
      email: "bluebill1049@hotmail.com"
    }
});
```
