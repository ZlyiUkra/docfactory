🚂 feature: reset to support callback syntax (#9051)

`reset` with partial form values will require invoking `getValues` at the same time, here is an improvement 👇

Convert your code from:

```tsx
reset({
  ...getValues(),
  partialData: 'onlyChangeThis'
})
```

to:

```tsx
reset((formValues) => {
  return {
    ...formValues,
    partialData: 'onlyChangeThis'
  }
})
```
