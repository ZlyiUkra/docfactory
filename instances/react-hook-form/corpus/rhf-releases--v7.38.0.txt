Tag v7.38.0, published 2022-10-18.

🕰 support validation for week and time input type (#9189)

```tsx
<input
  {...register("week", { min: "2022-W40", max: "2022-W50" })}
  type="week"
/>
<input
  {...register("time", { min: "11:00", max: "12:00" })}
  type="time"
/>
```
