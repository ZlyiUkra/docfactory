## React Hook Form focus on providing the best DX by simplify the API.

## ## useForm: Function

By invoking `useForm`, you will receive the following methods register , unregister , errors , watch, handleSubmit , reset, setError , setValue , getValues and formState .

`useForm` also has optional arguments. The following example demonstrate all options' default value.
`mode: string = 'onSubmit'`

Name | Type | Description

onSubmit (Default) | string | Validation will trigger on submit, invalid inputs will attach `onChange` event listeners to re-validate them.

onBlur | string | Validation will trigger on `blur` event.

onChange | string | Validation will trigger on `onChange` with each inputs, and lead to multiple re-render. Not recommended: Consider this as a bad performance practice.

♦

```
defaultValues:
               {[key:string]: string} = {}
```

You can set input default value with `defaultValue/defaultChecked` (read more at React doc for Default Values) or pass `defaultValues` as an optional argument to populate default values for the entire form.

Note: Values defined in `defaultValues` will be injected into watch as `defaultValue`.

Note: `defaultValues` doesn't auto populate with manually registered input. eg: `register({ name: 'test' })`. Because manual `register` field is not providing `ref` to React Hook Form.

```
const { register } = useForm({
  defaultValues: {
    firstName: "bill",
    lastName: "luo",
    email: "bluebill1049@hotmail.com",
    pets: [ 'dog', 'cat' ]
  }
})

<input name="firstName" ref={register} /> // ✅ works version
<input name="lastName" ref={() => register({ name: 'lastName' })} />
// ❌ above example does not work with defaultValues due to its ref is not provided
```

♦
`validationFields: string[] = []`
By providing an array of fields, which means only included fields will be validated. This option is useful when you want to toggle which fields are required to validate.
CodeSandbox
♦
`submitFocusError: boolean = true`
By default when user submit a form and contains error, the first error field will be focused.

Note: only registered field with `ref` will works, not with manual register input. eg: `register({ name: 'test' }) // doesn't work`

♦
`validationSchema: Object`
Apply form validation rules with `Yup` at the schema level, please refer the validationSchema section.

♦
`nativeValidation: boolean = false`
Set this option to `true` will enable browser's native validation. You can find out more about browser built-in validation , and refer to nativeValidation section for more detail and example.

## ## register: ({ name: string } | Ref, validateRule?) => void

## ## unregister: (name: string | string[]) => void

This method will allow you to `unregister` a single or array of inputs.

## ## handleSubmit: (data: Object, e: Event) => void

This function will pass you the form data when form validation is successful.

Note: you can pass an `async` function for asynchronous validation. eg: `handleSubmit(async (data) => await fetchAPI(data))`

## ## reset: (values?: Record<string, any>) => void

This function will reset fields value and errors within the form. You can pass `values` as an optional argument to reset your form into assigned default values.

Note: for controlled component like `React-Select` which doesn't expose `ref`, you will have to reset the input value manually through `setValue`.

## ## setError: (name: string, type: string, message?: string, ref?: Ref) => void

allows you to manually set an input error.

## ## clearError: (name?: string | string[]) => void

- `undefined`: reset all errors

- `string`: reset single error

- `string[]`: reset multiple errors

## ## setValue: (name: string, value: any, shouldValidate?: boolean) => void

This function allows you to dynamically set input/select value.

Note: by invoking this method `formState` will push input's `name` into `touched`.

You can also set `shouldValidate` to true and it will trigger field validation. eg: `setValue('name', 'value', true)`

## ## getValues: (payload?: { nest: boolean }) => Object

This function will return the entire form data.

- By default `getValues()` will return form data in a flat structure. eg: `{ test: 'data', test1: 'data1'}`

- Working on array fields form, `getValues({ nest: true })` will return data in a nested structure according to input `name`. eg: `{ test: [1, 2], test1: { data: '23' } }`

## ## triggerValidation: (payload?: { name: string; value?: any; } | { name: string; value?: any; }[]) => boolean

To manually trigger an input/select validation in the form.

Note: when validation failed, then `errors` object will be updated.

## ## validationSchema: Object

If you would like to centralize your validation rules with external validation schema, you can apply `validationSchema` at `useForm` as an optional argument. Currently support Yup for object schema validation.

## ## NativeValidation

Because native validation is triggering before `onSubmit` phase, we will have to move `handleSubmit` at button/input `onClick` and use `e.preventDefault()` at `onSubmit` callback to prevent page from refreshing.

## ## TypeScript

React Hook Form is built with `Typescript`, you can defined `Type` to support form values.
