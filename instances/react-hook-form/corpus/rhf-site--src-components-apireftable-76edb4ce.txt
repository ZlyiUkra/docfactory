`required` ``` string | { value: boolean, message: string | React.ReactElement } ``` | ``` <input {...register("test", { ${ isStandard ? "required: true" : `required: 'error message' // JS only: <p>error message</p> TS only support string` } })} /> ```

`maxLength` ``` { value: number, message: string | React.ReactElement } ``` | ``` <input {...register("test", { ${ isStandard ? "maxLength: 2" : `maxLength : { value: 2, message: 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

`minLength` ``` { value: number, message: string | React.ReactElement } ``` | ``` <input {...register("test", { minLength: ${ isStandard ? 1 : `{ value: 1, message: 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

`max` ``` { value: number, message: string | React.ReactElement } ``` | ``` <input type="number" {...register('test', { max: ${ isStandard ? 3 : `{ value: 3, message: 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

`min` ``` { value: number, message: string | React.ReactElement } ``` | ``` <input type="number" {...register("test", { min: ${ isStandard ? 3 : `{ value: 3, message: 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

`pattern` ``` { value: RegExp, message: string | React.ReactElement } ``` | ``` <input {...register("test", { pattern: ${ isStandard ? "/[A-Za-z]{3}/" : `{ value: /[A-Za-z]{3}/, message: 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

`validate` `Function | Object` | ``` <input {...register("test", { validate: ${ isStandard ? `value => value === '1'` : `value => value === '1' || 'error message' // JS only: <p>error message</p> TS only support string` } })} /> // object of callback functions <input {...register("test1", { validate: ${ isStandard ? `{ positive: v => parseInt(v) > 0, lessThanTen: v => parseInt(v) < 10, checkUrl: async () => await fetch() }` : `{ positive: v => parseInt(v) > 0 || 'should be greater than 0', lessThanTen: v => parseInt(v) < 10 || 'should be lower than 10', // you can do asynchronous validation as well checkUrl: async () => await fetch() || 'error message' // JS only: <p>error message</p> TS only support string }` } })} /> ```

valueAsNumber: `boolean` | Returns a Number normally. If something goes wrong `NaN` will be returned. - `valueAs` process is happening before validation. - only applies to text input. | ``` <input type="number" {...register("test", { valueAsNumber: true, })} /> ```

valueAsDate: `boolean` | Returns a Date normally. If something goes wrong `null` will be returned. - `valueAs` process is happening before validation. - only applies to text input. | ``` <input type="date" {...register("test", { valueAsDate: true, })} /> ```

setValueAs: `<T>(value: any) => T` | Return input value by running through the function. - `valueAs` process is happening before validation. Also, `setValueAs` is ignored if either `valueAsNumber` or `valueAsDate` are `true`. - only applies to text input. | ``` <input name="test" ref={ register({ setValueAs: v => parseInt(v), }) } /> ```

shouldUnregister: `boolean` | Input will be unregistered after unmount and defaultValues will be removed as well. | ``` <input name="test" ref={ register({ shouldUnregister: true }) } /> ```
