## watch: (names?: string | string[] | (data, options) => void) => unknown

## Return

`string` | `watch('inputName')` `watch('inputName', 'value')` | `any`

`string[]` | `watch(['inputName1'])` `watch(['field1'], { field1: '1' })` | `unknown[]`

`undefined` | `watch()` `watch(undefined, { field: '1' })` | `{[key:string]: any}`

`(data: unknown, { name: string, type: string }) => void` | `watch((data, { name, type }) => console.log(data, name, type))` | `{ unsubscribe: () => void }`
