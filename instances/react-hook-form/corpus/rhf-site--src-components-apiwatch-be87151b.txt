## ## watch: Function

This will watch specified input and return its value. first-time run `watch` will always return `undefined` because called before `render`, but you can set the default value as the second argument.

Type | Description | Example

string | Watch on individual input | `watch('inputName');` `watch('inputName', 'value'); // with default value`

string[] | Watch multiple inputs over the form | `watch(['inputName1', 'inputName2']);` `watch(['field1', 'field2'], { field1: '1', field2: '2'}); // with default value`

undefined | Watch every input fields in the form | `watch();` `watch(undefined, { field: 'value1' }); // with default value`
