## ## watch: (string | string[] | undefined) => any

This will watch specified input/inputs and return its value.

- When `defaultValue` is not defined, first render `watch` will return `undefined` because called before `register`, but you can set the `defaultValue` as the second argument to return value.

- However, if `defaultValues` was initialised in `useForm` as argument, then first render will return what's provided in `defaultValues`.

Type | Description | Example

string | Watch on individual input | ``` watch('inputName') // watch individual field or array fields via name as index ``` `watch('inputName', 'value') // with default value`

string[] | Watch multiple inputs over the form | `watch(['inputName1', 'inputName2'])` `watch(['field1', 'field2'], { field1: '1', field2: '2'}); // with default value`

undefined | Watch every input fields in the form | `watch()` `watch(undefined, { field: 'value1' }); // with default value`
