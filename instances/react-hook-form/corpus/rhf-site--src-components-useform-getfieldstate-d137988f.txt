## getFieldState

State of the field

## getFieldState: object

This method will return individual field state. It will be useful when you are try to retrieve nested value field state in a typesafe approach.

## Rules

- name need to match registered field name.

- formState will need to subscribed.

## Props

`name` | `string` | registered field name.

formState | `object` | When set to `true`, field error will be retained.

## Return

`isDirty` | `boolean` | field is modified. Condition: subscribe to `dirtyFields`.

isTouch | `boolean` | field has received a focus and blur event. Condition: subscribe to `touchedFields`.

invalid | `boolean` | field is not valid. Condition: subscribe to `errors`.

error | `undefined | FieldError` | field error object. Condition: subscribe to `errors`.
