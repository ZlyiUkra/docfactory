## useController: (arguments: UseControllerProps) => { field: object, meta: object }

Object Name

`field` | `onChange` | `(value: any) => void` | A function which send value to hook form and should be assigned with `onChange` prop.

`onBlur` | `(value: any) => void` | A function which send value to hook form and should be assigned with `onBlur` prop.

`value` | `unknown` | The value of this controlled component.

`ref` | `React.RefObject` | Assign `ref` to component's input ref, so hook form can focus on the error input.

`meta` | `invalid` | `boolean` | Invalid state for current input.

`isTouched` | `boolean` | Touched state for current controlled input.

`isDirty` | `boolean` | Dirty state for current controlled input.
