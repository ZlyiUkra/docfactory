## Register fields

One of the key concepts for React Hook Form is to register your uncontrolled fields into the hook, and enable them to be validated and gather the value for submitting.

Note: each fields required to have an unique `name` as key for the registration process.

## Apply validation

React Hook Form make form validation easy by aligning with existing HTML standard form validation .

List of validation rules supported by:

- required

- min

- max

- minLength

- maxLength

- pattern

- validate

You can read more detail on each rule at API page .

## Adapting existing form

Working on an existing form is fairly simple as well. The important step is to apply `register` into existing input or select component's `ref`.

## Work with UI library

Working with external component library should be easy and simple to integrate, React Hook Form has made it simple.

Note: Most of UI library do expose `innerRef` or `ref` to `register`. For components that are more complicated like `react-select` or `react-datepicker`, you can update value via `setValue` or trigger an error with `setError`.

The following example demonstrates usage with `react-select` and `material-ui`.

## Integrate global state

Forms are mostly about collecting user data. React Hook Form doesn't require you to have a state management to store your data. However, it allows you to easily integrate one like `Redux` or `MobX`

## Handle errors

React Hook Form provide an `errors` object to show you the errors within the form.
