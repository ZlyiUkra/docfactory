## Register fields

One of the key concepts for React Hook Form is to `register` your uncontrolled component into the Hook and hence enabling its value to be validated and gathered for submitting.

Note: each field requires to have a unique `name` as key for the registration process.

## Apply validation

React Hook Form make form validation easy by aligning with existing HTML standard form validation .

List of validation rules supported by:

- required

- min

- max

- minLength

- maxLength

- pattern

- validate

You can read more detail on each rule at API page .

## Adapting existing form

Working on an existing form is simple. The important step is to apply `register` into existing component's `ref`.

## Work with UI library

React Hook Form has made it easy to integrate with external UI components library.

Note: Most of UI library do expose `innerRef` or `ref` to `register`. For components that are more complicated like `react-select` or `react-datepicker`, you can manually update value via `setValue` or trigger an error with `setError`.

## Integrate global state

React Hook Form doesn't require you to have a state management to store your data, but you can easily integrate with one.

## Handle errors

React Hook Form provide an `errors` object to show you the errors within the form.
