## React hook form focus on providing the best DX by simplify the API.

## API

## useForm: Function

By invoking `useForm`, you will receive methods to register, errors, handleSubmit, watch and formState. (run `useForm` before `render`)

Apply form validation rules at the schema level, please refer the validationSchema section.

Name | Type | Description

onSubmit (Default) | string | Validation will trigger on submit, invalid inputs will attach `onChange` event listeners to re-validate them.

onBlur | string | Validation will trigger on `blur` event.

onChange | string | Validation will trigger `onChange` with each inputs, and lead to multiple re-render. Not recommended: Consider this as a bad performance practice.

## register: Function

## errors: Object

Object contain form errors or error messages belong to each input.

Name | Type | Description

`type` | string | Error type which according to your validation rules. eg: required, min, max

`message` | string | Register with validation and error message, then error message will return in this .

`ref` | React.RefObject | Reference fo your error input element.

## watch: Function

Watch over input change and return its value. first-time run `watch` will always return `undefined` because called before `render`. You can set the default value as the second argument.

Type | Description | Example

string | Target on individual input | `const value = watch('inputName');`

string[] | Watch multiple inputs over the form | `const values = watch(['inputName1', 'inputName2']);`

undefined | Watch every input fields in the form | `const values = watch();`

## handleSubmit: Function

This function will pass you the form data when form validation is successful.

## validationSchema: Object

If you would like to centralize your validation rules or external validation schema, you can apply `validationSchema` when you invoke `useForm`. we use Yup for object schema validation and the example below demonstrate the usage.

## formState: Object

This object contain information about the form state.

Name | Type | Description

`dirty` | boolean | Set to true after user interacted with any of the inputs.

`isSubmitted` | boolean | Set true after user submitted the form.

`touched` | string[] | An array of all inputs which have been interacted.

`isSubmitting` | boolean | During form submitting will set to true and after submitting set to false.

`submitCount` | number | Number of forms submit.
