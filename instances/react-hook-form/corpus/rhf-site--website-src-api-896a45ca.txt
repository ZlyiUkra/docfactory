## API

## useForm: { mode?: 'onSubmit' | 'onBlur' | 'onChange', validationSchema?: any }

By invoking `useForm`, you will receive methods to register, watch, validate and print errors. (run `useForm` before `render`)

Apply form validation rules at schema level, please refer the validationSchema section.

Name | Type | Description

onSubmit (Default) | string | Validation will trigger on submit, and then attach `onchange | blur | input` event listeners to re-validate them.

onBlur | string | Validation will trigger on input `blur` event.

onChange | string | (Not recommended) Validation will trigger `onChange` with each inputs, and lead to multiple render. Consider this as a bad performance practice.

## register: (args: Object):void

## errors: { [key: string]: | { ref: any; message: string | boolean; type: string; } | {}; }

Object contain form errors or error messages belong to each input.

## watch: (watchName: string | Array | undefined, defaultValue: string | Array | undefined) => string | number | boolean

Watch over input change and return its value. first time run `watch` will always return `undefined` because called before `render`. You can set default value as the second argument.

Type | Description | Example

string | Target on individual input | `const value = watch('inputName');`

Array | Watch multiple inputs over the form | `const values = watch(['inputName1', 'inputName2']);`

undefined | Watch every input fields in the form | `const values = watch();`

## handleSubmit: ({ [key: string]: string | number | boolean }) => void

This function will pass you the form data when from validation is successful.

## validationSchema: any

If you would like to centralise your validation rules or external validation schema, you can apply `validationSchema` when you invoke `useForm`. we use Yup for object schema validation and the example below demonstrate the usage.
