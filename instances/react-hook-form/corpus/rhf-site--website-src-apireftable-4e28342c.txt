Register `Ref` and validation rules into `react-hook-form`. Validation rules are all based on html standard. In addition, `react-hook-form` do allow custom validation too.

Important: input `name` is required and unique for `react-hook-form` to register them uniquely.

If you working on `arrays/array fields` (inject additional form section by action), you can assign input name as `name[index]`. Check out the example .
Register options Register with validation Register with validation and error message

Name | Type | Description | Example

`ref` | `React.RefObject` | React element ref | ``` <input name="test" ref={register} /> ```

`required` | A Boolean which, if true, indicates that the input must have a value before the form can be submitted. you can assign as string to return error message in the `errors` object. | ``` <input name="test" ref={ register({ ${isStandard ? 'required: true' : `required: 'error message'`} }) } /> ```

`maxLength` | ``` { value: number, message: string } ``` | The maximum length of the value to accept for this input. | ``` <input name="test" ref={ register({ ${ isStandard ? 'maxLength: 2' : `maxLength : { value: 2, message: 'error message' }` } }) } /> ```

`minLength` | ``` { value: number, message: string } ``` | The minimum length of the value to accept for this input. | ``` <input name="test" ref={ register({ minLength: ${ isStandard ? 1 : `{ value: 1, message: 'error message' }` } }) } /> ```

`max` | ``` { value: number, message: string } ``` | The maximum value to accept for this input. | ``` <input name="test" ref={ register({ max: ${ isStandard ? 3 : `{ value: 3, message: 'error message' }` } }) } /> ```

`min` | ``` { value: number, message: string } ``` | The minimum value to accept for this input. | ``` <input name="test" ref={ register({ min: ${ isStandard ? 3 : `{ value: 3, message: 'error message' }` } }) } /> ```

`pattern` | ``` { value: RegExp, message: string } ``` | The regex pattern for the input. | ``` <input name="test" ref={ register({ pattern: ${ isStandard ? '\\[A-Za-z]{3}\\' : `{ value: \\[A-Za-z]{3}\\, message: 'error message' }` } }) } /> ```

`validate` | `Function | Object` | You can pass a callback function as the argument to validate, or you can pass an object of callback functions to validate all of them. (refer to the examples) | ``` <input name="single" ref={ register({ validate: ${ isStandard ? `(value) => value === '1'` : `(value) => value === '1' || 'error message';` } }) } /> ```
