This is the function to register `Ref` and validation into `react-hook-form`. Validation rules are all based on html input/select's standard validation, however `react-hook-form` do allow custom validation with method `validate`.

Important: input name is required and unique for `react-hook-form` in order to register the input.
Register options Standard register with validation Register with validation and error message

Name | Type | Description | Example

`ref` | `HTMLInputElement` | React element ref | ``` <input name="test" ref={ref => register({ ref }) } /> ```

`required` | A Boolean which, if true, indicates that the input must have a value before the form can be submitted. you can assign as string to return error message in the `errors` object. | ``` <input name="test" ref={ref => register({ ref, ${isStandard ? 'required: true' : `required: 'error message'`} }) } /> ```

`maxLength` | ``` { value: number, message: string } ``` | The maximum length of the value to accept for this input. | ``` <input name="test" ref={ref => register({ ref, ${ isStandard ? 'maxLength: 2' : `maxLength : { value: 2, message: 'error message' }` } }) } /> ```

`minLength` | ``` { value: number, message: string } ``` | The minimum length of the value to accept for this input. | ``` <input name="test" ref={ref => register({ ref, minLength: ${isStandard ? 1 : `{ value: 1, message: 'error message' }`} }) } /> ```

`max` | ``` { value: number, message: string } ``` | The maximum value to accept for this input. | ``` <input name="test" ref={ref => register({ ref, max: ${isStandard ? 3 : `{ value: 3, message: 'error message' }`} }) } /> ```

`min` | ``` { value: number, message: string } ``` | The minimum value to accept for this input. | ``` <input name="test" ref={ref => register({ ref, min: ${isStandard ? 3 : `{ value: 3, message: 'error message' }`} }) } /> ```

`pattern` | ``` { value: RegExp, message: string } ``` | The regex pattern for the input. | ``` <input name="test" ref={ref => register({ ref, pattern: ${isStandard ? '\\[A-Za-z]{3}\\' : `{ value: \\[A-Za-z]{3}\\, message: 'error message' }`} }) } /> ```

`validate` | ``` { value: (Object) => Boolean | {[key: string]: (Object) => Boolean}, message: string } ``` | You can pass a callback function with value as the argument to validate, or you can pass an object of callback functions to validate all of them. (refer to the examples) | ``` <input name="single" ref={ref => register({ ref, validate: ${ isStandard ? `(value) => value === '1'`: `(value) => { return value === '1' ? 'error message' : true; }`} }) } /> <input name="multiple" ref={ref => register({ ref, validate: { isMoreThanOne: (value) => ${isStandard ? 'value > 1' : `{ return value > 1 ? 'error message': true; }`}, isLessThanTen: (value) => ${isStandard ? 'value > 1' : `{ return value < 10 ? 'error message': true; }`}, } }) } /> ```
