- createStaticRouter(
routes: RouteObject[],
context: StaticHandlerContext,
opts?: {
branches?: RouteBranch<DataRouteObject>[];
future?: Partial<FutureConfig>;
},
): DataRouter

Create a static DataRouter for server-side rendering

#### Parameters

- routes: RouteObject[]

The route objects to create a static DataRouter for

- context: StaticHandlerContext

The StaticHandlerContext returned from StaticHandler's `query`

- opts: { branches?: RouteBranch<DataRouteObject>[]; future?: Partial<FutureConfig> } = {}

Options

- ##### `Optional`branches?: RouteBranch<DataRouteObject>[]

#### Deprecated

This option is no longer used because branch caching is done automatically inside the static router.

- ##### `Optional`future?: Partial<FutureConfig>

Future flags for the static DataRouter

#### Returns DataRouter

A static DataRouter that can be used to render the provided routes

#### Example

```
export async function handleRequest(request: Request) {
  let { query, dataRoutes } = createStaticHandler(routes);
  let context = await query(request);

  if (context instanceof Response) {
    return context;
  }

  let router = createStaticRouter(dataRoutes, context);
  return new Response(
    ReactDOMServer.renderToString(<StaticRouterProvider ... />),
    { headers: { "Content-Type": "text/html" } }
  );
}

@public
```
