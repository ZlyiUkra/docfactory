# Interface FetcherSubmitFunction
# джерело: https://api.reactrouter.com/v8/interfaces/react-router.FetcherSubmitFunction.html
# отримано: 2026-09-25
# версія: 8.4.0

Submits a fetcher `<form>` to the server without reloading the page.

- FetcherSubmitFunction(
target: SubmitTarget,
options?: FetcherSubmitOptions,
): Promise<void>

#### Parameters

- target: SubmitTarget

Can be multiple types of elements and objects

`HTMLFormElement`

```
<fetcher.Form
  onSubmit={(event) => {
    fetcher.submit(event.currentTarget);
  }}
/>
```

`FormData`

```
const formData = new FormData();
formData.append("myKey", "myValue");
fetcher.submit(formData, { method: "post" });
```

Plain object that will be serialized as `FormData`

```
fetcher.submit({ myKey: "myValue" }, { method: "post" });
```

Plain object that will be serialized as JSON

```
fetcher.submit(
  { myKey: "myValue" },
  { method: "post", encType: "application/json" }
);
```

- `Optional`options: FetcherSubmitOptions
