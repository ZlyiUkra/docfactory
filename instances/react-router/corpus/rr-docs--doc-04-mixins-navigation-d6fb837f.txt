# Navigation
# джерело: https://github.com/remix-run/react-router/blob/v1.0.0-beta3/doc/04%20Mixins/Navigation.md
# отримано: 2026-09-25
# версія: 1.0.0-beta3, 1.0.0-beta2, 1.0.0-beta1, 1.0.0-alpha2

Mixes in the navigation methods of the router for convenient routing
from within components.

## Methods

### makePath

See router.makePath

### makeHref

See router.makeHref

### transitionTo

See router.transitionTo

### replaceWith

See router.replaceWith

### go

See router.go

### goBack

See router.goBack

### goForward

See router.goForward

## Example

```js
import { Navigation } from 'react-router';

React.createClass({

 mixins: [ Navigation ],

 render() {
   return (
     <div onClick={() => this.transitionTo('foo')}>Go to foo</div>
     <div onClick={() => this.replaceWith('bar')}>Go to bar without creating a new history entry</div>
     <div onClick={() => this.goBack()}>Go back</div>
   );
 }
});
```
