## Links

[MODES: framework]

## Summary

Reference Documentation ↗

Renders all the `<link>`
tags created by the route module's `links`
export. You should render it inside the `<head>`
of your document.

```tsx
import { Links } from "react-router";

export default function Root() {
  return (
    <html>
      <head>
        <Links />
      </head>
      <body></body>
    </html>
  );
}
```

## Signature

```tsx
function Links({ nonce, crossOrigin }: LinksProps): React.JSX.Element
```

## Props

### nonce

A `nonce`
attribute to render on the `<link>`
element

### crossOrigin

A `crossOrigin`
attribute to render on the `<link>`
element
