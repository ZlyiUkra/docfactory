## Summary

Reference Documentation ↗

A component-based version of useNavigate to use in a [`React.Component
Class`](https://reactjs.org/docs/react-component.html) where hooks are not
able to be used.

It's recommended to avoid using this component in favor of useNavigate

```tsx
<Navigate to="/tasks" />
```
