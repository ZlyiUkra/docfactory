# `createRoutes(routes)`
# джерело: https://github.com/remix-run/react-router/blob/v1.0.0-rc1/docs/api/createRoutes.md
# отримано: 2026-09-25
# версія: 1.0.0-rc1

Creates and returns an array of routes from the given object which may be a JSX route, a plain object route, or an array of either.

### params

#### `routes`

One or many `Routes` or Plain Routes.
