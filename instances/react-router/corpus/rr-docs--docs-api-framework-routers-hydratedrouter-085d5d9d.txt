## HydratedRouter

[MODES: framework]

## Summary

Framework-mode router component to be used to hydrate a router from a
`ServerRouter`. See `entry.client.tsx`.

## Signature

```tsx
function HydratedRouter(props: HydratedRouterProps)
```

## Props

### unstable_getContext

Context object to be passed through to `createBrowserRouter` and made
available to `clientAction`/`clientLoader`
functions
