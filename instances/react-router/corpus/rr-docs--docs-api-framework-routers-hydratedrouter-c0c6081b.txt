## HydratedRouter

[MODES: framework]

## Summary

Framework-mode router component to be used to to hydrate a router from a
`ServerRouter`. See `entry.client.tsx`.

## Signature

```tsx
function HydratedRouter(props: HydratedRouterProps)
```

## Props

### unstable_getContext

Context object to passed through to `createBrowserRouter` and made available to `clientLoader`/`clientAction`
functions
