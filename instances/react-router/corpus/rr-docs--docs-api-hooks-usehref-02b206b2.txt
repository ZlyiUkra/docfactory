## useHref

[MODES: framework, data, declarative]

## Summary

Reference Documentation ↗

Resolves a URL against the current location.

```tsx
import { useHref } from "react-router";

function SomeComponent() {
  let href = useHref("some/where");
  // "/resolved/some/where"
}
```
