## useInRouterContext

[MODES: framework, data]

## Summary

Reference Documentation ↗

Returns `true` if this component is a descendant of a `Router`, useful
to ensure a component is used within a `Router`.

## Signature

```tsx
function useInRouterContext(): boolean
```

## Returns

Whether the component is within a `Router` context
