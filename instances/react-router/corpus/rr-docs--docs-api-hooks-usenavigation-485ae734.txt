## useNavigation

[MODES: framework, data]

## Summary

Reference Documentation ↗

Returns the current `Navigation`, defaulting to an "idle" navigation
when no navigation is in progress. You can use this to render pending UI
(like a global spinner) or read `FormData`
from a form navigation.

```tsx
import { useNavigation } from "react-router";

function SomeComponent() {
  let navigation = useNavigation();
  navigation.state;
  navigation.formData;
  // etc.
}
```

## Signature

```tsx
function useNavigation(): Navigation
```

## Returns

The current `Navigation` object
