## useNavigationType

[MODES: framework, data, declarative]

## Summary

Reference Documentation ↗

Returns the current `Navigation` action which describes how the router
came to the current `Location`, either by a pop, push, or replace on
the `History` stack.

## Signature

```tsx
function useNavigationType(): NavigationType
```

## Returns

The current `NavigationType` type (`"PUSH"`, `"REPLACE"`, or `"POP"`)
