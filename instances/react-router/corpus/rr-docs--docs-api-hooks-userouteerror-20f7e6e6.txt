## useRouteError

[MODES: framework, data]

## Summary

Reference Documentation ↗

Accesses the error thrown during an ActionFunction, LoaderFunction, or component render to be used in a route module Error Boundary.

```tsx
export function ErrorBoundary() {
  const error = useRouteError();
  return <div>{error.message}</div>;
}
```

## Signature

```tsx
useRouteError(): unknown
```
