# API: `CurrentPath` (mixin)
# джерело: https://github.com/remix-run/react-router/blob/v0.10.2/docs/api/mixins/CurrentPath.md
# отримано: 2026-09-25
# версія: 0.10.2, 0.10.1, 0.10.0, 0.9.5, 0.9.4, 0.9.3, 0.9.2, 0.9.1, 0.9.0

A mixin for components that need to know the current URL path.

## Instance Methods

### `getCurrentPath()`

Returns the current URL path.

## Example

```js
var CurrentPath = require('react-router').CurrentPath;

var ShowThePath = React.createClass({
  mixins: [ CurrentPath ],
  render: function () {
    return (
      <div>The current path is: {this.getCurrentPath()}</div>
    );
  }
});
```
