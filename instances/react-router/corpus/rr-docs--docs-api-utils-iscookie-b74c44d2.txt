## isCookie

[MODES: framework, data]

## Summary

Reference Documentation ↗

Returns `true` if a value is a React Router `Cookie` object.

## Params

### object

The value to check.

## Returns

`true` if the value is a React Router `Cookie` object;
otherwise, `false`.
