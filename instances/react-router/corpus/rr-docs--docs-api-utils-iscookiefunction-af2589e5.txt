## IsCookieFunction

[MODES: framework, data]

## Summary

Reference Documentation ↗

A function that determines whether a value is a React Router `Cookie`
object.

## Signature

```tsx
type IsCookieFunction = (object: any) => object is Cookie;
```

## Params

### object

The value to check.

## Returns

`true` if the value is a React Router `Cookie` object;
otherwise, `false`.
