## IsSessionFunction

[MODES: framework, data]

## Summary

Reference Documentation ↗

A function that determines whether a value is a React Router `Session`
object.

## Signature

```tsx
type IsSessionFunction = (object: any) => object is Session;
```

## Params

### object

The value to check.

## Returns

`true` if the value is a React Router `Session` object;
otherwise, `false`.
