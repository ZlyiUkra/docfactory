# Navigating Outside of Components
# джерело: https://github.com/remix-run/react-router/blob/v2.0.0-rc5/docs/guides/advanced/NavigatingOutsideOfComponents.md
# отримано: 2026-09-25
# версія: 2.0.0-rc5, 2.0.0-rc4, 2.0.0-rc3, 2.0.0-rc2, 2.0.0-rc1

While you can use `this.context.router` to navigate around, many apps want to be able to navigate outside of their components. They can do that with the history the app gives to `Router`.

```js
// your main file that renders a Router
import { Router, browserHistory } from 'react-router'
import routes from './app/routes'
render(<Router history={browserHistory} routes={routes}/>, el)
```

```js
// somewhere like a redux/flux action file:
import { browserHistory } from './react-router'
browserHistory.push('/some/path')
```
