# Confirming Navigation
# джерело: https://github.com/remix-run/react-router/blob/v3.0.0-alpha.2/docs/guides/ConfirmingNavigation.md
# отримано: 2026-09-25
# версія: 3.0.0-alpha.2, 3.0.0-alpha.1, 2.8.1, 2.8.0, 2.6.0, 2.5.2, 2.5.1, 2.5.0, 2.4.1

You can prevent a transition from happening or prompt the user before leaving a route with a leave hook.

```js
const Home = withRouter(
  React.createClass({

    componentDidMount() {
      this.props.router.setRouteLeaveHook(this.props.route, this.routerWillLeave)
    },

    routerWillLeave(nextLocation) {
      // return false to prevent a transition w/o prompting the user,
      // or return a string to allow the user to decide:
      if (!this.state.isSaved)
        return 'Your work is not saved! Are you sure you want to leave?'
    },

    // ...

  })
)
```

Note that this example makes use of the withRouter higher-order component introduced in v2.4.0.
