# context.history
# джерело: https://github.com/remix-run/react-router/blob/v4.0.0-beta.7/packages/react-router/docs/context.history.md
# отримано: 2026-09-25
# версія: 4.0.0-beta.7

Warning! The objects provided on context are not considered public API.

Every `<Router>` puts its `history` object on `context` as `context.history`. This object is used internally to open a channel of communication between e.g. a `<Router>` and its descendant `<Route>`s, `<Link>`s, and `<Prompt>`s, etc.

`context.history` is also occasionally useful as public API, for example, in instances when you need to access the router's imperative API directly. However, we encourage you to use `context.history` only as a last resort. Context itself is an experimental API and may change in a future release of React.

All of the rendering props (`render`, `component`, `children`) in `<Route>` receive `history` as a prop. It's recommended to access `history` from there instead of from context.
