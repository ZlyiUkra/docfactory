# <Router>
# джерело: https://github.com/remix-run/react-router/blob/v4.0.0-beta.7/packages/react-router/docs/Router.md
# отримано: 2026-09-25
# версія: 4.0.0-beta.7

The common low-level interface for all router components. Higher-level routers include:

- `<BrowserRouter>`
- `<HashRouter>`
- `<MemoryRouter>`
- `<NativeRouter>`
- `<StaticRouter>`

Use a `<Router>` directly if you already have a `history` object.

```js
import { Router } from 'react-router'
import createBrowserHistory from 'history/createBrowserHistory'

const history = createBrowserHistory()

<Router history={history}>
  <App/>
</Router>
```

## history: object

A `history` object to use for navigation.

## children: node

A single child element to render.
