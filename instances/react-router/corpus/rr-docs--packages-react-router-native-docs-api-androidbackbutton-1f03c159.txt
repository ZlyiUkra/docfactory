# <AndroidBackButton>
# джерело: https://github.com/remix-run/react-router/blob/v4.2.2/packages/react-router-native/docs/api/AndroidBackButton.md
# отримано: 2026-09-25
# версія: 4.2.2, 4.2.1, 4.2.0, 4.1.1, 4.1.0, 4.0.0, 4.0.0-beta.8

Connects the android global back button to the router's history. When the initial location is reached, the default android back behavior takes over. Just render one somewhere in your app.

```js
<AndroidBackButton/>
```

## children

If you want to avoid the floating configuration component, you can compose with children.

```js
<NativeRouter>
  <AndroidBackButton>
    <App/>
  </AndroidBackButton>
</NativeRouter>

// instead of
<NativeRouter>
  <View>
    <AndroidBackButton/>
    <View>Some people don't like that.</View>
  </View>
</NativeRouter>
```
