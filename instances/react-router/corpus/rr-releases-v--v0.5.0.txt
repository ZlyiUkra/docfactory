# React Router release: v0.5.0
# джерело: https://github.com/remix-run/react-router/releases/tag/v0.5.0
# отримано: 2026-09-25
# версія: 0.5.0

Tag v0.5.0, published 2015-11-10, pre-release.

We brought back `<Routes/>`.

```js
// 0.4.x
var routes = (
  <Route handler={App} location="history">
    <Route name="about" handler="about"/>
  </Route>
);

// 0.5.x
var routes = (
  <Routes location="history">
    <Route handler={App}>
      <Route name="about" handler="about"/>
    </Route>
  </Routes>
);
```

## Changes

- 5af49d4 [changed] Split `<Routes>` component from `<Route>`
