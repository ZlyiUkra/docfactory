# JavaScript Environment Requirements
# джерело: https://github.com/reactjs/legacy.reactjs.org/blob/b5c75c4290d8394c34c980baed0935eeec97883e/content/docs/reference-javascript-environment-requirements.md
# отримано: 2026-09-15
# версія: 18.1.0

React 18 supports all modern browsers (Edge, Firefox, Chrome, Safari, etc).

If you support older browsers and devices such as Internet Explorer which do not provide modern browser features natively or have non-compliant implementations, consider including a global polyfill in your bundled application.

Here is a list of the modern features React 18 uses:
- `Promise`
- `Symbol`
- `Object.assign`

The correct polyfill for these features depend on your environment. For many users, you can configure your Browserlist settings. For others, you may need to import polyfills like `core-js` directly.
