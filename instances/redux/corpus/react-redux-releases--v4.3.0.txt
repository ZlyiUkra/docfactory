Tag v4.3.0, published 2016-02-04.

- Adds per-instance memoization API. If your `mapStateToProps` or `mapDispatchToProps` returns a function, _that_ function will be used instead for the given component instance. Most apps never need this, but it can be handy for custom memoization logic in apps with large component trees. It can bring significant performance improvements when used together with Reselect.
