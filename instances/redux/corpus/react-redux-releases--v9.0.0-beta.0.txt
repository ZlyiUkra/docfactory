Tag v9.0.0-beta.0, published 2023-10-01, pre-release.

This **beta release** fixes the imports of `use-sync-external-store` when used in an ESM environment, and includes the fixes in v8.1.3.

```bash
npm i react-redux@beta

yarn add react-redux@beta
```

We currently do not anticipate any major development or changes with React-Redux before v9 goes final, but that will be done in conjunction with the Redux Toolkit 2.0 release when it is ready.

## What's Changed

* Add stack to dev mode checks by @EskiMojo14 in https://github.com/reduxjs/react-redux/pull/2064
* Fix `uSES` imports and run against RTK CI examples by @markerikson in https://github.com/reduxjs/react-redux/pull/2070
* Fix useSelector() in combination with lazy loaded components breaks with react v18 (#1977) by @jeroenpx in https://github.com/reduxjs/react-redux/pull/2068
