Tag v9.1.1, published 2024-04-14.

This bugfix release fixes an issue with `connect` and React Native caused by changes to our bundling setup in v9.  Nested `connect` calls should work correctly now.

## What's Changed

* Remove unused isProcessingDispatch by @Connormiha in https://github.com/reduxjs/react-redux/pull/2122
* Move `Equals` constraint into an intersection type. by @DanielRosenwasser in https://github.com/reduxjs/react-redux/pull/2123
* Fix `useIsomorphicLayoutEffect` usage in React Native environments by @aryaemami59 in https://github.com/reduxjs/react-redux/pull/2156
