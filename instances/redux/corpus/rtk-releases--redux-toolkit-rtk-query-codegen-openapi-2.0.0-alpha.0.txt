# redux-toolkit release: RTK-Query OpenAPI Codegen v2.0.0-alpha.0
# джерело: https://github.com/reduxjs/redux-toolkit/releases/tag/%40rtk-query/codegen-openapi%402.0.0-alpha.0

Tag @rtk-query/codegen-openapi@2.0.0-alpha.0, published 2024-08-30.

This **alpha release** revamps the build and publishing setup for the RTK Query OpenAPI Codegen, as well as merging _numerous_ PRs from external contributors.

This should resolve many outstanding issues and feature requests.
