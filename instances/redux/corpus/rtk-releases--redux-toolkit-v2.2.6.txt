Tag v2.2.6, published 2024-06-29.

This **bugfix release**:
- Brings internal `useIsomorphicLayoutEffect` usage in line with React Redux in React Native environments
- Exports `FetchBaseQueryArgs` type
- Fixes an issue in recent `createEntityAdapter` sorting perf improvements that could (in specific cases) cause Immer to throw an error

## What's Changed

* Fix `useIsomorphicLayoutEffect` usage in React Native environments by @aryaemami59 in https://github.com/reduxjs/redux-toolkit/pull/4436
* Add export for FetchBaseQueryArgs by @WilsonCWong in https://github.com/reduxjs/redux-toolkit/pull/4465
* Fix Immer current usage when calling addManyMutably more than once by @JacobShafer in https://github.com/reduxjs/redux-toolkit/pull/4420
* Golf a few pieces of entity adapter code by @EskiMojo14 in https://github.com/reduxjs/redux-toolkit/pull/4485
