# Примірник reinforcement-learning

Цей примірник шукає в книжках, курсах і статтях про навчання з підкріпленням. Навчання з підкріпленням (reinforcement learning,
RL) — це спосіб навчити програму приймати рішення методом спроб. Програму, що вирішує, називають агентом. Агент бачить стан
середовища, обирає дію й дістає за неї винагороду — число, яке каже, наскільки добрим був наслідок. Правильної відповіді агентові
ніхто не показує: він сам шукає правило вибору дій (його називають політикою), що дає найбільшу суму винагород за довгий час.

Окрема проста форма цієї задачі — бандит. У бандиті кожне рішення стоїть окремо: агент обирає один варіант із кількох, одразу
бачить результат, і наступний стан від його вибору не залежить. Коли перед вибором агент ще й бачить додаткові дані, це контекстний
бандит. Так описується, наприклад, ставка з фіксованим терміном і відомою виплатою.

Примірник зібрано під експерименти з торгівлею. Тут лежить теорія: що таке марковський процес рішень, як агент оцінює стани й дії,
як він балансує між пробою нового і використанням відомого, як працюють DQN, PPO і SAC, як учитися на записаній історії без живого
середовища. Довідники API бібліотек лежать в інших примірниках: [`pytorch`](../pytorch/README.md), [`numpy`](../numpy/README.md).

так. Запити своїми словами знаходять потрібне 8 із 10.

## Слайди російською

Пошук цього примірника розрахований на англійську: модель векторів навчена на англійських текстах. Щоб російські слайди OTUS
знаходилися, зроблено дві речі. Кожне заняття має назву двома мовами («Basic algorithms: value-based / Основные алгоритмы RL. Value
based»), і ця назва входить у текст кожного фрагмента, тому англійський запит доходить до слайдів. У `config.json` стоїть
`"cyrillic_words": true`, тому російський запит шукається по словах. Назви алгоритмів (DQN, PPO, TD3) у слайдах написано латиницею,
і вони знаходяться за будь-якої мови запиту.

## Обмеження текстів

Формули в PDF витягуються як текст і часто розсипаються, а підписи до рисунків стоять посеред абзаців. Пояснення словами від
цього не страждає. Слайди лекцій — це короткі тези без зв'язного тексту.

## Як читаються файли

Книжки й статті читає `pdf-outline`: він ділить PDF на документи за закладками до заданої глибини, а глибші закладки робить
підзаголовками. Для цього примірника читач дістав необов'язкове поле `engine: "pdfium"`. У книжці Graesser і Keng бібліотека pypdf
склеює слова без пробілів, тому з цим полем текст усіх сторінок бере PDFium (pypdfium2). Сайт Spinning Up читає `html-pages`, курс
Hugging Face — `ghdocs-history`.

## Корпус лише локально

Корпус — це тексти глав і статей, а індекс — кеш фрагментів, з якого підіймається сервер. Платні книжки не можна поширювати, тому
**корпус, індекс і файли книжок у git не потрапляють** (`corpus/`, `index/` і `raw/` у `.gitignore`). У git лежать лише
налаштування примірника, а сервер працює лише на цій машині.

**Де тексти.** Вони лежать в архіві `~/archives/docfactory/reinforcement-learning-corpus-2026-11-12-finance.tar.gz` разом із паспортом,
сховищем сирого і файлами книжок у `raw/local/`. Копія лежить на Windows:
`C:\Distr\reinforcement-learning-corpus-2026-11-12-finance.tar.gz`. Архів звірено з диском файл за файлом, а копію — за SHA-256. Сервер
підіймається з кешу `index/passages.json` і колекції Qdrant, тому тексти йому не потрібні.

**Як повернути тексти** перед оновленням:

```
tar -xzf ~/archives/docfactory/reinforcement-learning-corpus-2026-11-12-finance.tar.gz -C instances/reinforcement-learning
./df reinforcement-learning smoke
```

**Якщо зникне кеш фрагментів.** Спершу поверніть тексти, а потім запустіть `./df reinforcement-learning vectors`: кеш збереться
заново.

Як оновлювати примірник, описано в [UPDATE.md](UPDATE.md).

## Як запустити

```
./df reinforcement-learning serve
```

Сервер слухає порт `8971`. Під'єднати його до Claude Code можна файлом `.mcp.json` цієї теки або командою:

```
claude mcp add --transport http --scope user reinforcement-learning-docs http://127.0.0.1:8971/mcp
```

Команда для Claude Code у Windows, коли сервер працює у WSL, та сама. У сесії Claude Code команда `/mcp` має показати сервер із
двома інструментами: `search_docs` і `read_section`. Якщо порт зайнятий, `serve` зупиняється з повідомленням про зайняту адресу:
тоді сервер цього примірника вже працює в іншому терміналі. Перевірка: `./df reinforcement-learning smoke` і
`./df reinforcement-learning quality`.
