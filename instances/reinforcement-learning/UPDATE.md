# Оновлення корпусу reinforcement-learning

Книжки й статті майже не міняються, тож оновлення — це здебільшого нова книжка чи стаття.

Правило: **нічого не видаляється.** Лише `vectors` прибирає точки своєї колекції, чиїх фрагментів уже немає в корпусі.

1. Поверніть тексти за [README, розділ «Корпус лише локально»](README.md#корпус-лише-локально).
2. Нова книжка з файлу: покладіть PDF у `instances/reinforcement-learning/raw/local/` під коротким іменем латиницею і допишіть джерело
   в `sources.json` за зразком сусідніх: читач `pdf-outline` (поле `depth` — до якої глибини закладок різати книжку на документи),
   поля `file`, `url` (сторінка видавця), `title`, `frozen: true`. Нова стаття з мережі: джерело `pdf-outline` з
   полями `url` (сам PDF), `page` і `within`.
3. Оновіть примірник:

```
./df reinforcement-learning refresh <id нового джерела>
./df reinforcement-learning manifest
./df reinforcement-learning vectors
./df reinforcement-learning smoke
./df reinforcement-learning quality
```

4. Запишіть нове число фрагментів у `checks.json`, зробіть новий архів і звірте його з диском. Лише тоді видаляйте тексти з теки
   та попередній архів.

Джерела-книжки позначено `frozen`, тому `refresh` без імен їх не чіпає: його без імен можна запускати, щоб перевірити статті й
сайти. Якщо читач змінився, перебудовують усі джерела цього читача: `refresh` з їхніми id. Старі файли з іншими іменами
`refresh` сам не видаляє, їх прибирають вручну перед `manifest`.
