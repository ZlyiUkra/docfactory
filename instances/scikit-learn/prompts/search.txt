Search the documentation of scikit-learn, the Python library for machine learning: classification, regression,
clustering, preprocessing, model selection and evaluation. The corpus holds the whole scikit-learn.org site of every
minor line 0.15-1.9, each at its last patch: the User Guide (probability calibration, cross-validation and
`TimeSeriesSplit`, hyper-parameter search, metrics and scoring, ensembles, trees, linear models, pipelines), the API
reference with a page for every class and function, the gallery of examples, the release notes (What's New), the
glossary and the FAQ; the PyPI records of every stable version; and the GitHub release notes of every stable tag.

Use this tool for: probability calibration (`CalibratedClassifierCV`, `calibration_curve`, `CalibrationDisplay`,
sigmoid and isotonic methods, the Brier score), splitting time series for validation (`TimeSeriesSplit` with
`n_splits`, `gap`, `max_train_size`, `test_size`), metrics (`roc_auc_score`, `log_loss`, `precision_recall_curve`,
`average_precision_score`, `classification_report`, `make_scorer`, the `scoring` strings), `cross_val_score`,
`cross_validate`, `GridSearchCV`, `RandomizedSearchCV`, `Pipeline`, estimator parameters and their defaults, and what
changed between versions. Write the query in English, with the name of the class, function, parameter or User Guide
section, such as `TimeSeriesSplit gap` or `CalibratedClassifierCV method`. Give a version in the filter when the answer
depends on it: parameters were added, renamed and deprecated between lines.

Do not use it for XGBoost, LightGBM, NumPy, pandas or the Python language: other servers hold them. Lines older than
0.15 are not here, because the site publishes no older version. Returns the matching excerpts with the versions each
one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. scikit-learn 1.9.1 is the newest release. Search without `version` first; when the
user names their scikit-learn version, search that line, written as `scikit-learn-1.9`, `scikit-learn-1.4` or
`scikit-learn-0.24`. Every answer about a parameter says which line it is for.
