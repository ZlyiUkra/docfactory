Search the documentation of SciPy, the Python library for scientific computing built on NumPy. The corpus holds the whole
docs.scipy.org site of the last patch of every minor line 0.7-1.18: the user guide (statistics, optimization, interpolation,
integration, signal processing, linear algebra, sparse matrices, Fourier transforms, spatial algorithms), the API reference
with a page for every function and class, and the release notes of every version; also the GitHub release notes and the
PyPI records.

Use this tool for: statistical distributions and their parameters (`scipy.stats.norm`, `t`, `skewnorm`, `fit`), statistical
tests (`ttest_ind`, `jarque_bera`, `shapiro`, `kstest`, `pearsonr`, `spearmanr`), descriptive statistics (`skew`, `kurtosis`,
`describe`), optimization (`minimize` with its methods and constraints, `least_squares`, `curve_fit`, `differential_evolution`,
`brentq`), filters and spectra (`scipy.signal.savgol_filter`, `butter`, `filtfilt`, `find_peaks`, `periodogram`), interpolation
and distances, and what changed between versions. Write the query in English with the module, function or parameter name,
such as `scipy.stats.t`, `minimize SLSQP` or `find_peaks prominence`. Give a version in the filter when the answer depends on
it.

Do not use it for NumPy itself (the numpy server holds it), for statistical models such as ARIMA and regression (the
statsmodels server holds them), for volatility models (the arch server) or for machine learning (the scikit-learn server).
Returns the matching excerpts with the versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest line is 1.18 (`scipy-1.18`). Search without `version` first; when the user names a
version, search that line. Function signatures and defaults changed between lines, so say which version an answer is for.
