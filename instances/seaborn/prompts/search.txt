Search the documentation of seaborn, the Python library that draws statistical charts on top of matplotlib from pandas
tables. The corpus holds the seaborn.pydata.org site of the current line 0.13 and of the archived lines 0.9, 0.10, 0.11 and
0.12: the user guide and tutorial (distributions, relationships, categorical data, regression, multi-plot grids, color
palettes, themes, the objects interface `seaborn.objects`), the API reference with a page for every function and class
(`histplot`, `kdeplot`, `displot`, `lineplot`, `scatterplot`, `relplot`, `boxplot`, `violinplot`, `heatmap`, `clustermap`,
`pairplot`, `jointplot`, `regplot`, `FacetGrid`, `PairGrid`, `set_theme`, `color_palette`), the example gallery and the
"what's new" pages of every version since 0.2; the GitHub release notes and the PyPI records of every stable version.

Use this tool for: how to draw the distribution of returns as a histogram with a density curve, how to show a correlation
matrix between currency pairs as a heatmap, how to compare groups with box and violin plots, how to plot many small charts
by a category, how to set a theme and a palette, and what changed between versions. Write the query in English with the
function, class or parameter name, such as `histplot`, `heatmap`, `annot`, `FacetGrid` or `set_theme`. Give a version in the
filter when the answer depends on it.

Do not use it for matplotlib itself (the matplotlib server holds it), for candlestick charts (the mplfinance and plotly
servers hold them) or for statistical models (the statsmodels server holds them). Returns the matching excerpts with the
versions each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest line is 0.13 (`seaborn-0.13`). Search without `version` first; when the user
names a version, search that line. Version 0.11 replaced `distplot` with `histplot`, `kdeplot` and `displot`, and 0.12 added
the objects interface, so say which version an answer is for.
