Return the full text of one excerpt of the Sentry documentation for JavaScript (the JavaScript
section of docs.sentry.io with every framework guide, the product, concepts, sentry-cli,
settings, integrations and REST API pages, the README, migration guides and changelogs of the
JavaScript SDK, of the bundler plugins and of sentry-cli, and the npm registry records of the
@sentry/* packages) by its identifier, together with the document it belongs to, the URL it was
taken from and the date the text was fetched from that URL -- so a quotation can be checked
against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- an option of Sentry.init or of a bundler plugin, a default
value, a sentry-cli flag or a version requirement quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not option names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: name the framework and the SDK version
when they matter, keep identifiers and titles in English, use Ukrainian words for Ukrainian
prose, and name the document you read.
