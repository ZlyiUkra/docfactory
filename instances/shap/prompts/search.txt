Search the documentation of SHAP (SHapley Additive exPlanations), the Python library that explains the output of a
machine learning model: for every single prediction it says how much each feature pushed the result up or down. The
corpus holds the shap.readthedocs.io site of the stable version 0.54: the introduction, the topical overviews, the
example notebooks (tabular data, tree models of XGBoost, LightGBM and scikit-learn, text, images, genomics), the API
examples and the API reference with a page for every explainer, plot and masker; the GitHub release notes of every
stable tag; and the PyPI record of every stable version with its README.

Use this tool for: `TreeExplainer` for XGBoost, LightGBM and scikit-learn trees (`feature_perturbation`,
`model_output`, `check_additivity`), `shap.Explainer`, the `Explanation` object (`values`, `base_values`, `data`),
`shap_values` and interaction values, the plots (`shap.plots.waterfall`, `beeswarm`, `bar`, `scatter`, `force`,
`heatmap`, `decision`), maskers and background data, explaining a single prediction, and what changed between versions.
Write the query in English, with the name of the class, function, plot or parameter, such as `TreeExplainer
feature_perturbation` or `shap.plots.waterfall`. Give a version in the filter only for release notes and PyPI records.

Do not use it for XGBoost, LightGBM, scikit-learn or NumPy themselves: other servers hold them. The site is here only
in its stable version 0.54, because Read the Docs publishes no older version; older versions are covered only by the
release notes and the PyPI READMEs. Returns the matching excerpts with the versions each one applies to, the source
address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. SHAP 0.54.1 is the newest release. Search without `version` first; when the user names
their SHAP version, search that line in the release notes, written as `shap-0.54`, `shap-0.46` or `shap-0.39`, and say
that the API reference describes 0.54.
