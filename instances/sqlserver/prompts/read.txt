Return the full text of one excerpt of the SQL Server documentation by its identifier, together with the page
it belongs to, every version whose documents contain this text, the URL it was taken from and the date the text
was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording
matters: the full syntax of a T-SQL statement and the meaning of each argument, a permissions table, a list of
limitations, the columns of a system view or DMV, a mssql-conf setting, an error message, a feature comparison
by edition, a migration step, a driver option and its default, a release note, an image tag table.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of `search_docs`:
names stay in English, say which SQL Server version or cloud product the excerpt is for, and the page you read.
