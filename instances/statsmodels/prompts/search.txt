Search the documentation of statsmodels, the Python library for statistical models, statistical tests and time series
analysis. The corpus holds the whole statsmodels.org site of every minor line 0.6-0.15, each at its last patch: the
User Guide (linear regression, generalized linear models, discrete choice models, robust and mixed models, time series
analysis, state space models, vector autoregressions, statistical tests and diagnostics), the API reference with a page
for every class, method and function, the example notebooks and the release notes; the PyPI records of every stable
version; and the GitHub release notes of every stable tag.

Use this tool for: time series models (`ARIMA`, `SARIMAX`, `AutoReg`, `ExponentialSmoothing`, `ETSModel`, `VAR`,
`VECM`, `MarkovRegression`, `UnobservedComponents`) with their `fit`, `forecast`, `get_forecast` and `predict`;
stationarity and cointegration tests (`adfuller`, `kpss`, `coint`, `coint_johansen`, `zivot_andrews`); autocorrelation
(`acf`, `pacf`, `plot_acf`, `plot_pacf`, `acorr_ljungbox`); decomposition (`seasonal_decompose`, `STL`, `MSTL`);
regression (`OLS`, `WLS`, `GLS`, `RollingOLS`, the formula interface `smf.ols`, robust covariance such as `HAC`);
results objects (`summary`, `params`, `pvalues`, `conf_int`, `aic`, `bic`); and what changed between versions. Write the
query in English, with the name of the class, function, parameter or User Guide section, such as `SARIMAX
seasonal_order` or `adfuller autolag`. Give a version in the filter when the answer depends on it: modules were moved,
renamed and removed between lines (the old `arima_model.ARIMA` was replaced by `arima.model.ARIMA` in 0.12).

Do not use it for pandas, NumPy, SciPy, scikit-learn, GARCH models of the `arch` package or the Python language:
statsmodels has no GARCH, and other servers hold the rest. Lines older than 0.6 are not here, because the site
publishes no older version. Returns the matching excerpts with the versions each one applies to, the source address and
the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. statsmodels 0.15.0 is the newest release. Search without `version` first; when the
user names their statsmodels version, search that line, written as `statsmodels-0.15`, `statsmodels-0.14` or
`statsmodels-0.9`. Every answer about a parameter says which line it is for.
