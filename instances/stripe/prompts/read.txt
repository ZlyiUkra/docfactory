Return the full text of one excerpt of the Stripe documentation by its identifier, together with the page or file it
belongs to, every version whose documents contain this text, the URL it was taken from and the date the text was
fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut at 600 characters, or when the exact wording matters:
an API parameter with its type and values, an object field, a code example in a given language, a webhook event,
a currency rule, a fee, a limit, an error code, a changelog entry of an API version, an SDK release note, a
version table from a package registry.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool accepts
comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of `search_docs`:
names stay in English, name the SDK and its version when the excerpt is from one, and the page you read.
