# Analytics API: management
# джерело: https://supabase.com/docs/reference/self-hosting-analytics/introduction
# отримано: 2026-09-24

## GET /api/endpoints

List endpoints

Responses:

- `200`: Endpoint List Response

## POST /api/endpoints

Create endpoint

Request body (application/json):

- `cache_duration_seconds` `integer`
- `enable_auth` `boolean`
- `inserted_at` `string`
- `max_limit` `integer`
- `name` `string`, required
- `proactive_requerying_seconds` `integer`
- `query` `string`, required
- `sandboxable` `boolean`
- `source_mapping` `object`
- `token` `string`
- `updated_at` `string`

Responses:

- `201`: Created Response
- `404`: Not found

## GET /api/endpoints/{token}

Fetch endpoint

Parameters:

- `token` (path, required) `string`: Endpoint Token

Responses:

- `200`: Endpoint Response
- `404`: Not found
