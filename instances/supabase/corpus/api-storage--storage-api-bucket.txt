# Storage API: bucket
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Bucket end-points

## GET /bucket/

Gets all buckets

Security: bearerAuth

Parameters:

- `limit` (query) `integer`
- `offset` (query) `integer`
- `sortColumn` (query) `string, one of id, name, created_at, updated_at`
- `sortOrder` (query) `string, one of asc, desc`
- `search` (query) `string`

Responses:

- `200`: Successful response
- `4XX`: Error response

## POST /bucket/

Create a bucket

Security: bearerAuth

Request body (application/json):

- `name` `string`, required
- `id` `string`
- `public` `boolean`
- `type` `string, one of STANDARD, ANALYTICS`
- `file_size_limit`
- `allowed_mime_types` `array of string`

Responses:

- `200`: Successful response
- `4XX`: Error response
