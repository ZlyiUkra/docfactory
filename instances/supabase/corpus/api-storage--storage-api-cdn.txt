# Storage API: cdn
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

CDN cache management

## DELETE /cdn/{bucketName}/{*}

Purge cache for an object

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `200`: Successful response
- `4XX`: Error response
