# Storage API: iceberg
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Apache Iceberg REST catalog

## GET /iceberg/v1/config

Get Iceberg catalog configuration

Security: bearerAuth

Parameters:

- `warehouse` (query, required) `string`

Responses:

- `200`: Default Response

## HEAD /iceberg/v1/config

Get Iceberg catalog configuration

Security: bearerAuth

Parameters:

- `warehouse` (query, required) `string`

Responses:

- `200`: Default Response

## GET /iceberg/v1/{prefix}/namespaces

List namespaces

Security: bearerAuth

Parameters:

- `pageToken` (query) `string`
- `pageSize` (query) `number`
- `parent` (query) `string`
- `prefix` (path, required) `string`

Responses:

- `200`: Default Response

## POST /iceberg/v1/{prefix}/namespaces

Create a namespace

Security: bearerAuth

Parameters:

- `prefix` (path, required) `string`

Request body (application/json):

- `namespace` `string`, required
- `properties` `object`

Responses:

- `200`: Default Response

Create a table

Security: bearerAuth

Parameters:

- `pageToken` (query) `string`
- `pageSize` (query) `number`
- `parent` (query) `string`
- `prefix` (path, required) `string`
- `namespace` (path, required) `string`

Responses:

- `200`: Default Response

## POST /iceberg/v1/{prefix}/namespaces/{namespace}/tables

Create a table in the given namespace

Security: bearerAuth

Parameters:

- `prefix` (path, required) `string`
- `namespace` (path, required) `string`

Request body (application/json):

- `name` `string`, required
- `location` `string`
- `schema`, required
- `spec` `object`
- `properties` `object`
- `stage-create` `boolean`
- `write-order` `object`

Responses:

- `200`: Default Response

## HEAD /iceberg/v1/{prefix}/namespaces/{namespace}/tables

Create a table

- `parent` (query) `string`
- `prefix` (path, required) `string`
- `namespace` (path, required) `string`

Responses:

- `200`: Default Response

## GET /iceberg/v1/{prefix}/namespaces/{namespace}/tables/{table}

Load an Iceberg Table

Security: bearerAuth

Parameters:

- `prefix` (path, required) `string`
- `namespace` (path, required) `string`
- `table` (path, required) `string`

Responses:

- `200`: Default Response

## POST /iceberg/v1/{prefix}/namespaces/{namespace}/tables/{table}

Commit updates to multiple tables in an atomic operation

Security: bearerAuth

Parameters:

- `prefix` (path, required) `string`
- `namespace` (path, required) `string`
- `table` (path, required) `string`

Request body (application/json):

- `requirements` `array of object`, required: Assertions to validate before applying updates
- `updates` `array of object`, required: Metadata updates to apply to the table

Responses:

- `200`: Default Response

## DELETE /iceberg/v1/{prefix}/namespaces/{namespace}/tables/{table}

Drop a Table

Security: bearerAuth

Parameters:

- `purgeRequested` (query) `string, one of true, false, True, False`: If true, the table will be permanently deleted
- `prefix` (path, required) `string`
- `namespace` (path, required) `string`
- `table` (path, required) `string`

Responses:

- `200`: Default Response
