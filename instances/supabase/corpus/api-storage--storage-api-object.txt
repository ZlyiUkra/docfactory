# Storage API: object
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Object end-points

## GET /object/{bucketName}/{*}

Get object

Serve objects

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `4XX`: Default Response

## POST /object/{bucketName}/{*}

Upload a new object

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `200`: Successful response
- `4XX`: Error response

## PUT /object/{bucketName}/{*}

Update the object at an existing key

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `200`: Successful response
- `4XX`: Error response

## DELETE /object/{bucketName}/{*}

Delete an object

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `200`: Successful response
- `4XX`: Error response

## HEAD /object/{bucketName}/{*}

Retrieve object info

Head object info

Security: bearerAuth

Parameters:

- `height` (query) `integer`
- `width` (query) `integer`
- `resize` (query) `string, one of cover, contain, fill`
- `format` (query) `string, one of origin, avif, webp`
- `quality` (query) `integer`
- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `4XX`: Default Response

## DELETE /object/{bucketName}

Delete multiple objects

Security: bearerAuth

Parameters:

- `bucketName` (path, required) `string`

Request body (application/json):

- `prefixes` `array of string`, required

Responses:

- `200`: Successful response
- `4XX`: Error response

## POST /object/copy

- `200`: Successful response
