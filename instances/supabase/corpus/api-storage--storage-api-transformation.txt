# Storage API: transformation
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Image transformation

## GET /render/image/authenticated/{bucketName}/{*}

Render an authenticated image with the given transformations

Security: bearerAuth

Parameters:

- `height` (query) `integer`
- `width` (query) `integer`
- `resize` (query) `string, one of cover, contain, fill`
- `format` (query) `string, one of origin, avif, webp`
- `quality` (query) `integer`
- `download` (query) `string`
- `bucketName` (path, required) `string`
- `*` (path, required) `string`

Responses:

- `4XX`: Error response
