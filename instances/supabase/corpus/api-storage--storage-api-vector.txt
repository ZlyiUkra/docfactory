# Storage API: vector
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Vector storage and search

## POST /vector/CreateIndex

Create a vector index

Security: bearerAuth

Request body (application/json):

- `dataType` `string, one of float32`, required
- `dimension` `number`, required
- `distanceMetric` `string, one of cosine, euclidean`, required
- `indexName` `string`, required: 3-63 chars, lowercase letters, numbers, hyphens, dots; must start/end with letter or number. Must be unique within the vector bucket.
- `metadataConfiguration` `object`
- `vectorBucketName` `string`, required

Responses:

- `200`: Default Response

## POST /vector/DeleteIndex

- `200`: Default Response

## POST /vector/PutVectors

Put vectors into an index

Security: bearerAuth

Request body (application/json):

- `vectorBucketName` `string`, required
- `indexName` `string`, required: 3-63 chars, lowercase letters, numbers, hyphens, dots; must start/end with letter or number. Must be unique within the vector bucket.
- `vectors` `array of object`, required

Responses:

- `200`: Default Response

## POST /vector/QueryVectors

Query vectors

Security: bearerAuth

Request body (application/json):

- `filter` `object`: Boolean filter expression. Supports field operators ($eq, $ne, $gt, $gte, $lt, $lte, $in, $nin, $exists) and logical operators ($and, $or) with arbitrary nesting.
- `indexArn` `string`
- `indexName` `string`, required
- `queryVector` `object`, required
- `returnDistance` `boolean`
- `returnMetadata` `boolean`
- `topK` `number`, required
- `vectorBucketName` `string`, required

Responses:

- `200`: Default Response
