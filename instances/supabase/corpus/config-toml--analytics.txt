# config.toml: Analytics
# джерело: https://supabase.com/docs/guides/local-development/cli/config
# отримано: 2026-09-24

Analytics settings.

## analytics.enabled

- Required: no
- Default: `false`

Enable the local Logflare service.

See also:

- Self-hosted Logflare Configuration: https://supabase.com/docs/reference/self-hosting-analytics/list-endpoints#getting-started

## analytics.port

- Required: no
- Default: `54327`

Port to the local Logflare service.

## analytics.vector_port

- Required: no
- Default: `54328`

Port to the local syslog ingest service.

## analytics.backend

- Required: no
- Default: `"postgres"`

Configure one of the supported backends:

- `postgres`
- `bigquery`

See also:

- Self-hosted Logflare Configuration: https://supabase.com/docs/reference/self-hosting-analytics/list-endpoints#getting-started
