# config.toml: API
# джерело: https://supabase.com/docs/guides/local-development/cli/config
# отримано: 2026-09-24

Auth settings.

## api.enabled

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: api enabled
- Required: no
- Default: `true`

Enable the local PostgREST service.

See also:

- PostgREST configuration: https://postgrest.org/en/stable/configuration.html

## api.port

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: api port
- Required: no
- Default: `54321`

Port to use for the API URL.

Usage:

```toml
[api]
port = 54321
```

See also:

- PostgREST configuration: https://postgrest.org/en/stable/configuration.html

## api.schemas

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: api schemas
- Required: no
- Default: `["public", "storage", "graphql_public"]`

Schemas to expose in your API. Tables, views and functions in this schema will get API endpoints. `public` and `storage` are always included.

See also:

- PostgREST configuration: https://postgrest.org/en/stable/configuration.html

## api.extra_search_path

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: api extra search path
- Required: no
- Default: `["public", "extensions"]`

Extra schemas to add to the search_path of every request. public is always included.

See also:

- PostgREST configuration: https://postgrest.org/en/stable/configuration.html

## api.max_rows

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: api max rows
- Required: no
- Default: `1000`

The maximum number of rows returned from a view, table, or function. Limits payload size for accidental or malicious requests.

See also:

- PostgREST configuration: https://postgrest.org/en/stable/configuration.html
