# config.toml: Dashboard
# джерело: https://supabase.com/docs/guides/local-development/cli/config
# отримано: 2026-09-24

Dashboard settings.

## studio.enabled

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: studio enabled
- Required: no
- Default: `true`

Enable the local Supabase Studio dashboard.

## studio.port

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: studio port
- Required: no
- Default: `54323`

Port to use for Supabase Studio.

## studio.api_url

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: studio api url
- Required: no
- Default: `"http://localhost"`

External URL of the API server that frontend connects to.

## studio.openai_api_key

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: studio openai api key
- Required: no
- Default: `env(OPENAI_API_KEY)`

OpenAI API key used for AI features in the Studio dashboard.
DO NOT commit your OpenAI API key to git. Use environment variable substitution instead.

See also:

- OpenAI API Keys: https://platform.openai.com/api-keys
