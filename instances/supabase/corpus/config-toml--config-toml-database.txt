Database settings.

## db.port

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: db port
- Required: no
- Default: `54322`

Port to use for the local database URL.

See also:

- PostgreSQL configuration: https://postgrest.org/en/stable/configuration.html

## db.migrations.schema_paths

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: db migrations schema paths
- Required: no
- Default: `[]`

An ordered list of schema files, directories, or glob patterns describing your database, relative to the `supabase` directory. For example: `["./schemas/*.sql"]`.
Only the legacy `migra` diff engine uses this setting, where it controls the order in which declarative schema files are applied. The `pg-delta` diff engine (see `experimental.pgdelta.enabled`) ignores it and orders declarative files automatically based on the dependencies between statements.

See also:

- Declarative database schemas: https://supabase.com/docs/guides/local-development/declarative-database-schemas
