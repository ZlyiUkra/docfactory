# config.toml: Storage
# джерело: https://supabase.com/docs/guides/local-development/cli/config
# отримано: 2026-09-24

Storage settings.

## storage.enabled

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage enabled
- Required: no
- Default: `true`

Enable the local Storage service.

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config

## storage.file_size_limit

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage file size limit
- Required: no
- Default: `"50MiB"`

The maximum file size allowed for all buckets in the project.

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config

## storage.buckets..public

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage buckets bucket name public
- Required: no
- Default: `false`

Enable public access to the bucket.

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config

## storage.buckets..file_size_limit

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage buckets bucket name file size limit
- Required: no

The maximum file size allowed (e.g. "5MB", "500KB").

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config

## storage.buckets..allowed_mime_types

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage buckets bucket name allowed mime types
- Required: no

The list of allowed MIME types for objects in the bucket.

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config

## storage.buckets..objects_path

- Setting: key of supabase/config.toml (local project and supabase config push)
- In words: storage buckets bucket name objects path
- Required: no

The local directory to upload objects to the bucket.

See also:

- Storage server configuration: https://supabase.com/docs/guides/self-hosting/storage/config
