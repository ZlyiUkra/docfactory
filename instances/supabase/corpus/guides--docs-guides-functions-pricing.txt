# Pricing
# джерело: https://supabase.com/docs/guides/functions/pricing
# отримано: 2026-09-24

$2 per 1 million invocations. You are only charged for usage exceeding your
subscription plan's quota.

| Plan       | Quota     | Over-Usage                   |
| ---------- | --------- | ---------------------------- |
| Free       | 500,000   | -                            |
| Pro        | 2 million | $2 per 1 million invocations |
| Team       | 2 million | $2 per 1 million invocations |
| Enterprise | Custom    | Custom                       |

For a detailed explanation of how charges are calculated, refer to Manage Edge Function Invocations usage.
