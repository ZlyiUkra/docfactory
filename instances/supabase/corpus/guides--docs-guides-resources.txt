# Resources
# джерело: https://supabase.com/docs/guides/resources
# отримано: 2026-09-24

Resources for getting started building with Supabase.

- **Examples:** Official GitHub examples, curated content from the community, and more.
- **Glossary:** Definitions for terminology and acronyms used in the Supabase documentation.

### Migrate to Supabase

- **Auth0:** Move your auth users from Auth0 to a Supabase project.
- **Firebase Auth:** Move your auth users from a Firebase project to a Supabase project.
- **Firestore Data:** Migrate the contents of a Firestore collection to a single Postgres table.
- **Firebase Storage:** Convert your Firebase Storage files to Supabase Storage.
- **Heroku:** Migrate your Heroku Postgres database to Supabase.
- **Render:** Migrate your Render Postgres database to Supabase.
- **Amazon RDS:** Migrate your Amazon RDS database to Supabase.
- **Postgres:** Migrate your Postgres database to Supabase.
- **MySQL:** Migrate your MySQL database to Supabase.
- **Microsoft SQL Server:** Migrate your Microsoft SQL Server database to Supabase.

### Postgres resources

- **Managing Indexes:** Improve query performance using various index types in Postgres.
- **Cascade Deletes:** Understand the types of foreign key constraint deletes.
- **Drop all tables in schema:** Delete all tables in a given schema.
- **Select first row per group:** Retrieve the first row in each distinct group.
- **Print Postgres version:** Find out which version of Postgres you are running.
