# Self-hosted Realtime: Database Settings
# джерело: https://supabase.com/docs/reference/self-hosting-realtime/introduction
# отримано: 2026-09-24

Connecting to your database.

## DB_HOST

- Required: yes
- Default: `localhost`

Database host URL

## DB_NAME

- Required: yes
- Default: `postgres`

Database name

## DB_USER

- Required: yes
- Default: `postgres`

Database user

## DB_PASSWORD

- Required: yes
- Default: `postgres`

Database password

## DB_PORT

- Required: yes
- Default: `5432`

Database port

## DB_SSL

- Required: yes
- Default: `true`

Database SSL connection

## DB_IP_VERSION

- Required: yes
- Default: `IPv4`

Connect to database via either IPv4 or IPv6. Disregarded if database host is an IP address (e.g. '127.0.0.1') and recommended if database host is a name (e.g. 'db.abcd.supabase.co') to prevent potential non-existent domain (NXDOMAIN) errors.
