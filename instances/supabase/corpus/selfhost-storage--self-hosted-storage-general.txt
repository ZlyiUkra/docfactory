# Self-hosted Storage: General
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

General Settings

## ANON_KEY

- Setting: environment variable of the self-hosted Storage server
- In words: anon key
- Required: yes

A long-lived JWT with anonymous Postgres privileges.

## SERVICE_KEY

- Setting: environment variable of the self-hosted Storage server
- In words: service key
- Required: yes

A long-lived JWT with Postgres privileges to bypass Row Level Security.

## TENANT_ID

- Setting: environment variable of the self-hosted Storage server
- In words: tenant id
- Required: yes

The ID of a Storage tenant.

## REGION

- Setting: environment variable of the self-hosted Storage server
- Required: yes

Region of your S3 bucket.

## GLOBAL_S3_BUCKET

- Setting: environment variable of the self-hosted Storage server
- In words: global s3 bucket
- Required: yes

Name of your S3 bucket.

## POSTGREST_URL

- Setting: environment variable of the self-hosted Storage server
- In words: postgrest url
- Required: yes

The URL of your PostgREST server.

## PGRST_JWT_SECRET

- Setting: environment variable of the self-hosted Storage server
- In words: pgrst jwt secret
- Required: yes

A JWT Secret for the PostgREST database.

## DATABASE_URL

- Setting: environment variable of the self-hosted Storage server
- In words: database url
- Required: yes

The URL of your Postgres database.

## PGOPTIONS

- Setting: environment variable of the self-hosted Storage server
- Required: yes

Additional configuration parameters for Postgres startup.

## FILE_SIZE_LIMIT

- Setting: environment variable of the self-hosted Storage server
- In words: file size limit
- Required: yes

The maximum file size allowed.

## STORAGE_BACKEND

- Setting: environment variable of the self-hosted Storage server
- In words: storage backend
- Required: yes

The storage provider.

## FILE_STORAGE_BACKEND_PATH

- Setting: environment variable of the self-hosted Storage server
- In words: file storage backend path
- Required: yes

The location storage when the "STORAGE_BACKEND" is set to "file".
