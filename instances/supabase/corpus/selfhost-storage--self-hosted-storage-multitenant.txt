# Self-hosted Storage: Multi-tenant
# джерело: https://supabase.com/docs/reference/self-hosting-storage/introduction
# отримано: 2026-09-24

Configuration items for multi-tenant servers.

## IS_MULTITENANT

- Setting: environment variable of the self-hosted Storage server
- In words: is multitenant
- Required: yes

Operate across multiple tenants.

## MULTITENANT_DATABASE_URL

- Setting: environment variable of the self-hosted Storage server
- In words: multitenant database url
- Required: yes

The URL of the multitenant Postgres database.

## X_FORWARDED_HOST_REGEXP

- Setting: environment variable of the self-hosted Storage server
- In words: x forwarded host regexp
- Required: yes

TBD.

## POSTGREST_URL_SUFFIX

- Setting: environment variable of the self-hosted Storage server
- In words: postgrest url suffix
- Required: yes

The suffix for the PostgREST instance.

## ADMIN_API_KEYS

- Setting: environment variable of the self-hosted Storage server
- In words: admin api keys
- Required: yes

Secure API key for administrative endpoints.

## ENCRYPTION_KEY

- Setting: environment variable of the self-hosted Storage server
- In words: encryption key
- Required: yes

An key for encryting/decrypting secrets.
