# How to View Database Metrics
# джерело: https://supabase.com/docs/guides/troubleshooting/how-to-view-database-metrics-uqf2z_
# отримано: 2026-09-24

To monitor real-time metrics of your database, like CPU, EBS, active database connections, and memory usage, you can deploy a Grafana Dashboard. Check our GitHub repo for setup instructions for local or free Fly.io deployments. Refer to our concise documentation to learn more about the metrics endpoint.

While the Dashboard's Reports Page displays some metric data, it provides hourly averages, not real-time by the second data. However, it offers query metrics, which the Grafana Dashboard does not include.
