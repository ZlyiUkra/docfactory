# "insufficient privilege" when accessing pg_stat_statements
# джерело: https://supabase.com/docs/guides/troubleshooting/insufficient-privilege-when-accessing-pgstatstatements-e5M_EQ
# отримано: 2026-09-24

If you see the error "insufficient privilege" when accessing pg\_stat\_statements or when accessing Query Performance Report, it means that the Postgres role does not have required permissions.

In this case, you can run the below command to allow the Postgres role to read all statistics from the system:

```
grant pg_read_all_stats to postgres;
```
