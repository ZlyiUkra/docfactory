# "JWT Expired" Error in Supabase Dashboard
# джерело: https://supabase.com/docs/guides/troubleshooting/jwt-expired-error-in-supabase-dashboard-F06k3x
# отримано: 2026-09-24

When the Dashboard issues JWT expired errors, it usually means your computer's time is not in sync with the actual time.

Go to https://time.is/ to compare your computer's clock with your local time. If your computer's time is inaccurate, sync it to resolve the issue
