# Why am I being redirected to the wrong url when using auth redirectTo option?
# джерело: https://supabase.com/docs/guides/troubleshooting/why-am-i-being-redirected-to-the-wrong-url-when-using-auth-redirectto-option-_vqIeO
# отримано: 2026-09-24

Why are redirects going to localhost instead of the production site URL?
In order for the provided `redirectTo` option to work you must set the exact URL in the shown Redirect URL's setting.

image

For more information on formats for redirect URL settings see the documentation here: https://supabase.com/docs/guides/auth/redirect-urls#use-wildcards-in-redirect-urls
