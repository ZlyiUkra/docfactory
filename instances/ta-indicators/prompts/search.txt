Search the documentation of technical analysis indicator libraries for Python: TA-Lib (the C library and its Python
wrapper), pandas-ta-classic (the community-maintained fork of pandas-ta) and ta (bukosabino). The corpus holds: the
ta-lib.org site of TA-Lib 0.8 with one page per function (the formula, notes on seeding and the unstable start, inputs,
outputs, parameters with defaults and accepted ranges), its API, specification and install pages, and the TA-Lib C change
log and release notes; the docs/ folder and README of the TA-Lib Python wrapper at the last patch of every minor line
0.4-0.8 (Function API, Abstract API, Streaming API, the function groups), its change log, release notes and PyPI records;
the docs and README of pandas-ta-classic 0.3-0.9 and the code of its indicators split into functions, because each
indicator's description, sources, calculation, arguments and defaults live in the docstring of its function, plus its
change log and PyPI records, and the PyPI records of the original pandas-ta; the code of ta 0.1-0.11 split into classes
and functions, its README, its release table and PyPI records.

Use this tool for: the exact formula an indicator uses (RSI with Wilder smoothing, ATR, ADX, EMA seeding, Bollinger
Bands, MACD, Stochastic, CCI, Ichimoku), default parameters and accepted values, how many leading bars are unstable or
NaN (lookback, `TA_SetUnstablePeriod`), candlestick pattern functions, the Python call signature (`talib.RSI`,
`talib.abstract.Function`, `talib.stream`, `df.ta.rsi`, `ta.momentum.RSIIndicator`), column names that pandas-ta-classic
returns, and what changed between versions. Comparing two libraries is a common need: the same indicator can be smoothed
or seeded differently, and a model trained on one library's values behaves differently on another's. Write the query
in English with the indicator or function name, such as `RSI`, `ATR`, `talib.abstract` or `bbands`. Give a version in
the filter when the answer depends on it.

Do not use it for MetaTrader built-in indicators (iRSI, iATR and the like belong to the MQL4 and MQL5 servers), for
pandas itself, NumPy or backtesting libraries: other servers hold them. Returns the matching excerpts with the versions
each one applies to, the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.

Which version to search first. The newest lines are TA-Lib C 0.8 (`ta-lib-0.8`), the TA-Lib Python wrapper 0.8
(`talib-python-0.8`), pandas-ta-classic 0.9 (`pandas-ta-classic-0.9`) and ta 0.11 (`ta-0.11`). Search without `version`
first; when the user names a library version, search that line. Every answer says which library and which version it
is for: results and defaults changed between versions (pandas-ta-classic 0.9 changed results on warm-up bars, TA-Lib
0.8.3 changed the RSI output on flat input).
