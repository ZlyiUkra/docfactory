  @headlessui/vue

  A set of completely unstyled, fully accessible UI components for Vue 3, designed to integrate
  beautifully with Tailwind CSS.

## Installation

Please note that **this library only supports Vue 3**.

```sh
npm install @headlessui/vue
```
