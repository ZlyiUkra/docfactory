# Install Tailwind CSS with AdonisJS
# джерело: https://v3.tailwindcss.com/docs/guides/adonisjs
# отримано: 2026-09-30
# версія: 3.4

Setting up Tailwind CSS in an AdonisJS project.

## Create your project

Start by creating a new AdonisJS project if you don’t have one set up already. The most common approach is to use Create AdonisJS.

Terminal

```terminal
npm init adonisjs@latest my-project -- --kit=web
cd my-project
```

## Install Tailwind CSS

Install `tailwindcss` and its peer dependencies, then generate your `tailwind.config.js` and `postcss.config.js` files.

Terminal

```terminal
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
```

## Configure your template paths

Add the paths to all of your template files in your `tailwind.config.js` file.

tailwind.config.js

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./resources/**/*.edge",
    "./resources/**/*.{js,ts,jsx,tsx,vue}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

## Add the Tailwind directives to your CSS

Add the `@tailwind` directives for each of Tailwind’s layers to your `./resources/css/app.css` file.

app.css

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## Start your build process

Run your build process with `npm run dev`.

Terminal

```terminal
npm run dev
```

## Start using Tailwind in your project

Make sure your compiled CSS is included in the `<head>` then start using Tailwind’s utility classes to style your content.

home.edge

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
<body>
  <h1 class="text-3xl font-bold underline">
    Hello world!
  </h1>
</body>
</html>
```
