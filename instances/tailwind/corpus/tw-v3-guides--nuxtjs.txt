# Install Tailwind CSS with Nuxt
# джерело: https://v3.tailwindcss.com/docs/guides/nuxtjs
# отримано: 2026-09-30
# версія: 3.4

Setting up Tailwind CSS in a Nuxt project.

## Create your project

Start by creating a new Nuxt project if you don’t have one set up already. The most common approach is to use the Nuxt Command Line Interface .

Terminal

```terminal
npx nuxi init my-project
cd my-project
```

## Install Tailwind CSS

Install `tailwindcss` and its peer dependencies via npm, and then run the init command to generate a `tailwind.config.js` file.

Terminal

```terminal
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init
```

## Add Tailwind to your PostCSS configuration

Add `tailwindcss` and `autoprefixer` to the `postcss.plugins` object in your `nuxt.config.js` file.

nuxt.config.js

```js
// https://nuxt.com/docs/api/configuration/nuxt-config
export default defineNuxtConfig({
  devtools: { enabled: true },
  postcss: {
    plugins: {
      tailwindcss: {},
      autoprefixer: {},
    },
  },
})
```

## Configure your template paths

Add the paths to all of your template files in your `tailwind.config.js` file.

tailwind.config.js

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    "./components/**/*.{js,vue,ts}",
    "./layouts/**/*.vue",
    "./pages/**/*.vue",
    "./plugins/**/*.{js,ts}",
    "./app.vue",
    "./error.vue",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

## Add the Tailwind directives to your CSS

Create an `./assets/css/main.css` file and add the `@tailwind` directives for each of Tailwind’s layers.

main.css

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## Add the CSS file globally

Add your newly-created `./assets/css/main.css` to the `css` array in your `nuxt.config.js` file.

nuxt.config.js

```js
// https://nuxt.com/docs/api/configuration/nuxt-config
export default defineNuxtConfig({
  devtools: { enabled: true },
  css: ['~/assets/css/main.css'],
  postcss: {
    plugins: {
      tailwindcss: {},
      autoprefixer: {},
    },
  },
})
```

## Start your build process

Run your build process with `npm run dev`.

Terminal

```terminal
npm run dev
```

## Start using Tailwind in your project

Start using Tailwind’s utility classes to style your content.

app.vue

```html
<template>
  <h1 class="text-3xl font-bold underline">
    Hello world!
  </h1>
</template>
```

## Using Nuxt Modules

### Create your project

Start by creating a new Nuxt project if you don’t have one set up already. The most common approach is to use the Nuxt Command Line Interface .

Terminal

```terminal
npx nuxi init my-project
cd my-project
```

### Install Tailwind CSS

Using nuxi, install the `@nuxtjs/tailwindcss` module and then run the init command to generate a `tailwind.config.js` file.

Terminal

```terminal
npm install
npx nuxi module add @nuxtjs/tailwindcss
npx tailwindcss init
```

### Start your build process

Run your build process with `npm run dev`.

Terminal

```terminal
npm run dev
```

### Start using Tailwind in your project

Start using Tailwind’s utility classes to style your content.

app.vue

```html
<template>
  <h1 class="text-3xl font-bold underline">
    Hello world!
  </h1>
</template>
```
