The Angular adapter is available as a community library: ngneat/query. It is based on the TanStack/query-core.

## Installation

```bash
$ npm i @ngneat/query
# or
$ pnpm add @ngneat/query
# or
$ yarn add @ngneat/query
```

Check the complete documentation on GitHub.
