# InvalidateQueryFilters
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.3/docs/framework/lit/reference/interfaces/InvalidateQueryFilters.md
# отримано: 2026-09-26
# версія: 5.103.3

Defined in: packages/query-core/src/types.ts:771

Filters used to select queries, for example in `queryClient.getQueriesData` or `queryClient.invalidateQueries`.
All provided filters must match; filters that are left unspecified are ignored.
