# MutationState
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.3/docs/framework/lit/reference/interfaces/MutationState.md
# отримано: 2026-09-26
# версія: 5.103.3, 5.103.2

Defined in: packages/query-core/src/mutation.ts:30

The raw state stored on a `Mutation` instance. This is the underlying state
that observer results (e.g. `MutationObserverResult`) are derived from.

|  `context` | `TOnMutateResult` \| `undefined` | The value returned by `onMutate`, if defined. Passed to `onSuccess`, `onError` and `onSettled` as the mutation's context. |
