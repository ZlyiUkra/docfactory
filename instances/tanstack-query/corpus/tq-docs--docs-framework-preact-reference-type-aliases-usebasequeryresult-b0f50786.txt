# UseBaseQueryResult
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.102.8/docs/framework/preact/reference/type-aliases/UseBaseQueryResult.md
# отримано: 2026-09-26

```ts
type UseBaseQueryResult<TData, TError> = QueryObserverResult<TData, TError>;
```

Defined in: preact-query/src/types.ts:313

The result of `useQuery` when `initialData` isn't set — `data` may be `undefined` while the query is
`pending`. Re-exports QueryObserverResult from `@tanstack/query-core`. `useInfiniteQuery` returns
UseInfiniteQueryResult instead.

## Type Parameters

### TData

`TData` = `unknown`

The type `data` ends up as after `select` runs.

### TError

`TError` = `DefaultError`

The type of errors your `queryFn` may throw.
