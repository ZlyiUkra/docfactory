# useIsMutating
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@4.44.0/docs/framework/react/reference/useIsMutating.md
# отримано: 2026-09-26
# версія: 4.44.0, 4.43.0, 4.42.0, 4.41.1, 4.41.0, 4.40.2, 4.40.1, 4.40.0, 4.39.2, 4.39.1, 4.39.0

`useIsMutating` is an optional hook that returns the `number` of mutations that your application is fetching (useful for app-wide loading indicators).

```tsx
import { useIsMutating } from '@tanstack/react-query'
// How many mutations are fetching?
const isMutating = useIsMutating()
// How many mutations matching the posts prefix are fetching?
const isMutatingPosts = useIsMutating({ mutationKey: ['posts'] })
```

**Options**

- `filters?: MutationFilters`: Mutation Filters
- `context?: React.Context<QueryClient | undefined>`
  - Use this to use a custom React Query context. Otherwise, `defaultContext` will be used.

**Returns**

- `isMutating: number`
  - Will be the `number` of the mutations that your application is currently fetching.
