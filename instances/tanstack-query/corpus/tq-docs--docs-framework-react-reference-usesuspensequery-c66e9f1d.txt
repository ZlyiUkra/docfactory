# useSuspenseQuery
# джерело: https://github.com/TanStack/query/blob/v5.68.1/docs/framework/react/reference/useSuspenseQuery.md
# отримано: 2026-09-26
# версія: 5.68.1, 5.68.0, 5.67.3

```tsx
const result = useSuspenseQuery(options)
```

**Options**

The same as for useQuery, except for:

- `throwOnError`
- `enabled`
- `placeholderData`

**Returns**

Same object as useQuery, except that:

- `data` is guaranteed to be defined
- `isPlaceholderData` is missing
- `status` is always `success`
  - the derived flags are set accordingly.

**Caveat**

Cancelation does not work.
