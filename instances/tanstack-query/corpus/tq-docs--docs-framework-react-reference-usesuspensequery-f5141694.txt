# useSuspenseQuery
# джерело: https://github.com/TanStack/query/blob/v5.76.2/docs/framework/react/reference/useSuspenseQuery.md
# отримано: 2026-09-26
# версія: 5.76.2, 5.76.1, 5.76.0, 5.75.8, 5.75.7, 5.75.6, 5.75.5, 5.75.4, 5.75.3, 5.75.2, 5.75.1, 5.75.0, 5.74.11, 5.74.10, 5.74.9, 5.74.8, 5.74.7, 5.74.6, 5.74.5, 5.74.4, 5.74.3, 5.74.2, 5.74.1, 5.74.0

```tsx
const result = useSuspenseQuery(options)
```

**Options**

The same as for useQuery, except for:

- `throwOnError`
- `enabled`
- `placeholderData`

**Returns**

Same object as useQuery, except that:

- `data` is guaranteed to be defined
- `isPlaceholderData` is missing
- `status` is either `success` or `error`
  - the derived flags are set accordingly.

**Caveat**

Cancellation does not work.
