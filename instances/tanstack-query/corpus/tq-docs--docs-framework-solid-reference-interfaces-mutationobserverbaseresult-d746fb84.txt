# MutationObserverBaseResult
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.3/docs/framework/solid/reference/interfaces/MutationObserverBaseResult.md
# отримано: 2026-09-26
# версія: 5.103.3

Defined in: packages/query-core/src/types.ts:1449

The raw state stored on a `Mutation` instance. This is the underlying state
that observer results (e.g. `MutationObserverResult`) are derived from.

## Extends

- `MutationState`\<`TData`, `TError`, `TVariables`, `TOnMutateResult`\>

## Extended by

- `MutationObserverIdleResult`
- `MutationObserverLoadingResult`
- `MutationObserverErrorResult`
- `MutationObserverSuccessResult`
