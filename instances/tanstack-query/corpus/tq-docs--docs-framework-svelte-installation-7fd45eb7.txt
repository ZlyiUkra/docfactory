# Installation
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.90.12/docs/framework/svelte/installation.md
# отримано: 2026-09-26
# версія: 5.90.12, 5.90.11, 5.90.10, 5.90.9, 5.90.8, 5.90.7, 5.90.6, 5.90.5, 5.90.4

You can install Svelte Query via NPM.

### NPM

```bash
npm i @tanstack/svelte-query
```

or

```bash
pnpm add @tanstack/svelte-query
```

or

```bash
yarn add @tanstack/svelte-query
```

or

```bash
bun add @tanstack/svelte-query
```

> Wanna give it a spin before you download? Try out the basic example!
