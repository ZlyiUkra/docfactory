# setQueryClientContext
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.1/docs/framework/svelte/reference/functions/setQueryClientContext.md
# отримано: 2026-09-26
# версія: 5.103.1, 5.103.0

```ts
function setQueryClientContext(client): void;
```

Defined in: packages/svelte-query/src/context.ts:45

Sets a `QueryClient` on Svelte's context, so it can be read with getQueryClientContext (or
useQueryClient) from any descendant component. `QueryClientProvider` wraps this — use it directly
only if you need to set the client from your own component instead.

## Parameters

### client

`QueryClient`

The `QueryClient` to make available to descendant components.

## Returns

`void`

## Example

```svelte
<script lang="ts">
  import { QueryClient, QueryClientProvider } from '@tanstack/svelte-query'

  const queryClient = new QueryClient()
</script>

<QueryClientProvider client={queryClient}>
  ...
</QueryClientProvider>
```
