# MutationFilters
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.3/docs/framework/svelte/reference/interfaces/MutationFilters.md
# отримано: 2026-09-26
# версія: 5.103.3, 5.103.2

Defined in: packages/query-core/src/utils.ts:64

Filters used to select mutations, for example in `mutationCache.findAll` or `queryClient.isMutating`.
All provided filters must match; filters that are left unspecified are ignored.
