# InfiniteData
# джерело: https://github.com/TanStack/query/blob/@tanstack%2Fquery-core@5.103.3/docs/framework/vue/reference/interfaces/InfiniteData.md
# отримано: 2026-09-26
# версія: 5.103.3

Defined in: packages/query-core/src/types.ts:249

The data shape of an infinite query: every page fetched so far, plus the page param each one was fetched with.
`pages` and `pageParams` are index-aligned — `pageParams[i]` is the param that produced `pages[i]`.
