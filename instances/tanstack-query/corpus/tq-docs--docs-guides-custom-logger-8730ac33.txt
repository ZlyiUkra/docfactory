# Custom Logger
# джерело: https://github.com/TanStack/query/blob/v4.0.4/docs/guides/custom-logger.md
# отримано: 2026-09-26
# версія: 4.0.4, 4.0.3, 4.0.2, 4.0.1, 4.0.0

If you want to change how information is logged by React Query, you can set a custom logger when creating a `QueryClient`.

```js
const queryClient = new QueryClient({
  logger: {
    log: (...args) => {
      // Log debugging information
    },
    warn: (...args) => {
      // Log warning
    },
    error: (...args) => {
      // Log error
    },
  },
})
```
