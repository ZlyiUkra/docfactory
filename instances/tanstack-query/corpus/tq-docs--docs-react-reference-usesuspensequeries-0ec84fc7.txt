# useSuspenseQueries
# джерело: https://github.com/TanStack/query/blob/v5.17.2/docs/react/reference/useSuspenseQueries.md
# отримано: 2026-09-26
# версія: 5.17.2, 5.17.1, 5.17.0, 5.16.1, 5.16.0, 5.15.5, 5.15.4, 5.15.3, 5.15.2

```tsx
const result = useSuspenseQueries(options)
```

**Options**

The same as for useQueries, except that each `query` can't have:

- `suspense`
- `throwOnError`
- `enabled`
- `placeholderData`

**Returns**

Same structure as useQueries, except that for each `query`:

- `data` is guaranteed to be defined
- `isPlaceholderData` is missing
- `status` is always `success`
  - the derived flags are set accordingly.
