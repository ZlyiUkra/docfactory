# useQueryClient
# джерело: https://github.com/TanStack/query/blob/v4.0.4/docs/reference/useQueryClient.md
# отримано: 2026-09-26
# версія: 4.0.4, 4.0.3, 4.0.2, 4.0.1, 4.0.0

The `useQueryClient` hook returns the current `QueryClient` instance.

```js
import { useQueryClient } from '@tanstack/react-query'

const queryClient = useQueryClient()
```
