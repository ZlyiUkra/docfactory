# hydration/Hydrate
# джерело: https://github.com/TanStack/query/blob/v3.1.2-beta.1/docs/src/pages/reference/hydration/HydrateComp.md
# отримано: 2026-09-26
# версія: 3.1.2-beta.1, 3.1.1, 3.1.0, 3.0.1, 3.0.0, 2.25.0

`hydration/Hydrate` adds a previously dehydrated state into the `cache` that would returned by running `useQueryCache`. If the cache already contains data, the new queries will be intelligently merged based on update timestamp.

```js
import { Hydrate } from 'react-query/hydration'

function App() {
  return <Hydrate state={dehydratedState}>...</Hydrate>
}
```

**Options**

- `state: DehydratedState`
  - The state to hydrate
- `options: HydrateOptions`
  - Optional
  - `defaultOptions: QueryOptions`
    - The default query options to use for the hydrated queries.
