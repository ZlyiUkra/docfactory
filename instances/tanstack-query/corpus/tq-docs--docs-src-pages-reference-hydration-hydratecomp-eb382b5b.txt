# hydration/Hydrate
# джерело: https://github.com/TanStack/query/blob/v3.23.2/docs/src/pages/reference/hydration/HydrateComp.md
# отримано: 2026-09-26
# версія: 3.23.2, 3.23.1, 3.23.0, 3.22.0, 3.21.1, 3.21.0, 3.20.0, 3.19.6, 3.19.5, 3.19.4, 3.19.3, 3.19.2, 3.19.1, 3.19.0, 3.18.1, 3.18.0, 3.17.3, 3.17.2, 3.17.1, 3.17.0, 3.16.1

`hydration/Hydrate` adds a previously dehydrated state into the `queryClient` that would be returned by `useQueryClient()`. If the client already contains data, the new queries will be intelligently merged based on update timestamp.

```js
import { Hydrate } from 'react-query/hydration'

function App() {
  return <Hydrate state={dehydratedState}>...</Hydrate>
}
```

**Options**

- `state: DehydratedState`
  - The state to hydrate
- `options: HydrateOptions`
  - Optional
  - `defaultOptions: QueryOptions`
    - The default query options to use for the hydrated queries.
