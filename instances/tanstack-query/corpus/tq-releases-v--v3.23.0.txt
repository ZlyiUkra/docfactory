## 3.23.0 (2021-09-08)

### Features

* Allow handling some errors locally while using error boundaries (#2619) (ee7ca0b)

Please note that prior to this release, if you've set `useErrorBoundary: false` _and_ `suspense: true`, you would still get all errors in an ErrorBoundary, because `suspense` would _always_ throw errors to ErrorBoundaries.

This was fixed with #2619, and the `useErrorBoundary` flag is now also respected if `suspense` is enabled.
