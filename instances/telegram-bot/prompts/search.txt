Search the Telegram Bot API documentation of core.telegram.org. The corpus holds the whole bots section of the site as a
snapshot of 09.11.2026: the Bot API reference (the HTTP interface bots use at api.telegram.org) with one page per method
and per type, the formatting options (MarkdownV2, HTML, message entities), the rich messages, the Bot API changelog of
every version, and the guides for bots: BotFather, commands, keyboards, inline mode, privacy mode, webhooks, Mini Apps
and the `Telegram.WebApp` client API, payments and Telegram Stars, games, the FAQ on limits and updates, the tutorial,
Serverless, the sample bots; and the README of the self-hosted Bot API server.

Use this tool for: which Bot API method does something and what its parameters, limits and return type are
(`sendMessage`, `getUpdates`, `setWebhook`, `editMessageText`, `answerCallbackQuery`, `sendPhoto`); what a type holds
(`Update`, `Message`, `CallbackQuery`, `InlineKeyboardMarkup`); how long polling and webhooks differ and how offsets
work; how to format text; what rate limits apply; since which Bot API version a field exists. Write the query
in English with the method, type or field name, or with plain words for what is wanted.

Do not use this tool for the Telegram API that full clients use on behalf of a user (MTProto, TDLib), nor for
third-party bot libraries (python-telegram-bot, aiogram, Telegraf, grammY): their documentation is not here. Returns
the matching excerpts with the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
