Return the full text of one excerpt of the Tesseract OCR documentation by its identifier, together with the page
or file it belongs to, every version whose documents contain this text, the URL it was taken from and the date
the text was fetched -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt came back cut (`truncated: true`), or when the exact wording
matters: a command-line option and its values (--psm, --oem, -l, -c), a configuration variable and its default,
a training tool and its flags, a method of TessBaseAPI or the C API, an OCRmyPDF option or Python API argument,
a tesseract.js worker method, a pytesseract or tesserocr function, a ChangeLog entry, a release note, a version
table from npm or PyPI.

Do not guess identifiers: they are not URLs and cannot be assembled by hand. Every identifier this tool
accepts comes from the `id` field of a `search_docs` result.

The text comes back in English. Answer the user in their own language and follow the rules of
`search_docs`: names stay in English, name the component (Tesseract, OCRmyPDF, tesseract.js, pytesseract,
tesserocr, node-tesseract-ocr), the version and the page you read.
