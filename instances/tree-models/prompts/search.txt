Search books and papers about tree-based machine learning. The corpus holds chapters of books: Greenwell, Tree-Based Methods for
Statistical Learning in R; Zhou, Ensemble Methods (2nd ed.); Breiman, Friedman, Olshen, Stone, Classification and Regression Trees;
Rokach and Maimon, Data Mining with Decision Trees; Genuer and Poggi, Random Forests with R; Louppe, Understanding Random Forests;
Kuhn and Johnson, Applied Predictive Modeling and Feature Engineering and Selection; Boehmke and Greenwell, Hands-On Machine Learning
with R; Molnar, Interpretable Machine Learning; Géron, Hands-On Machine Learning (2nd ed.); López de Prado, Advances in Financial
Machine Learning; Jansen, Machine Learning for Algorithmic Trading (both editions). It also holds papers: Breiman's Random Forests,
Extremely Randomized Trees, the random forest guided tour of Biau and Scornet, hyperparameter tuning of Probst et al., ranger,
Hummingbird, XGBoost, CatBoost, Grinsztajn et al. on tabular data, Strobl et al. on biased variable importance, TreeSHAP, quantile
regression forests, generalized random forests; and the decision tree and ensemble pages of the scikit-learn User Guide.

Use this tool for: how a split is chosen and why trees overfit; how bagging, random forests, extra trees and boosting reduce error;
which hyperparameters matter (number of trees, mtry, node size, depth, learning rate) and how to tune them; how training and
prediction time grow and how to make them faster; how to measure and explain feature importance without bias; out-of-bag error,
cross-validation and leakage in financial time series; prediction intervals with quantile forests; when trees beat neural networks.
Write the query in English with the name of the method or with plain words for what is wanted.

Do not use this tool for the API of XGBoost, LightGBM, scikit-learn classes or NumPy: other servers hold those references. Returns
the matching excerpts with the source address and the fetch date.

Every excerpt carries an `id`; pass the `id` of an excerpt to `read_section` to get the whole thing.

The `search` field of the result says how the excerpts were found: "words" means the words of the query had to appear
in the text, so a query phrased in other words than the documentation uses may miss; "meaning+words" means a second,
meaning-based index answered as well, and a paraphrase had a chance.
