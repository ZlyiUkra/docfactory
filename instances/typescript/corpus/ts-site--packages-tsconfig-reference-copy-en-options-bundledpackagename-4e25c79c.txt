# джерело: https://github.com/microsoft/TypeScript-Website/blob/fa2c64eb0c0f71e1c007468a9951b1258a403bfc/packages/tsconfig-reference/copy/en/options/bundledPackageName.md
# отримано: 2026-09-29
# версія: 4.0.5

When you mix `declaration` and `outFile` the resulting .d.ts needs to know what the root name of the module is so that paths can be correctly resolved internally.

For example, this project:

```ts
// @filename: projectRoot/index.ts
export * from "./nested/base";

// @filename: projectRoot/nested/base.ts
export const a = "123";
```

With the following `tsconfig.json`:

```json
{
  "compilerOptions": {
    "outFile": "index.js",
    "declaration": true,
    "module": "amd",
    "bundledPackageName": "hello"
  }
}
```

Would create this `index.d.ts` where the internal modules resolve according to the name from `bundledPackageName`:

```ts
// @filename: projectRoot/index.ts
export * from "./nested/base";

// @filename: projectRoot/nested/base.ts
export const a = "123";
// @bundledPackageName: hello
// @module: amd
// @outfile: index.js
// @declaration: true
// @showEmit
// @showEmittedFile: index.d.ts
```
