# джерело: https://github.com/microsoft/TypeScript-Website/blob/17a55eccd975d5d33790ec4b52f1f6e5e2ffca29/packages/tsconfig-reference/copy/en/options/disableSolutionSearching.md
# отримано: 2026-09-29
# версія: 4.0.3

When working with composite TypeScript projects, this option provides a way to declare that you do not want a project to be included when using features like _find all references_ or _jump to definition_ in an editor.

This flag is something you can use to increase responsiveness in large composite projects.
