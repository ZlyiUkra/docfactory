# джерело: https://github.com/microsoft/TypeScript-Website/blob/78d3b56c69ef1ee46453d291c09db4985b7e931e/packages/tsconfig-reference/copy/en/options/keyofStringsOnly.md
# отримано: 2026-09-29
# версія: 4.0.2

This flag changes the `keyof` type operator to return `string` instead of `string | number` when applied to a type with a string index signature.

This flag is used to help people keep this behavior from before TypeScript 2.9's release.
