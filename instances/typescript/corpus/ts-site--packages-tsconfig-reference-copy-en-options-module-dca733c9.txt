# джерело: https://github.com/microsoft/TypeScript-Website/blob/fa2c64eb0c0f71e1c007468a9951b1258a403bfc/packages/tsconfig-reference/copy/en/options/module.md
# отримано: 2026-09-29
# версія: 4.0.5

Sets the module system for the program. See the Modules reference page for more information. You very likely want `"CommonJS"`.

Changing `module` affects `moduleResolution` which also has a reference page.

Here's some example output for this file:

```ts
// @filename: constants.ts
export const valueOfPi = 3.142;
// ---cut---
// @filename: index.ts
import { valueOfPi } from "./constants";

export const twoPi = valueOfPi * 2;
```

#### `CommonJS`

```ts
// @showEmit
// @module: commonjs
// @filename: constants.ts
export const valueOfPi = 3.142;
// ---cut---
// @filename: index.ts
import { valueOfPi } from "./constants";

export const twoPi = valueOfPi * 2;
```
