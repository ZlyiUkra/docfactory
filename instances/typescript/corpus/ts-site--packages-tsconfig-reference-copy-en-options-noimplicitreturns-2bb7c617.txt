# джерело: https://github.com/microsoft/TypeScript-Website/blob/78d3b56c69ef1ee46453d291c09db4985b7e931e/packages/tsconfig-reference/copy/en/options/noImplicitReturns.md
# отримано: 2026-09-29
# версія: 4.0.2

When enabled, TypeScript will check all code paths in a function to ensure they return a value.

```ts
// @errors: 2366 2322
function lookupHeadphonesManufacturer(color: "blue" | "black"): string {
  if (color === "blue") {
    return "beats";
  } else {
    "bose";
  }
}
```
