# отримано: 2026-09-29
# версія: 4.0.3

When enabled, TypeScript will check all code paths in a function to ensure they return a value.

```ts
// @errors: 2366 2322
function lookupHeadphonesManufacturer(color: "blue" | "black"): string {
  if (color === "blue") {
    return "beats";
  } else {
    "bose";
  }
}
```
