# tsconfig-reference/copy/en/options/preserveValueImports
# джерело: https://github.com/microsoft/TypeScript-Website/blob/62f87a80f571762ff252eb38b53b890f9f864acb/packages/tsconfig-reference/copy/en/options/preserveValueImports.md
# отримано: 2026-09-29
# версія: 5.0.3

Deprecated in favor of `verbatimModuleSyntax`.

There are some cases where TypeScript can't detect that you're using an import. For example, take the following code:

```ts
import { Animal } from "./animal.js";

eval("console.log(new Animal().isDangerous())");
```

or code using 'Compiles to HTML' languages like Svelte or Vue. `preserveValueImports` will prevent TypeScript from removing the import, even if it appears unused.

When combined with `isolatedModules`: imported types _must_ be marked as type-only because compilers that process single files at a time have no way of knowing whether imports are values that appear unused, or a type that must be removed in order to avoid a runtime crash.
