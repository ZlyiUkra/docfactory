# tsconfig-reference/copy/en/options/strictPropertyInitialization
# джерело: https://github.com/microsoft/TypeScript-Website/blob/78d3b56c69ef1ee46453d291c09db4985b7e931e/packages/tsconfig-reference/copy/en/options/strictPropertyInitialization.md
# отримано: 2026-09-29
# версія: 4.0.2

When set to true, TypeScript will raise an error when a class property was declared but not set in the constructor.

```ts
// @errors: 2564
class UserAccount {
  name: string;
  accountType = "user";

  email: string;
  address: string | undefined;

  constructor(name: string) {
    this.name = name;
    // Note that this.email is not set
  }
}
```

In the above case:

- `this.name` is set specifically.
- `this.accountType` is set by default.
- `this.email` is not set and raises an error.
- `this.address` is declared as potentially `undefined` which means it does not have to be set.
