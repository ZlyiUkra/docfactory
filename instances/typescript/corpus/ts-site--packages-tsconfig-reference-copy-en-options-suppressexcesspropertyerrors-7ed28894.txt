# tsconfig-reference/copy/en/options/suppressExcessPropertyErrors
# джерело: https://github.com/microsoft/TypeScript-Website/blob/17a55eccd975d5d33790ec4b52f1f6e5e2ffca29/packages/tsconfig-reference/copy/en/options/suppressExcessPropertyErrors.md
# отримано: 2026-09-29
# версія: 4.0.3

This disables reporting of excess property errors, such as the one shown in the following example:

```ts
// @errors: 2322
type Point = { x: number; y: number };
const p: Point = { x: 1, y: 3, m: 10 };
```

This flag was added to help people migrate to the stricter checking of new object literals in TypeScript 1.6.

We don't recommend using this flag in a modern codebase, you can suppress one-off cases where you need it using `// @ts-ignore`.
