# tsconfig-reference/copy/en/options/suppressImplicitAnyIndexErrors
# джерело: https://github.com/microsoft/TypeScript-Website/blob/17a55eccd975d5d33790ec4b52f1f6e5e2ffca29/packages/tsconfig-reference/copy/en/options/suppressImplicitAnyIndexErrors.md
# отримано: 2026-09-29
# версія: 4.0.3

Turning `suppressImplicitAnyIndexErrors` on suppresses reporting the error about implicit anys when indexing into objects, as shown in the following example:

```ts
// @noImplicitAny: true
// @suppressImplicitAnyIndexErrors: false
// @strict: true
// @errors: 7053
const obj = { x: 10 };
console.log(obj["foo"]);
```

Using `suppressImplicitAnyIndexErrors` is quite a drastic approach. It is recommended to use a `@ts-ignore` comment instead:

```ts
// @noImplicitAny: true
// @strict: true
const obj = { x: 10 };
// @ts-ignore
console.log(obj["foo"]);
```
