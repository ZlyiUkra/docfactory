Tag v0.0.5, published 2026-09-07.

`Bucket.fromEnv` now accepts options directly while preserving the existing environment-variable-name form.

```ts
Bucket.fromEnv({ cache: "immutable" })
Bucket.fromEnv(undefined, { cache: "immutable" })
Bucket.fromEnv("MEDIA_TOKEN", { cache: "immutable" })
```

Exports the `FromEnvOptions` type. Includes regression coverage for optional environment names and option forwarding.

PR: https://github.com/upstash/blob-js/pull/3
