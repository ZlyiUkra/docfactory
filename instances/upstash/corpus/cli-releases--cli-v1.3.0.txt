Tag v1.3.0, published 2026-09-07.

Adds Blob bucket management to the Upstash CLI.

- Create, list, inspect, and delete Blob buckets with `upstash blob`.
- Obtain temporary S3 credentials using a bucket ID or `UPSTASH_BLOB_TOKEN`.
- Retry credential requests and deletion while a newly created bucket finishes provisioning.

Install or upgrade:

```sh
npm install -g @upstash/cli@1.3.0
upstash blob --help
```
