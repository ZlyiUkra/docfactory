# Library Access
# джерело: https://github.com/upstash/context7/blob/v1.0.29/docs/dashboard/libraries.mdx
# отримано: 2026-10-16
# версія: context7-mcp-1.0.29, context7-mcp-1.0.28

Control which public libraries your team can access and configure maximum token limits for API requests from the libraries tab.

## Public Library Access

Configure which public libraries your team can access:

**All Sources** (Default): Access to all public libraries, including future additions

**Select Specific**: Choose individual libraries or organizations

**Disable Public**: Private repos only (requires at least one private repo)

Only owners and admins can change these settings.

## Token Limits

Set the maximum tokens per API request (**1,000 to 100,000**) to control the amount of documentation retrieved in each response. This helps prevent overwhelming the context window of LLMs with excessive documentation.

Note:

  For private repositories, see the Private Repositories page.
