The default action is `copy`.

## Usage

```mdx
<Prompt description="Copy this prompt" actions={["copy", "cursor"]}>
  Explain this API in one paragraph.
</Prompt>
```

Set `actions={[]}` to hide the actions. `icon` and `iconType` are optional.
