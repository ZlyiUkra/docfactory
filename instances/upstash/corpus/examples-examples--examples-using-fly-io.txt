Fly Example with Redis

    Explore the seamless integration of Redis in Fly applications with this example project, harnessing the power of distributed caching and efficient data storage.

This is a simple application used in the fly.io Getting Started documentation showing how to deploy a Node application using Flyctl's builtin Nodejs deployment option.

- Run flyctl init
- When prompted for a builder, select builtin Nodejs.
- Run flyctl deploy

## server.js

```js
const express = require("express");
const app = express();
const port = process.env.PORT || 3000;
const { Redis } = require("@upstash/redis");

const redis = new Redis({
  url: "REPLACE_HERE",
  token: "REPLACE_HERE",
});

app.get(["/", "/:name"], async (req, res) => {
  const greeting = "<h1>Hello From Node on Fly!</h1>";
  if (req.url !== "/favicon.ico") {
    const data = await redis.incr("count");
    res.send(`${greeting}</br> Counter: ${data}`);
  } else {
    res.send("");
  }
});

app.listen(port, () => console.log(`HelloNode app listening on port ${port}!`));
```
