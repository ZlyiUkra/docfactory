## What's Changed

In this version, we remove Llama Processor since it was causing issues for us. Therefore, we release a major version since the removal of llama-parse processor is not backwards compatible.

* Add organization parameter by @CahidArda in https://github.com/upstash/rag-chat/pull/80
* Update Exports & Add CI Tests by @ytkimirti in https://github.com/upstash/rag-chat/pull/79
* Remove llama processor by @CahidArda in https://github.com/upstash/rag-chat/pull/83

**Full Changelog**: https://github.com/upstash/rag-chat/compare/v1.6.4...v2.0.0

### Migration

Most of the API is unchanged. You should only have to make changes If you were using the llama-parse processor:

```ts
await ragChat.add({
  type: "...",
  fileSource: "...",
  // llama parse
  processor: {
    name: "llama-parse",
    options: ...
  }
})
```

If you were using llama-parse, you can opt to use the unstructured processsor.
