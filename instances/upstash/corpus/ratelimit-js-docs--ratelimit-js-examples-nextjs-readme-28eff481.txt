This example shows how to use Tailwind CSS
(v3.0) with Next.js. It follows
the steps outlined in the official
Tailwind docs.

## How to use

Execute
`create-next-app`
with npm or
Yarn to bootstrap the example:

```bash
yarn create next-app -e https://github.com/upstash/next-template your-app-name
```
