# Redis Search Aggregation SDK Examples
# джерело: https://github.com/upstash/redis-analytics/blob/a7e0afc8a694dad44777c4172e14d955d5e8f640/docs/redis-search-aggregate.md
# отримано: 2026-10-16

This document provides examples of using the Redis Search aggregation API with the Upstash Redis SDK.

## Setup

First, create an index with a schema:

```typescript
import { Redis } from "@upstash/redis";
import { createIndex, s } from "@upstash/redis/search";

const redis = new Redis({ url: "...", token: "..." });

const schema = s.object({
  title: s.string(),
  category: s.string().noTokenize(),
  categoryId: s.number(),
  price: s.number(),
  quantity: s.number(),
});

const index = await createIndex(redis, {
  name: "products-idx",
  schema,
  dataType: "json",
  prefix: "product:",
});
```

## 1. Basic Aggregation (`$stats`)

Calculates statistics (count, min, max, sum, average) for the `price` field for all documents matching the query.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    s: { $stats: { field: "price" } },
  },
});
```

**Result:**

```typescript
{
  s: {
    count: 9,
    min: 0,
    max: 80,
    sum: 360,
    avg: 40
  }
}
```

## 2. Terms Aggregation (`$terms`)

Groups documents by the `categoryId` field and counts the number of documents in each category.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    by_cat: { $terms: { field: "categoryId" } },
  },
});
```

**Result:**

```typescript
{
  by_cat: {
    buckets: [
      { key: 0, docCount: 3 }, // electronics
      { key: 1, docCount: 3 }, // clothing
      { key: 2, docCount: 3 }, // books
    ];
  }
}
```

## 5. Nested Aggregations

First groups by `categoryId` and then calculates the average price within each category.

**SDK Usage:**

```typescript

## 7. Aggregation with Search Results (`limit`)

The `limit` parameter includes search hits in the response alongside the aggregation results.

**SDK Usage:**

```typescript
const [aggResult, searchResults] = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    s: { $stats: { field: "price" } },
  },
  limit: 3,
});
```

**Result:**

When using `limit`, the result is a tuple with aggregation results and search hits:

```typescript
// aggResult
{
  s: {
    count: 9,
    min: 0,
    max: 80,
    sum: 360,
    avg: 40
  }
}

// searchResults
[
  { key: "product:doc:0", score: 1.0, /* document fields */ },
  { key: "product:doc:1", score: 1.0, /* document fields */ },
  { key: "product:doc:2", score: 1.0, /* document fields */ }
]
```

## 8. Nested Aggregations with Multiple Metrics

Combine grouping with multiple metric aggregations.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    by_cat: {
      $terms: { field: "categoryId" },
      $aggs: {
        avg_price: { $avg: { field: "price" } },
        min_price: { $min: { field: "price" } },
        max_price: { $max: { field: "price" } },
        sum_qty: { $sum: { field: "quantity" } },
      },
    },
  },
});
```

**Result:**

```typescript
{
  by_cat: {
    buckets: [
      {
        key: 0,
        docCount: 3,
        avg_price: { value: 30 },
        min_price: { value: 0 },
        max_price: { value: 60 },
        sum_qty: { value: 9 },
      },
      // ... more buckets
    ];
  }
}
```

## 9. Range Aggregation with Nested Stats

Combine range bucketing with nested statistics.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    price_ranges: {
      $range: {
        field: "price",
        ranges: [{ to: 30 }, { from: 30, to: 60 }, { from: 60 }],
      },
      $aggs: {
        qty_stats: { $stats: { field: "quantity" } },
      },
    },
  },
});
```

**Result:**

```typescript
{
  price_ranges: {
    buckets: [
      {
        key: "*-30",
        docCount: 3,
        to: 30,
        qty_stats: { count: 3, min: 0, max: 2, sum: 3, avg: 1 },
      },
      // ... more buckets
    ];
  }
}
```

## 10. Metric Aggregations

Individual metric aggregations without bucketing.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    avg_price: { $avg: { field: "price" } },
    sum_price: { $sum: { field: "price" } },
    min_price: { $min: { field: "price" } },
    max_price: { $max: { field: "price" } },
    count_price: { $count: { field: "price" } },
    unique_categories: { $cardinality: { field: "categoryId" } },
  },
});
```

**Result:**

```typescript
{
  avg_price: { value: 40 },
  sum_price: { value: 360 },
  min_price: { value: 0 },
  max_price: { value: 80 },
  count_price: { value: 9 },
  unique_categories: { value: 3 }
}
```

## 11. Extended Statistics

Get detailed statistics including variance and standard deviation.

**SDK Usage:**

```typescript
const result = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    es: { $extendedStats: { field: "price", sigma: 2 } },

});
```

**Result:**

## 12. Percentiles

Calculate percentiles for a field.

**SDK Usage:**

```typescript
// Keyed format (default)
const result1 = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    p: { $percentiles: { field: "price", percents: [50, 95, 99] } },
  },
});

// Unkeyed format
const result2 = await index.aggregate({
  filter: { title: { $eq: "product" } },
  aggregations: {
    p: { $percentiles: { field: "price", percents: [50, 95], keyed: false } },
  },
});
```

**Results:**

```typescript
// Keyed format
{
  p: {
    values: {
      "50.0": 40,
      "95.0": 76,
      "99.0": 79.2
    }
  }
}

// Unkeyed format
{
  p: {
    values: [
      { key: 50, value: 40 },
      { key: 95, value: 76 }
    ]
  }
}
```
