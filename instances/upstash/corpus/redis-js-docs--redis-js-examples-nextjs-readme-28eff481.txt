# Next.js + Tailwind CSS Example
# джерело: https://github.com/upstash/redis-js/blob/v1.5.0/examples/nextjs/README.md
# отримано: 2026-10-16
# версія: redis-1.5.0, redis-1.4.0

This example shows how to use Tailwind CSS
(v3.0) with Next.js. It follows
the steps outlined in the official
Tailwind docs.

## How to use

Execute
`create-next-app`
with npm or
Yarn to bootstrap the example:

```bash
yarn create next-app -e https://github.com/upstash/next-template your-app-name
```
