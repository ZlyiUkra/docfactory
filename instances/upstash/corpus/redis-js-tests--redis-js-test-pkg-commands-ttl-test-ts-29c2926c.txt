afterAll(cleanup);

## returns the ttl on a key

```ts
test("returns the ttl on a key", async () => {
  const key = newKey();
  const ttl = 60;
  await new SetExCommand([key, ttl, "value"]).exec(client);
  const res = await new TtlCommand([key]).exec(client);
  expect(res).toEqual(ttl);
});
```
