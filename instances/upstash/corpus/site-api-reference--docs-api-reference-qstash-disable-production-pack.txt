# Developer API: Disable Production Pack
# джерело: https://upstash.com/docs/api-reference/qstash/disable-production-pack
# отримано: 2026-10-16

> Disables the production pack for a QStash instance.

`POST /qstash/disable-prodpack/{id}`

## Request

`POST https://api.upstash.com/v2/qstash/disable-prodpack/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  QStash user ID

## Response

**200** — Production pack disabled successfully

Example:

```json
"OK"
```
