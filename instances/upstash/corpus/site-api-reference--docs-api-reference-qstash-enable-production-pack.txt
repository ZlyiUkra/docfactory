# Developer API: Enable Production Pack
# джерело: https://upstash.com/docs/api-reference/qstash/enable-production-pack
# отримано: 2026-10-16

> Enables the production pack for a QStash instance.

`POST /qstash/enable-prodpack/{id}`

## Request

`POST https://api.upstash.com/v2/qstash/enable-prodpack/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  QStash user ID

## Response

**200** — Production pack enabled successfully

Example:

```json
"OK"
```
