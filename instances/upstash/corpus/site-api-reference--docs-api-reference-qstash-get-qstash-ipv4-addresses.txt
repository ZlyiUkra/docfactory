# Developer API: Get QStash IPv4 Addresses
# джерело: https://upstash.com/docs/api-reference/qstash/get-qstash-ipv4-addresses
# отримано: 2026-10-16

> Returns the list of IPv4 addresses used by QStash for sending requests.

`GET /qstash/ipv4`

## Request

`GET https://api.upstash.com/v2/qstash/ipv4`

Authentication: not stated.

## Response

**200** — List of IPv4 CIDR blocks

Example:

```json
[
  "3.125.136.186/32",
  "18.198.95.233/32"
]
```
