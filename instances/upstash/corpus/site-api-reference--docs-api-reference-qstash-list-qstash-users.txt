# Developer API: List QStash Users
# джерело: https://upstash.com/docs/api-reference/qstash/list-qstash-users
# отримано: 2026-10-16

> Retrieves a list of all QStash users associated with the account, including plan details, limits, and configuration.

`GET /qstash/users`

## Request

`GET https://api.upstash.com/v2/qstash/users`

Authentication: `basicAuth` headers.

## Response

**200** — Successful response
