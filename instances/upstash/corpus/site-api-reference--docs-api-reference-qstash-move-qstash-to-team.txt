# Developer API: Move QStash to Team
# джерело: https://upstash.com/docs/api-reference/qstash/move-qstash-to-team
# отримано: 2026-10-16

> Moves a QStash instance to a different team.

`POST /qstash/move-to-team`

## Request

`POST https://api.upstash.com/v2/qstash/move-to-team`

Authentication: `basicAuth` headers.

**Request body** (`application/json`)

- `qstash_id` (string, required)
  ID of the QStash instance to move

- `target_team_id` (string, required)
  ID of the target team

## Response

**200** — QStash moved successfully

Example:

```json
"OK"
```
