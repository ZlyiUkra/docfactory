# Developer API: Set QStash Plan
# джерело: https://upstash.com/docs/api-reference/qstash/set-qstash-plan
# отримано: 2026-10-16

> Changes the QStash account to a different plan type.
This operation changes the plan and associated limits for the QStash account.

`POST /qstash/set-plan/{id}`

## Request

`POST https://api.upstash.com/v2/qstash/set-plan/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  QStash user ID

**Request body** (`application/json`)

- `plan_name` (string, required)
  Target plan to upgrade to
  One of: `paid`, `qstash_fixed_1m`, `qstash_fixed_10m`, `qstash_fixed_100m`
  Example: `paid`

## Response

**200** — QStash plan changed successfully

Example:

```json
"OK"
```
