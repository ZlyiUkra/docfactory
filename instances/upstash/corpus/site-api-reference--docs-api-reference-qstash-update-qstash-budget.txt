# Developer API: Update QStash Budget
# джерело: https://upstash.com/docs/api-reference/qstash/update-qstash-budget
# отримано: 2026-10-16

> Updates the monthly spending budget limit for a QStash instance.

`PATCH /qstash/update-budget/{id}`

## Request

`PATCH https://api.upstash.com/v2/qstash/update-budget/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  QStash user ID

**Request body** (`application/json`)

- `budget` (integer, required)
  Monthly spending budget limit in dollars. Minimum 20, maximum 10000, or 0 for no limit.
  Minimum: `0`
  Maximum: `10000`
  Example: `100`

## Response

**200** — Budget updated successfully

Example:

```json
"OK"
```
