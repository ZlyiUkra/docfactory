# Developer API: Delete Search Index
# джерело: https://upstash.com/docs/api-reference/search/delete-search-index
# отримано: 2026-10-16

> Permanently deletes a search index and all its data

`DELETE /search/{id}`

## Request

`DELETE https://api.upstash.com/v2/search/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the search index to be deleted

## Response

**200** — Search Index Deleted Successfully

Example:

```json
"OK"
```
