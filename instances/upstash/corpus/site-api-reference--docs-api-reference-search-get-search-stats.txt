# Developer API: Get Search Stats
# джерело: https://upstash.com/docs/api-reference/search/get-search-stats
# отримано: 2026-10-16

> Get search statistics for all the search indices associated with the authenticated user

`GET /search/stats`

## Request

`GET https://api.upstash.com/v2/search/stats`

Authentication: `basicAuth` headers.

## Response

**200** — Statistics for the search indices retrieved successfully

- `record_count` (integer)
  Total number of indexed records across all indexes
  Example: `10`

- `request` (integer)
  Total API requests count across all indexes
  Example: `10`

- `bandwidth` (integer)
  Total bandwidth usage in bytes across all indexes
  Example: `750`

- `storage` (integer)
  Total storage usage in bytes across all indexes
  Example: `950`

- `billing` (number, float)
  Current billing amount across all indexes
  Example: `0.001`

- `rerank_count` (integer)
  Total reranking operations count across all indexes
  Example: `0`
