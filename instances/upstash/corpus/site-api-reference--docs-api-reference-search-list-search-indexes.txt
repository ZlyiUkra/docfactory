# Developer API: List Search Indexes
# джерело: https://upstash.com/docs/api-reference/search/list-search-indexes
# отримано: 2026-10-16

> Returns a list of all search indices belonging to the authenticated user.

`GET /search`

## Request

`GET https://api.upstash.com/v2/search`

Authentication: `basicAuth` headers.

## Response

**200** — Successfully retrieved list of search indices.
