# Developer API: Rename Search Index
# джерело: https://upstash.com/docs/api-reference/search/rename-search-index
# отримано: 2026-10-16

> Renames a search index.

`POST /search/{id}/rename`

## Request

`POST https://api.upstash.com/v2/search/{id}/rename`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the search index

**Request body** (`application/json`)

- `name` (string, required)
  New name for the index
  Example: `new-index-name`

## Response

**200** — Search index renamed successfully

Example:

```json
"OK"
```
