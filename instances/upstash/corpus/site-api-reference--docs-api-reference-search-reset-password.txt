# Developer API: Reset Password
# джерело: https://upstash.com/docs/api-reference/search/reset-password
# отримано: 2026-10-16

> This endpoint resets the regular and readonly tokens of a search index.

`POST /search/{id}/reset-password`

## Request

`POST https://api.upstash.com/v2/search/{id}/reset-password`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the search index

## Response

**200** — Search index passwords reset successfully

Example:

```json
"OK"
```
