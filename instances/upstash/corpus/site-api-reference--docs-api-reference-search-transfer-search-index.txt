# Developer API: Transfer Search Index
# джерело: https://upstash.com/docs/api-reference/search/transfer-search-index
# отримано: 2026-10-16

> Transfers ownership of a search index to another team.
Transferring to a personal account is not supported.
However, transferring from a personal account to a team is allowed.

`POST /search/{id}/transfer`

## Request

`POST https://api.upstash.com/v2/search/{id}/transfer`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the search index

**Request body** (`application/json`)

- `target_account` (string, required)
  The ID of the target team account.
  Example: `99a4c327-31f0-490f-a594-043ade84085a`

## Response

**200** — Search index transferred successfully

Example:

```json
"OK"
```
