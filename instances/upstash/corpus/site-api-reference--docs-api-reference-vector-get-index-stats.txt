# Developer API: Get Index Stats
# джерело: https://upstash.com/docs/api-reference/vector/get-index-stats
# отримано: 2026-10-16

> Retrieves statistics and metrics for a specific vector index

`GET /vector/index/{id}/stats`

## Request

`GET https://api.upstash.com/v2/vector/index/{id}/stats`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the vector index

- `period` (query, string)
  Time period for statistics aggregation. Each period returns 60 datapoints
  with intervals adjusted to the period length.

  Exceptionally for 30 days, it returns 240 datapoints with 3-hour intervals for increased granularity.
  One of: `1h`, `3h`, `12h`, `1d`, `3d`, `7d`, `30d`
  Default: `1h`
  Example: `3h`

## Response

**200** — Statistics for the specified vector index retrieved successfully

- `pending_index_count` (integer)
  Number of pending index operations
  Example: `1`

- `current_vector_count` (integer)
  Current number of vectors in the index
  Example: `1000`

- `daily_query_count` (integer)
  Total number of query operations executed today
  Example: `100`

- `daily_update_count` (integer)
  Total number of update operations executed today
  Example: `10`

- `monthly_query_count` (integer)
  Total query operations in current month
  Example: `1000`

- `monthly_update_count` (integer)
  Total update operations in current month
  Example: `1000`

- `monthly_bandwidth_usage` (integer)
  Total bandwidth used in current month (bytes)

- `storage_usage` (integer)
  Current storage used (bytes)
  Example: `7000`

- `monthly_cost` (number, float)
  Total cost in current month
  Example: `0.5`
