# Upstash: AI Tools
# джерело: https://upstash.com/docs/agent-resources/overview
# отримано: 2026-10-16

> Connect your AI coding agent to Upstash.

Upstash ships Skills, a CLI, an MCP server, and llms.txt so your agent can build on and manage Redis, QStash, Workflow, Vector, Search, and Box. Set them all up with one command, or pick your agent for step-by-step instructions.

## Set up with one command

Run this in your terminal:

```bash
npx upstash
```

It detects Claude Code, Codex, Cursor, Gemini CLI, VS Code, GitHub Copilot CLI, and OpenCode, and lets you pick which to set up. Each one gets the Upstash MCP server and skills: as the Upstash plugin where the agent supports plugins, otherwise written into its config. The MCP server signs in with OAuth on first use. See the CLI page for flags.

## Set up by hand

Install the Upstash skill. It includes the `upstash` CLI reference, so this one step is enough for most workflows:

```bash
npx skills add upstash/skills
```

To let your agent read and change your account directly, add the MCP server. The **remote** server needs nothing installed — connect over HTTP and approve the OAuth consent on first use (shown here for Claude Code):

```bash
claude mcp add --scope user --transport http upstash https://mcp.upstash.com/mcp
```

Prefer a headless setup, or need Upstash Box tools? Run the local server with a Developer API key:

```bash
npx -y @upstash/mcp-server@latest --email YOUR_EMAIL --api-key YOUR_API_KEY
```

See the MCP server page for remote vs. local, authentication, and feature options.

Note:
Only working against a single Redis database? The lightweight Redis MCP needs just that database's REST URL and token, not an account API key.

## Building AI into your app?

The resources above are for agents that help you build. If you're building agents or AI features into your own product, start here:

**Agent memory & chat history**

Long-term memory, RAG, and chat history for the Vercel AI SDK and Eve, backed by Redis.

**Vector**

Embeddings and semantic search for RAG pipelines, with LangChain, LlamaIndex, and AI SDK integrations.

**Workflow Agents**

Durable multi-agent orchestration with retries and no timeouts. Works with AI SDK and LangChain tools.

**Box**

Sandboxed cloud containers with Claude Code, Codex, or OpenCode built in, for running agents at scale.

**Search**

Full-text and semantic search over your documents, ready to serve as a retrieval tool.

**QStash for LLM calls**

Call LLM APIs with retries, callbacks, batching, and a 2-hour timeout from serverless runtimes.
