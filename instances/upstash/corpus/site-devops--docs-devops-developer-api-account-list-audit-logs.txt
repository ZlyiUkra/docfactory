# DevOps: List Audit Logs
# джерело: https://upstash.com/docs/devops/developer-api/account/list_audit_logs
# отримано: 2026-10-16

> This endpoint lists all audit logs of user.

`GET /auditlogs`

## Request

`GET https://api.upstash.com/v2/auditlogs`

Authentication: `basicAuth` headers.

## Response

**200** — Audit logs retrieved successfully
