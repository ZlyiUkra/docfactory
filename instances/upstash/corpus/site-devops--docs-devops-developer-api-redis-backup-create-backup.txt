# DevOps: Create Backup
# джерело: https://upstash.com/docs/devops/developer-api/redis/backup/create_backup
# отримано: 2026-10-16

> This endpoint creates a backup for a Redis database.

`POST /redis/create-backup/{id}`

## Request

`POST https://api.upstash.com/v2/redis/create-backup/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the Redis database

**Request body** (`application/json`)

- `name` (string, required)
  Name of the backup

## Response

**200** — Backup created successfully

Example:

```json
"OK"
```
