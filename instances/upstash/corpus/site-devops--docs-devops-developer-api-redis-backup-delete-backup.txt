# DevOps: Delete Backup
# джерело: https://upstash.com/docs/devops/developer-api/redis/backup/delete_backup
# отримано: 2026-10-16

> This endpoint deletes a backup of a Redis database.

`DELETE /redis/delete-backup/{id}/{backup_id}`

## Request

`DELETE https://api.upstash.com/v2/redis/delete-backup/{id}/{backup_id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the Redis database

- `backup_id` (path, string, required)
  The ID of the backup to delete

## Response

**200** — Backup deleted successfully

Example:

```json
"OK"
```
