# DevOps: Disable Daily Backup
# джерело: https://upstash.com/docs/devops/developer-api/redis/backup/disable_dailybackup
# отримано: 2026-10-16

> This endpoint disables daily backup for a Redis database.

`PATCH /redis/disable-dailybackup/{id}`

## Request

`PATCH https://api.upstash.com/v2/redis/disable-dailybackup/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the Redis database

## Response

**200** — Daily backup disabled successfully

Example:

```json
"OK"
```
