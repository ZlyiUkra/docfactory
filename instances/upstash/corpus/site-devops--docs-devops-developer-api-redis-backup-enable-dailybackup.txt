# DevOps: Enable Daily Backup
# джерело: https://upstash.com/docs/devops/developer-api/redis/backup/enable_dailybackup
# отримано: 2026-10-16

> This endpoint enables daily backup for a Redis database.

`PATCH /redis/enable-dailybackup/{id}`

## Request

`PATCH https://api.upstash.com/v2/redis/enable-dailybackup/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the Redis database

## Response

**200** — Daily backup enabled successfully

Example:

```json
"OK"
```
