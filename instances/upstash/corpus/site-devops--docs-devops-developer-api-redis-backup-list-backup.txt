# DevOps: List Backup
# джерело: https://upstash.com/docs/devops/developer-api/redis/backup/list_backup
# отримано: 2026-10-16

> This endpoint lists all backups for a Redis database.

`GET /redis/list-backup/{id}`

## Request

`GET https://api.upstash.com/v2/redis/list-backup/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the Redis database

## Response

**200** — Backups retrieved successfully
