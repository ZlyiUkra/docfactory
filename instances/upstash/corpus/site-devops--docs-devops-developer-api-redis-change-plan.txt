# DevOps: Change Database Plan
# джерело: https://upstash.com/docs/devops/developer-api/redis/change_plan
# отримано: 2026-10-16

> This endpoint changes the plan of a Redis database.

`POST /redis/{id}/change-plan`

## Request

`POST https://api.upstash.com/v2/redis/{id}/change-plan`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database whose plan will be changed

**Request body** (`application/json`)

- `database_id` (string)
  ID of the database
  Example: `6gcefvfd-9627-2tz5-4l71-c5679g19d2g4`

- `plan_name` (string, required)
  The new plan for the database
  One of: `free`, `payg`, `fixed_250mb`, `fixed_1gb`, `fixed_5gb`, `fixed_10gb`, `fixed_50gb`, `fixed_100gb`, `fixed_500gb`
  Example: `fixed_1gb`

- `auto_upgrade` (boolean)
  Whether to enable automatic upgrade for the database
  Example: `true`

- `prod_pack_enabled` (boolean)
  Whether to enable the production pack for the database
  Example: `false`

## Response

**200** — Plan changed successfully

Example:

```json
"OK"
```
