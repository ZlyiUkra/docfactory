# DevOps: Delete Database
# джерело: https://upstash.com/docs/devops/developer-api/redis/delete_database
# отримано: 2026-10-16

> This endpoint deletes a database.

`DELETE /redis/database/{id}`

## Request

`DELETE https://api.upstash.com/v2/redis/database/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database to be deleted

## Response

**200** — OK

Example:

```json
"OK"
```
