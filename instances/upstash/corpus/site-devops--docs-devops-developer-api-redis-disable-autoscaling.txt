# DevOps: Disable Auto Upgrade
# джерело: https://upstash.com/docs/devops/developer-api/redis/disable_autoscaling
# отримано: 2026-10-16

> This endpoint disables Auto Upgrade for given database.

`POST /redis/disable-autoupgrade/{id}`

## Request

`POST https://api.upstash.com/v2/redis/disable-autoupgrade/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database to disable auto upgrade

## Response

**200** — Auto upgrade disabled successfully

Example:

```json
"OK"
```
