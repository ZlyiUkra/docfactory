# DevOps: Disable Eviction
# джерело: https://upstash.com/docs/devops/developer-api/redis/disable_eviction
# отримано: 2026-10-16

> This endpoint disables eviction for given database.

`POST /redis/disable-eviction/{id}`

## Request

`POST https://api.upstash.com/v2/redis/disable-eviction/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database to disable eviction

## Response

**200** — Eviction disabled successfully

Example:

```json
"OK"
```
