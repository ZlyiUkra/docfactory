# DevOps: Enable Auto Upgrade
# джерело: https://upstash.com/docs/devops/developer-api/redis/enable_autoscaling
# отримано: 2026-10-16

> This endpoint enables Auto Upgrade for given database.

`POST /redis/enable-autoupgrade/{id}`

## Request

`POST https://api.upstash.com/v2/redis/enable-autoupgrade/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database to enable auto upgrade

## Response

**200** — Auto upgrade enabled successfully

Example:

```json
"OK"
```
