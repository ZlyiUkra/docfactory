# DevOps: Enable Eviction
# джерело: https://upstash.com/docs/devops/developer-api/redis/enable_eviction
# отримано: 2026-10-16

> This endpoint enables eviction for given database.

`POST /redis/enable-eviction/{id}`

## Request

`POST https://api.upstash.com/v2/redis/enable-eviction/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database to enable eviction

## Response

**200** — Eviction enabled successfully

Example:

```json
"OK"
```
