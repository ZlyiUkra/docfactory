# DevOps: Get Database Stats
# джерело: https://upstash.com/docs/devops/developer-api/redis/get_database_stats
# отримано: 2026-10-16

> This endpoint gets detailed stats of a database.

`GET /redis/stats/{id}`

## Request

`GET https://api.upstash.com/v2/redis/stats/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database

## Response

**200** — Database stats retrieved successfully

  - `x` (string, required)

    Example: `2023-05-22 10:59:23.426 +0000 UTC`

  - `y` (number, required)
