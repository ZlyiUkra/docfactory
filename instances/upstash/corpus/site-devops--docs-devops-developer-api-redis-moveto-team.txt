# DevOps: Move To Team
# джерело: https://upstash.com/docs/devops/developer-api/redis/moveto_team
# отримано: 2026-10-16

> This endpoint moves database under a target team

`POST /redis/move-to-team`

## Request

`POST https://api.upstash.com/v2/redis/move-to-team`

Authentication: `basicAuth` headers.

**Request body** (`application/json`)

- `team_id` (string, required)
  The ID of the target team

- `database_id` (string, required)
  The ID of the database to be moved

## Response

**200** — Database moved successfully

Example:

```json
"OK"
```
