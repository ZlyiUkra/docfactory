# DevOps: Update Database Budget
# джерело: https://upstash.com/docs/devops/developer-api/redis/update_budget
# отримано: 2026-10-16

> This endpoint updates the monthly budget of a Redis database.

`PATCH /redis/update-budget/{id}`

## Request

`PATCH https://api.upstash.com/v2/redis/update-budget/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the database whose budget will be updated

**Request body** (`application/json`)

- `budget` (integer, required)
  The new monthly budget for the database

## Response

**200** — Budget updated successfully

Example:

```json
"OK"
```
