# DevOps: Update Regions
# джерело: https://upstash.com/docs/devops/developer-api/redis/update_regions
# отримано: 2026-10-16

> Update the regions of a database

`POST /redis/update-regions/{id}`

## Request

`POST https://api.upstash.com/v2/redis/update-regions/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of your database

**Request body** (`application/json`)

- `read_regions` (array of string, required)
  Array of Read Regions of the Database

## Response

**200** — Regions updated successfully

Example:

```json
"OK"
```
