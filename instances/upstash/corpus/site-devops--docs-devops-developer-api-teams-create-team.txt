# DevOps: Create Team
# джерело: https://upstash.com/docs/devops/developer-api/teams/create_team
# отримано: 2026-10-16

> This endpoint creates a new team.

`POST /team`

## Request

`POST https://api.upstash.com/v2/team`

Authentication: `basicAuth` headers.

**Request body** (`application/json`)

- `team_name` (string, required)
  Name of the new team
  Example: `myteam`

- `copy_cc` (boolean, required)
  Whether to copy existing credit card information to team or not
  Example: `true`

## Response

**200** — Team created successfully

- `team_id` (string)
  ID of the team
  Example: `95849b27-40d0-4532-8695-d2028847f823`

- `team_name` (string)
  Name of the team
  Example: `test_team_name`

- `copy_cc` (boolean)
  Whether creditcard information added to team during creation or not
  Example: `true`
