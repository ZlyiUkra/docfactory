# DevOps: Delete Team Member
# джерело: https://upstash.com/docs/devops/developer-api/teams/delete_team_member
# отримано: 2026-10-16

> This endpoint deletes a team member from the specified team.

`DELETE /teams/member`

## Request

`DELETE https://api.upstash.com/v2/teams/member`

Authentication: `basicAuth` headers.

**Request body** (`application/json`)

- `team_id` (string, required)
  Id of the team to remove the member from
  Example: `95849b27-40d0-4532-8695-d2028847f823`

- `member_email` (string, required)
  Email of the team member to remove
  Example: `example@upstash.com`

## Response

**200** — Team member deleted successfully

Example:

```json
"OK"
```
