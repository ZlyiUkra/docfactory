# DevOps: Delete Team
# джерело: https://upstash.com/docs/devops/developer-api/teams/delete_team
# отримано: 2026-10-16

> This endpoint deletes a team.

`DELETE /team/{id}`

## Request

`DELETE https://api.upstash.com/v2/team/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The ID of the team to delete

## Response

**200** — Team deleted successfully

Example:

```json
"OK"
```
