# DevOps: Get Team Members
# джерело: https://upstash.com/docs/devops/developer-api/teams/get_team_members
# отримано: 2026-10-16

> This endpoint list all members of a team.

`GET /teams/{team_id}`

## Request

`GET https://api.upstash.com/v2/teams/{team_id}`

Authentication: `basicAuth` headers.

**Parameters**

- `team_id` (path, string, required)
  ID of the team

## Response

**200** — Team members retrieved successfully
