# DevOps: List Teams
# джерело: https://upstash.com/docs/devops/developer-api/teams/list_teams
# отримано: 2026-10-16

> This endpoint lists all teams of user.

`GET /teams`

## Request

`GET https://api.upstash.com/v2/teams`

Authentication: `basicAuth` headers.

## Response

**200** — Teams retrieved successfully
