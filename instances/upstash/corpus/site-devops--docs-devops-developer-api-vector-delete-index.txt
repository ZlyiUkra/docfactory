# DevOps: Delete Index
# джерело: https://upstash.com/docs/devops/developer-api/vector/delete_index
# отримано: 2026-10-16

> This endpoint deletes an index.

`DELETE /vector/index/{id}`

## Request

`DELETE https://api.upstash.com/v2/vector/index/{id}`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the index to be deleted

## Response

**200** — Index deleted successfully

Example:

```json
"OK"
```
