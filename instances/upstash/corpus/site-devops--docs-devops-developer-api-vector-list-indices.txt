# DevOps: List Indices
# джерело: https://upstash.com/docs/devops/developer-api/vector/list_indices
# отримано: 2026-10-16

> This endpoint returns the data related to all indices of an account as a list.

`GET /vector/index`

## Request

`GET https://api.upstash.com/v2/vector/index`

Authentication: `basicAuth` headers.

## Response

**200** — Indices retrieved successfully
