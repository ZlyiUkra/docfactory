# DevOps: Rename Index
# джерело: https://upstash.com/docs/devops/developer-api/vector/rename_index
# отримано: 2026-10-16

> This endpoint is used to change the name of an index.

`POST /vector/index/{id}/rename`

## Request

`POST https://api.upstash.com/v2/vector/index/{id}/rename`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the index to be renamed

**Request body** (`application/json`)

- `name` (string, required)
  The new name of the index

## Response

**200** — Index renamed successfully

Example:

```json
"OK"
```
