# DevOps: Reset Index Passwords
# джерело: https://upstash.com/docs/devops/developer-api/vector/reset_index_passwords
# отримано: 2026-10-16

> This endpoint is used to reset regular and readonly tokens of an index.

`POST /vector/index/{id}/reset-password`

## Request

`POST https://api.upstash.com/v2/vector/index/{id}/reset-password`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the index to reset the password for

## Response

**200** — Index passwords reset successfully

Example:

```json
"OK"
```
