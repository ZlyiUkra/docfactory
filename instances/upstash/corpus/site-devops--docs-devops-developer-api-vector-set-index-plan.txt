# DevOps: Set Index Plan
# джерело: https://upstash.com/docs/devops/developer-api/vector/set_index_plan
# отримано: 2026-10-16

> This endpoint is used to change the plan of an index.

`POST /vector/index/{id}/setplan`

## Request

`POST https://api.upstash.com/v2/vector/index/{id}/setplan`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the index to change plan for

**Request body** (`application/json`)

- `target_plan` (string, required)
  The new plan for the index
  One of: `free`, `payg`, `fixed`

## Response

**200** — Index plan changed successfully

Example:

```json
"OK"
```
