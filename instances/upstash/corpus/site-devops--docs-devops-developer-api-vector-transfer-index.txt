# DevOps: Transfer Index
# джерело: https://upstash.com/docs/devops/developer-api/vector/transfer_index
# отримано: 2026-10-16

> This endpoint is used to transfer an index to another team.
Transferring to a personal account is not supported. However, transferring an index from a personal account to a team is allowed.

`POST /vector/index/{id}/transfer`

## Request

`POST https://api.upstash.com/v2/vector/index/{id}/transfer`

Authentication: `basicAuth` headers.

**Parameters**

- `id` (path, string, required)
  The unique ID of the index to be transferred

**Request body** (`application/json`)

- `target_account` (string, required)
  The team ID of the target team.
  Example: `99a4c327-31f0-490f-a594-043ade84085a`

## Response

**200** — Index transferred successfully

Example:

```json
"OK"
```
