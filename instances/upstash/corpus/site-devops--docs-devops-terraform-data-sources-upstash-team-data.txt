# DevOps: upstash_team_data
# джерело: https://upstash.com/docs/devops/terraform/data_sources/upstash_team_data
# отримано: 2026-10-16

```hcl
data "upstash_team_data" "teamData" {
  team_id = resource.upstash_team.exampleTeam.team_id
}
```

## Schema

### Required

-  (string, required)
  Unique Cluster ID for created cluster

  ### Read-Only

  - `copy_cc` (bool)
    Whether Credit Card is copied

  - `id` (number)
    The ID of this resource.

  - `team_members` (map(string))
    Members of the team. (Owner must be specified, which is the owner of the api
    key.)

  - `team_name` (string)
    Name of the team
