# DevOps: upstash_qstash_topic
# джерело: https://upstash.com/docs/devops/terraform/resources/upstash_qstash_topic
# отримано: 2026-10-16

> Create and manage QStash topics

```hcl
resource "upstash_qstash_topic" "exampleQStashTopic" {
  name = "exampleQStashTopicName"
}
```

## Schema

### Required

-  (string, required)
  Name of the QStash topic

  ### Read-Only

  - `endpoints` (list(map(string)))
    Endpoints for the QStash topic

  - `id` (string)
    The ID of this resource.

  - `topic_id` (string)
    Unique QStash topic ID for requested topic
