# QStash: Retry a DLQ message
# джерело: https://upstash.com/docs/qstash/api-reference/dlq/retry-a-dlq-message
# отримано: 2026-10-16

> Retry delivery of a message from the DLQ

`POST /v2/dlq/retry/{dlqId}`

When a DLQ message is retried, a new message with the same body and headers is created and scheduled for delivery.
The original DLQ message is then removed from the DLQ.

Note:
You can pass all configuration headers to override the configuration of the original message.

For example, if the retry count of the original message is 5, you can set it to 0 for the retried message by passing `Upstash-Retries: 0 ` header to this request.
Check out publish documentation for complete list of configuration options you can pass.

## Request

`POST https://qstash-{region}.upstash.io/v2/dlq/retry/{dlqId}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `dlqId` (path, string, required)
  The DLQ ID of the message you want to retry.

## Response

**201** — Message retry initiated successfully

- `messageId` (string)
  Unique identifier for the published message or the old message ID if deduplicated

- `deduplicated` (boolean)
  Whether this message is a duplicate and was not sent to the destination.

**404** — If the message is not found in the DLQ, (either is has been removed by you, or automatically), the endpoint returns a 404 status code.

- `error` (string, required)
  Error message
