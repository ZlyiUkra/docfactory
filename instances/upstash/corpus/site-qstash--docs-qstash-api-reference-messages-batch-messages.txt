# QStash: Batch Messages
# джерело: https://upstash.com/docs/qstash/api-reference/messages/batch-messages
# отримано: 2026-10-16

> Send multiple messages in a single request

`POST /v2/batch`

## Request

`POST https://qstash-{region}.upstash.io/v2/batch`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Request body** (`application/json`)

## Response

**200** — Messages published successfully

**400** — Bad request

- `error` (string, required)
  Error message
