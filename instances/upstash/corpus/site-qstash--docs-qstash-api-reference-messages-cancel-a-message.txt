# QStash: Cancel a Message
# джерело: https://upstash.com/docs/qstash/api-reference/messages/cancel-a-message
# отримано: 2026-10-16

> Cancel a pending message

`DELETE /v2/messages/{messageId}`

## Request

`DELETE https://qstash-{region}.upstash.io/v2/messages/{messageId}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `messageId` (path, string, required)
  The identifier of the message to cancel.

## Response

**202** — Message canceled successfully

- `cancelled` (integer)
  Number of messages cancelled. Always `1`.

**404** — Message not found

- `error` (string, required)
  Error message
