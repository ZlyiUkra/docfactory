# QStash: Delete a queue
# джерело: https://upstash.com/docs/qstash/api-reference/queues/delete-a-queue
# отримано: 2026-10-16

> Deletes a queue

`DELETE /v2/queues/{queueName}`

## Request

`DELETE https://qstash-{region}.upstash.io/v2/queues/{queueName}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `queueName` (path, string, required)
  The name of the queue to delete.

## Response

**200** — Queue deleted successfully
