# QStash: List Queues
# джерело: https://upstash.com/docs/qstash/api-reference/queues/list-queues
# отримано: 2026-10-16

> List all your queues

`GET /v2/queues`

## Request

`GET https://qstash-{region}.upstash.io/v2/queues`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

## Response

**200** — List of queues
