# QStash: Delete a Schedule
# джерело: https://upstash.com/docs/qstash/api-reference/schedules/delete-a-schedule
# отримано: 2026-10-16

> Delete a schedule

`DELETE /v2/schedules/{scheduleId}`

## Request

`DELETE https://qstash-{region}.upstash.io/v2/schedules/{scheduleId}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `scheduleId` (path, string, required)
  The ID of the schedule to delete.

## Response

**200** — Schedule deleted successfully
