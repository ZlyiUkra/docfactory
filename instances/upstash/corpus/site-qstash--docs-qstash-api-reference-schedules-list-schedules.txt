# QStash: List schedules
# джерело: https://upstash.com/docs/qstash/api-reference/schedules/list-schedules
# отримано: 2026-10-16

> List all schedules

`GET /v2/schedules`

## Request

`GET https://qstash-{region}.upstash.io/v2/schedules`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

## Response

**200** — List of schedules
