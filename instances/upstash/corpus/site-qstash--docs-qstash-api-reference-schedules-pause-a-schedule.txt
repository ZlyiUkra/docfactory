# QStash: Pause a Schedule
# джерело: https://upstash.com/docs/qstash/api-reference/schedules/pause-a-schedule
# отримано: 2026-10-16

> Pause a Schedule

`POST /v2/schedules/{scheduleId}/pause`

When a schedule is paused, the cron trigger will simply be ignored.

If the schedule is already paused, this action has no effect.

## Request

`POST https://qstash-{region}.upstash.io/v2/schedules/{scheduleId}/pause`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `scheduleId` (path, string, required)
  The ID of the schedule to pause.

## Response

**200** — Schedule paused successfully
