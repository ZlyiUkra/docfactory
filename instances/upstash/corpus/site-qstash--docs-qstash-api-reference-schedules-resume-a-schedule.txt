# QStash: Resume a Schedule
# джерело: https://upstash.com/docs/qstash/api-reference/schedules/resume-a-schedule
# отримано: 2026-10-16

> Resume a paused Schedule

`POST /v2/schedules/{scheduleId}/resume`

Resuming a schedule marks the schedule as active. This means the upcoming messages will be delivered and will not be ignored.

If the schedule is already active, this action has no effect.

## Request

`POST https://qstash-{region}.upstash.io/v2/schedules/{scheduleId}/resume`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `scheduleId` (path, string, required)
  The ID of the schedule to resume.

## Response

**200** — Schedule resumed successfully
