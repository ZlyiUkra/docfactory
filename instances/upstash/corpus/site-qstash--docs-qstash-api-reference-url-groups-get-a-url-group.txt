# QStash: Get a URL Group
# джерело: https://upstash.com/docs/qstash/api-reference/url-groups/get-a-url-group
# отримано: 2026-10-16

> Retrieve details of a specific URL Group

`GET /v2/topics/{urlGroupName}`

## Request

`GET https://qstash-{region}.upstash.io/v2/topics/{urlGroupName}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `urlGroupName` (path, string, required)
  The name of the URL Group to retrieve.

## Response

**200** —

- `name` (string)
  URL Group name

- `createdAt` (integer)
  Creation timestamp of URL Group in Unix milliseconds

- `updatedAt` (integer)
  Last update timestamp of URL Group in Unix milliseconds

- `endpoints` (array of object)

  - `name` (string)
    The name of the endpoint

  - `url` (string)
    The URL of the endpoint

**404** — URL Group not found

- `error` (string, required)
  Error message
