# QStash: Remove Endpoints
# джерело: https://upstash.com/docs/qstash/api-reference/url-groups/remove-endpoints
# отримано: 2026-10-16

> Remove one or more endpoints from a URL Group

`DELETE /v2/topics/{urlGroupName}/endpoints`

Remove one or multiple endpoints from a URL Group. If all endpoints have been removed, the URL Group will be deleted.

## Request

`DELETE https://qstash-{region}.upstash.io/v2/topics/{urlGroupName}/endpoints`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `urlGroupName` (path, string, required)
  The name of your URL Group.

**Request body** (`application/json`)

- `endpoints` (array of object, required)
  Then list of endpoints to remove from URL Group. Either name or url must be provided.

  - `name` (string)
    The name of the endpoint

  - `url` (string)
    The URL of the endpoint

## Response

**200** — Endpoint(s) removed successfully
