# QStash: Upsert URL Group and Endpoint
# джерело: https://upstash.com/docs/qstash/api-reference/url-groups/upsert-url-group-and-endpoint
# отримано: 2026-10-16

> Add an endpoint to a URL Group

`POST /v2/topics/{urlGroupName}/endpoints`

Add one or multiple endpoints to a URL Group. If the URL Group does not exist, it will be created.

## Request

`POST https://qstash-{region}.upstash.io/v2/topics/{urlGroupName}/endpoints`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `urlGroupName` (path, string, required)
  The name of your URL Group. If it doesn't exist yet, it will be created.

**Request body** (`application/json`)

- `endpoints` (array of object, required)

  - `url` (string, required)
    The URL of the endpoint

  - `name` (string)
    Optional name for the endpoint

## Response

**200** — Endpoint(s) added successfully
