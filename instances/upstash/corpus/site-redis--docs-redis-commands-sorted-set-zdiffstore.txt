# Redis: ZDIFFSTORE
# джерело: https://upstash.com/docs/redis/commands/sorted-set/zdiffstore
# отримано: 2026-10-16

> Store sorted set difference.

Use `ZDIFFSTORE` to compute the difference between sorted sets and store it in another key.

The destination receives the members of the first source that appear in none of the others, keeping their scores from that source. It is overwritten if it exists and deleted when the result is empty, and the reply is the number of members stored.

Materializing the result is worthwhile when the same filtered ranking is read repeatedly or paged through, since the destination is an ordinary sorted set.

## Syntax

```redis
ZDIFFSTORE <destination> <numkeys> <key> [<key> ...]
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<destination>` | Yes | No | Redis key used as destination. |
| `<numkeys>` | Yes | No | Number of key arguments that follow. |
| `<key>` | Yes | Yes | Redis key targeted by the command. |

## Important points

- `numkeys` must equal the number of key arguments that immediately follow it.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer |
| RESP3 | Integer |

Note:
Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.

## Examples

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

**Redis CLI**

```bash
ZDIFFSTORE destination-key 1 my-key
```

**@upstash/redis**

```ts
import { Redis } from "@upstash/redis";

const redis = Redis.fromEnv();

const values = await redis.zdiffstore("destination", 2, "key1", "key2");
```

**upstash_redis**

```python
from upstash_redis import Redis

redis = Redis.from_env()
result = redis.zdiffstore("destination-key", ["my-key"])
print(result)
```

**ioredis**

```ts
import Redis from "ioredis";

const redis = new Redis(process.env.REDIS_URL!);
const result = await redis.zdiffstore("destination-key", "1", "my-key");
console.log(result);
```

**node-redis**

```ts
import { createClient } from "redis";

const client = await createClient({ url: process.env.REDIS_URL })
  .on("error", console.error)
  .connect();
const result = await client.zDiffStore("destination-key", "my-key");
console.log(result);
```

**redis-py**

```python
import os
import redis

client = redis.from_url(os.environ["REDIS_URL"])
result = client.zdiffstore("destination-key", ["my-key"])
print(result)
```

**go-redis**

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.ZDiffStore(context.Background(), "destination-key", "my-key").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

**jedis**

```java
import java.net.URI;

import redis.clients.jedis.Jedis;

try (Jedis jedis = new Jedis(new URI(System.getenv("REDIS_URL")))) {
  Object result = jedis.zdiffstore("destination-key", "my-key");
  System.out.println(result);
}
```

**redis-rs**

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("ZDIFFSTORE");
    command.arg("destination-key");
    command.arg("1");
    command.arg("my-key");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
