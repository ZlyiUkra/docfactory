# Redis: VECTOR.COUNT
# джерело: https://upstash.com/docs/redis/commands/vector/vector-count
# отримано: 2026-10-16

> Count the vectors in an index.

Use `VECTOR.COUNT` to get the number of vectors currently stored in an index.

Replacing the vector under an existing ID does not change the count, since the ID is what is counted. An index that does not exist counts as `0` rather than raising an error, so the command can be used as a cheap emptiness check without a prior `EXISTS`.

Vector indexes are an Upstash extension. See the vector command overview for how an index is created, written to, and queried.

## Syntax

```redis
VECTOR.COUNT <index>
```

## Arguments

| Argument | Required | Repeatable | Description |
| --- | --- | --- | --- |
| `<index>` | Yes | No | Key holding the vector index. |

## Important points

- An index that does not exist replies `0`. Use `VECTOR.INFO`, which replies null, to tell an empty index from a missing one.

## Response

The reply reports the result of the operation. Error replies have the same shape in RESP2 and RESP3 and are surfaced as exceptions by the SDKs below.

| Protocol | Reply |
| --- | --- |
| RESP2 | Integer |
| RESP3 | Integer |

Note:
Client libraries often decode bulk strings, maps, sets, and numeric strings into language-native values. The table describes the Redis wire reply.

## Examples

TCP examples use the TLS `REDIS_URL` from the Upstash console. REST examples use `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.

**Redis CLI**

```bash
VECTOR.COUNT my-index
```

**@upstash/redis**

```ts
import { Redis } from "@upstash/redis";

const redis = Redis.fromEnv();

const index = redis.vector.index("my-index");
const count = await index.count();
console.log(count);
```

**upstash_redis**

```python
from upstash_redis import Redis

redis = Redis.from_env()

index = redis.vector.index("my-index")
count = index.count()
print(count)
```

**ioredis**

```ts
import Redis from "ioredis";

const redis = new Redis(process.env.REDIS_URL!);
const result = await redis.call("VECTOR.COUNT", "my-index");
console.log(result);
```

**node-redis**

```ts
import { createClient } from "redis";

const client = await createClient({ url: process.env.REDIS_URL })
  .on("error", console.error)
  .connect();
const result = await client.sendCommand(["VECTOR.COUNT", "my-index"]);
console.log(result);
```

**redis-py**

```python
import os
import redis

client = redis.from_url(os.environ["REDIS_URL"])
result = client.execute_command("VECTOR.COUNT", "my-index")
print(result)
```

**go-redis**

```go
package main

import (
    "context"
    "fmt"
    "os"

    "github.com/redis/go-redis/v9"
)

func main() {
    opts, err := redis.ParseURL(os.Getenv("REDIS_URL"))
    if err != nil {
        panic(err)
    }
    client := redis.NewClient(opts)
    result, err := client.Do(context.Background(), "VECTOR.COUNT", "my-index").Result()
    if err != nil {
        panic(err)
    }
    fmt.Println(result)
}
```

**jedis**

```java
import java.net.URI;

import redis.clients.jedis.Jedis;

try (Jedis jedis = new Jedis(new URI(System.getenv("REDIS_URL")))) {
  Object result = jedis.sendCommand(() -> "VECTOR.COUNT".getBytes(), "my-index");
  System.out.println(result);
}
```

**redis-rs**

```rust
fn main() -> redis::RedisResult<()> {
    let url = std::env::var("REDIS_URL").expect("REDIS_URL is not set");
    let client = redis::Client::open(url)?;
    let mut connection = client.get_connection()?;

    let mut command = redis::cmd("VECTOR.COUNT");
    command.arg("my-index");
    let result: redis::Value = command.query(&mut connection)?;
    println!("{result:?}");
    Ok(())
}
```
