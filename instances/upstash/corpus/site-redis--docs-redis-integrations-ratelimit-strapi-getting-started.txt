# Redis: Upstash Ratelimit Strapi Integration
# джерело: https://upstash.com/docs/redis/integrations/ratelimit/strapi/getting-started
# отримано: 2026-10-16

Strapi is an open-source, Node.js based, Headless CMS that saves developers a lot of development time, enabling them to build their application backends quickly by decreasing the lines of code necessary.

You can use Upstash's HTTP and Redis based Ratelimit package integration with Strapi to protect your APIs from abuse.

## Getting started

### Installation

```bash
npm install --save @upstash/strapi-plugin-upstash-ratelimit
```

```bash
yarn add @upstash/strapi-plugin-upstash-ratelimit
```

### Create database

Create a new redis database on Upstash Console. See related docs for further info related to creating a database.

### Set up environment variables

Get the environment variables from Upstash Console, and set it to `.env` file as below:

```shell
UPSTASH_REDIS_REST_TOKEN="<YOUR_TOKEN>"
UPSTASH_REDIS_REST_URL="<YOUR_URL>"
```

### Configure the plugin

You can use

```typescript
export default () => ({
  "strapi-plugin-upstash-ratelimit": {
    enabled: true,
    resolve: "./src/plugins/strapi-plugin-upstash-ratelimit",
    config: {
      enabled: true,
      token: process.env.UPSTASH_REDIS_REST_TOKEN,
      url: process.env.UPSTASH_REDIS_REST_URL,
      strategy: [
        {
          methods: ["GET", "POST"],
          path: "*",
          limiter: {
            algorithm: "fixed-window",
            tokens: 10,
            window: "20s",
          },
        },
      ],
      prefix: "@strapi",
    },
  },
});
```
