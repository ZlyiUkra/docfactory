# Redis: ARCOUNT
# джерело: https://upstash.com/docs/redis/sdks/py/commands/array/arcount
# отримано: 2026-10-16

> Count the occupied slots in an array.

For sparse arrays, this differs from ARLEN, which returns the highest occupied index plus one.

## Arguments

-  (str, required)
  The array key.

  ## Response

  -  (int, required)
    The number of slots containing values, or zero for a missing key.

```py
redis.arset("readings", 1000, "sample")
print(redis.arcount("readings"))  # 1
print(redis.arlen("readings"))  # 1001
```

  See the server command reference for protocol details.
