# Redis: GETBIT
# джерело: https://upstash.com/docs/redis/sdks/py/commands/bitmap/getbit
# отримано: 2026-10-16

> Retrieve a single bit.

## Arguments

-  (str, required)
  The key of the bitset

  -  (int, required)
    Specify the offset at which to get the bit.

    ## Response

    -  (int, required)
      The bit value stored at offset.

```py
bit = redis.getbit(key, 4)
```
