# Redis: SETBIT
# джерело: https://upstash.com/docs/redis/sdks/py/commands/bitmap/setbit
# отримано: 2026-10-16

> Set a single bit in a string.

## Arguments

-  (str, required)
  The key of the bitset

  -  (int, required)
    Specify the offset at which to set the bit.

    -  (0 | 1, required)
      The bit to set

      ## Response

      -  (0 | 1, required)
        The original bit value stored at offset.

```py
original_bit = redis.setbit(key, 4, 1)
```
