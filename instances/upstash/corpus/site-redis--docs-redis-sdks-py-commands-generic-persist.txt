# Redis: PERSIST
# джерело: https://upstash.com/docs/redis/sdks/py/commands/generic/persist
# отримано: 2026-10-16

> Remove any timeout set on the key.

## Arguments

-  (str, required)
  The key to persist

  ## Response

  -  (bool)
    `True` if the timeout was set

```py
redis.set("key1", "Hello")
redis.expire("key1", 10)

assert redis.ttl("key1") == 10

redis.persist("key1")

assert redis.ttl("key1") == -1
```
