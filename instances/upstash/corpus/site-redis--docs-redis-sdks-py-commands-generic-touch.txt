# Redis: TOUCH
# джерело: https://upstash.com/docs/redis/sdks/py/commands/generic/touch
# отримано: 2026-10-16

> Alters the last access time of one or more keys

## Arguments

-  (*List[str], required)
  One or more keys.

  ## Response

  -  (int)
    The number of keys that were touched.

```py
redis.touch("key1", "key2", "key3")
```
