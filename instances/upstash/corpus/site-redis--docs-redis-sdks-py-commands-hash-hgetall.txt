# Redis: HGETALL
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hgetall
# отримано: 2026-10-16

> Retrieves all fields from a hash.

## Arguments

-  (str, required)
  The key to get.

  ## Response

  -  (Optional[str], required)
    An object with all fields in the hash.

```py
redis.hset("myhash", values={
"field1": "Hello",
"field2": "World"
})

assert redis.hgetall("myhash") == {"field1": "Hello", "field2": "World"}
```
