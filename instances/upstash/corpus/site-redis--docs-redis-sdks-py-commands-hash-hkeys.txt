# Redis: HKEYS
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hkeys
# отримано: 2026-10-16

> Return all field names in the hash stored at key.

## Arguments

-  (str, required)
  The key of the hash.

  ## Response

  -  (List[str], required)
    The field names of the hash

```py
redis.hset("myhash", values={
    "field1": "Hello",
    "field2": "World"
})

assert redis.hkeys("myhash") == ["field1", "field2"]
```
