# Redis: HLEN
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hlen
# отримано: 2026-10-16

> Returns the number of fields contained in the hash stored at key.

## Arguments

-  (str, required)
  The key of the hash.

  ## Response

  -  (int, required)
    How many fields are in the hash.

```py
assert redis.hlen("myhash") == 0

redis.hset("myhash", values={
    "field1": "Hello",
    "field2": "World"
})

assert redis.hlen("myhash") == 2
```
