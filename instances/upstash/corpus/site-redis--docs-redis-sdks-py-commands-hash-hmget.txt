# Redis: HMGET
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hmget
# отримано: 2026-10-16

> Return the requested fields and their values.

## Arguments

-  (str, required)
  The key of the hash.

  -  (*List[str], required)
    One or more fields to get.

    ## Response

    -  (List[str | None], required)
      An object containing the fields and their values.

```py
redis.hset("myhash", values={
    "field1": "Hello",
    "field2": "World"
})

assert redis.hmget("myhash", "field1", "field2") == ["Hello", "World"]
```
