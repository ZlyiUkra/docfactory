# Redis: HMSET
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hmset
# отримано: 2026-10-16

> Write multiple fields to a hash.

## Arguments

-  (str, required)
  The key of the hash.

  -  (Dict[str, Any], required)
    A dictionary of fields and their values.

    ## Response

    -  (int, required)
      The number of fields that were added.

```py
# Set multiple fields
assert redis.hset("myhash"{
  "field1": "Hello",
  "field2": "World"
}) == 2
```
