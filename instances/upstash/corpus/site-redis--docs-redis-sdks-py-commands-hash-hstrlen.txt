# Redis: HSTRLEN
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hstrlen
# отримано: 2026-10-16

> Returns the string length of a value in a hash.

## Arguments

-  (str, required)
  The key of the hash.

  -  (str, required)
    The name of the field.

    ## Response

    -  (int, required)
      `0` if the hash or field does not exist. Otherwise the length of the string.

```py
length = redis.hstrlen("key", "field")
```
