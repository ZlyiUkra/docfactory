# Redis: HVALS
# джерело: https://upstash.com/docs/redis/sdks/py/commands/hash/hvals
# отримано: 2026-10-16

> Returns all values in the hash stored at key.

## Arguments

-  (str, required)
  The key of the hash.

  ## Response

  -  (List[str], required)
    All values in the hash, or an empty list when key does not exist.

```py
redis.hset("myhash", values={
  "field1": "Hello",
  "field2": "World"
})

assert redis.hvals("myhash") == ["Hello", "World"]
```
