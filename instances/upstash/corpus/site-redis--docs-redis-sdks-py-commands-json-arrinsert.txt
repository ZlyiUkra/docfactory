# Redis: JSON.ARRINSERT
# джерело: https://upstash.com/docs/redis/sdks/py/commands/json/arrinsert
# отримано: 2026-10-16

> Insert the json values into the array at path before the index (shifts to the right).

## Arguments

-  (str, required)
  The key of the json entry.

  -  (str, required)
    The path of the array.

    -  (int, required)
      The index where to insert the values.

      -  (...TValue[], required)
        One or more values to append to the array.

        ## Response

        -  (List[int], required)
          The length of the array after the insertion.

```py
length = redis.json.arrinsert("key", "$.path.to.array", 2, "a", "b")
```
