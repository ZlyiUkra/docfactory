# Redis: JSON.FORGET
# джерело: https://upstash.com/docs/redis/sdks/py/commands/json/forget
# отримано: 2026-10-16

> Delete a key from a JSON document.

## Arguments

-  (str, required)
  The key of the json entry.

  -  (str, required)
    The path to forget. `$` is the root.

    ## Response

    -  (int, required)
      How many paths were deleted.

```py
redis.json.forget("key", "$.path.to.value")
```
