# Redis: JSON.MERGE
# джерело: https://upstash.com/docs/redis/sdks/py/commands/json/merge
# отримано: 2026-10-16

> Merges the JSON value at path in key with the provided value.

## Arguments

-  (str, required)
  The key of the json entry.

  -  (str, required)
    The path of the value to set.

    -  (TValue, required)
      The value to merge with.

      ## Response

      -  (true, required)
        Returns true if the merge was successful.

```py
redis.json.merge("key", "$.path.to.value", {"new": "value"})
```
