# Redis: JSON.STRAPPEND
# джерело: https://upstash.com/docs/redis/sdks/py/commands/json/strappend
# отримано: 2026-10-16

> Append the json-string values to the string at path.

## Arguments

-  (str, required)
  The key of the json entry.

  -  (str, required)
    The path of the string.

    -  (str, required)
      The value to append to the existing string.

      ## Response

      -  (List[int], required)
        The length of the string after the appending.

```py
redis.json.strappend("key", "$.path.to.str", "abc")
```
