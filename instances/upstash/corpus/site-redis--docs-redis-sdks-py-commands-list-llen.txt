# Redis: LLEN
# джерело: https://upstash.com/docs/redis/sdks/py/commands/list/llen
# отримано: 2026-10-16

> Returns the length of the list stored at key.

## Arguments

-  (str, required)
  The key of the list.

  ## Response

  -  (int, required)
    The length of the list at key.

```py
redis.rpush("key", "a", "b", "c")

assert redis.llen("key") == 3
```
