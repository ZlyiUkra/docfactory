# Redis: RPUSH
# джерело: https://upstash.com/docs/redis/sdks/py/commands/list/rpush
# отримано: 2026-10-16

> Push an element at the end of the list.

## Arguments

-  (str, required)
  The key of the list.

  -  (*List[str], required)
    One or more elements to push at the end of the list.

    ## Response

    -  (int, required)
      The length of the list after the push operation.

```py
assert redis.rpush("mylist", "one", "two", "three") == 3

assert lrange("mylist", 0, -1) == ["one", "two", "three"]
```
