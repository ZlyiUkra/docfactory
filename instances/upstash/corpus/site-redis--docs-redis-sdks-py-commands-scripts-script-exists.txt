# Redis: SCRIPT EXISTS
# джерело: https://upstash.com/docs/redis/sdks/py/commands/scripts/script_exists
# отримано: 2026-10-16

> Check if scripts exist in the script cache.

## Arguments

-  (List[str], required)
  The sha1 of the scripts to check.

  ## Response

  -  (List[bool], required)
    A list of booleans indicating if the script exists in the script cache.

```py
# Script 1 exists
# Script 0 does not
await redis.scriptExists("<sha1>", "<sha2>") == [1, 0]
```
