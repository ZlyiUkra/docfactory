# Redis: SCRIPT LOAD
# джерело: https://upstash.com/docs/redis/sdks/py/commands/scripts/script_load
# отримано: 2026-10-16

> Load the specified Lua script into the script cache.

## Arguments

-  (str, required)
  The script to load.

  ## Response

  -  (str, required)
    The sha1 of the script.

```py
sha1 = redis.script_load("return 1")

assert redis.evalsha(sha1) == 1
```
