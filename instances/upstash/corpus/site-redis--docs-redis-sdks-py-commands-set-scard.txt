# Redis: SCARD
# джерело: https://upstash.com/docs/redis/sdks/py/commands/set/scard
# отримано: 2026-10-16

> Return how many members are in a set

## Arguments

-  (str, required)
  The key of the set.

  ## Response

  -  (int, required)
    How many members are in the set.

```py
redis.sadd("key", "a", "b", "c");

assert redis.scard("key") == 3
```
