# Redis: SDIFF
# джерело: https://upstash.com/docs/redis/sdks/py/commands/set/sdiff
# отримано: 2026-10-16

> Return the difference between sets

## Arguments

-  (*List[str], required)
  The keys of the sets to perform the difference operation on.

  ## Response

  -  (set[str], required)
    The resulting set.

```py
redis.sadd("set1", "a", "b", "c");
redis.sadd("set2", "c", "d", "e");

assert redis.sdiff("set1", "set2") == {"a", "b"}
```
