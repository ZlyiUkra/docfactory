# Redis: SINTER
# джерело: https://upstash.com/docs/redis/sdks/py/commands/set/sinter
# отримано: 2026-10-16

> Return the intersection between sets

## Arguments

-  (*List[str], required)
  The keys of the sets to perform the intersection operation on.

  ## Response

  -  (set[str], required)
    The resulting set.

```py
redis.sadd("set1", "a", "b", "c");
redis.sadd("set2", "c", "d", "e");

assert redis.sinter("set1", "set2") == {"c"}
```
