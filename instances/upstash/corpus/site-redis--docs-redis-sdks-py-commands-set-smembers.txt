# Redis: SMEMBERS
# джерело: https://upstash.com/docs/redis/sdks/py/commands/set/smembers
# отримано: 2026-10-16

> Return all the members of a set

## Arguments

-  (str, required)
  The key of the set.

  ## Response

  -  (set[str], required)
    The members of the set.

```py
redis.sadd("set", "a", "b", "c");
assert redis.smembers("set") == {"a", "b", "c"}
```
