# Redis: XGROUP DELCONSUMER
# джерело: https://upstash.com/docs/redis/sdks/py/commands/stream/xgroup_delconsumer
# отримано: 2026-10-16

> Delete a consumer from a consumer group.

## Arguments

-  (str, required)
  The key of the stream.

  -  (str, required)
    The consumer group name.

    -  (str, required)
      The consumer name to delete.

      ## Response

      -  (int)
        Returns the number of pending messages the consumer had.

```py
result = redis.xgroup_delconsumer("mystream", "mygroup", "consumer1")
```
