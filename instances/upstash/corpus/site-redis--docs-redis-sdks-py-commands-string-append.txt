# Redis: APPEND
# джерело: https://upstash.com/docs/redis/sdks/py/commands/string/append
# отримано: 2026-10-16

> Append a value to a string stored at key.

## Arguments

-  (str, required)
  The key to get.

  -  (required)
    The value to append.

    ## Response

    -  (int, required)
      How many characters were added to the string.

```py
redis.set("key", "Hello")

assert redis.append("key", " World") == 11

assert redis.get("key") == "Hello World"
```
