# Redis: GET
# джерело: https://upstash.com/docs/redis/sdks/py/commands/string/get
# отримано: 2026-10-16

> Return the value of the specified key or `None` if the key doesn't exist.

## Arguments

-  (str, required)
  The key to get.

  ## Response

  -  (required)
    The response is the value stored at the key or `None` if the key doesn't exist.

```py
redis.set("key", "value")

assert redis.get("key") == "value"
```
