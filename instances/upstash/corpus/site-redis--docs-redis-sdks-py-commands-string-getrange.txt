# Redis: GETRANGE
# джерело: https://upstash.com/docs/redis/sdks/py/commands/string/getrange
# отримано: 2026-10-16

> Return a substring of value at the specified key.

## Arguments

-  (str, required)
  The key to get.

  -  (int, required)
    The start index of the substring.

    -  (int, required)
      The end index of the substring.

      ## Response

      -  (str, required)
        The substring.

```py
redis.set("key", "Hello World")

assert redis.getrange("key", 0, 4) == "Hello"
```
