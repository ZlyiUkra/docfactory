# Redis: MSET
# джерело: https://upstash.com/docs/redis/sdks/py/commands/string/mset
# отримано: 2026-10-16

> Set multiple keys in one go.

For billing purposes, this counts as a single command.

## Arguments

-  (Dict[str, Any], required)
  An object where the keys are the keys to set, and the values are the values to set.

  ## Response

  -  (bool, required)
    `True` if the operation succeeded.

```py
redis.mset({
  "key1": "value1",
  "key2": "value2"
})
```
