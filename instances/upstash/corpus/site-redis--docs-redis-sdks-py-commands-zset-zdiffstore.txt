# Redis: ZDIFFSTORE
# джерело: https://upstash.com/docs/redis/sdks/py/commands/zset/zdiffstore
# отримано: 2026-10-16

> Writes the difference between sets to a new key.

## Arguments

-  (str, required)
  The key to write the difference to.

  -  (List[str], required)
    The keys to compare.

    ## Response

    -  (int)
      The number of elements in the resulting set.

```py
redis.zadd("key1", {"a": 1, "b": 2, "c": 3})

redis.zadd("key2", {"c": 3, "d": 4, "e": 5})

# a and b
assert redis.zdiffstore("dest", ["key1", "key2"]) == 2
```
