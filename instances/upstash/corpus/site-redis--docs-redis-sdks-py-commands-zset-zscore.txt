# Redis: ZSCORE
# джерело: https://upstash.com/docs/redis/sdks/py/commands/zset/zscore
# отримано: 2026-10-16

> Returns the scores of a member.

## Arguments

-  (str, required)
  The key to get.

  ## Response

  -  (TMember, required)
    A member of the sortedset.

```py
redis.zadd("myset", {"a": 1, "b": 2, "c": 3})

assert redis.zscore("myset", "a") == 1
```
