# Redis: ARCOUNT
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/array/arcount
# отримано: 2026-10-16

> Count the occupied slots in an array.

For sparse arrays, this differs from ARLEN, which returns the highest occupied index plus one.

## Arguments

-  (string, required)
  The array key.

  ## Response

  -  (number, required)
    The number of slots containing values, or zero for a missing key.

```ts
await redis.arset("readings", 1000, "sample");
console.log(await redis.arcount("readings")); // 1
console.log(await redis.arlen("readings")); // "1001"
```

  See the server command reference for protocol details.
