# Redis: PING
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/auth/ping
# отримано: 2026-10-16

> Send a ping to the server and get a response if the server is alive.

## Arguments

No arguments

## Response

-  (string, required)
  `PONG`

```ts
const response = await redis.ping();
console.log(response); // "PONG"
```
