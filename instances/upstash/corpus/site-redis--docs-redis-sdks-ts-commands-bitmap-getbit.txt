# Redis: GETBIT
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/bitmap/getbit
# отримано: 2026-10-16

> Retrieve a single bit.

## Arguments

-  (string, required)
  The key of the bitset

  -  (integer, required)
    Specify the offset at which to get the bit.

    ## Response

    -  (integer, required)
      The bit value stored at offset.

```ts
const bit = await redis.getbit(key, 4);
```
