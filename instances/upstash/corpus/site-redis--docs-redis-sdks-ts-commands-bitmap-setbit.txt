# Redis: SETBIT
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/bitmap/setbit
# отримано: 2026-10-16

> Set a single bit in a string.

## Arguments

-  (string, required)
  The key of the bitset

  -  (integer, required)
    Specify the offset at which to set the bit.

    -  (0 | 1, required)
      The bit to set

      ## Response

      -  (0 | 1, required)
        The original bit value stored at offset.

```ts
const originalBit = await redis.setbit(key, 4, 1);
```
