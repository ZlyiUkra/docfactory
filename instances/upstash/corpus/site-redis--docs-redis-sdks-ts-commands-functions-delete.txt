# Redis: FUNCTION DELETE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/functions/delete
# отримано: 2026-10-16

> Delete a library and all its functions.

## Arguments

-  (string, required)
  The name of the library to delete.

  ## Response

  -  (string, required)
    "OK"

```ts
await redis.functions.delete("mylib")
```
