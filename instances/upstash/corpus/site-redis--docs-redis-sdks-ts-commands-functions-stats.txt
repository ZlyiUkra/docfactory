# Redis: FUNCTION STATS
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/functions/stats
# отримано: 2026-10-16

> Return information about the function running engine.

## Response

-  (Object, required)
  Stats about the engines and functions.

Note:
  Currently, `LUA` is the only supported engine.

  -  (Object)

    -  (Object)

      -  (number)
        The number of libraries.

        -  (number)
          The number of functions.

```ts
const stats = await redis.functions.stats()

console.log(stats)
// {
//   engines: {
//     LUA: {
//       librariesCount: 3,
//       functionsCount: 15
//     }
//   }
// }
```
