# Redis: PERSIST
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/persist
# отримано: 2026-10-16

> Remove any timeout set on the key.

## Arguments

-  (string, required)
  The key to persist

  ## Response

  -  (integer, required)
    `1` if the timeout was removed, `0` if `key` does not exist or does not have an associated timeout.

```ts
await redis.persist(key);
```
