# Redis: PEXPIRE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/pexpire
# отримано: 2026-10-16

> Sets a timeout on key. After the timeout has expired, the key will automatically be deleted.

## Arguments

-  (string, required)
  The key to expire.

  -  (integer)
    The number of milliseconds until the key expires.

    ## Response

    -  (integer, required)
      `1` if the timeout was applied, `0` if `key` does not exist.

```ts
 await redis.pexpire(key, 60_000); // 1 minute
```
