# Redis: RANDOMKEY
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/randomkey
# отримано: 2026-10-16

> Returns a random key from database

## Arguments

No arguments

## Response

-  (string, required)
  A random key from database, or `null` when database is empty.

```ts
const key = await redis.randomkey();
```
