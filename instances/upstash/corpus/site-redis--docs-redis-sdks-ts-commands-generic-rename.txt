# Redis: RENAME
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/rename
# отримано: 2026-10-16

> Rename a key

## Arguments

-  (string, required)
  The original key.

  -  (string, required)
    A new name for the key.

    ## Response

    -  (string, required)
      `OK`

```ts
 await redis.rename("old", "new");
```
