# Redis: RENAMENX
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/renamenx
# отримано: 2026-10-16

> Rename a key if it does not already exist.

## Arguments

-  (string, required)
  The original key.

  -  (string, required)
    A new name for the key.

    ## Response

    -  (0 | 1, required)
      `1` if key was renamed, `0` if key was not renamed.

```ts
const renamed = await redis.renamenx("old", "new");
```
