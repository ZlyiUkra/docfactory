# Redis: TOUCH
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/touch
# отримано: 2026-10-16

> Alters the last access time of one or more keys

## Arguments

-  (...string[], required)
  One or more keys.

  ## Response

  -  (integer, required)
    The number of keys that were touched.

```ts
await redis.touch("key1", "key2", "key3");
```
