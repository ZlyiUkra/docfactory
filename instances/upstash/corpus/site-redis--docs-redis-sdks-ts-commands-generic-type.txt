# Redis: TYPE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/generic/type
# отримано: 2026-10-16

> Get the type of a key.

## Arguments

-  (string, required)
  The key to get.

  ## Response

  -  (string, required)
    The type of the key.

    One of `string` | `list` | `set` | `zset` | `hash` | `none`

```ts
await redis.set("key", "value");
const t = await redis.type("key");
console.log(t) // "string"
```
