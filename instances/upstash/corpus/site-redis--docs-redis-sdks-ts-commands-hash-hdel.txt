# Redis: HDEL
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hdel
# отримано: 2026-10-16

> Deletes one or more hash fields.

## Arguments

-  (string, required)
  The key to get.

  -  (required)
    One or more fields to delete.

    ## Response

    -  (integer, required)
      The number of fields that were removed from the hash.

```ts
await redis.hdel(key, 'field1', 'field2');
// returns 5
```
