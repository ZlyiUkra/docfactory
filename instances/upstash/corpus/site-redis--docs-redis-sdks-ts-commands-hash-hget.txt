# Redis: HGET
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hget
# отримано: 2026-10-16

> Retrieves the value of a hash field.

## Arguments

-  (string, required)
  The key to get.

  -  (string, required)
    The field to get.

    ## Response

    -  (TValue | null, required)
      The value of the field, or `null`, when field is not present in the hash or key does not exist.

```ts
await redis.hset("key", {field: "value"});
const field = await redis.hget("key", "field");
console.log(field); // "value"
```
