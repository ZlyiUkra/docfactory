# Redis: HGETALL
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hgetall
# отримано: 2026-10-16

> Retrieves all fields from a hash.

## Arguments

-  (string, required)
  The key to get.

  ## Response

  -  (TValue | null, required)
    An object with all fields in the hash.

```ts
await redis.hset("key", {
  field1: "value1",
  field2: "value2",
  });
const hash = await redis.hgetall("key");
console.log(hash); // { field1: "value1", field2: "value2" }
```
