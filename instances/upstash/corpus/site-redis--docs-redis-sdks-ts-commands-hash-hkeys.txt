# Redis: HKEYS
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hkeys
# отримано: 2026-10-16

> Return all field names in the hash stored at key.

## Arguments

-  (string, required)
  The key of the hash.

  ## Response

  -  (string[], required)
    The field names of the hash

```ts
await redis.hset("key", {
  id: 1,
  username: "chronark",
  });
const fields = await redis.hkeys("key");
console.log(fields); // ["id", "username"]
```
