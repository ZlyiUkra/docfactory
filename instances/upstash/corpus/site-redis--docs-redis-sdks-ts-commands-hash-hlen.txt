# Redis: HLEN
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hlen
# отримано: 2026-10-16

> Returns the number of fields contained in the hash stored at key.

## Arguments

-  (string, required)
  The key of the hash.

  ## Response

  -  (integer, required)
    How many fields are in the hash.

```ts
await redis.hset("key", {
  id: 1,
  username: "chronark",
  });
const fields = await redis.hlen("key");
console.log(fields); // 2
```
