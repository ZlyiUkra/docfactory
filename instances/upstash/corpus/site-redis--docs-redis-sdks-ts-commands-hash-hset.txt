# Redis: HSET
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hset
# отримано: 2026-10-16

> Write one or more fields to a hash.

## Arguments

-  (string, required)
  The key of the hash.

  -  ({ [fieldName]: TValue }, required)
    An object of fields and their values.

    ## Response

    -  (integer, required)
      The number of fields that were added.

```ts
await redis.hset("key", {
  id: 1,
  username: "chronark",
  name: "andreas"
  });
```
