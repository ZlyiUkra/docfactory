# Redis: HSETNX
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hsetnx
# отримано: 2026-10-16

> Write a field to a hash but only if the field does not exist.

## Arguments

-  (string, required)
  The key of the hash.

  -  (string, required)
    The name of the field.

    -  (TValue, required)
      Any value, if it's not a string it will be serialized to JSON.

      ## Response

      -  (integer, required)
        `1` if the field was set, `0` if it already existed.

```ts
await redis.hsetnx("key", "id", 1)
```
