# Redis: HSTRLEN
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/hash/hstrlen
# отримано: 2026-10-16

> Returns the string length of a value in a hash.

## Arguments

-  (string, required)
  The key of the hash.

  -  (string, required)
    The name of the field.

    ## Response

    -  (integer, required)
      `0` if the hash or field does not exist. Otherwise the length of the string.

```ts
const length = await redis.hstrlen("key", "field")
```
