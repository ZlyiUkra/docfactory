# Redis: JSON.ARRINDEX
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/arrindex
# отримано: 2026-10-16

> Search for the first occurrence of a JSON value in an array.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path of the array. `$` is the root.

    -  (TValue, required)
      The value to search for.

      -  (integer)
        The start index.

        -  (integer)
          The stop index.

          ## Response

          -  (integer[], required)
            The index of the first occurrence of the value in the array, or -1 if not found.

```ts
const index = await redis.json.arrindex("key", "$.path.to.array", "a");
```
