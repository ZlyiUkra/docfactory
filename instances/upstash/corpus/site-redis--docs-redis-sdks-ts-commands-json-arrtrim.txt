# Redis: JSON.ARRTRIM
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/arrtrim
# отримано: 2026-10-16

> Trim an array so that it contains only the specified inclusive range of elements.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path of the array. `$` is the root.

    -  (integer, required)
      The start index of the range.

      -  (integer, required)
        The stop index of the range.

        ## Response

        -  (integer[], required)
          The length of the array after the trimming.

```ts
const length = await redis.json.arrtrim("key", "$.path.to.array", 2, 10);
```
