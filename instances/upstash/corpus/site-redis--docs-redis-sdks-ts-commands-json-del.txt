# Redis: JSON.DEL
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/del
# отримано: 2026-10-16

> Delete a key from a JSON document.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path to delete. `$` is the root.

    ## Response

    -  (integer, required)
      How many paths were deleted.

```ts
await redis.json.del("key", "$.path.to.value");
```
