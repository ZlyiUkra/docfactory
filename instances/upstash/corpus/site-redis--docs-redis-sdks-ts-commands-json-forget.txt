# Redis: JSON.FORGET
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/forget
# отримано: 2026-10-16

> Delete a key from a JSON document.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path to forget. `$` is the root.

    ## Response

    -  (integer, required)
      How many paths were deleted.

```ts
await redis.json.forget("key", "$.path.to.value");
```
