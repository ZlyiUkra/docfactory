# Redis: JSON.MERGE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/merge
# отримано: 2026-10-16

> Merges the JSON value at path in key with the provided value.

## Arguments

-  (str, required)
  The key of the json entry.

  -  (str, required)
    The path of the value to set.

    <ParamField body="value" type="string | number | Record<string, unknown> | Array" required>
    The value to merge with.

    ## Response

    -  (string, required)
      Returns "OK" if the merge was successful.

```ts
await redis.json.merge("key", "$.path.to.value", {"new": "value"})
```
