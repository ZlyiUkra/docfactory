# Redis: JSON.NUMMULTBY
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/nummultby
# отримано: 2026-10-16

> Multiply the number value stored at `path` by number.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path of the array. `$` is the root.

    -  (number, required)
      The number to multiply by.

      ## Response

      -  (integer[], required)
        The new value after multiplying

```ts
const newValue = await redis.json.nummultby("key", "$.path.to.value", 2);
```
