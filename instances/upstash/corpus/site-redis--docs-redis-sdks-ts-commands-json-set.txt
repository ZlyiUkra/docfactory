# Redis: JSON.SET
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/json/set
# отримано: 2026-10-16

> Set the JSON value at path in key.

## Arguments

-  (string, required)
  The key of the json entry.

  -  (string, required)
    The path of the value to set. `$` is the root.

    -  (TValue, required)
      The value to set.

      ## Response

      -  (OK, required)
        `OK`

```ts
Set the JSON value at path in key.
redis.json.set(key, "$.path", value);
```

```ts
const value = ...
redis.json.set(key, "$.path", value, { nx:true });
```
```ts
const value = ...
redis.json.set(key, "$.path", value, { xx:true });
```
