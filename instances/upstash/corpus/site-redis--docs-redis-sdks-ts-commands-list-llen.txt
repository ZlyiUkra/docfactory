# Redis: LLEN
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/list/llen
# отримано: 2026-10-16

> Returns the length of the list stored at key.

## Arguments

-  (string, required)
  The key of the list.

  ## Response

  -  (number, required)
    The length of the list at key.

```ts
await redis.rpush("key", "a", "b", "c");
const length = await redis.llen("key");
console.log(length); // 3
```
