# Redis: LREM
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/list/lrem
# отримано: 2026-10-16

> Remove the first `count` occurrences of an element from a list.

## Arguments

-  (string, required)
  The key of the list.

  -  (number, required)
    How many occurrences of the element to remove.

    -  (TValue, required)
      The element to remove

      ## Response

      -  (integer, required)
        The number of elements removed.

```ts
await redis.lpush("key", "a", "a", "b", "b", "c");
const removed = await redis.lrem("key", 4, "b");
console.log(removed) // 2
```
