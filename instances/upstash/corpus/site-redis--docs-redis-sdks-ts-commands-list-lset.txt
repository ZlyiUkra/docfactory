# Redis: LSET
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/list/lset
# отримано: 2026-10-16

> Set a value at a specific index.

## Arguments

-  (string, required)
  The key of the list.

  -  (number, required)
    At which index to set the value.

    -  (TValue, required)
      The value to set.

      ## Response

      -  (OK, required)
        `OK`

```ts
await redis.lpush("key", "a", "b", "c");
await redis.lset("key", 1, "d");

// list is now ["a", "d", "c"]
```
