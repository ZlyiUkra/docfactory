# Redis: LTRIM
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/list/ltrim
# отримано: 2026-10-16

> Trim a list to the specified range

## Arguments

-  (string, required)
  The key of the list.

  -  (number, required)
    The index of the first element to keep.

    -  (TValue, required)
      The index of the first element to keep.

      ## Response

      -  (OK, required)
        `OK`

```ts
await redis.lpush("key", "a", "b", "c", "d");
await redis.ltrim("key", 1, 2);
// the list is now ["b", "c"]
```
