# Redis: EVAL_RO
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/scripts/eval_ro
# отримано: 2026-10-16

> Evaluate a read-only Lua script server side.

## Arguments

-  (string, required)
  The read-only lua script to run.

  -  (string[], required)
    All of the keys accessed in the script

    -  (unknown[], required)
      All of the arguments you passed to the script

      ## Response

      -  (any, required)
        The result of the script.

```ts
const script = `
    return ARGV[1]
`
const result = await redis.evalRo(script, [], ["hello"]);
console.log(result) // "hello"

```
