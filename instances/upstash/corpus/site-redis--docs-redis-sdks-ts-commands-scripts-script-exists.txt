# Redis: SCRIPT EXISTS
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/scripts/script_exists
# отримано: 2026-10-16

> Check if scripts exist in the script cache.

## Arguments

-  (string[], required)
  The sha1 of the scripts to check.

  ## Response

  -  (number[], required)
    An array of numbers. `1` if the script exists, otherwise `0`.

```ts
await redis.scriptExists("<sha1>", "<sha2>")

// Returns 1
// [1, 0]
```
