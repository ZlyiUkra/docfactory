# Redis: SCRIPT FLUSH
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/scripts/script_flush
# отримано: 2026-10-16

> Removes all scripts from the script cache.

## Arguments

-  (Object)

  -  (boolean)
    Performs the flush asynchronously.

    -  (boolean)
      Performs the flush synchronously.

```ts
await redis.scriptFlush();
```

```ts
await redis.scriptFlush({
  async: true,
});
```
