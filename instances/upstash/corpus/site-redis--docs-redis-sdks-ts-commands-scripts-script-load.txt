# Redis: SCRIPT LOAD
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/scripts/script_load
# отримано: 2026-10-16

> Load the specified Lua script into the script cache.

## Arguments

-  (string, required)
  The script to load.

  ## Response

  -  (string, required)
    The sha1 of the script.

```ts
const script = `
  local value = redis.call('GET', KEYS[1])
  return value
`;
const sha1 = await redis.scriptLoad(script);

```
