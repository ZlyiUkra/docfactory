# Redis: DBSIZE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/server/dbsize
# отримано: 2026-10-16

> Count the number of keys in the database.

## Arguments

This command has no arguments

## Response

-  (integer, required)
  The number of keys in the database

```ts
const keys = await redis.dbsize();
console.log(keys) // 20
```
