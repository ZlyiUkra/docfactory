# Redis: FLUSHDB
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/server/flushdb
# отримано: 2026-10-16

Warning:
Deletes all keys permanently. Use with caution!

## Arguments

-  (boolean)
  Whether to perform the operation asynchronously.
  Defaults to synchronous.

```ts
await redis.flushdb();
```
```ts
await redis.flushdb({async: true})
```
