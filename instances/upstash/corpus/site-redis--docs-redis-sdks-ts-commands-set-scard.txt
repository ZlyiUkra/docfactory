# Redis: SCARD
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/set/scard
# отримано: 2026-10-16

> Return how many members are in a set

## Arguments

-  (string, required)
  The key of the set.

  ## Response

  -  (number, required)
    How many members are in the set.

```ts
await redis.sadd("key", "a", "b", "c");
const cardinality = await redis.scard("key");
console.log(cardinality); // 3
```
