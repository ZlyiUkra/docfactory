# Redis: SMEMBERS
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/set/smembers
# отримано: 2026-10-16

> Return all the members of a set

## Arguments

-  (string, required)
  The key of the set.

  ## Response

  -  (TMember[], required)
    The members of the set.

```ts
await redis.sadd("set", "a", "b", "c");
const members =  await redis.smembers("set");
console.log(members); // ["a", "b", "c"]
```
