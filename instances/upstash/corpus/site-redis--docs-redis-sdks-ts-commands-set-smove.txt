# Redis: SMOVE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/set/smove
# отримано: 2026-10-16

> Move a member from one set to another

## Arguments

-  (string, required)
  The key of the set to move the member from.

  -  (string, required)
    The key of the set to move the member to.

    -  (TMember)
      The members to move

      ## Response

      -  (0 | 1, required)
        `1` if the member was moved, `0` if not.

```ts
await redis.sadd("original", "a", "b", "c");
const moved =  await redis.smove("original", "destination", "a");
// moved:       1
// original:    ["b", "c"]
// destination: ["a"]
```
