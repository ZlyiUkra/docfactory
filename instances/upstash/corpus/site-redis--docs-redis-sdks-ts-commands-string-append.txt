# Redis: APPEND
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/string/append
# отримано: 2026-10-16

> Append a value to a string stored at key.

## Arguments

-  (string, required)
  The key to get.

  -  (required)
    The value to append.

    ## Response

    -  (integer, required)
      How many characters were added to the string.

```ts
await redis.append(key, "Hello");
// returns 5
```
