# Redis: GETRANGE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/string/getrange
# отримано: 2026-10-16

> Return a substring of value at the specified key.

## Arguments

-  (string, required)
  The key to get.

  -  (integer, required)
    The start index of the substring.

    -  (integer, required)
      The end index of the substring.

      ## Response

      -  (string, required)
        The substring.

```ts
const substring = await redis.getrange("key", 2, 4);
```
