# Redis: ZCARD
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zcard
# отримано: 2026-10-16

> Returns the number of elements in the sorted set stored at key.

## Arguments

-  (string, required)
  The key to get.

  ## Response

  -  (integer, required)
    The number of elements in the sorted set.

```ts

await redis.zadd("key",
    { score: 1, member: "one"},
    { score: 2, member: "two" },
);
const elements = await redis.zcard("key");
console.log(elements); // 2
```
