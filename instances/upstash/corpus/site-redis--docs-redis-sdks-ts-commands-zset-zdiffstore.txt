# Redis: ZDIFFSTORE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zdiffstore
# отримано: 2026-10-16

> Writes the difference between sets to a new key.

## Arguments

-  (string, required)
  The key to write the difference to.

  -  (integer, required)
    How many keys to compare.

    -  (...string[], required)
      The keys to compare.

      ## Response

      -  (required)
        The number of elements in the resulting set.

```ts
const values = await redis.zdiffstore("destination", 2, "key1", "key2");
```
