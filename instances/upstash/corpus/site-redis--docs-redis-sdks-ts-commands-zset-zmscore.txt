# Redis: ZMSCORE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zmscore
# отримано: 2026-10-16

> Returns the scores of multiple members.

## Arguments

-  (string, required)
  The key to get.

  ## Response

  -  (TMember[], required)
    The members of the sorted set.

```ts

await redis.zadd("key",
    { score: 1, member: "m1" },
    { score: 2, member: "m2" },
    { score: 3, member: "m3" },
    { score: 4, member: "m4" },
)

const scores = await redis.zmscore("key", ["m2", "m4"])
console.log(scores) // [2, 4]
```
