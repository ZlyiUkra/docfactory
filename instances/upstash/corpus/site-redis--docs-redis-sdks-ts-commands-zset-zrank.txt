# Redis: ZRANK
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zrank
# отримано: 2026-10-16

> Returns the rank of a member

## Arguments

-  (string, required)
  The key to get.

  -  (TMember, required)
    The member to get the rank of.

    ## Response

    -  (integer, required)
      The rank of the member.

```ts
const rank = await redis.rank("key", "member");
```
