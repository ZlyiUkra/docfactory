# Redis: ZSCORE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zscore
# отримано: 2026-10-16

> Returns the scores of a member.

## Arguments

-  (string, required)
  The key to get.

  ## Response

  -  (TMember, required)
    A member of the sortedset.

```ts

await redis.zadd("key",
    { score: 1, member: "m1" },
    { score: 2, member: "m2" },
    { score: 3, member: "m3" },
    { score: 4, member: "m4" },
)

const score = await redis.zscore("key", "m2")
console.log(score) // 2
```
