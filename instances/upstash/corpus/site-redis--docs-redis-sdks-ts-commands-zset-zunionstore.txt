# Redis: ZUNIONSTORE
# джерело: https://upstash.com/docs/redis/sdks/ts/commands/zset/zunionstore
# отримано: 2026-10-16

> Writes the union between sets to a new key.

## Arguments

-  (string, required)
  The key to write the union to.

  -  (integer, required)
    How many keys to compare.

    -  (string | string[], required)
      The keys to compare.

      -

        -  (sum | min | max)
          The aggregation method.

          -  (number)
            The weight to apply to each key.

            -  (number[])
              The weights to apply to each key.

              ## Response

              -  (required)
                The number of elements in the resulting set.

```ts
await redis.zadd(
    "key1",
    { score: 1, member: "member1" },
)
await redis.zadd(
    "key2",
    { score: 1, member: "member1" },
    { score: 2, member: "member2" },
)

const res = await redis.zunionstore("destination", 2, ["key1", "key2"]);
console.log(res) // 2
```

