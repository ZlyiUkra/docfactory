# Workflow: Get Flow Control Key
# джерело: https://upstash.com/docs/workflow/api-reference/flow-control/get-flow-control-key
# отримано: 2026-10-16

> Get details of a specific Flow Control key

`GET /v2/flowControl/{flowControlKey}`

## Request

`GET https://qstash-{region}.upstash.io/v2/flowControl/{flowControlKey}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `flowControlKey` (path, string, required)
  The Flow Control key to retrieve

## Response

**200** — Flow control key details

- `flowControlKey` (string)
  The flow control key name

- `waitlistSize` (integer)
  The number of messages waiting due to flow control configuration.

**404** — Flow Control key not found

- `error` (string, required)
  Error message
