# Workflow: List Flow Control Keys
# джерело: https://upstash.com/docs/workflow/api-reference/flow-control/list-flow-control-keys
# отримано: 2026-10-16

> List all Flow Control keys

`GET /v2/flowControl`

## Request

`GET https://qstash-{region}.upstash.io/v2/flowControl`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

## Response

**200** — Flow control keys retrieved successfully
