# Workflow: Resume Flow Control Key
# джерело: https://upstash.com/docs/workflow/api-reference/flow-control/resume-flow-control-key
# отримано: 2026-10-16

> Resumes the delivery of messages associated with a specific flow-control key.

`POST /v2/flowControl/{flowControlKey}/resume`

When a flow-control key is resumed, messages associated with that key will begin to be delivered again.

## Request

`POST https://qstash-{region}.upstash.io/v2/flowControl/{flowControlKey}/resume`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `flowControlKey` (path, string, required)
  The flow-control key to resume.

## Response

**200** — The flow-control key has been resumed.

**400** — Bad request. Returned when the flow-control key is not provided.

- `error` (string, required)
  Error message
