# Workflow: List Waiters
# джерело: https://upstash.com/docs/workflow/api-reference/notify/list-waiters
# отримано: 2026-10-16

> List all active waiters for a specific event ID.

Returns information about all workflow runs that are currently waiting for the specified event.

`GET /v2/waiters/{eventId}`

## Request

`GET https://qstash-{region}.upstash.io/v2/waiters/{eventId}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `eventId` (path, string, required)
  The event ID to list waiters for.

## Response

**200** — List of active waiters

**400** — Bad Request - Invalid event ID

- `error` (string, required)
  Error message

**401** — Unauthorized

- `error` (string, required)
  Error message

**500** — Internal Server Error

- `error` (string, required)
  Error message
