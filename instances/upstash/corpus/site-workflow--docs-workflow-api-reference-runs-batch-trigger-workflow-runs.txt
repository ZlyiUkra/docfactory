# Workflow: Batch Trigger Workflow Runs
# джерело: https://upstash.com/docs/workflow/api-reference/runs/batch-trigger-workflow-runs
# отримано: 2026-10-16

> Start multiple workflow runs in a single request.

`POST /v2/batch/trigger`

## Request

`POST https://qstash-{region}.upstash.io/v2/batch/trigger`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Request body** (`application/json`)

## Response

**201** — Workflow runs triggered successfully

**400** — Bad Request

- `error` (string, required)
  Error message

**401** — Unauthorized

- `error` (string, required)
  Error message

**500** — Internal Server Error

- `error` (string, required)
  Error message
