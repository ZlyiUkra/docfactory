# Workflow: Cancel Workflow Run
# джерело: https://upstash.com/docs/workflow/api-reference/runs/cancel-workflow-run
# отримано: 2026-10-16

> Cancel an ongoing workflow run.

`DELETE /v2/workflows/runs/{workflowRunId}`

## Request

`DELETE https://qstash-{region}.upstash.io/v2/workflows/runs/{workflowRunId}`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

**Parameters**

- `workflowRunId` (path, string, required)
  The ID of the workflow run to cancel.

## Response

**200** — Workflow run cancelled successfully

**404** — A workflow run is not found with the given id.

**500** — An unexpected error occured.
