# Workflow: Get Signing Keys
# джерело: https://upstash.com/docs/workflow/api-reference/signing-keys/get-signing-keys
# отримано: 2026-10-16

> Retrieve your current and next signing keys

`GET /v2/keys`

## Request

`GET https://qstash-{region}.upstash.io/v2/keys`

Authentication: `bearerAuth`, `bearerAuthQuery` headers.

## Response

**200** — Signing keys retrieved successfully

- `current` (string)
  The current signing key.

- `next` (string)
  The next signing key.
