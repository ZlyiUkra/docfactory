# отримано: 2026-10-16

This MCP server needs your Upstash account email and an API key.

1. Sign in to the Upstash Console
2. Create an API key under Account → API Keys
3. Add both to your settings below

Readonly API keys work — the server then disables every tool that would change
state, so the agent can still read your account but not modify it. Upstash Box
tools are unavailable with a readonly key.
