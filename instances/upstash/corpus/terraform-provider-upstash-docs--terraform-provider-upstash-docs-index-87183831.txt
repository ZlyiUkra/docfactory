## Example Usage

```terraform
provider "upstash" {
  email = "FILL_HERE"
  api_key  = "FILL_HERE"
}
```

## Authenticate the Provider

The Upstash provider requires `email` and `api_key` in order to authenticate.
Email is your email address while registering Upstash.
API KEY can be generated from the Upstash Console.
Plese see our API KEY documentation.

## Schema

### Required

- **api_key** (String, Sensitive)
- **email** (String)
