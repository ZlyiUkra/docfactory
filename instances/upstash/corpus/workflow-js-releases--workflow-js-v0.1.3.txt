Tag v0.1.3, published 2024-11-12.

## What's Changed

Features:
* Allow string duration such as `1d` or `30s` in `context.sleep` & `context.waitForEvent` by @fahreddinozcan in https://github.com/upstash/workflow-js/pull/12
* Integrations for Astro and Express by @fahreddinozcan in https://github.com/upstash/workflow-js/pull/13 and https://github.com/upstash/workflow-js/pull/14
* Add `client.trigger` to make it possible to start workflows and get the workflow run id by @CahidArda in https://github.com/upstash/workflow-js/pull/18
* Add `context.call` retry option by @CahidArda in https://github.com/upstash/workflow-js/pull/19
* Add CI tests by @CahidArda in https://github.com/upstash/workflow-js/pull/21

Fixes:
* Sort steps with .sort instead of .toSorted to allow Node18 by @CahidArda in https://github.com/upstash/workflow-js/pull/17
* Add bootstrap script and fix examples by @CahidArda in https://github.com/upstash/workflow-js/pull/15
