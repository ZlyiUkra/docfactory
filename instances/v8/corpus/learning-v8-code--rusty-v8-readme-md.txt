## rusty-v8 example

This directory contains an example that uses
rusty-v8 which is V8 Rust binding which
is used in Deno.

It tries to reproduce hello-world.cc but uses rusty-v8.

### Building

```console
$ cargo build
```

### Run

```console
$ cargo run
```
