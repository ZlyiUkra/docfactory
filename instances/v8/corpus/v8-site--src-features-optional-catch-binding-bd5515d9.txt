# Optional `catch` binding
# джерело: https://github.com/v8/v8.dev/blob/9d6ee9c6b56a167300db5cfec28d806ce99aa39b/src/features/optional-catch-binding.md
# отримано: 2026-09-29
# версія: 8.0, 2020, 7.9, 7.8, 2019, 7.7, 7.6

The `catch` clause of `try` statements used to require a binding:

```js
try {
  doSomethingThatMightThrow();
} catch (exception) {
  //     ^^^^^^^^^
  // We must name the binding, even if we don’t use it!
  handleException();
}
```

In ES2019, `catch` can now be used without a parameter. This is useful if you don’t have a need for the `exception` object in the code that handles the exception.

```js
try {
  doSomethingThatMightThrow();
} catch { // → No binding!
  handleException();
}
```
