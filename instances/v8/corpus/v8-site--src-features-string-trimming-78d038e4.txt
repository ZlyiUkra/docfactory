# `String.prototype.trimStart` and `String.prototype.trimEnd`
# джерело: https://github.com/v8/v8.dev/blob/9d6ee9c6b56a167300db5cfec28d806ce99aa39b/src/features/string-trimming.md
# отримано: 2026-09-29
# версія: 8.0, 2020, 7.9, 7.8, 2019, 7.7, 7.6

ES2019 introduces `String.prototype.trimStart()` and `String.prototype.trimEnd()`:

```js
const string = '  hello world  ';
string.trimStart();
// → 'hello world  '
string.trimEnd();
// → '  hello world'
string.trim(); // ES5
// → 'hello world'
```

This functionality was previously available through the non-standard `trimLeft()` and `trimRight()` methods, which remain as aliases of the new methods for backward compatibility.

```js
const string = '  hello world  ';
string.trimStart();
// → 'hello world  '
string.trimLeft();
// → 'hello world  '
string.trimEnd();
// → '  hello world'
string.trimRight();
// → '  hello world'
string.trim(); // ES5
// → 'hello world'
```
