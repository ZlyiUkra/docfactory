# `String.prototype.trimStart` and `String.prototype.trimEnd`
# джерело: https://github.com/v8/v8.dev/blob/c4c5bc336cc1f00ec14a05a93dd371c29cfe4bc6/src/features/string-trimming.md
# отримано: 2026-09-29
# версія: 9.1, 2021, 9.0, 8.9, 8.8, 8.7, 8.6, 2020, 8.5, 8.4, 8.3, 8.1

ES2019 introduces `String.prototype.trimStart()` and `String.prototype.trimEnd()`:

```js
const string = '  hello world  ';
string.trimStart();
// → 'hello world  '
string.trimEnd();
// → '  hello world'
string.trim(); // ES5
// → 'hello world'
```

This functionality was previously available through the non-standard `trimLeft()` and `trimRight()` methods, which remain as aliases of the new methods for backward compatibility.

```js
const string = '  hello world  ';
string.trimStart();
// → 'hello world  '
string.trimLeft();
// → 'hello world  '
string.trimEnd();
// → '  hello world'
string.trimRight();
// → '  hello world'
string.trim(); // ES5
// → 'hello world'
```
