Return the full text of one excerpt of the V8 site v8.dev or of the learning-v8 notes and
code by its identifier, together with the document it belongs to, every V8 version and year
whose site contained this text (none for learning-v8), the URL
it was taken from and the date the text was fetched from that URL -- so a quotation can be
checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut at 600 characters, or
when the exact wording matters -- a d8 or gn command line, a V8 flag, a compiler tier's
behaviour, a benchmark number or a code example quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not API names and cannot be assembled by hand.
Every identifier this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the site is written. Answer the user in their own
language, and follow the same rules as for `search_docs`: keep identifiers, flags and titles
in English, use Ukrainian words for Ukrainian prose, and name the version and the document
you read.
