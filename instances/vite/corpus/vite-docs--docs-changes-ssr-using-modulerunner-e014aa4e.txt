# SSR using `ModuleRunner` API
# джерело: https://github.com/vitejs/vite/blob/v6.0.0-alpha.23/docs/changes/ssr-using-modulerunner.md
# отримано: 2026-10-01
# версія: 6.0.0-alpha.23, 6.0.0-alpha.22, 6.0.0-alpha.21, 6.0.0-alpha.20

::: tip Feedback
Give us feedback at Environment API feedback discussion
:::

`server.ssrLoadModule` has been replaced by Module Runner.

Affect scope: `Vite Plugin Authors`

::: warning Future Deprecation
`ModuleRunner` was first introduce in `v6.0`. The deprecation of `server.ssrLoadModule` is planned for a future major. To identify your usage, set `future.deprecationWarnings.ssrLoadModule` to `true` in your vite config.
:::
