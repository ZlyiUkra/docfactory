# отримано: 2026-10-01
# версія: 8.0.0, 8.0.0-beta.18, 8.0.0-beta.17, 8.0.0-beta.16, 8.0.0-beta.15, 8.0.0-beta.14, 8.0.0-beta.13, 8.0.0-beta.12, 8.0.0-beta.11, 8.0.0-beta.10, 8.0.0-beta.9, 8.0.0-beta.8

Unless noted, the options in this section are applied to all dev, build, and preview.

## worker.format

- **Type:** `'es' | 'iife'`
- **Default:** `'iife'`

Output format for worker bundle.

## worker.plugins

- **Type:** [`() => (Plugin | Plugin[])[]`](./shared-options#plugins)

Vite plugins that apply to the worker bundles. Note that config.plugins only applies to workers in dev, it should be configured here instead for build.
The function should return new plugin instances as they are used in parallel rollup worker builds. As such, modifying `config.worker` options in the `config` hook will be ignored.

## worker.rolldownOptions

- **Type:** `RolldownOptions`

Rollup options to build worker bundle.

## worker.rollupOptions

- **Type:** `RolldownOptions`
- **Deprecated**

This option is an alias of `worker.rolldownOptions` option. Use `worker.rolldownOptions` option instead.
