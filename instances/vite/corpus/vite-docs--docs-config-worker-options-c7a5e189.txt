# Worker Options
# джерело: https://github.com/vitejs/vite/blob/v4.1.0-beta.1/docs/config/worker-options.md
# отримано: 2026-10-01
# версія: 4.1.0-beta.1

Options related to Web Workers.

## worker.format

- **Type:** `'es' | 'iife'`
- **Default:** `iife`

Output format for worker bundle.

## worker.plugins

- **Type:** [`(Plugin | Plugin[])[]`](./shared-options#plugins)

Vite plugins that apply to worker bundle. Note that config.plugins does not apply to workers, it should be configured here instead.

## worker.rollupOptions

- **Type:** `RollupOptions`

Rollup options to build worker bundle.
