## Official Plugins

### @vitejs/plugin-vue

- Provides Vue 3 Single File Components support.

### @vitejs/plugin-vue-jsx

- Provides Vue 3 JSX support (via dedicated Babel transform).

### @vitejs/plugin-react-refresh

- Provides React Fast Refresh Support.
