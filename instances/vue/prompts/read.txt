Return the full text of one excerpt of the Vue documentation by its identifier, together with the document it
belongs to, every version whose documents contain this text, the URL it was taken from and the date the text
was fetched from that URL -- so a quotation can be checked against the source even a year later.

Call this after `search_docs` when the excerpt you need came back cut (`truncated: true`), or when the exact
wording matters -- an API signature and its options, a default value, a component's props, a deprecation and
its replacement, a migration step or a code example quoted half-way is how a wrong answer starts.

Do not guess identifiers: they are not URLs, not API names and cannot be assembled by hand. Every identifier
this tool accepts comes from the `id` field of a `search_docs` result.

The text comes back in English, as the documentation is written. Answer the user in their own language; keep
identifiers and titles in English, and name the version and the document you read.
