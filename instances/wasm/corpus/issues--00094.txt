# WebAssembly spec issue #94: Filename extension for S-expression test files
# джерело: https://github.com/WebAssembly/spec/issues/94
# отримано: 2026-09-30

Issue #94, opened by sunfishcode on 2015-09-30, closed (completed) on 2015-10-01.

The test files in ml-proto/test were originally name with a '.wasm' extension. However, we might expect .wasm to eventually be the filename extension for the official binary format. I propose we use '.wase' for the S-expression text format.

I accidentally committed a patch implementing this to master in be2b6ea5eefd338f647c5c698142492698644544 which renames the files to '.wase', rather than submitting a pull request. I'm happy to revert it, or I'm happy to submit a new patch using some other extension, following whatever consensus we get here.
