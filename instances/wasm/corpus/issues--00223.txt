# WebAssembly spec issue #223: Questionable 'arity mismatch'
# джерело: https://github.com/WebAssembly/spec/issues/223
# отримано: 2026-09-30

Issue #223, opened by ghost on 2016-02-01, closed (completed) on 2016-02-02.

This example fails with a 'arity mismatch' in the ml-proto. It is accepted by sexp-wasm.

```
(module
 (func $f1 (result i32)
   (block $l0
     (br_if (i32.const 1) $l0
       (block $l1
         (br $l1 (i32.const 1))))
     (i32.const 1))))
```
