# WebAssembly spec issue #231: Add `--entry` command line parameter
# джерело: https://github.com/WebAssembly/spec/issues/231
# отримано: 2026-09-30

Issue #231, opened by jfbastien on 2016-02-03, closed (completed) on 2016-02-12.

I'd like to be able to invoke `wasm.opt awesome.wast --entry main` and automatically get `main` invoked (as if `awesome.wast` had `(invoke main ...)`). This is desirable because I already have valid `.wast` files (and create `.wasm` binaries with them), and `invoke` is an extra for spec's convenience which isn't valid `.wast`. It's similar to how C programs by default have `main` as an entry point and UNIX-y environments `_start` (which then calls `main`).

binaryen's interpreter supports a similar option, and automatically figure out the number of parameters for main (because the export sometimes has 0, 1, or 2 parameters):
https://github.com/WebAssembly/binaryen/commit/c0c40ceaf1c5e2c4fc966b36ec04592e6c67979f
