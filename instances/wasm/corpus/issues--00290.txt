# WebAssembly spec issue #290: invalid type mismatch
# джерело: https://github.com/WebAssembly/spec/issues/290
# отримано: 2026-09-30

Issue #290, opened by wanderer on 2016-05-17, closed (completed) on 2016-05-30.

The following code generates this error when ran
`test.wast:21.28-21.42: type mismatch: expression has type i32 but the context requires i64`
code:

```
(module
  (func $test
    (param $a i64)
    (local $b i64)
    (param $c i64)
    (local $d i64)
    (param $e i64)
    (local $f i64)
    (param $g i64)
    (local $h i64)

    (param $i i64)
    (local $j i64)
    (param $k i64)
    (local $l i64)
    (param $m i64)
    (local $n i64)
    (param $o i64)

    (param $memIndex i32)
    (set_local $i (i64.and (get_local $i) (i64.const 4294967295)))
  )
)
```

if I remove one (and it doesn't matter which one) `param` or `local` it runs without error
