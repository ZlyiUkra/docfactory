# WebAssembly spec issue #303: multiple blocks can have the same label. Is this correct?
# джерело: https://github.com/WebAssembly/spec/issues/303
# отримано: 2026-09-30

Issue #303, opened by wanderer on 2016-07-01, closed (completed) on 2016-07-01.

multiple blocks can have the same label. Is this correct behavior?
example

```
(module
  (start $main)
  (func $main
    (block $0
        (block $0
         (br $0)
        ))))
```

## Comment by kripken, 2016-07-01

I believe so. The name is scoped, so the `br` sees the closest one to it, basically.

## Comment by rossberg, 2016-07-01

Right, labels simply use ordinary lexical scoping.
