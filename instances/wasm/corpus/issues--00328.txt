# WebAssembly spec issue #328: Confusing error message about "constant expression"
# джерело: https://github.com/WebAssembly/spec/issues/328
# отримано: 2026-09-30

Issue #328, opened by sunfishcode on 2016-09-01, closed (completed) on 2016-11-22.

memory.wast and a few others have tests like this:

```
(assert_invalid
  (module (memory 1) (data (i32.ctz (i32.const 0))))
  "constant expression required"
)
```

This error message is confusing, because the expression here is arguably a constant expression, under some commonly-used meanings of those words. I propose changing it to "initializer expression", as that's the terminology used in the design documents.
