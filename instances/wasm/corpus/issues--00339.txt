# WebAssembly spec issue #339: If label is in scope in if condition
# джерело: https://github.com/WebAssembly/spec/issues/339
# отримано: 2026-09-30

Issue #339, opened by sunfishcode on 2016-09-11, closed (completed) on 2016-09-12.

This program

```
(module
  (func (export "foo") (result i32)
    (block $purple
      (if $if (br $if) (return (i32.const 0)) (return (i32.const 1)))
      (return (i32.const 2))
    )
    (return (i32.const 3))
  )
)
```

validates and returns 3 in ml-proto in the block-sigs branch. This is surprising, since it suggests that control is being transfered to the $purple label, even though there is no fallthrough path to the $purple label and no branch syntactically mentioning $purple. I believe the desired behavior here would be to issue an error that $if is not in scope within the `if` condition, which would look slightly counterintuitive, but would make sense given the underlying wasm structure.
