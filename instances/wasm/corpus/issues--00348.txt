# WebAssembly spec issue #348: JS glue code for i64 a little off
# джерело: https://github.com/WebAssembly/spec/issues/348
# отримано: 2026-09-30

Issue #348, opened by titzer on 2016-09-21, closed (completed) on 2016-09-23.

The spec tool for generating a JS self-contained test has a little bug when it comes to the wrapping of i64 tests: it generates

instance(...blob..., {$$}).exports.run()

But here $$ is the instance, but that also has an exports object, so this should be:

instance(...blob..., {$$: $$["exports"]}).exports.run()

Or the $$ instance should be register'd, which makes the second argument unnecessary.
