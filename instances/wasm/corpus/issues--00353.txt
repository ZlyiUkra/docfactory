# WebAssembly spec issue #353: ml-proto rejects memories with names
# джерело: https://github.com/WebAssembly/spec/issues/353
# отримано: 2026-09-30

Issue #353, opened by dschuff on 2016-09-29, closed (completed) on 2016-10-11.

If a memory is given a name:

```
(module
 (memory $0 0)
)
```

ml-proto emits a syntax error parsing the name.
However if you define the name along with an export, as in the following test from exports.wast
`(module (memory $a (export "a") 0))`
then it's happy.
