## Comment by rossberg, 2016-12-07

Yes. We had deferred them so far because the binary format was still undergoing many changes. But now might be a good time.

Note that the S-expression format _can_ express binaries, see binary.wast, which might be a good starting place for adding at least basic stuff. Contributions welcome. :)
