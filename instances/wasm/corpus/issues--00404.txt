# WebAssembly spec issue #404: Do elements need to have valid function indices?
# джерело: https://github.com/WebAssembly/spec/issues/404
# отримано: 2026-09-30

Issue #404, opened by wanderer on 2016-12-19, closed (completed) on 2016-12-20.

for example, this seems to be valid currently but would not be valid if function indices had to exist.
```
(module
  (type $T (func (result i32)))
  (table anyfunc (elem 0 $t2 $some_non_existance_index 9999999) )

  (func $t1 (type $T) (i32.const 1))
  (func $t2 (type $T) (i32.const 2))

  (func (export "callt") (param $i i32) (result i32)
    (call_indirect $T (get_local $i))
  )
)
```

## Comment by binji, 2016-12-19

This is already invalid in the spec interpreter:
```
test.wast:3.30-3.55: syntax error: unknown function $some_non_existance_index
```
and if you comment that out:
```
test.wast:4.30-4.37: invalid module: unknown function 9999999
```
