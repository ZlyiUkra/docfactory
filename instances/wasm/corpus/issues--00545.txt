# WebAssembly spec issue #545: [doc] mapping of convert instructions -> numerics in exec section
# джерело: https://github.com/WebAssembly/spec/issues/545
# отримано: 2026-09-30

Issue #545, opened by binji on 2017-08-15, closed (completed) on 2017-08-29.

I'm probably missing something, but I don't see how to go from exec-cvtop to the associated numeric conversion.

It looks like it should call `\cvtop_{t_1,t_2}(c_1)`, where `t_1` and `t_2` are one of `i32`, `i64`, `f32` or `f64`. But the `cvtop` numerics are defined like `\extends_{M,N}(i)` where `M` and `N` are used as sizes, not types. I think this is resolved for unary and binary ops via this rule, but I don't see how that would apply to the conversion instructions.
