# WebAssembly spec issue #586: Minor: Errors in embedding spec don't give sufficient information
# джерело: https://github.com/WebAssembly/spec/issues/586
# отримано: 2026-09-30

Issue #586, opened by littledan on 2017-10-17, closed (completed) on 2017-10-20.

In the specification for read_table, an error is returned in two cases:
- If the table contains an unfilled entry
- If an out-of-bounds index is passed in

In the JS interface spec, the first case results in a TypeError, and the second case results in a RangeError. The JS spec can get around this by maintaining a parallel structure \[\[Values]] which is sufficient for doing this checking itself, but the overall result is a little messy. I imagine that other embedding environments might also want to differentiate between these two conditions.
