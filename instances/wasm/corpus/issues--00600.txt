# WebAssembly spec issue #600: Textual spec should indicate that memory alignments are stored as log2
# джерело: https://github.com/WebAssembly/spec/issues/600
# отримано: 2026-09-30

Issue #600, opened by eholk on 2017-11-07, closed (completed) on 2017-11-09.

Apologies if this is written somewhere else and I missed it, but https://webassembly.github.io/spec/binary/instructions.html#binary-memarg does not seem to mention that alignments are stored as the log2 of the alignment (e.g. 3 instead of 8). The spec interpreter does the left-shift though, so it looks like log2 is what is actually used. The textual spec should mention this too.

## Comment by rossberg, 2017-11-08

Good point, see #601. In the spec the AST itself uses log2, so adding the note there instead.
