# WebAssembly spec issue #612: [spec] call_indirect missing validation rule
# джерело: https://github.com/WebAssembly/spec/issues/612
# отримано: 2026-09-30

Issue #612, opened by HugoGuiroux on 2017-12-01, closed (completed) on 2017-12-05.

call_indirect execution specification specifies that:  `Assert: due to validation, a value with value type i32 is on the top of the stack.`

However, there is no mention of such constraint in the call_indirect validation specification. Nonetheless, the caml implementation seems to take this into account.
