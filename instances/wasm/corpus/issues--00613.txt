# WebAssembly spec issue #613: [spec] global initializer type validation
# джерело: https://github.com/WebAssembly/spec/issues/613
# отримано: 2026-09-30

Issue #613, opened by HugoGuiroux on 2017-12-01, closed (completed) on 2017-12-05.

Globals are allocated with values initialized during the instantiation. Thanks to validation, the type of the val is checked against the type of the global.

I think it would be nice to add to the global allocation specification a remark like `Assert: due to validation, type of val is equals to globaltype`, which seems to be details used frequently throughout the spec.

## Comment by rossberg, 2017-12-04

Explicit assertions are only used to guard consecutive execution steps that would fail if a specific condition didn't hold. There are many other properties one could assert in many places, but doing so would clutter the semantics. Verifying that all expected typing properties hold is the role of the soundness statement in the appendix.
