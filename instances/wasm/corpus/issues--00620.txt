According to https://webassembly.github.io/spec/binary/modules.html#binary-section:

> the u32 size of the contents, in bytes.

Take the following example in wat2wasm: the size of the type section is `00` which is on 1 byte instead of 4 bytes for the u32.

I'm not able to fully understand the code in the OCaml interpreter but it seems that the size is ignored (which explains the value found in the WASM).

## Comment by binji, 2017-12-08

`u32` is defined here as a variable-length integer, so it can be between 1 and 5 bytes long, depending on its value.
