Is there any interpreter be written in JavaScript to be compatible older browsers?

## Comment by rossberg, 2018-01-29

Not that I'm aware. And while it would be possible for the time being, it would mostly defeat the purpose, because it would likely run very slow. To support older browsers, it's more effective to serve them an asm.js version of the same code.
