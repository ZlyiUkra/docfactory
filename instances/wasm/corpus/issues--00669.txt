# WebAssembly spec issue #669: [bikeshed] Wrong fonts and spacing
# джерело: https://github.com/WebAssembly/spec/issues/669
# отримано: 2026-09-30

Issue #669, opened by rossberg on 2018-02-13, closed (completed) on 2019-01-25. Labels: editorial.

The Bikeshed version of the spec does not seem to respect \mathit and \mathrm formats in some contexts. Consequently, all letters are type-set as individual variables in italic font and spacing and kerning is off.

(See e.g. rendering of the "s with [i] = e" notation here or the rendering of variable names like "i16" in the note here.)

Note: Cases like "with" and "if" are probably due to the use of \mbox?
