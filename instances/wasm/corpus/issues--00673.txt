# WebAssembly spec issue #673: [bikeshed] Spurious grey bar
# джерело: https://github.com/WebAssembly/spec/issues/673
# отримано: 2026-09-30

Issue #673, opened by rossberg on 2018-02-13, closed (completed) on 2018-04-10.

The subitem of step 9 of module instantiation have a spurious grey bar to the left that does not appear elsewhere in the algo. Also appears in a couple of other places e.g. in this section.

## Comment by tabatkins, 2018-04-10

This isn't a CSS issue; the HTML is broken.  For some unknown reason, the algorithm HTML is using `<blockquote>` on some of the sub-algorithms.  By default blockquotes get the gray-line styling.  That's just the wrong markup and should be removed.

## Comment by tabatkins, 2018-04-10

Ah, I see. The markup problem is clearer in Andreas' second link - rather than the nested steps being represented by a nested `ol`, the markup is instead:

```
<ol><li>...</ol>
<blockquote>
  <ol>...</ol>
</blockquote>
<ol><li>...</ol>
```

That is, the blockquote is being used for stylistic purposes to indent the inner algorithm, and the steps of the outer algorithm are broken into two separate lists. This is all kinds of bad HTML.
