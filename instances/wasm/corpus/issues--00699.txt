## Comment by rossberg, 2018-02-16

Hm, I have no idea. The first problem probably is: if you want to link against C then you have to go through Ocaml's foreign function interface. Other than that, I found this, but no idea how difficult it would be to make that all work, especially across platforms.

But I don't see the problem with just starting the interpreter as a separate process. It starts up fast.

## Comment by rossberg, 2018-02-16

Is that due to start-up, though? Note that the interpreter is not written for speed at all, and in fact is extremely slow in places; on execution for example, due to the small-step reduction rules it implements verbatim to match the spec literally (but which results in quadratic runtime).
