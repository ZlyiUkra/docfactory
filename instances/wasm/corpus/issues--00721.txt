# WebAssembly spec issue #721: fdivN arguments order
# джерело: https://github.com/WebAssembly/spec/issues/721
# отримано: 2026-09-30

Issue #721, opened by franky47 on 2018-02-27, closed (completed) on 2018-02-27.

The documentation for `fdivN`​ states:
```
4.3.3.6. fdivN​(z1​,z2​)
...
Else return the result of dividing z2​ by z1​ , rounded to the nearest representable value

...  floatN​(z1​/z2​)​​
```
There is a discrepancy in the description, it should read:
```
Else return the result of dividing z1 by z2​ , rounded to the nearest representable value
```

Source: https://www.w3.org/TR/wasm-core/#-href-exec-numericshtmlop-fdivmathrmfdiv_n-z_1-z_2
