# WebAssembly spec issue #737: Parse error w/ flat call_indirect
# джерело: https://github.com/WebAssembly/spec/issues/737
# отримано: 2026-09-30

Issue #737, opened by binji on 2018-03-02, closed (completed) on 2018-03-20.

The following .wat file doesn't parse:
```
(table 1 anyfunc)
(func
  i32.const 0
  call_indirect)
```

It seems that this rule is the problem, requiring a following `instr`:
```
call_instr_results :
  | LPAR RESULT value_type_list RPAR call_instr_results
    { fun c -> let ts, es = $5 c in $3 @ ts, es }
  | instr
    { fun c -> [], $1 c }
```

Changing it to `/* empty */ { fun c -> [], [] }` introduces shift/reduce conflicts.
