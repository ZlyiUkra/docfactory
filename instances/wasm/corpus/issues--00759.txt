# WebAssembly spec issue #759: [spec] Debuggability as design goal
# джерело: https://github.com/WebAssembly/spec/issues/759
# отримано: 2026-09-30

Issue #759, opened by liminzhu on 2018-03-27, closed (completed) on 2018-03-29.

In design goals in core spec,

`WebAssembly code is also intended to be easy to inspect and debug, especially in environments like web browsers, but such features are beyond the scope of this specification.`

Do we consider this out of scope for the spec? Text format is for that purpose and is defined in the core spec.

## Comment by rossberg, 2018-03-29

Well, the text format of course is a sort of prerequisite for debugging, but I wouldn't consider it a debugging aid per se (it has other uses, too). This sentence was meant to clarify that this spec doesn't define things like stack traces, break points, or other sorts of debugging interfaces.

## Comment by liminzhu, 2018-03-29

This makes sense. Thanks for the explanation.
