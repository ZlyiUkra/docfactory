# WebAssembly spec issue #768: [js-api] "Creating a host function" requires a functype parameter
# джерело: https://github.com/WebAssembly/spec/issues/768
# отримано: 2026-09-30

Issue #768, opened by rossberg on 2018-04-09, closed (completed) on 2018-10-15.

The algorithm to create a host function uses the function's type:

* in step 1.1 implicitly as "the signature",
* in step 1.6 as |functype|.

However, that type is not actually provided. The algorithm needs to take |functype| as a parameter.
