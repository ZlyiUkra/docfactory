# WebAssembly spec issue #816: Default value in constructor of Global
# джерело: https://github.com/WebAssembly/spec/issues/816
# отримано: 2026-09-30

Issue #816, opened by dontcallmedom on 2018-06-07, closed (completed) on 2018-06-11.

The current definition of the constructor for `Global` uses a default value for the 2nd argument:
  `Constructor(GlobalDescriptor descriptor, unrestricted double value = 0)`

AFAIU, default values can only be used with optional arguments - so I think `value` should be marked as `optional`.

## Comment by rossberg, 2018-06-07

Actually, I think there is another problem here, namely that the type of the value depends on the descriptor. In the future, it might denote a non-numeric type, so double is not adequate. It should probably be `any` and default to `undefined`.

## Comment by binji, 2018-06-07

@rossberg That's a good point, but we discussed in the meeting having globals of the numeric types default to 0. So I suppose we need to handle it specially in the constructor's algorithm.
