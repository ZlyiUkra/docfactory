# отримано: 2026-09-30

Issue #864, opened by Kimundi on 2018-08-22, closed (completed) on 2018-08-22.

Hi, I'm not sure if this is the right place for this, but I'm using the testsuite from this crate successfully for a toy interpreter of the MVP, and I've run into the issue that the testsuite allows import/exports of mutable globals, which breaks some of the MVP-only tooling I'm using.

I've found some wording along the lines of "Mutable globals got merged into the spec", so I'm assuming that this is the result of the feature being accepted in some fashion (though I'm not yet aware where exactly I would find out such developments), but it prevents me from just using the most up-to-date version of the testsuite from this repo.

Currently I'm using a fork where I've manually removed the mutable global tests, but I'm wondering if there is some official way to get a MVP-compatible version of the testsuite, or wether it would make sense to provide one as a stable base for current and future tooling.

## Comment by rossberg, 2018-08-22

Mutable globals were included late in the process, but are officially part of the MVP now. So in that sense, the test suite in this repo *is* the MVP-compatible version you are looking for (and is intended to be).

Edit: Once the W3C standard has been released, we will probably create a tag or branch for the MVP version of the repo and then add more stuff.
