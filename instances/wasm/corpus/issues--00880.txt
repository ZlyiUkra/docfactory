# WebAssembly spec issue #880: Embedding limits test should test max module size of 1 GiB
# джерело: https://github.com/WebAssembly/spec/issues/880
# отримано: 2026-09-30

Issue #880, opened by titzer on 2018-09-24, closed (completed) on 2022-08-04. Labels: test.

In implementing the test for embedding limitations, the maximum module size of 1GiB is not tested.

(this was mostly because creating such a large module is slow and unreliable on JS engines, as it is likely to run out of memory trying to allocate such a large array buffer).
