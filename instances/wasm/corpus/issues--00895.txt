# WebAssembly spec issue #895: [interpreter] No support for custom sections
# джерело: https://github.com/WebAssembly/spec/issues/895
# отримано: 2026-09-30

Issue #895, opened by nomeata on 2018-10-18, closed (completed) on 2018-10-20.

The WebAssembly standard allows for custom named sections, but the reference interpretation does not seem to include this possibility in its AST or decoder.

I would expect something esesntially like
```
type module_ = module_' Source.phrase
and module_' =
{
  …
  custom_sections : (name * string)  list;
}
```
(with possibly a proper record and use of `Source.phrase`).

## Comment by rossberg, 2018-10-19

This design is intentional, since the AST is supposed to mirror the spec. Note that custom sections are  a feature of the binary format, not the abstract syntax. Among other things, they don't have any representation in the text format (although the annotations proposal adds an analogue).

## Comment by nomeata, 2018-10-20

Interesting point. I also learned since that custom sections can simply be appended to the binary format, so at least for encoding the lack of AST support in the library is less of a hurdle than I thought initially.
