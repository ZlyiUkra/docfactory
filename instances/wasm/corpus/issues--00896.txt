# WebAssembly spec issue #896: [bikeshed] Incorrect links in footnotes
# джерело: https://github.com/WebAssembly/spec/issues/896
# отримано: 2026-09-30

Issue #896, opened by jmdejong on 2018-10-19, closed (completed) on 2022-08-04. Labels: editorial.

On several occasions in the single-page specification the links from the footnotes pointing back to their location in the text point to the wrong id.
For example in the footnote about the stack machine the link that is supposed to take you back to where you were instead takes you to the mention of memory safety, which is actually the link target for another footnote.
This was tested in Firefox 62.0.3

I believe the cause of this is that the document was designed for a multi-page view, and therefore the ids that are being linked to are automatically generated, but with the same name.

A possible solution could be to prefix these ids with the section name when combining them into the single-page version.
