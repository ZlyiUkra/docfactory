# WebAssembly spec issue #917: Running interpreter's 'winmake.bat' does not produce 'wasm.exe'
# джерело: https://github.com/WebAssembly/spec/issues/917
# отримано: 2026-09-30

Issue #917, opened by analogrelay on 2018-11-20, closed (completed) on 2018-11-20.

Prereqs:
* Windows Machine
* Install OCaml

**Repro Steps**:
1. Clone this repo
2. `cd interpreter`
3. `winmake.bat`

**Expected Behavior**: `wasm.exe` is dropped in the current directory

**Actual Behavior**: No `wasm.exe` is dropped. The `-o` switch in the final OCaml build instruction has `main/main.d.byte` in it. Renaming this file to `wasm.exe` results in a working interpreter.
