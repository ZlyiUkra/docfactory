## Comment by rossberg, 2018-11-26

The "env.*" imports are generated by Emscripten and provided by Emscripten's JS glue code to work on the Web. The reference interpreter doesn't know anything about them. It can only instantiate modules that do not have platform-specific imports.

## Comment by ireneGP, 2018-11-26

In other words, I shouldn't be able to leverage the interpreter here to execute a simple "hello world" code right? Since even for such piece of code it needs to talk with the JS part and print out. ## Comment by rossberg, 2018-11-26

@ireneGP, yes that's right. The reference interpreter is intended for testing the execution of the Wasm instruction set itself. It is mostly useful for compiler and VM engineers, not so much for users of their tools.
