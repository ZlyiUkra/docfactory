## Comment by littledan, 2018-12-13

This constant has some interesting history; see https://github.com/WebAssembly/spec/issues/607#issue-277476473 . It used to be unenforced (in multiple browsers, due to separate bugs!), so it had to be raised to meet web reality.

What's the need for a round number? To me, this one seems as good as any; the important thing is that it be the same everywhere.
