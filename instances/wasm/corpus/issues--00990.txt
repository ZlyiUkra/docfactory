# WebAssembly spec issue #990: Validation for function section and code section in binary spec
# джерело: https://github.com/WebAssembly/spec/issues/990
# отримано: 2026-09-30

Issue #990, opened by rianhunter on 2019-03-21, closed (completed) on 2019-04-16.

To find out the validation rules for WebAssembly, I usually refer to the validation section of the spec. The validation rule that the number of entries in the function section and the code section are the same are in a different location:

https://github.com/WebAssembly/spec/blame/master/document/core/binary/modules.rst#L424

This is slightly not intuitive. When I wrote my parser I didn't include that rule, and when I wrote my validator I didn't include that rule. This is just a humble suggestion but maybe specify this more boldly in the binary section of the spec, and repeat it as a note in the validation section (Even though it only deals with abstract WebAssembly structures not the binary format).
