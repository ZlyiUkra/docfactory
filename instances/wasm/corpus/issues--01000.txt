# WebAssembly spec issue #1000: Use Unicode scalar values instead of Unicode code points
# джерело: https://github.com/WebAssembly/spec/issues/1000
# отримано: 2026-09-30

Issue #1000, opened by ghost on 2019-04-14, closed (completed) on 2019-04-16.

I've noticed that the spec does not allow surrogate code points in names which means the technical definition of `codepoint` is incorrect in terms of the Unicode standard.

Unicode code point is any value in the range [0, 10FFFF].
Unicode scalar value is any Unicode code point except high-surrogate and low-surrogate code points.

So please, rename `codepoint` to something like `scalar_value` or `unicode_scalar_value`.
