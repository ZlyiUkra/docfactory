## Comment by binji, 2019-07-10

No, there are different formats for those too:

```wasm
;; "flat" format
block
  nop
  i32.const 1
  i32.const 2
  i32.add
  drop
end

;; sexpr format
(block
  (nop)
  (drop
    (i32.add (i32.const 1) (i32.const 2)))
)
```

Same with `if` and `loop` too. `if` has a bit more syntax though:

```wasm
;; flat format
i32.const 1 ;; condition
if
  nop
else
  nop
end

;; sexpr format
(if
  (i32.const 1)  ;; condition
  (nop)
  (nop)
)

;; alternate sexpr format
(if
  (i32.const 1)
  (then (nop))
  (else (nop))
)
```

These all produce identical binary output.
