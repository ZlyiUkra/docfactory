# WebAssembly spec issue #1048: OCaml Dependency is Problematic for Windows
# джерело: https://github.com/WebAssembly/spec/issues/1048
# отримано: 2026-09-30

Issue #1048, opened by RyanLamansky on 2019-07-20, closed (completed) on 2022-08-04.

The first line of the Windows instructions in the interpreter README link to a page which immediately states
> This installer is out of date
> This installer no longer works. Do not use it.

The page endorses Andreas Hauptmann's installer, which when attempting to run, is intercepted by Window's Smart Screen malware filter.

Is there a drama-free way of getting the spec interpreter running on Windows?

_Gripe: building the official spec interpreter in a language that only has official builds for Linux was a questionable decision, in my opinion._
