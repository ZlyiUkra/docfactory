## Comment by CarpeDiemKopi, 2019-08-06

I finally managed to create wasm.exe with the OCaml compiler 4.02.3_BuckleScript.

I will set the instructions step by step here:
**windows 10   CygWin64   standard C toolchain   OCaml 4.02.3 + BuckleScript-1   compiling from source   OPam**

`.bash_profile`
```
export SHELLOPTS
set -o igncr
export PATH=$PATH:"/cygdrive/d/Development/OCaml/home/Charleen/.opam/ocaml-4.02.3BS/_opam/bin" # ocamlc.exe
export PATH=$PATH:"/cygdrive/d/development/OCaml/spec/interpreter"  # wasm.exe
export PATH=$PATH:"/cygdrive/d/development/ocaml/home/Charleen/.opam/opam-2.0.5/bin"
export CYGWIN=nodosfilewarning winsymlinks # :native

alias npm="'/cygdrive/c/Program Files/nodejs/npm.cmd'"
alias node="'/cygdrive/c/Program Files/nodejs/node.exe'"
alias bsb="'/cygdrive/c/Program Files/nodejs/node_modules/bs-platform/lib/bsb.exe'" #bsb.exe

notepadplusplus() {
     cd `dirname $1`
     "/cygdrive/c/Program Files (x86)/Notepad++/notepad++.exe" `basename $1`
     cd -
}
alias n++=notepadplusplus


```
