# WebAssembly spec issue #1066: Float literal syntax spec and tests don't match
# джерело: https://github.com/WebAssembly/spec/issues/1066
# отримано: 2026-09-30

Issue #1066, opened by AndrewScheidecker on 2019-09-07, closed (completed) on 2019-09-17.

The spec defines the syntax for `fN` to require a decimal point or exponent, and defines `f(32|64).const` to only accept a `fN` as their immediate operand.

However, there are many tests that use `f(32|64).const` without a decimal point or exponent; e.g.:
https://github.com/WebAssembly/spec/blob/d22a7659e5f2f09be9532e2c72c04407134cc08e/test/core/float_literals.wast#L82
