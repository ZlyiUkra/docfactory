# WebAssembly spec issue #1095: Should "read the imports' check the type of Global objects?
# джерело: https://github.com/WebAssembly/spec/issues/1095
# отримано: 2026-09-30

Issue #1095, opened by Ms2ger on 2019-10-22, closed (completed) on 2020-02-17.

https://webassembly.github.io/spec/js-api/#read-the-imports has

> 1. If externtype is of the form 𝗀𝗅𝗈𝖻𝖺𝗅 mut valtype,
>    1. If v is a Global instance,
>       1. Let globaladdr be v.[[Global]]

seemingly without checking `global_type(store, globaladdr)`. Should it?

## Comment by rossberg, 2019-10-22

It doesn't need to -- as in the other cases of imports, the type is checked in module_instantiate. This case should probably have the same note as the others.

Thanks for the pointer, agreed about the note. Might be worth writing a test as well.
