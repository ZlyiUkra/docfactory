# WebAssembly spec issue #1139: Relax OCaml < 4.08.0 for wasm 1.0
# джерело: https://github.com/WebAssembly/spec/issues/1139
# отримано: 2026-09-30

Issue #1139, opened by fangyi-zhou on 2020-03-07, closed (completed) on 2020-03-18.

https://opam.ocaml.org/packages/wasm/wasm.1.0/ shows wasm 1.0 requires OCaml < 4.08.0.
Is there a reason for this constraint? There are API changes in 1.1, and some packages depending are wasm 1.0 inherit this version constraint (See https://github.com/FStarLang/kremlin/issues/169), but I was able to build wasm 1.0 with OCaml 4.08.1 (after silencing deprecation warnings) and tests are passing.

## Comment by rossberg, 2020-03-16

Good question, I don't know if there was a reason for the constraint. @msprotz would probably know. Happy to approve a PR to change it, if it works without.
