Issue #1155, opened by ngzhian on 2020-03-25, closed (completed) on 2020-06-17.

I was trying to repro some errors that I observed in travis, and realized there were a couple of missing steps that don't seem to be documented elsewhere. I'll write some of those down here, and probably can put it in README.md or CONTRIBUTING.md later.

1. when this repo is cloned, we need to clone submodules too, `git clone --recurse-submodules https://github.com/WebAssembly/spec`, this is to bring in document/core/util/katex
2. you need to install yarnpkg (and npm), you will see this in .travis.yml
3. you will need texlive-full (also in .travis)
