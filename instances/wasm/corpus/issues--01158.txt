# WebAssembly spec issue #1158: [interpreter] Table size limit is too strict
# джерело: https://github.com/WebAssembly/spec/issues/1158
# отримано: 2026-09-30

Issue #1158, opened by acfoltzer on 2020-03-26, closed (completed) on 2020-03-27.

The following module fails validation (`wasm -d test.wat`):
```wat
(module
  (table (;0;) 0xFFFFFFFF funcref))
```

The error message indicates that this _should_ be allowed, though:
```
test.wat:2.3-2.35: invalid module: table size must be at most 2^32
```

The largest table size that _does_ validate is `0x7FFFFFFF`, or `Int32.max_int`, so I suspect this is a signedness issue in the validator.
