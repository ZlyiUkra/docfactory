# WebAssembly spec issue #1183: [spec] Execution vs Validation: blocktype expansion
# джерело: https://github.com/WebAssembly/spec/issues/1183
# отримано: 2026-09-30

Issue #1183, opened by philipahlberg on 2020-04-24, closed (completed) on 2020-06-18.

The description for Control Instructions in the instructions section under Execution, uses an `expand_F` function to transform a block type to a function type.

In the corresponding instructions section under Validation, the `expand_F` function is not used. Instead, the transformation is covered separately by the types section under Validation (as far as I can tell).

Would it be possible to unify these two approaches? As it is, it seems like they are out of sync.

## Comment by rossberg, 2020-05-05

The expand function is only defined when the blocktype is valid in the first place. So it cannot be used in validation itself. Think of it as part of the execution semantics.
