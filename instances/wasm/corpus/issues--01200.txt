# WebAssembly spec issue #1200: [interpreter] Add command line option to control maximum recursion depth
# джерело: https://github.com/WebAssembly/spec/issues/1200
# отримано: 2026-09-30

Issue #1200, opened by mdesharnais on 2020-05-26, closed (completed) on 2022-08-04.

At this moment, the maximum recursion depth is hard-coded to 300. When experimenting with recursive functions, I rapidly reached this limit and had to change manually it in the source code before recompiling the interpreter.

This number feels arbitrary and I cannot think of any reason to prevent users from setting it to a number that fit their purpose. I propose to add a command line option (e.g. `-max-recursion-depth <natural-number>`) with 300 being the default value.

I am just starting to get to know the code base but, if this suggestion is accepted, I am willing to provide a pull request.
