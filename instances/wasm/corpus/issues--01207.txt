## Comment by ngzhian, 2020-06-10

I think this is a bikeshed issue. Looking at the generated file `_build/bikeshed_mathjax/index.html` line 11046, you'll see `t_2^<em>`, but it should really be `t_2^*` if you look at `_build/bikeshed_singlehtml/index_fixed.html`

## Comment by ngzhian, 2020-06-10

Filed https://github.com/tabatkins/bikeshed/issues/1704

## Comment by ngzhian, 2020-06-10

@Ms2ger correctly spotted the issue as the 2 `*` in the equation, and that `index.bs` specifies

```
Markup Shorthands: css no, markdown yes, algorithm no, idl no
```

causing it to be recognized as italics. The fix is to change `markdown yes` to `markdown no`. AFAICT there is no difference (see https://github.com/tabatkins/bikeshed/issues/1704#issuecomment-642177186 for the diff) in other parts of the generated document. As @binji observed, we shouldn't have Markdown in the document we pass to bikeshed anymore.
