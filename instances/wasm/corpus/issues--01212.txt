# WebAssembly spec issue #1212: [interpreter] Local variable index is incorrect with function type use
# джерело: https://github.com/WebAssembly/spec/issues/1212
# отримано: 2026-09-30

Issue #1212, opened by binji on 2020-06-17, closed (completed) on 2020-07-23.

The interpreter has the wrong result for the following test:

```wat
(module
  (type $sig (func (param i32) (result i32)))
  (func (export "test") (type $sig)
    (local $var i32)
    (local.get $var))
)

(assert_return (invoke "test" (i32.const 42)) (i32.const 0))
```

This function should return `0`, not `42`.
