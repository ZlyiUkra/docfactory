# WebAssembly spec issue #1243: Document compilation: `sphinx.ext.mathbase` has been deprecated
# джерело: https://github.com/WebAssembly/spec/issues/1243
# отримано: 2026-09-30

Issue #1243, opened by hachi8833 on 2020-08-29, closed (completed) on 2020-08-29.

Ref: https://www.sphinx-doc.org/en/master/extdev/deprecated.html

The following declarations in mathdef.py and mathdefbs.py under document/core/util/ have been deprecated in recent sphinx:

```python
from sphinx.ext.mathbase import math
from sphinx.ext.mathbase import MathDirective
```

At least, they should be updated like the following, which are still incomplete:

```python
import math
from docutils.parsers.rst.roles import math_role
from sphinx.directives.patches import MathDirective
```

Revising as above still causes an error on `ext_math_role` in mathdef.py:

>   File "/Users/hachi8833/deve/wasm/spec/document/core/util/mathdef.py", line 59, in ext_math_role
    return [math(raw, text)], []
TypeError: 'module' object is not callable

Current sphinx version on my macOS Catalina environment:


The spec is set up to build with Sphinx version 2.4.4. If possible can you pin your installation of Sphinx to 2.4.4 and try again? You will still get the deprecation warnings in the output, but it will build fine.
