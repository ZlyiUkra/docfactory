# WebAssembly spec issue #1247: Wrong superscript for signed integer to float conversion
# джерело: https://github.com/WebAssembly/spec/issues/1247
# отримано: 2026-09-30

Issue #1247, opened by akirilov-arm on 2020-09-04, closed (completed) on 2020-09-08.

The formal notation for the signed integer to float conversion uses the superscript `u` instead of `s`.
