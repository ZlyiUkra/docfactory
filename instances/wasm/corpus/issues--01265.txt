# WebAssembly spec issue #1265: [Question] Caching compiled wasmBinaryFile with WebAssembly.instantiate
# джерело: https://github.com/WebAssembly/spec/issues/1265
# отримано: 2026-09-30

Issue #1265, opened by rzydek on 2020-11-27, closed (completed) on 2022-08-04.

I've got inlined wasmBinary in base64 format and I want to instantiate it without Fetch API and cache it to avoid compilation on every page refresh. I am also curious if there is a way to abort second browser compilation?

## Comment by titzer, 2020-11-30

Unfortunately decoding base64 to binary and then feeding that to the Wasm engine is going to defeat the browser's HTTP-cache-based Wasm module caching. Your best bet is to have the .wasm file as a separate HTTP resource.

## Comment by rossberg, 2022-08-04

Closing as answered.
