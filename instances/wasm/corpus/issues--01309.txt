# WebAssembly spec issue #1309: Obsolete note in "5.4.1. Control Instructions"
# джерело: https://github.com/WebAssembly/spec/issues/1309
# отримано: 2026-09-30

Issue #1309, opened by SpecLad on 2021-04-10, closed (completed) on 2021-04-21.

In section 5.4.1 it says:

> In future versions of WebAssembly, the zero byte occurring in the encoding of the `call_indirect` instruction may be used to index additional tables.

However, there is no zero byte in the encoding of this instruction. This note is probably a leftover from before the instruction was extended to support multiple tables.
