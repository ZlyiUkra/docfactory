# WebAssembly spec issue #1316: Typo in runtime semantics of table.init
# джерело: https://github.com/WebAssembly/spec/issues/1316
# отримано: 2026-09-30

Issue #1316, opened by manoskouk on 2021-04-29, closed (completed) on 2021-05-10.

In the spec of table.init it is defined that `val=𝑆.𝖾𝗅𝖾𝗆𝗌[𝐹.𝗆𝗈𝖽𝗎𝗅𝖾.𝖾𝗅𝖾𝗆𝖺𝖽𝖽𝗋𝗌[𝑥]].𝖾𝗅𝖾𝗆[𝑠])`. It should be `elemaddrs[y]` instead.
