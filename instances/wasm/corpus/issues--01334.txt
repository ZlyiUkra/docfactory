# WebAssembly spec issue #1334: [spec] Possible typo in Memory Instructions
# джерело: https://github.com/WebAssembly/spec/issues/1334
# отримано: 2026-09-30

Issue #1334, opened by rahulv4667 on 2021-06-17, closed (completed) on 2021-06-17.

In the second para of memory instructions, it states `The static address offset is added to the dynamic address operand, yielding a 33 bit effective address that is the zero-based index at which the memory is accessed.`. Is it 32-bit effective address or am I missing some concept?

## Comment by rossberg, 2021-06-17

No, that's intentional. Adding two 32 bit values (static offset and dynamic operand) yields a result in the 33 bit range. Of course, any value outside the 32 bit range will inevitably cause an out of bounds error.
