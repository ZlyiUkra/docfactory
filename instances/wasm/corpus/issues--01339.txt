# WebAssembly spec issue #1339: Grammar railroad diagram
# джерело: https://github.com/WebAssembly/spec/issues/1339
# отримано: 2026-09-30

Issue #1339, opened by mingodad on 2021-06-29, closed (completed) on 2022-08-04.

I've done a experimental tool to convert bison grammars to a kind of EBNF understood by https://www.bottlecaps.de/rr/ui to generate railroad diagrams see bellow the converted `spec/master/interpreter/text/parser.mly` and with some hand made changes to allow view it at https://www.bottlecaps.de/rr/ui the order of the rules could be changed to a better view of the railroad diagrams. Copy and paste the EBNF bellow on https://www.bottlecaps.de/rr/ui tab Edit Grammar then switch to the tab View Diagram.
