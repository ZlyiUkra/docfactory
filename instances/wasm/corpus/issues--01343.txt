# WebAssembly spec issue #1343: Test more side-effects/order of execution
# джерело: https://github.com/WebAssembly/spec/issues/1343
# отримано: 2026-09-30

Issue #1343, opened by SoniEx2 on 2021-07-10, closed (completed) on 2022-08-04.

There should be a side-effects test-suite. In particular, trapping is a side-effect.

Code like this:

```
i32.const 0 i32.const 0 i32.div_s i32.const 1 global.set 0 local.set 0
```

breaks on an implementation that currently passes every other test. (the test should set the global to 0, call this code, and assert that the global is still 0.)

More importantly, this example is a fundamental core semantic. That's why it should be part of the spec test.
