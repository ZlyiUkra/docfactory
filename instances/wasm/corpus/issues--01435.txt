# WebAssembly spec issue #1435: Is `vectype` part of `valtype`?
# джерело: https://github.com/WebAssembly/spec/issues/1435
# отримано: 2026-09-30

Issue #1435, opened by Cyborus04 on 2022-03-28, closed (completed) on 2022-04-04.

In the syntax spec, `valtype` is defined as `numtype | reftype | vectype`, but in the binary spec it is defined as `numtype | reftype`. Is there a reason for this conflict?

## Comment by ngzhian, 2022-03-28

`vectype` should be part of `valtype`, we probably missed this when merging the SIMD proposal into the main spec. Fixed in #1436 .
