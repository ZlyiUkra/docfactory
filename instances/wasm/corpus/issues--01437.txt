# WebAssembly spec issue #1437: Strange range in `extmul` definition
# джерело: https://github.com/WebAssembly/spec/issues/1437
# отримано: 2026-09-30

Issue #1437, opened by Cyborus04 on 2022-03-30, closed (completed) on 2022-03-30.

In the execution definition for *t2*x*N*\.extmul\_*half*\_*t1*x*M*\_*sx*, it reads:

> Let i\* be the sequence lanest1xM(c1)[N : N]
> Let j\* be the sequence lanest1xM(c2)[N : N]

This seems to be a range of length 0. Should this be [N : M] instead?

## Comment by ngzhian, 2022-03-30

Yea it looks weird, because the range syntax is `[ start_index : length ]`,  (not `[ start_index : end_index ]`), from https://webassembly.github.io/spec/core/syntax/conventions.html#notation-slice

e.g. `s[4:4] -> s[4] ... s[4+4-1] -> s[4] ... s[7]`

Ohh, okay, thanks for clearing that up. 👍🏻 I'm used to Rust's range style
