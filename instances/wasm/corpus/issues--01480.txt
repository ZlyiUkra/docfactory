# WebAssembly spec issue #1480: error: wasm is not available for OCaml 4.13
# джерело: https://github.com/WebAssembly/spec/issues/1480
# отримано: 2026-09-30

Issue #1480, opened by nomeata on 2022-05-27, closed (completed) on 2022-06-01.

While doing a routine dependency upgrade for a certain Ocaml based project that happens to use `wasm` from opam as a library, I get the error message
```
error: wasm is not available for OCaml 4.13.1
```
and indeed the metadata at https://opam.ocaml.org/packages/wasm/ for 1.1.1 lists >=4.08.0 & <4.13 as the constraints on ocamlc.

Can we have a new opam release that relaxes this bounds?
