# WebAssembly spec issue #1494: Do not use MathML for BNF definitions
# джерело: https://github.com/WebAssembly/spec/issues/1494
# отримано: 2026-09-30

Issue #1494, opened by ethindp on 2022-06-13, closed (completed) on 2022-08-04.

Currently the specification uses MathML for grammar definitions of both the text and byte-code forms. Though this might've been done to enhance accessibility, it actually makes it harder to read the spec. As an example, the section for "Administrative Instructions" contains the `instr` production. Normally, I would be able to trivially navigate and read this production in the way its formatted, making it easy to interpret. However, since it uses MathML, my screen reader reads the entire production at once, so I can't navigate the rule by, say, alternatives. I would recommend only using MathML on mathematical operations/formuli/etc., and simply using code blocks for productions and everything else.
