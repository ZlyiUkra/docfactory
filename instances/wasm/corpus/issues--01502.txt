In some tests (`elem.wasm`, `data.wasm`...) there are some values imported from a `"test"` module. Example from elem.wast:

```wasm
(assert_invalid
  (module
    (global (import "test" "global-i32") i32)
    (table 1 funcref)
    (elem (offset (global.get 0) (global.get 0)))
  )
  "type mismatch"
)
```

I tried to find such a `"test"` module but couldn't find any definition or documentation anywhere. Thus I'm wondering if I really missed it or  if it's indeed not supposed to exist because the various tests referencing it should fail before they actually need it.

## Comment by rossberg, 2022-07-11

Technically, it doesn't really matter, because validation happens during compilation, whereas imports are only resolved later, during linking. But I'd be happy accepting a PR that uses a "real" module. ;)
