# WebAssembly spec issue #1509: mathjax: you can't use 'macro parameter character #' in math mode with the SVG renderer
# джерело: https://github.com/WebAssembly/spec/issues/1509
# отримано: 2026-09-30

Issue #1509, opened by nagisa on 2022-07-27, closed (completed) on 2022-08-04.

When MathJax is set to use the SVG renderer, loading a new page will fail to render any math blocks with the following message:

You can't use 'macro parameter character #' in math mode

To reproduce:

1. Open any specification page with maths in it;
2. Right-click on one of the math blocks, select “Math Settings > Math Renderer > SVG”
3. Reload the page.

This is on Firefox 103.0a1, but appears to be reproducible on Chromium as well. The SVG renderer works if I select SVG renderer after the maths have already been rendered with CHTML.

It is critical for me that the SVG renderer works in order to avoid this issue: https://github.com/mathjax/MathJax/issues/2904
