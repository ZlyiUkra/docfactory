`nan:canonical` and `-nan:canonical` both valid canonical NaNs right?

If desn't we have current situation for
```wast
(f64.sqrt (f64.const -1))
```
x84 arch return:
```wast
(f64.const nan:0x8000000000000)
```
while ARM64 (Apple M1 for example):
```wast
(f64.const -nan:0x8000000000000)
```
So which point is correct?
1) Both are correct (WebAssembly does not guarantee non-determinism for NaNs)
2) WebAssembly implementations for x86 do not behave correctly
3) WebAssembly implementations for ARM do not behave correctly
