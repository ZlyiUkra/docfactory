# WebAssembly spec issue #1551: Binary format issues
# джерело: https://github.com/WebAssembly/spec/issues/1551
# отримано: 2026-09-30

Issue #1551, opened by pepyakin on 2022-10-19, closed (completed) on 2022-10-20.

In binary format under modules it says here

> All sections can be empty.

It might seem to refer that sections like `code` or `elem` could be seen as vectors. However, there is an outlier — the `start` section, which is explicitly one element. Thus it cannot be empty.

Also, the binary format in the formal notation indicates that there could be several sections of one kind (again, except for the `start` section). I assume that they are intended to be concatenated probably to serve linking purposes. However, the prose part of the specification specifically states

> other [non-custom] sections must occur at most once

Am I missing anything? Which is it in the end?

## Comment by rossberg, 2022-10-20

Ah, "empty" here refers to producing the empty byte sequence for a grammar symbol, which is possible for all section symbols, including startsec (and datacountsec, which is of a similar nature). The remark is supposed to point out that even a module where all sections are absent is allowed.

Can you elaborate how you derive that sections (other than custom) can be repeated? The grammar contains each of those sections exactly once.
