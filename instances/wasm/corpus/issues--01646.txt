# WebAssembly spec issue #1646: Do there any JS APIs for accessing the WASM GC type?
# джерело: https://github.com/WebAssembly/spec/issues/1646
# отримано: 2026-09-30

Issue #1646, opened by kylo5aby on 2023-04-27, closed (completed) on 2023-04-28.

Hi,
Maybe my question is stupid, Currently, if we want to access GC type value through js-api, it output `object`, I wonder if there have JS APIs to access the fields of wasm gc type value? V8 have already provide C++ related APIs to access them, but in JS it seems not support yet.  I would like to know if the JavaScript API will support this feature in the future, and if not, what are the challenges?

Thanks.

## Comment by rossberg, 2023-04-27

The initial API is described here: https://github.com/WebAssembly/gc/blob/main/proposals/gc/MVP-JS.md

It indeed does not offer much in the way of accessing GC objects from JS. That was left for future versions, because such an API is far from trivial (e.g., all the Wasm type structure needs to be reflected in JS), and it's not clear what exactly it should offer.
