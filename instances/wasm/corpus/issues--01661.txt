# WebAssembly spec issue #1661: Missing `id?` in func specification.
# джерело: https://github.com/WebAssembly/spec/issues/1661
# отримано: 2026-09-30

Issue #1661, opened by TobiasHT5 on 2023-06-04, closed (completed) on 2023-06-05.

This is how the spec defines functions in text format:

functype ::= '(' 'func' t1*:vec(param) t2*:vec(result) ')'

It should be like:

functype ::= '(' 'func' id? t1*:vec(param) t2*:vec(result) ')'

To show that functions can be named as well.
