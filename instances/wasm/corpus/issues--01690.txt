# WebAssembly spec issue #1690: [Question] Why we have to push a dummy frame when invoking a function?
# джерело: https://github.com/WebAssembly/spec/issues/1690
# отримано: 2026-09-30

Issue #1690, opened by r1ru on 2023-10-16, closed (completed) on 2023-10-16.

The spec says to push a "dummy frame" onto the stack when invoking a function, but I don't see the need for this.

This frame doesn't seem to be used or popped anywhere. Am I missing something?

Invocation

## Comment by conrad-watt, 2023-10-16

The WebAssembly spec assumes that _every_ instruction executes inside some frame, even if that instruction (in the case of `invoke`) immediately creates an inner frame where the "real" execution is done. Creating an empty "dummy" frame here means that we can treat `invoke` uniformly whether it occur at the top level or within a nested function call. We could relax this assumption to avoid the need for a dummy frame, but this would make the spec less regular in other places.
