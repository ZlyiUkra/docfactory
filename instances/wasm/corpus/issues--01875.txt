# WebAssembly spec issue #1875: Possible issue with validation of elem offset
# джерело: https://github.com/WebAssembly/spec/issues/1875
# отримано: 2026-09-30

Issue #1875, opened by MI3Guy on 2025-03-04, closed (completed) on 2025-03-05.

For the wasm-3.0 branch, the validation for the elem section states that the offset expression must be valid with type `[i32]`. I would have expected this to be a type matching the index type of the table.

Some of the test cases are generating i64 constants in this position when converted to binary using the interpreter, and based on the spec of the text format, I believe that is correct.

## Comment by bvisness, 2025-03-04

You're right, that seems to be a mistake. The `𝐶.tables[𝑥] = limits 𝑡` is also wrong; it should have an address type, which should then be used with the offset.

## Comment by MI3Guy, 2025-03-04
