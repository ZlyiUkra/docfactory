# WebAssembly spec issue #1889: [spec/interpreter] Mismatch about constant instructions `extern.convert_any` and `any.convert_extern`
# джерело: https://github.com/WebAssembly/spec/issues/1889
# отримано: 2026-09-30

Issue #1889, opened by f52985 on 2025-04-02, closed (completed) on 2025-04-04.

In `wasm-3.0` branch, there is a mismatch between the specification and the interpreter regarding whether `extern.convert_any` and `any.convert_extern` are constant instructions.

The specification treats these instructions as constant, but the reference interpreter's validation does not, causing the following code to be rejected:
```wat
;; const.wat
(module
  (global externref (ref.null any) (extern.convert_any))
  (global anyref (ref.null extern) (any.convert_extern))
)
```
```sh
$ wasm const.wat
const.wat:2.21-2.56: validation error: constant expression required
```

I believe the specification is the correct one (not entirely sure, though).

Additionally, I could not find a dedicated test for checking the constant-ness of instructions.
If that is missing, I think a separated `.wast` test should be added for this purpose.
(I attempted to name it `const.wast`, but that name is already used for testing `nt.const` instructions.)
