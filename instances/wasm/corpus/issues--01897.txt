The comparison operation is called with one operand and operands of different types. Is this allowed? Shouldn't this fail validation? Doesn't validate in my local node engine.

## Comment by dschuff, 2025-04-25

The `br` instruction (and other unconditional control transfers) is stack-polymorphic, meaning that for validation purposes it leaves the stack in an "unconstrained" state, such that any type can be consumed from it. So these tests are basically checking that property, that the instruction validates when various different types are required by the comparison instructions.
So yes, this should pass validation (and both this test and node's implementation have done so since wasm's MVP); if your local system is failing this, there must be some sort of bigger problem.
