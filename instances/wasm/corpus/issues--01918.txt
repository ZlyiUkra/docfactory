# WebAssembly spec issue #1918: Inconsistent text and binary formats for `table.init`
# джерело: https://github.com/WebAssembly/spec/issues/1918
# отримано: 2026-09-30

Issue #1918, opened by osa1 on 2025-06-13, closed (completed) on 2025-06-16.

Binary format reference: https://webassembly.github.io/spec/core/binary/instructions.html#table-instructions
Text format reference: https://webassembly.github.io/spec/core/text/instructions.html#table-instructions

In the binary format `elemidx` comes before optional `tableidx`.

In the text format the optional `tableidx` comes first.

Should they be consistent? Is it possible to change the text format now?

Relatedly, I'm wondering where in the spec we mention that the table indices in table instructions are optional, with `0` as the default?

## Comment by rossberg, 2025-06-16

That was intentional. In the binary format, the source comes first for historical reasons. For the text format, we decided to stay consistent with the destination-first ordering of all other transfer instructions. The same difference applies to memory.init in Wasm 3.0.
