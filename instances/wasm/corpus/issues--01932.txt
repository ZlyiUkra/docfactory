# WebAssembly spec issue #1932: Fix conventions for "large productions"
# джерело: https://github.com/WebAssembly/spec/issues/1932
# отримано: 2026-09-30

Issue #1932, opened by vursc on 2025-06-20, closed (completed) on 2025-06-24.

In the current Core Specification, Structure: Conventions states that

> Large productions may be split into multiple definitions, indicated by ending the first one with explicit ellipses, `sym ::= A1 | ...`, and starting continuations with ellipses, `sym ::= ... | A2`.

This convention is used in Structure: Instructions for the `instr` production.

A slightly different convention is used in Binary Format: Instructions for the `instr` production, and in Text Format: Instructions for the `plaininstr` production. Specifically, continuations start with `... |`, but the first definition does not end with `| ...`. Also, neither Binary Format: Conventions nor Text Format: Conventions state this convention. I think this is just a simple oversight.

I propose that the convention quoted above be adopted for the other two, and be stated in the respective "Conventions" subsections.

I can create a pull request if this proposal is accepted.
