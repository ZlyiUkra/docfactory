# WebAssembly spec issue #1960: [spec] Unmodified standards appear in wasm 3.0
# джерело: https://github.com/WebAssembly/spec/issues/1960
# отримано: 2026-09-30

Issue #1960, opened by MacroModel on 2025-08-18, closed (completed) on 2025-08-19.

In Section 7.6.1, WASM 3.0 adds a data count section and a tag section compared to WASM 1.0, and the name provides tag information. However, why does the specification still specify "The name section should appear only once in a module, and only after the `data` section."?

## Comment by MacroModel, 2025-08-18

Should this restriction be removed or moved to after the tag section?

## Comment by bvisness, 2025-08-18

The data section must come after the tag section and data count section. In fact, the data section is the final non-custom section to appear in a WASM module (see here). Therefore the tag and data count sections do not affect where the name custom section can appear in a module.
