# WebAssembly spec issue #1972: Loading instruction reference in a browser takes 10-20 seconds to render
# джерело: https://github.com/WebAssembly/spec/issues/1972
# отримано: 2026-09-30

Issue #1972, opened by alexcrichton on 2025-09-18, closed (completed) on 2025-09-19.

Loading this page -- https://webassembly.github.io/spec/core/binary/instructions.html#numeric-instructions -- takes 10 to 20 seconds depending on Firefox, Safari, or Chrome used to render it. Looking at the console it looks predominantly spent in JS rendering time as opposed to network time. Would it be possible to pre-render mathjax or frob some setting? If not it's not the end of the world, but I figured I'd at least ask the question in case an expert on the rendering process knows of a knob to turn.

## Comment by Alan-Liang, 2025-09-19

After a bit of profiling, it seems that most of the time was spent on an accessibility feature called "semantic enrichment" (context menu > accessibility > options); disabling it resulted in a 4x speedup on my device.

That option was disabled by default in mathjax 3.x, but enabled by default in 4.x.

## Comment by rossberg, 2025-09-19

Interesting find! I have turned off semantic enrichment by default for now. Perhaps this means that we need two versions of the HTML, one ordinary and one accessibility-enhanced?
