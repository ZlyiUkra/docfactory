# WebAssembly spec issue #1977: `inez_N` is specified in exec/numerics, but does not appear anywhere else (inc. binary encoding)
# джерело: https://github.com/WebAssembly/spec/issues/1977
# отримано: 2026-09-30

Issue #1977, opened by nagisa on 2025-09-19, closed (completed) on 2025-09-23.

https://webassembly.github.io/spec/core/exec/numerics.html#op-inez specifies the integer not-equal zero operation, an inverse of `ieqz`. However, only `eqz` has a defined binary encoding, while `nez` does not. Oversight?

## Comment by rossberg, 2025-09-23

The set of primitive ops defined in that section is a superset of plain numerics opcodes. Some of the ops are only used by SIMD instructions. For example, inez is needed to define the `txN.all_true` instruction.
