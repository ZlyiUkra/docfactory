# WebAssembly spec issue #2005: [spec] Typos in "Name section" section
# джерело: https://github.com/WebAssembly/spec/issues/2005
# отримано: 2026-09-30

Issue #2005, opened by alessiofaieta on 2025-10-07, closed (completed) on 2025-10-08.

In section "7.7.1 Name Section" there are two typos in the formal notation of the "field name subsection" and "tag name subsection". The subscript of `namesubsection` should be equal to the subsection id, so 10 and 11 respectively.

I suppose that it is enough to put the subscripts in curly braces, but I couldn't manage to replicate the steps to build the PDF, so I cannot check that this solution works. More precisely, what I suggest is to change:
- https://github.com/WebAssembly/spec/blob/cb970072b061dd1731b103a3896fd0c854b04ea5/document/core/appendix/custom.rst?plain=1#L181
  to
```
  \Bnamesubsection_{10}(\Bindirectnamemap) \\
```
- https://github.com/WebAssembly/spec/blob/cb970072b061dd1731b103a3896fd0c854b04ea5/document/core/appendix/custom.rst?plain=1#L197
  to
```
  \Bnamesubsection_{11}(\Bindirectnamemap) \\
```

If this is correct, I can submit a pull request.
