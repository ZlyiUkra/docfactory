# WebAssembly spec issue #2076: Incorrect tag comparison in throw_ref semantics
# джерело: https://github.com/WebAssembly/spec/issues/2076
# отримано: 2026-09-30

Issue #2076, opened by tlively on 2026-02-09, closed (completed) on 2026-02-10.

The semantics for `throw_ref` include the comparison of the thrown exception's tag address with a tag address from the configuration: `z.exns[a].tag = z.tags[x]`

However, if you click on `tags` in `z.tags[x]`, it just links to https://webassembly.github.io/spec/core/exec/runtime.html#syntax-state, which is here: `state ::= store; frame`

From there you still want to find `tags`. `frame` does not have a field called `tags`, so you look in the definition of store: `store :: = { tags taginst* ... }`

But `z.exns[a].tag` is a `tagaddr`, so it looks like we're comparing a `taginst` to a `tagaddr` here, which makes no sense.

We should have instead compared `z.exns[a].tag = z.module.tags[x]`, where `z.module` comes from the `frame`.
