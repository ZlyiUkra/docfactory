# WebAssembly spec issue #2080: Tests don't check that backwards branches implicitly trim the stack
# джерело: https://github.com/WebAssembly/spec/issues/2080
# отримано: 2026-09-30

Issue #2080, opened by Sainan on 2026-02-12, closed (completed) on 2026-02-13.

Kinda self-reporting here that I have a broken implementation, but it seems loop.wast, br.wast, br_if.wast, & labels.wast pass regardless of this:
```wat
(module
  (func (export "test") (param) (result i32)
    (local $i i32)
    i32.const 1
    (loop $loop (param) (result)
      (local.set $i (i32.add (local.get $i) (i32.const 1)))
      i32.const 2
      (br_if $loop (i32.lt_s (local.get $i) (i32.const 10)))
      drop
      )
    )
  )
```
The expected return value of this function is `1`, but an incorrect implementation that does not implement the implicit dropping/trimming of the stack would produce `2`.
