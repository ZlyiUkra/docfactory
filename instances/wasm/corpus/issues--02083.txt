# WebAssembly spec issue #2083: Inconsistent Grammar Notation for Splitting Large Productions
# джерело: https://github.com/WebAssembly/spec/issues/2083
# отримано: 2026-09-30

Issue #2083, opened by florianhartung on 2026-02-13, closed (completed) on 2026-02-16.

In the latest Wasm Core Specification, this grammar notation exists in multiple places:

> Large productions may be split into multiple definitions, indicated by ending the first one with explicit ellipses, `sym ::= A1`, and starting continuations with ellipses, `sym ::= ... | A2`.

Here, a `| ...` is missing in the first part of the definition.

For comparison, consider the same notation described in version 2.0:

> Large productions may be split into multiple definitions, indicated by ending the first one with explicit ellipses, `sym ::= A1 | ...`, and starting continuations with ellipses, `sym ::= ... | A2`.

I also noticed that the `| ...` notation is not used anywhere in the specification anymore (for example the first `instr` production used it previously). I'm not sure about whether this was done on purpose, but either way the sentence in the first quote is inconsistent.
