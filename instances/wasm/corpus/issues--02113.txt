# WebAssembly spec issue #2113: `_binary-mut` anchor points to the wrong place
# джерело: https://github.com/WebAssembly/spec/issues/2113
# отримано: 2026-09-30

Issue #2113, opened by Taywee on 2026-03-14, closed (completed) on 2026-03-16.

`_binary-mut` is anchored to the global types section, but it's actually defined in the comptype section. The generated documentation has anchor links that take you to the global types section, where it's not actually defined.
