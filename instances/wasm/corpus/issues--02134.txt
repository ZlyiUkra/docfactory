# WebAssembly spec issue #2134: [spec] Typo in module abbreviation text format
# джерело: https://github.com/WebAssembly/spec/issues/2134
# отримано: 2026-09-30

Issue #2134, opened by alessiofaieta on 2026-04-07, closed (completed) on 2026-04-07.

In the section about the text format of modules, talking about the possible abbreviations (https://webassembly.github.io/spec/core/text/modules.html#id10), it is written:

> In a source file, the toplevel `‘(’ ‘module’ decldots ‘)’` surrounding the module body may be omitted.

I suppose that the string `decldots` is a typo. In the source code, it corresponds to `Tdecldots`, I tried to change it to `Tdecldots_(I)` and it gets substituted with ellipses (`...`).

If this fix is correct, I can submit a pull request.
