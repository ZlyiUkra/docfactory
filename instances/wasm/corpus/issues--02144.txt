# WebAssembly spec issue #2144: Constant expression section says "val" instead of "instr"
# джерело: https://github.com/WebAssembly/spec/issues/2144
# отримано: 2026-09-30

Issue #2144, opened by bvisness on 2026-04-20, closed (completed) on 2026-06-22.

The validation section on constant expressions is structured like so:

```
instr* is constant if:
  - For all instr in instr*:
    - instr is constant.
val is constant if:
  - <list of all the constant instructions>
```

Where did `val` come from? It links to #syntax-val, which is obviously wrong. Unfortunately, since this prose is generated by SpecTec, I have been unable to track down the source of this bug on my own. (Too in the weeds for me to work through right now, unfortunately.)

## Comment by rossberg, 2026-04-20

Yes, that looks like a bug in prose generation. `val` is a subset of `instr`. I guess there is some respective naming heuristics in the prose generator that goes wrong here. @f52985, can you please take a look?
