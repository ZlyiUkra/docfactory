# WebAssembly spec issue #2164: TOC entries in PDFs have extra reference tags in them
# джерело: https://github.com/WebAssembly/spec/issues/2164
# отримано: 2026-09-30

Issue #2164, opened by ezrakilty on 2026-05-12, closed (completed) on 2026-05-12.

The Table of Contents in a PDF has somewhat unreadable entries, because some extra reference tags are included there. Andreas identified this as probably a Sphinx bug, but filing it here for whatever can be done locally.

## Comment by rossberg, 2026-05-12

Yeah, this seems to be a known problem with the hyperref Latex package. Unfortunately, the workaround suggested there (using `\texorpdfstring`) doesn't work for us, since the links are generated from macros embedded in formulas.

So unfortunately, I don't see a practical way to avoid it on our end. The workaround is to limit the bookmarks depth to 3 levels, since such refs only occur on the 4th level. PTAL at #2165.
