# WebAssembly spec issue #2209: some scripts expect an "unknown operator" for negative alignment
# джерело: https://github.com/WebAssembly/spec/issues/2209
# отримано: 2026-09-30

Issue #2209, opened by redianthus on 2026-07-13, closed (completed) on 2026-07-27.

Hi,

I'm currently adding SIMD support in Owi. I'm using the reference test suite, which contains some test cases where a `"unknown operator"` error is expected when a module contains `v128.load align=-1` (a negative alignment). Is it on purpose? Wouldn't it be better to switch to "alignment must be positive" or something similar?

## Comment by rossberg, 2026-07-13

That's just the generic error message produced by the lexer when encountering a character sequence that is not recognised as a token (`align=n` is a single token). It would require a special case in the lexer to produce another message.

## Comment by rossberg, 2026-07-22

The immediates of `v128.const` are arbitrary numbers syntactically, since they can be negative or floats depending on the lane type.

Lane indices OTOH are natural numbers, so a negatives or floats are not expected in their syntax.
