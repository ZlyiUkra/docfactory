# WebAssembly spec issue #2213: [spec] Incorrect loop typing rule in Wasm 1.0
# джерело: https://github.com/WebAssembly/spec/issues/2213
# отримано: 2026-09-30

Issue #2213, opened by lzy0505 on 2026-07-26, closed (completed) on 2026-07-27.

The `Instr_ok/loop` rule of Wasm 1.0 in 6-typing.spectec  is wrong.

The source says:
```
rule Instr_ok/loop:
  C |- LOOP t? instr* : eps -> t?
  -- Instrs_ok: {LABELS (eps)} ++ C |- instr* : eps -> eps
```

But according to the WebAssembly 1.0 specification:
```
C, labels [] ⊢ instr* : [] → [t?]
---------------------------------
C ⊢ loop [t?] instr* : [] → [t?]
```
the premise should require:
`instr* : eps -> t?`
not:
`instr* : eps -> eps`
