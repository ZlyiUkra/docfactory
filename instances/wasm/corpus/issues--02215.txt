# WebAssembly spec issue #2215: [spec] Incorrect `call_indirect` typing rule in Wasm 1.0
# джерело: https://github.com/WebAssembly/spec/issues/2215
# отримано: 2026-09-30

Issue #2215, opened by lzy0505 on 2026-07-27, closed (completed) on 2026-07-27.

The `Instr_ok/call_indirect` rule of Wasm 1.0 in 6-typing.spectec  is wrong.

The source says:
```
rule Instr_ok/call_indirect:
  C |- CALL_INDIRECT x : t_1* I32 -> t_2?
  -- if C.TYPES[x] = t_1* -> t_2?
```

According to the WebAssembly 1.0 specification:
```
C.tables[0] = limits funcref    C.types[x] = [t1*] -> [t2*]
----------------------------------------------------------------
C |- call_indirect x : [t1* i32] -> [t2*]
```
the premise is missing `-- if C.TABLES[0] = lim`
