# WebAssembly spec issue #2222: [spectec] Wasm 1.0: Missing bounds check on successful store rules
# джерело: https://github.com/WebAssembly/spec/issues/2222
# отримано: 2026-09-30

Issue #2222, opened by lzy0505 on 2026-08-02, closed (completed) on 2026-09-01.

The WebAssembly Specification Release 1.0 PDF Section 4.4.4:

```
ea = i + memarg.offset
ea + |t|/8 ≤ |S.mems[F.module.memaddrs[0]].data|    // ordinary store

ea = i + memarg.offset
ea + N/8 ≤ |S.mems[F.module.memaddrs[0]].data|      // packed store
```
The current spectec rules `Step/store-num-val` and `Step/store-pack-val` omit those premises.

## Comment by rossberg, 2026-09-01

This in fact was an intentional simplification. The application of $with_mem is undefined when out-of-bounds, so the rule already isn't applicable in that case, and the extra condition technically redundant.

## Comment by lzy0505, 2026-09-01

Right. Thanks for the clarification!
