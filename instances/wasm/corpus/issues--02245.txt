# WebAssembly spec issue #2245: [spectec] Wasm 1.0: `$instantiate` missing premises
# джерело: https://github.com/WebAssembly/spec/issues/2245
# отримано: 2026-09-30

Issue #2245, opened by lzy0505 on 2026-09-04, open.

The Wasm 1.0 Specification PDF section 4.5.4 has the following three checks for `$instantiate`:
```
⊢ module : externtype_imⁿ → externtype_ex*
(S ⊢ externval : externtype)ⁿ
(⊢ externtype ≤ externtype_im)ⁿ
```

They are missing in Wasm 1.0 SpecTec.
