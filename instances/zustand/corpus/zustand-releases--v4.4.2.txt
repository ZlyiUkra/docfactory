Tag v4.4.2, published 2023-10-02.

This adds `useShallow` hook to cover some use cases that are deprecated with v4.4.0 change. Check out the guide.

## Migration Guide

#1991 requires something like below if you are using the `devtools` middleware _and_ TypeScript.
```diff
  import { devtools } from 'zustand/middleware'
+ import type {} from '@redux-devtools/extension'
```
